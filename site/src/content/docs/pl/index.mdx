## Ze Strapi w trzech poleceniach

Wyeksportuj projekt Strapi, zaimportuj go do nowego projektu Verdin i uruchom. Typy
zawartości, wpisy ze szkicami i wersjami językowymi, relacje i biblioteka multimediów
przechodzą w całości; API treści zachowuje swój kształt, więc frontend dalej działa.

```sh title="Terminal"
npx strapi export --no-encrypt -f my-export        # w projekcie Strapi
verdin new my-site && cd my-site && verdin import strapi ../my-export.tar.gz
verdin dev                                         # http://localhost:1337/admin
```

## Czytaj treść tak, jak już to robisz

<Tabs syncKey="api">
  <TabItem label="REST">
    ```sh
    curl 'localhost:1337/api/articles?filters[title][$containsi]=rust&populate=category&sort=publishedAt:desc'
    ```
  </TabItem>
  <TabItem label="GraphQL">
    ```graphql
    query {
      articles(filters: { title: { containsi: "rust" } }, sort: ["publishedAt:desc"]) {
        documentId
        title
        category { name }
      }
    }
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```ts
    import { createClient } from '@verdin/client';
    import type { VerdinSchema } from './verdin-types'; // verdin types -o src/verdin-types.ts

    const verdin = createClient<VerdinSchema>({ url: 'http://localhost:1337' });
    const { data } = await verdin.collection('articles').find({
      filters: { title: { $containsi: 'rust' } },
      populate: { category: true },
      sort: ['publishedAt:desc'],
    });
    ```
  </TabItem>
</Tabs>

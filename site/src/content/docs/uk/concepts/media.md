Медіатека містить зображення, відео, аудіо та інші файли, які використовує ваш вміст. На цій
сторінці пояснено, як файли зберігаються, описуються й пов'язуються з документами. Про видачу
зображень зі зміненим розміром на вашому сайті див. [Зображення](/uk/guides/frontend/images/).

## Файли

Кожне завантаження — це запис файлу у форматі Strapi, тож фронтенди, написані для Strapi,
читають його без змін (`formats` скорочено):

```json
{
  "id": 5,
  "documentId": "v3k…",
  "name": "harbour.jpg",
  "alternativeText": "Boats in the harbour at dawn",
  "caption": null,
  "width": 2400,
  "height": 1600,
  "focalPoint": { "x": 0.4, "y": 0.6 },
  "formats": {
    "thumbnail": { "url": "/uploads/harbour_thumbnail_4f1c.jpg", "width": 234, "height": 156 },
    "large": { "url": "/uploads/harbour_large_4f1c.jpg", "width": 1000, "height": 667 }
  },
  "hash": "harbour_4f1c",
  "ext": ".jpg",
  "mime": "image/jpeg",
  "size": 812.4,
  "url": "/uploads/harbour_4f1c.jpg",
  "previewUrl": null,
  "provider": "local",
  "provider_metadata": null,
  "createdAt": "2026-09-25T09:00:00.000Z",
  "updatedAt": "2026-09-25T09:00:00.000Z",
  "publishedAt": "2026-09-25T09:00:00.000Z"
}
```

- `size` вказано в кілобайтах, як у Strapi.
- MIME-тип визначається за байтами файлу, а не за тим, що заявляє клієнт.
- `focalPoint` позначає частину зображення, яка має лишатися в кадрі під час обрізання.

Файли не мають чернеток: завантаження доступне одразу після збереження.

## Медіатека

В адмін-панелі **Медіатека** показує файли з пошуком, фільтрами за типом і папками.
Адміністратори завантажують файли, імпортують їх за URL, редагують назву, альтернативний
текст, підпис і фокусну точку, замінюють вміст файлу зі збереженням його id і бачать, **де він
використовується**: медіаполя, медіа всередині компонентів, блоки rich text і Markdown, що
містить його URL.

**Папки** впорядковують медіатеку для редакторів. Об'єкти файлів у відповідях API їх не
показують, але завантаження через API вмісту може вказати id папки у своєму `fileInfo`.
Видалення папки видаляє файли в ній.

Доступ адміністраторів контролюють дозволи `media.read`, `media.create`, `media.update` і
`media.delete`. Вбудована роль Author може редагувати й видаляти лише файли, які сама
завантажила. Див. [Дозволи](/uk/concepts/permissions/).

## Медіаполя

Тип вмісту пов'язує файли через атрибут `media`:

```json
"cover": { "type": "media", "allowedTypes": ["images"] },
"gallery": { "type": "media", "multiple": true, "allowedTypes": ["images", "videos"] }
```

| Параметр | Типово | Опис |
| --- | --- | --- |
| `multiple` | `false` | Містити список файлів замість одного. |
| `allowedTypes` | будь-який файл | Будь-що з `images`, `videos`, `audios` і `files` (усе інше); перевіряється під час кожного запису за збереженим MIME-типом. |

Медіаполя поводяться як зв'язки: кожна версія документа має власні посилання, публікація
копіює їх, а `required` перевіряється під час публікації. Вони зберігаються в окремій таблиці
зв'язків для кожного поля. Усередині [компонентів](/uk/concepts/components-and-dynamic-zones/)
id файлів зберігаються в JSON компонента.

Під час запису надсилайте id файлів: `5`, `{ "id": 5 }`, `[5, 6]` або `null`, щоб очистити
поле. Під час читання медіаполя повертаються, лише коли їх заповнено (`populate=cover`), як
об'єкти файлів. Видалення файлу прибирає його з усіх документів, що його використовували.

## Формати зображень

Коли завантажується растрове зображення, Verdin генерує формати Strapi у власному форматі
зображення, з урахуванням його EXIF-орієнтації:

| Формат | Розмір |
| --- | --- |
| `thumbnail` | Вписується в 245 × 156 |
| `large` | 1000 px завширшки |
| `medium` | 750 px завширшки |
| `small` | 500 px завширшки |

Формат пропускається, якщо оригінал не більший за нього. `[upload].breakpoints` змінює ширини
й назви, а `responsive_formats = false` вимикає їх. `max_original_size` зменшує великі
оригінали під час завантаження, що також видаляє їхні метадані (EXIF, GPS).
`max_image_megapixels` (типово 100) відхиляє зображення, декодування яких забрало б забагато
пам'яті. З локальним провайдером `/uploads` також може змінювати розмір і конвертувати
зображення на запит; див. [Зображення](/uk/guides/frontend/images/).

## Провайдери сховища

Файли зберігає провайдер, заданий у `[upload].provider`:

| Провайдер | Де зберігає файли | Звідки віддає |
| --- | --- | --- |
| `local` (типово) | У `public/uploads` (параметр `dir`) відносно проєкту | За адресою `/uploads` на сервері Verdin |
| `s3` | У будь-якому S3-сумісному бакеті: AWS S3, Cloudflare R2, Backblaze B2, MinIO, RustFS… | З `public_url` бакета або CDN |

```toml title="verdin.toml"
[upload]
provider = { name = "s3", bucket = "media", region = "auto",
             endpoint = "https://<account>.r2.cloudflarestorage.com",
             public_url = "https://media.example.com" }
```

Облікові дані S3 беруться зі стандартних змінних середовища `AWS_*`, ніколи з `verdin.toml`.
Усі параметри наведено в [довіднику конфігурації](/uk/reference/configuration/).

Збережені імена мають вигляд `{slug}_{random}{ext}` і ніколи не змінюються, тож URL можна
кешувати назавжди. З кількома екземплярами Verdin використовуйте S3: локальні файли існують
лише на тому екземплярі, який їх отримав.

## Безпека

- Завантаження записуються потоком у тимчасові файли, ніколи не тримаються в пам'яті й
  обмежені `[upload].max_file_size` (типово 200 МБ), щонайбільше 20 файлів на запит.
- Файли з `/uploads` віддаються із заголовками `Content-Security-Policy: sandbox` і
  `X-Content-Type-Options: nosniff`. Усе, що не є зображенням, відео, аудіо, PDF чи простим
  текстом, надсилається як завантаження, тож завантажений HTML- чи SVG-файл не може запускати
  скрипти на вашому домені. На S3 об'єкти таких типів теж зберігаються як завантаження.

## Медіа через API вмісту

API вмісту має маршрути завантаження Strapi, що перевіряються за дозволами для **Медіатека**
(`plugin::upload`):

| Маршрут | Дозвіл |
| --- | --- |
| `POST /api/upload` (multipart `files`, необов'язковий `fileInfo`) | `create` |
| `POST /api/upload?id={id}` (новий `fileInfo`, за бажання новий файл) | `update` |
| `GET /api/upload/files` | `find` |
| `GET /api/upload/files/{id}` | `findOne` |
| `DELETE /api/upload/files/{id}` | `delete` |

Як і в Strapi, вони повертають звичайні об'єкти й масиви файлів без обгортки `data`. Див.
[REST API](/uk/api/rest/#медіатека). Зміни надсилають [події вебхуків](/uk/api/webhooks/) і
[реального часу](/uk/api/realtime/) `media.create`, `media.update` і `media.delete`.

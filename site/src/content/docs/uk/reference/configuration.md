Конфігурація складається з шарів: **вбудовані типові значення ← `verdin.toml` ← середовище**.
Файл необов'язковий; кожен ключ має типове значення. Невідомі ключі відхиляються, тож
друкарська помилка ламає запуск, а не ігнорується.

- Перевизначайте будь-який ключ через `VERDIN_<SECTION>__<KEY>` (два підкреслення), наприклад
  `VERDIN_SERVER__PORT=8080` або `VERDIN_ADMIN__SECURE_COOKIES=false`. Вкладені таблиці
  потребують ще одного `__`: `VERDIN_ADMIN__BRANDING__TITLE=ACME`. Невідомі ключі тут теж
  відхиляються, тож будь-яка змінна, що починається з `VERDIN_` і містить `__`, має називати
  справжній ключ.
- `VERDIN_DATABASE_URL` — скорочення для `database.url`.
- Файл — це `verdin.toml` у робочому каталозі або шлях, заданий через `-c, --config` чи
  `VERDIN_CONFIG`. Відносні шляхи в ньому (схема, плагіни, завантаження, файли SQLite)
  розв'язуються відносно каталогу файлу.
- Файл `.env` поруч із конфігурацією завантажується першим; змінні, уже задані в середовищі,
  мають пріоритет.

Секрети ніколи не читаються з `verdin.toml`; див. [Змінні середовища](#змінні-середовища).

## `[server]`

| Ключ | Типово | Опис |
| --- | --- | --- |
| `host` | `"0.0.0.0"` | Адреса, яку слухати. |
| `port` | `1337` | Порт, який слухати. |
| `public_url` | не задано | Адреса, за якою браузери дістаються сервера, напр. `"https://cms.example.com"`. Використовується для посилань у листах і callbacks SSO; типово `http://localhost:{port}`. |
| `body_limit` | `"1mb"` | Найбільше тіло звичайних запитів до API (завантаження мають власний ліміт). Кількість байтів або рядок із `b`, `kb`, `mb` чи `gb`. |
| `request_timeout_secs` | `30` | Обмеження часу звичайних запитів до API. |
| `sync_interval_secs` | `10` | Як часто підхоплювати налаштування, змінені іншими екземплярами (функції, перемикачі плагінів, локалі, процеси перевірки); `0` вимикає (один екземпляр). |
| `trusted_proxies` | `[]` | Зворотні проксі (IP або діапазони CIDR, напр. `["10.0.0.0/8"]`), чий `X-Forwarded-For` називає клієнта. Обмеження частоти й журнали аудиту використовують цю адресу; без цього всі клієнти за проксі мають одну адресу. |

### Локальний провайдер

Файли в `dir` (відносно проєкту), які Verdin віддає на `/uploads`.

```toml

```

### `[upload.transforms]`

Трансформації зображень локальних файлів: `/uploads/<file>?preset=thumb` або
`?w=&h=&fit=&format=&q=` з підписом. Рендери кешуються на диску й скидаються, коли файл
змінюється (включно з його фокусною точкою). Обрізання cover тримають фокусну точку файлу в
кадрі; зображення ніколи не збільшуються. Трансформувати можна JPEG, PNG, WebP, TIFF і BMP (не
GIF, які можуть бути анімованими).

| Ключ | Типово | Опис |
| --- | --- | --- |
| `enabled` | `true` | Віддавати трансформації. |
| `presets` | `{}` | Іменовані трансформації, завжди дозволені: `{ w, h, fit, format, q }`. |
| `allow_arbitrary` | `false` | Приймати будь-які параметри без підпису. Кожен окремий URL рендериться й кешується, тож лише для довірених мереж. |
| `max_size` | `4096` | Найбільші `w` або `h` у пікселях. |
| `cache_dir` | `".cache/transforms"` | Де зберігаються рендери (відносно проєкту; можна безпечно видаляти). |

Параметри: `w`, `h` (пікселі), `fit` (`cover`, типово, обрізає до рамки; `inside` вписує в неї;
`fill` розтягує), `format` (`jpeg`, `png`, `webp`; вивід WebP без втрат) і `q` (якість JPEG,
1–100, типово 80).

```toml
[upload.transforms.presets]
thumb = { w = 300, h = 300 }
hero = { w = 1600, h = 600, format = "webp" }
```

**Підписані URL.** Коли задано `VERDIN_IMAGE_SECRET`, `s` — це шістнадцятковий HMAC-SHA256 від
`<file>?<canonical query>`, де канонічний запит перелічує нетипові параметри, відсортовані за
назвою (`fit`, `format`, `h`, `q`, `w`; `fit=cover` пропускається):

```js
import { createHmac } from 'node:crypto';
const s = createHmac('sha256', process.env.VERDIN_IMAGE_SECRET)
  .update('photo_1a2b.jpg?format=webp&w=800')
  .digest('hex');
const url = `/uploads/photo_1a2b.jpg?format=webp&w=800&s=${s}`;
```

### Провайдер S3

Будь-який S3-сумісний сервіс (AWS, Cloudflare R2, MinIO, Backblaze B2…). Облікові дані
беруться зі стандартних змінних середовища `AWS_*` (`AWS_ACCESS_KEY_ID`,
`AWS_SECRET_ACCESS_KEY`).

| Ключ | Типово | Опис |
| --- | --- | --- |
| `bucket` | обов'язковий | Назва бакета. |
| `region` | не задано | Регіон бакета. |
| `endpoint` | не задано | Власний ендпоінт для сервісів не від AWS, напр. `https://<account>.r2.cloudflarestorage.com`. |
| `public_url` | обов'язковий | Публічна базова URL бакета або його CDN; файли посилаються як `{public_url}/{key}`. |
| `prefix` | `""` | Префікс ключів у бакеті. |
| `path_style` | `false` | Запити в стилі path (MinIO і більшість самохостингових сервісів). |

```toml
[upload]
provider = { name = "s3", bucket = "media", region = "auto",
             endpoint = "https://<account>.r2.cloudflarestorage.com",
             public_url = "https://media.example.com" }
```

## `[telemetry]`

Трейси та звіти про помилки, обоє типово вимкнені й використовуються лише `verdin start` і
`verdin dev` (див. [Моніторинг](/uk/deploy/monitoring/#трейси-opentelemetry)).

| Ключ | Типово | Опис |
| --- | --- | --- |
| `enabled` | `false` | Експортувати трейси OpenTelemetry HTTP-запитів і їхніх запитів до бази даних через OTLP/HTTP (protobuf). `OTEL_SDK_DISABLED=true` вимикає це. |
| `endpoint` | не задано (`http://localhost:4318`) | Базовий URL колектора; додається `/v1/traces`. `OTEL_EXPORTER_OTLP_ENDPOINT` (базовий URL) і `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT` (повний URL) мають пріоритет. |
| `service_name` | `"verdin"` | `service.name` трейсів. `OTEL_SERVICE_NAME` має пріоритет. |
| `sample_ratio` | `1.0` | Частка збережених трейсів, від `0.0` до `1.0`. Запит із заголовком `traceparent` іде за рішенням викликача. |
| `sentry_dsn` | не задано | Звітувати про паніки й відповіді 5xx до Sentry. `SENTRY_DSN` має пріоритет. |
| `sentry_environment` | не задано | Середовище Sentry. `SENTRY_ENVIRONMENT` має пріоритет; якщо не задано — `production` у `verdin start` і `development` у `verdin dev`. |

## `[ai]`

Дії ШІ в адмінці (коли функцію **Дії ШІ** ввімкнено в «Налаштування → Функції»): переклад запису
іншою локаллю, альтернативний текст для зображень, підсумок тексту, пропозиції SEO-метаданих.
Вони повертають пропозиції; без редактора нічого не зберігається. Ключ читається з
`VERDIN_AI_KEY` (локальним серверам він не потрібен).

| Ключ | Типово | Опис |
| --- | --- | --- |
| `provider` | `"none"` | `anthropic`, `openai` або `openai-compatible` (Ollama, LM Studio, vLLM…). |
| `model` | `claude-sonnet-5` для `anthropic` | Модель; обов'язкова для інших провайдерів. |
| `base_url` | адреса провайдера | Інший ендпоінт, напр. `http://localhost:11434/v1`. |
| `max_tokens` | `2048` | Найдовша відповідь. |

```toml
[ai]
provider = "anthropic"
```

Кожен адміністратор може робити 30 запитів до ШІ на хвилину. Вміст і зображення надсилаються
провайдерові: вибирайте того, якого дозволяє ваша організація.

## `[cdn]`

Очищає кеші CDN, коли вміст публічно змінюється. Відповіді API вмісту позначаються тегами `vd`
і `vd-<singularName>` (заголовки `Cache-Tag` і `Surrogate-Key`).

| Ключ | Типово | Опис |
| --- | --- | --- |
| `provider` | `"none"` | `cloudflare`, `fastly` або `webhook`. |
| `zone_id` | не задано | Зона Cloudflare (очищення за тегом). |
| `service_id` | не задано | Сервіс Fastly (очищення за surrogate key). |
| `url` | не задано | `webhook`: отримує `POST { "tags": [...] }`. |
| `debounce_ms` | `1000` | Скільки збирати зміни перед очищенням. |

API-токен читається з `VERDIN_CDN_TOKEN` (надсилається вебхукам як bearer-токен).

## `[cluster]`

Спільна шина подій для кількох екземплярів одного проєкту (див.
[Кілька екземплярів](/uk/deploy/scaling/#спільна-шина-подій)).

| Ключ | Типово | Опис |
| --- | --- | --- |
| `bus` | `"none"` | `none`: події реального часу, присутність, інвалідація кешу й оновлення пошуку залишаються в кожному екземплярі. `database`: вони доходять до кожного екземпляра через базу даних проєкту (`LISTEN/NOTIFY` у PostgreSQL, опитування в MySQL, MariaDB і SQLite). |
| `poll_interval_ms` | `1000` | Як часто MySQL, MariaDB і SQLite читають події інших екземплярів. PostgreSQL будить `NOTIFY`, і він використовує цей темп лише тоді, коли не може слухати. |
| `instance_id` | не задано (випадковий при кожному запуску) | Назва цього екземпляра на шині й у журналах. |

```toml
[cluster]
bus = "database"
```

Задайте це на кожному екземплярі або через `VERDIN_CLUSTER__BUS=database`.

## Змінні середовища

Окрім перевизначень `VERDIN_<SECTION>__<KEY>`, Verdin читає такі змінні:

| Змінна | Опис |
| --- | --- |
| `VERDIN_CONFIG` | Шлях до файлу конфігурації (те саме, що `--config`). |
| `VERDIN_DATABASE_URL` | Скорочення для `database.url`. |
| `VERDIN_ADMIN_JWT_SECRET` | Підписує токени сесій адміністраторів. Обов'язкова, щонайменше 32 байти; згенеруйте через `verdin secrets`. |
| `VERDIN_TOKEN_PEPPER` | Хеш із ключем для збережених токенів. Обов'язкова, щонайменше 32 байти; згенеруйте через `verdin secrets`. |
| `VERDIN_ADMIN_PASSWORD` | Пароль для `verdin admin create` і `verdin admin reset-password` (інакше читається зі stdin); див. [довідник командного рядка](/uk/reference/cli/). |
| `VERDIN_EMAIL_SMTP_PASSWORD` | Пароль SMTP. |
| `VERDIN_EMAIL_API_KEY` | API-ключ провайдерів Resend і Postmark. |
| `VERDIN_SSO_<ID>_SECRET` | Секрет клієнта провайдера SSO; `<ID>` — id провайдера великими літерами з `-`, заміненим на `_` (див. [Єдиний вхід](/uk/guides/auth/sso/)). |
| `VERDIN_OAUTH_<PROVIDER>_SECRET` | Секрет клієнта провайдера OAuth для кінцевих користувачів, названий так само, як для SSO (див. [Кінцеві користувачі](/uk/guides/auth/end-users/)). |
| `VERDIN_AI_KEY` | API-ключ провайдера `[ai]`. |
| `VERDIN_CDN_TOKEN` | API-токен провайдера `[cdn]`. |
| `VERDIN_IMAGE_SECRET` | Підписує URL трансформацій зображень (див. [`[upload.transforms]`](#uploadtransforms)). |
| `VERDIN_METRICS_TOKEN` | Bearer-токен для збирання `/_metrics`, коли `[metrics].enabled`; має пріоритет над `[metrics].token`. |
| `OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT` | Колектор для трейсів [`[telemetry]`](#telemetry); мають пріоритет над `[telemetry].endpoint`. Інші стандартні змінні `OTEL_EXPORTER_OTLP_*` (заголовки, тайм-аут, стиснення) теж застосовуються. |
| `OTEL_SERVICE_NAME`, `OTEL_RESOURCE_ATTRIBUTES` | Ресурс експортованих трейсів; `OTEL_SERVICE_NAME` має пріоритет над `[telemetry].service_name`. |
| `OTEL_SDK_DISABLED` | `true` вимикає експорт трейсів, навіть коли `[telemetry].enabled`. |
| `SENTRY_DSN`, `SENTRY_ENVIRONMENT` | Звіти про помилки Sentry; мають пріоритет над `[telemetry].sentry_dsn` і `sentry_environment`. |
| `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` | Облікові дані провайдера завантажень S3. |
| `RUST_LOG` | Фільтр журналу; має пріоритет над `[log].level`. |

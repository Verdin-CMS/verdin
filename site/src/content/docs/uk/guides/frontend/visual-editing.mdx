Візуальне редагування перетворює сторінку попереднього перегляду на мапу адмін-панелі:
редактор наводить курсор на заголовок, клацає **Edit**, і запис відкривається з фокусом на
цьому полі. Воно спирається на [Попередній перегляд](/uk/guides/content/preview/): спершу
налаштуйте URL попереднього перегляду, потім додайте на сторінку попереднього перегляду дві
складові, описані нижче.

Verdin ховає в кожному тексті, який повертає, невелику невидиму карту джерел (техніка, відома як
*stega*), а скрипт-оверлей знаходить ці тексти на сторінці. У ваших компонентах нічого не
змінюється: позначений текст відображається, як будь-який інший.

## Налаштування

<Steps>

1. Увімкніть **Попередній перегляд** у **Налаштування → Функції**, виберіть
   **Налаштувати URL попереднього перегляду** і задайте кожному типу вмісту URL сторінки, що
   його показує. Розділ **Візуальне редагування** того самого діалогу показує тег скрипту й
   заголовок для вашого сервера. Див. [Попередній перегляд](/uk/guides/content/preview/).

2. На сторінці попереднього перегляду отримуйте вміст із токеном і заголовком
   `x-verdin-stega: true`. Токен — це токен попереднього перегляду з URL попереднього перегляду
   (`?preview=…`, що надсилається назад як `x-verdin-preview`) або API-токен:

   ```js
   const response = await fetch(`${CMS}/api/articles/${documentId}?status=draft&populate=*`, {
     headers: {
       'x-verdin-preview': previewToken, // or Authorization: Bearer <API token>
       'x-verdin-stega': 'true',
     },
   });
   ```

3. Завантажте оверлей на тій самій сторінці:

   ```html
   <script src="https://cms.example.com/admin/api/visual-editing.js" defer></script>
   ```

   Шлях відповідає [`[admin].path`](/uk/reference/configuration/): `{path}/api/visual-editing.js`.

</Steps>

З [типізованим клієнтом](/uk/guides/frontend/typed-client/) передайте обидва заголовки в
`headers`:

```ts
const preview = createClient<VerdinSchema>({
  url: CMS,
  headers: { 'x-verdin-preview': previewToken, 'x-verdin-stega': 'true' },
});
const { data } = await preview.collection('articles').findOne(documentId, {
  status: 'draft',
  populate: '*',
});
```

Карти джерел додаються лише до REST-відповідей, не до GraphQL: читайте вміст попереднього
перегляду через REST API.

Наведіть курсор на позначений текст на сторінці: він отримує зелений контур і кнопку **Edit**.
У попередньому перегляді поруч в адмінці (**Відкрити попередній перегляд** → **Поруч**) кнопка
просить адмінку відкрити поле просто там. Коли сторінку відкрито окремо, кнопка відкриває запис
у новій вкладці.

<Aside type="note">
Карти джерел додаються лише до запитів `GET`, що надсилають `x-verdin-stega: true` **і** токен
(`Authorization` або `x-verdin-preview`). Публічний трафік і все, що кешує ваш CDN, їх ніколи не
містять, а позначені відповіді надсилаються з `Cache-Control: private, no-store`.
</Aside>

## Що позначається

| Позначається | Не позначається |
| --- | --- |
| Атрибути `string`, `text` і `richtext` | `uid`, `email`, `password`, `enumeration` |
| Перший текст кожного блоку атрибута `blocks` | Числа, булеві значення, дати, JSON |
| Те саме всередині компонентів і динамічних зон (`seo.metaTitle`, `blocks.2.title`) | Порожні рядки |
| Заповнені зв'язки, що вказують на пов'язаний запис | Медіаполя |

Оверлей також читає позначки в атрибутах `alt` і `title`, тож позначений текст, який ви
помістили в один із них (скажімо, поле підпису, використане як `alt`), лишається клікабельним.

## Прибирайте позначки там, де текст — це дані

Позначки — це невидимі символи, додані в кінець тексту. Там, де ви використовуєте значення як
дані, а не показуєте його (ключ, URL, порівняння, перевірка довжини `<title>`), спершу приберіть
їх:

```js
const clean = (text) => text.replace(/⁤[​-‍⁠]*⁣/g, '');

if (clean(article.category.name) === 'News') { /* … */ }
```

Поля, що за своєю природою є даними, як-от slug `uid` і enumeration, ніколи не позначаються,
тож маршрутизація за `slug` працює як є.

## Як кодується позначка

Для інструментів, що самі читають позначки: позначка — це U+2064, потім кожен байт UTF-8 від

```json
{"origin":"verdin","href":"https://cms.example.com/admin/content/api::article/<documentId>?locale=en&field=seo.metaTitle"}
```

у вигляді чотирьох цифр за основою 4 (старша перша), записаних символами U+200B, U+200C, U+200D
і U+2060, потім U+2063. URL адмінки береться з [`[server].public_url`](/uk/reference/configuration/)
і `[admin].path`. Оверлей надсилає `{ type: 'verdin:edit', href }` батьківському вікну через
`postMessage`; адмінка реагує на це, лише коли повідомлення надходить з origin URL попереднього
перегляду.

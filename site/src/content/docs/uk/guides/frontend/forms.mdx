Функція **Форми** обробляє форми вашого сайту (контакти, підписка на розсилку, реєстрація на
подію) без стороннього сервісу форм. Редактори визначають поля в адмін-панелі, ваш сайт
показує їх і надсилає дані у Verdin, а надіслані дані валідуються, зберігаються, пересилаються
поштою й експортуються в CSV.

## Увімкнення

У **Налаштування → Функції** увімкніть **Форми**, потім виберіть **Керувати формами** (або
перейдіть до **Налаштування → Форми**). Керування формами й читання надісланих даних потребує
дозволу **Керування SEO, перенаправленнями, меню та формами** (`site.manage`), який має
вбудована роль Editor. Див. [Дозволи](/uk/reference/permissions/).

Для листів-сповіщень налаштуйте провайдера в [`[email]`](/uk/reference/configuration/); з
типовим провайдером `log` листи лише записуються в журнал сервера.

## Створіть форму

<Steps>

1. У **Налаштування → Форми** виберіть **Нова форма**.
2. Дайте їй назву (наприклад, **Контакти**) і **Слаг** (`contact`). Слаг є частиною URL форми.
3. На вкладці **Поля** виберіть **Додати поле** для кожного поля, з **Мітка**, **Назва**,
   **Тип**, **Обов’язкове**, **Заповнювач** і **Максимальна довжина**.
4. На вкладці **Налаштування** задайте:
   - **Сповіщати**: адреси ел. пошти, що отримують кожне надсилання.
   - **Повідомлення про успіх**: повертається вашому сайту після надсилання.
   - **Пастка для спаму**: типово ввімкнено (див. [Спам](#спам)).
5. Збережіть. Вкладка **Інтеграція** показує публічний ендпоінт і приклад для копіювання.

</Steps>

| Тип | Мітка в адмінці | Приймає |
| --- | --- | --- |
| `text` | **Текст** | Будь-який текст. |
| `email` | **Ел. пошта** | Адресу ел. пошти. |
| `textarea` | **Довгий текст** | Будь-який текст. |
| `number` | **Число** | Число, зберігається як число. |
| `select` | **Вибір** | Один із його **Варіанти** (по одному на рядок). |
| `checkbox` | **Прапорець** | `true`, `on`, `1` або `yes` — позначено; усе інше — ні. Обов'язковий прапорець має бути позначений. |
| `date` | **Дата** | Будь-який текст (використовуйте `<input type="date">`). |
| `url` | **URL** | URL. |
| `tel` | **Телефон** | Будь-який текст. |

Назви полів починаються з літери, далі йдуть літери, цифри чи `_`, і вони унікальні в межах
форми. Форма має від 1 до 50 полів. Значення мають щонайбільше **Максимальна довжина** символів
(типово 5 000, щонайбільше 20 000).

## Показ форми

`GET /api/_forms/{slug}` повертає визначення, тож ваш сайт може показати поля, які вибрали
редактори:

```json
{
  "data": {
    "slug": "contact",
    "name": "Contact",
    "fields": [
      { "name": "email", "label": "Email", "type": "email", "required": true },
      { "name": "message", "label": "Message", "type": "textarea", "required": true, "maxLength": 2000 },
      { "name": "topic", "label": "Topic", "type": "select", "options": ["Sales", "Support"] }
    ],
    "honeypot": "_gotcha"
  }
}
```

`honeypot` дорівнює `null`, коли пастку для спаму вимкнено. Визначення кешується на хвилину
(`Cache-Control: public, max-age=60`).

## Надсилання

`POST /api/_forms/{slug}` приймає значення як JSON (поля або `{ "data": { … } }`) чи як звичайне
надсилання форми (`application/x-www-form-urlencoded`). Токен не потрібен.

<Tabs syncKey="form">
<TabItem label="HTML-форма">

```html
<form method="post" action="https://cms.example.com/api/_forms/contact">
  <input name="email" type="email" required />
  <textarea name="message" required maxlength="2000"></textarea>
  <input name="_gotcha" tabindex="-1" autocomplete="off" aria-hidden="true" style="position:absolute;left:-9999px" />
  <button>Send</button>
</form>
```

</TabItem>
<TabItem label="fetch">

```js
const response = await fetch('https://cms.example.com/api/_forms/contact', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ data: { email, message, _gotcha: '' } }),
});
const body = await response.json();
if (response.ok) showThanks(body.data.message);
else showErrors(body.error.details.errors); // [{ path: ['email'], message: 'must be an email address' }]
```

</TabItem>
</Tabs>

| Відповідь | Коли |
| --- | --- |
| `201` з `{ "data": { "message": … } }` | Прийнято. `message` — це **Повідомлення про успіх** або `Thank you!`. |
| `400` `ValidationError` | Значення бракує або воно некоректне. `details.errors` перелічує `{ path, message }` для кожного поля. |
| `404` | Форми з таким slug немає або функцію вимкнено. |
| `413` | Надіслані дані більші за 64 КБ. |
| `429` | Той самий відвідувач надіслав у цю форму понад 10 разів за хвилину. |

Значення обрізаються від пробілів і перевіряються за полями. Невідомі поля відкидаються, тож
відвідувач не може додати дані, яких ви не просили.

Звичайне надсилання HTML-форми отримує JSON-відповідь як сторінку. Для кращого досвіду
надсилайте через `fetch` і показуйте повідомлення самі. Надсилання з браузера на інший origin
потребує origin вашого сайту в [`[api].cors_origins`](/uk/reference/configuration/).

### Спам

Коли **Пастка для спаму** ввімкнено, додайте до форми приховане порожнє поле `_gotcha`. Боти
заповнюють усі поля; надсилання із заповненим `_gotcha` отримує відповідь «прийнято» (`201`) і
відкидається, тож бот нічого не дізнається. Разом з обмеженням частоти це зупиняє більшість
спаму у формах без CAPTCHA.

## Читання надісланих даних

Вкладка **Надіслані дані** форми показує, що надіслали відвідувачі, з часом у стовпці
**Отримано**. Надіслані дані можна видалити, а **Експортувати CSV** завантажує їх усі.

Кожне прийняте надсилання також пересилається на адреси зі **Сповіщати** з посиланням на
надіслані дані в адмінці (побудованим із [`[server].public_url`](/uk/reference/configuration/)).

<Aside type="note">
Verdin зберігає значення кожного надсилання, user agent відвідувача і хеш із ключем його
IP-адреси (а не саму адресу) — цього досить, щоб помітити флуд, не відстежуючи людей.
Видалення форми видаляє її надіслані дані.
</Aside>

## Admin API

Адмін-панель використовує `/admin/api/site/forms` і `/admin/api/site/forms/{id}`, а також
`/admin/api/site/forms/{id}/submissions` і `…/submissions/export` (CSV), з access token
адміністратора й `site.manage`. Див. [Admin API](/uk/api/admin/).

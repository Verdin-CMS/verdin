Функція **Меню** дає редакторам іменовані дерева навігації (шапка, підвал, бічна панель), що
посилаються на сторінки, записи чи інші сайти. Ваш сайт отримує меню за його slug і показує
його; посилання на записи враховують стан публікації та шлях запису.

У Strapi для цього зазвичай потрібен плагін навігації або саморобний тип вмісту для меню; у
Verdin це вбудовано.

## Увімкнення

У **Налаштування → Функції** увімкніть **Меню**, потім виберіть **Керувати меню** (або
перейдіть до **Налаштування → Меню**). Керування меню потребує дозволу **Керування SEO,
перенаправленнями, меню та формами** (`site.manage`), який має вбудована роль Editor. Див.
[Дозволи](/uk/reference/permissions/).

Щоб посилатися на записи за шляхом, налаштуйте також шаблони шляхів у
[SEO та мапа сайту](/uk/guides/frontend/seo-and-sitemap/).

## Створіть меню

<Steps>

1. У **Налаштування → Меню** виберіть **Нове меню**.
2. Дайте йому назву (наприклад, **Основна навігація**) і **Слаг** (`main`): малі літери, цифри
   й дефіси. Сайти отримують меню за його slug.
3. Виберіть **Додати пункт** і заповніть його:
   - **Мітка**: текст посилання, до 255 символів.
   - **Посилається на**: **URL-адреса**, **Запис** або **Нічого (заголовок)**.
   - **URL**: шлях (`/about`), якір (`#team`) або посилання `http(s)`, `mailto:` чи `tel:`.
   - Для запису виберіть **Вибрати запис**: виберіть **Тип вмісту**, якщо можна пов'язати
     кілька, знайдіть записи й виберіть один.
   - **Відкривається в**: **Тій самій вкладці** або **Новій вкладці**.
4. Перетягуйте пункти, щоб упорядкувати й вкласти їх, або скористайтеся їхніми кнопками. З
   клавіатури, на маркері перетягування: Alt+↑ і Alt+↓ переміщують пункт, Alt+→ вкладає його
   під пункт вище, Alt+← виносить назовні.
5. Збережіть.

</Steps>

Меню має щонайбільше 5 рівнів і 500 пунктів.

## Отримання меню

Сайти читають меню з `GET /api/_menus/{slug}` без токена. Додайте `?locale=` для локалізованого
вмісту:

```sh title="Terminal"
curl 'https://cms.example.com/api/_menus/main?locale=fr'
```

```json
{
  "data": {
    "slug": "main",
    "name": "Main navigation",
    "items": [
      { "id": "a1", "label": "Blog", "url": "/blog" },
      {
        "id": "a2",
        "label": "Topics",
        "children": [
          {
            "id": "a3",
            "label": "Rust",
            "entry": { "uid": "api::category", "documentId": "hx2n8r3w…", "path": "/fr/topics/rust" },
            "url": "/fr/topics/rust"
          }
        ]
      },
      { "id": "a4", "label": "Contact", "url": "mailto:hello@example.com", "target": "_blank" }
    ]
  }
}
```

Як розв'язуються посилання на записи:

- Запис, не опублікований у запитаній локалі, прибирається з меню (разом із дочірніми
  пунктами). Меню ніколи не розкривають чернетки.
- `entry.path` береться з шаблону типу в [SEO та мапа сайту](/uk/guides/frontend/seo-and-sitemap/),
  заповненого полями запису й локаллю. Він дорівнює `null`, коли тип не має шаблону або запис
  його не заповнює.
- Коли пункт не має власного `url`, він отримує шлях як `url`, тож більшості сайтів досить
  читати `url`.

Без `locale` записи читаються в типовій локалі. Відповідь надсилається з
`Cache-Control: public, max-age=60`.

## Показ меню

```tsx title="Nav.tsx"
type Item = { label: string; url?: string; target?: '_self' | '_blank'; children?: Item[] };

export async function Nav({ locale }: { locale: string }) {
  const response = await fetch(`${process.env.VERDIN_URL}/api/_menus/main?locale=${locale}`);
  const { data } = await response.json();
  return <ul>{data.items.map((item: Item) => <NavItem key={item.label} item={item} />)}</ul>;
}

function NavItem({ item }: { item: Item }) {
  return (
    <li>
      {item.url ? <a href={item.url} target={item.target}>{item.label}</a> : <span>{item.label}</span>}
      {item.children?.length ? <ul>{item.children.map((child) => <NavItem key={child.label} item={child} />)}</ul> : null}
    </li>
  );
}
```

<Aside type="note">
Після видалення меню `/api/_menus/{slug}` відповідає `404`, як і після вимкнення функції.
Обробіть це на своєму сайті, наприклад не показуючи навігацію.
</Aside>

## Admin API

Адмін-панель використовує `/admin/api/site/menus` (`GET`, `POST`) і
`/admin/api/site/menus/{id}` (`GET`, `PUT`, `DELETE`), з access token адміністратора й
`site.manage`. Див. [Admin API](/uk/api/admin/).

Список кожного типу вмісту в адмінці експортує свої записи в CSV чи JSON і імпортує їх назад
із файлу того самого виду: щоб виправити багато записів в електронній таблиці, завантажити
каталог товарів або скопіювати записи між проєктами. У цьому посібнику описано обидва напрямки
та формат файлу.

Це для записів одного типу вмісту за раз. Щоб перенести цілий проєкт, див.
[`verdin export` і `verdin import verdin`](/uk/reference/cli/). Щоб перейти зі Strapi, див.
[Міграція зі Strapi](/uk/migrate/from-strapi/).

## Перш ніж почати

- Експорт потребує доступу на читання до типу вмісту. Експортуються лише поля, які ваша роль
  може читати.
- Імпорт потребує доступу на створення, на оновлення або обох: рядкам, що створюють записи,
  потрібне створення, рядкам, що їх оновлюють, — оновлення. Публікація імпортованих рядків
  потребує ще й публікації. Див. [Дозволи](/uk/reference/permissions/).

## Експорт записів

<Steps>

1. Відкрийте список типу вмісту й налаштуйте його так, як має виглядати експорт: фільтри,
   пошук, сортування, статус і локаль.
2. Виберіть **Експортувати**, потім **Експортувати як CSV** або **Експортувати як JSON**.

</Steps>

Файл містить записи, які показує список, з його фільтрами, пошуком і сортуванням, з усіх
сторінок, до 50 000 записів. Кожен рядок починається з `documentId`, далі йдуть поля.

## Імпорт записів

<Steps>

1. Відкрийте список типу вмісту й виберіть **Імпортувати**.
2. Виберіть **Файл**: `.csv` із рядком заголовків або `.json` зі списком об'єктів, до 1 МБ.
3. У розділі **Стовпці** виберіть, у яке поле йде кожен стовпець. Стовпці, названі як поле, уже
   зіставлено. Виберіть **Пропустити**, щоб не враховувати стовпець, і
   **ID документа (оновлення)** для стовпця, що називає наявні записи.
4. За бажання ввімкніть **Публікувати імпортовані записи**. Інакше вони зберігаються як
   чернетки.
5. Виберіть **Перевірити**. Verdin перевіряє кожен рядок, включно з обмеженнями й
   посиланнями, нічого не записуючи, і повідомляє, які рядки він створив би, оновив чи
   відхилив.
6. За потреби виправте файл, потім виберіть **Імпортувати**.

</Steps>

Як записуються рядки:

- Рядок із `documentId` оновлює цей запис; інші створюють нові записи.
- Рядки записуються по одному. Рядок, що не вдався, показується в звіті з полем і проблемою та
  пропускається; інші все одно записуються.
- Звіт перелічує до 100 рядків із помилками, а також стовпці, які не збіглися з жодним полем.
- Імпорт приймає щонайбільше 5 000 рядків. Розбивайте більші файли.
- Записи записуються в поточній локалі списку.

<Aside type="caution">
Імпорт проганяє ваші рядки через ту саму валідацію, що й редактор, але скасування немає.
Спершу запустіть **Перевірити** й експортуйте список перед великим оновленням, щоб мати змогу
його відновити. Коли ввімкнено [історію вмісту](/uk/guides/content/content-history/), кожен
оновлений запис зберігає попередню версію.
</Aside>

## Формат файлу

Поля мають ту саму форму, що й формат запису API вмісту:

| Поле | Значення |
| --- | --- |
| Текст, числа, булеві значення, дати | Як в API (`true`/`false`, дати ISO 8601). |
| Зв'язки | `documentId` пов'язаних записів. |
| Медіа | Id файлів із медіатеки. |
| Поліморфні зв'язки | `uid:documentId`, наприклад `api::article:k3v9…`. |
| Компоненти, динамічні зони, blocks і JSON | JSON. |

У CSV списки (кілька зв'язків чи файлів) з'єднуються через `|`.

```csv title="articles.csv"
documentId,title,slug,featured,tags
,Hello world,hello-world,true,t1a2b3|t4c5d6
k3v9x8…,Updated title,updated-title,false,
```

Ті самі рядки в JSON:

```json title="articles.json"
[
  { "title": "Hello world", "slug": "hello-world", "featured": true, "tags": ["t1a2b3", "t4c5d6"] },
  { "documentId": "k3v9x8…", "title": "Updated title", "slug": "updated-title", "featured": false }
]
```

Експорт списку — це завжди коректний файл імпорту для того самого типу вмісту.

## Admin API

- `GET /admin/api/content/{uid}/export?format=csv` (або `json`) приймає параметри запиту
  списку: `filters`, `_q`, `sort`, `status` і `locale`.
- `POST /admin/api/content/{uid}/import?locale=` приймає вміст файлу як рядок:

```json
{
  "format": "csv",
  "data": "title,slug\nHello world,hello-world\n",
  "mapping": { "slug": "slug", "notes": null },
  "dryRun": true,
  "publish": false
}
```

`mapping` зіставляє стовпець із полем; `null` пропускає стовпець, а незіставлені стовпці
зберігають свою назву. Тіло запиту обмежене `[server].body_limit` (типово 1 МБ).

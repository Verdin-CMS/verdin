Дайджест для редакторів — це щоденний лист, який повідомляє кожному адміністратору, скільки
записів кожного типу вмісту змінилося відтоді, як він їх востаннє переглядав. Він вимкнений
для всіх, доки кожен адміністратор не ввімкне його сам. У цьому посібнику описано бік
адмінки, налаштування сервера й роботу з кількома екземплярами.

## Як працює «непереглянуте»

Запис стає для вас непереглянутим, коли хтось інший змінює його через будь-який API. Він знову
стає переглянутим, щойно ви його відкриєте. Ті самі позначки керують значками **Нових** на
бічній панелі (вимкніть їх через **Показувати значки нових елементів**) і віджетом
**Ще не переглянуті** на домашній сторінці.

## Увімкнення дайджесту

<Steps>

1. Відкрийте свій **Профіль** (або меню налаштувань на верхній панелі).
2. У розділі **Налаштування** увімкніть **Щоденний лист про непереглянуті зміни**.

</Steps>

Перемикач задає налаштування `"digest": "daily"` для вашого облікового запису
(`PUT /admin/api/users/me/preferences`). Вимикається так само.

Що ви отримуєте:

- Лист із кількістю непереглянутих записів для кожного типу вмісту, який ви можете читати, і
  посиланням на адмін-панель.
- Нічого в дні, коли нічого нового немає.
- Лише поки ваш обліковий запис активний.

## Налаштування сервера

Дайджест надсилається о `[digest].hour_utc` через `[email]`:

```toml title="verdin.toml"
[email]
provider = "smtp"
from = "Verdin <no-reply@example.com>"

[email.smtp]
host = "smtp.example.com"

[digest]
hour_utc = 7    # 0–23, UTC; 8 by default
```

| Ключ | Типово | Опис |
| --- | --- | --- |
| `[digest].enabled` | `true` | Надсилати дайджест із цього екземпляра. |
| `[digest].hour_utc` | `8` | Година (UTC), о якій надсилається дайджест. |

Посилання в листі використовує `[server].public_url`; задайте його, коли Verdin працює за
проксі. З типовим поштовим провайдером `log` листи лише записуються в журнал сервера. Див.
[довідник конфігурації](/uk/reference/configuration/).

## Кілька екземплярів

Кожен екземпляр з `[digest].enabled = true` намагається надіслати дайджест у задану годину.
Перший, хто забере день у базі даних, надсилає його, а інші пропускають цей день, тож
адміністратори отримують один лист. Щоб завдання виконувалося на відомому екземплярі, задайте
`enabled = false` на інших:

```sh title="Terminal"
VERDIN_DIGEST__ENABLED=false verdin start
```

<Aside type="note">
Дайджест — доповнення Verdin; у Strapi відповідника немає.
</Aside>

Попередній перегляд відкриває чернетку запису на вашому власному сайті ще до публікації.
Редактор будує посилання із шаблону URL для кожного типу вмісту й додає короткочасний токен,
який дає вашому сайту змогу прочитати саме цю чернетку. У цьому посібнику ви налаштуєте
шаблони й бік сайту.

Щоб клацати текст у попередньому перегляді й переходити до його поля, додайте поверх цього
[Візуальне редагування](/uk/guides/frontend/visual-editing/).

## Перш ніж почати

- Увімкніть **Налаштування → Функції → Попередній перегляд**. Типово його вимкнено.
- Зміна налаштувань функції потребує **Керування функціями** (`features.manage`).
- Відкриття попереднього перегляду потребує доступу на читання до запису. Див.
  [Дозволи](/uk/reference/permissions/).

## Налаштуйте URL попереднього перегляду

<Steps>

1. На картці **Попередній перегляд** у **Налаштування → Функції** виберіть
   **Налаштувати URL попереднього перегляду**.
2. У розділі **Шаблони URL** введіть сторінку свого сайту, що показує чернетку кожного типу
   вмісту. Залиште тип порожнім, щоб він не мав попереднього перегляду.
3. За бажання змініть **Термін дії посилання (хвилини)**: типово 60, щонайбільше 10080 (7 днів).
4. Збережіть.

</Steps>

Шаблон — це URL `http` або `https` із заповнювачами у фігурних дужках:

| Заповнювач | Чим заповнюється |
| --- | --- |
| `{slug}`, `{title}`, `{locale}`… | Будь-яким полем верхнього рівня чернетки. Невідомі заповнювачі стають порожніми. |
| `{documentId}`, `{uid}` | Id документа й uid типу вмісту. |
| `{token}` | Токеном попереднього перегляду. Без цього заповнювача токен додається як параметр запиту `preview`. |

Для статей прикладу:

```text
https://example.com/blog/{slug}?locale={locale}
```

дає `https://example.com/blog/hello-world?locale=en&preview=<token>`.

Ті самі налаштування в JSON, як їх зберігає функція (`PUT /admin/api/features/preview`):

```json
{
  "enabled": true,
  "settings": {
    "urls": { "api::article": "https://example.com/blog/{slug}?locale={locale}" },
    "ttlMinutes": 60
  }
}
```

## Відкрийте попередній перегляд

У редакторі запису виберіть **Відкрити попередній перегляд**, щоб відкрити чернетку на своєму
сайті в новій вкладці, або **Поруч**, щоб показати її на панелі поруч із формою, з ширинами
**Комп’ютер**, **Планшет** і **Мобільний**. Бічна панель перезавантажується після кожного
збереження. Якщо вона лишається порожньою, ваш сайт, імовірно, забороняє вбудовування у frame:
використовуйте **Відкрити в новій вкладці**.

## Читання чернетки на сайті

Ваша сторінка попереднього перегляду бере токен з URL і надсилає його назад до API вмісту в
заголовку `x-verdin-preview`, запитуючи чернетку:

<Diagram
  caption="Запит попереднього перегляду"
  code={`sequenceDiagram
  participant E as Редактор
  participant V as Verdin
  participant S as Ваш сайт
  E->>V: Відкрити попередній перегляд
  V-->>E: URL з токеном попереднього перегляду
  E->>S: GET /blog/hello-world?preview=token
  S->>V: GET /api/articles/documentId?status=draft<br/>x-verdin-preview: token
  V-->>S: чернетка`}
/>

<Tabs syncKey="api">
<TabItem label="REST">

```sh title="Terminal"
curl -H "x-verdin-preview: $PREVIEW_TOKEN" \
  'https://cms.example.com/api/articles/<documentId>?status=draft'
```

</TabItem>
<TabItem label="GraphQL">

Токен попереднього перегляду читає REST API вмісту. На сторінці попереднього перегляду
отримуйте чернетку через REST.

</TabItem>
<TabItem label="TypeScript">

```ts
import { createClient } from '@verdin/client';
import type { VerdinSchema } from './verdin-types';

const preview = createClient<VerdinSchema>({
  url: 'https://cms.example.com',
  headers: { 'x-verdin-preview': token },
});
const { data } = await preview
  .collection('articles')
  .findOne(documentId, { status: 'draft' });
```

</TabItem>
</Tabs>

Той самий заголовок працює для поодиноких типів (`GET /api/<singularName>?status=draft`).

Що дає токен:

- Він дає своєму власникові змогу читати цей один документ, включно з чернетками, доки токен
  не спливе.
- Він не може читати інші документи, переглядати списки записів чи щось записувати.
- Відповіді на запити попереднього перегляду ніколи не кешуються.

<Aside type="caution">
Будь-хто з посиланням може читати чернетку, доки токен не спливе. Тримайте термін дії коротким
і не поширюйте посилання попереднього перегляду в публічних місцях.
</Aside>

Сторінка попереднього перегляду зазвичай шукає запис за полем на кшталт `slug`. Оскільки
токен читає за `documentId`, додайте `{documentId}` і до шаблону або виконуйте пошук id за
slug на своєму боці.

## Admin API

`GET /admin/api/content/{uid}/{documentId}/preview?locale=` повертає посилання для кнопки
редактора:

```json
{ "data": { "url": "https://example.com/blog/hello-world?locale=en&preview=…", "token": "…", "expiresAt": "2026-09-29T11:00:00.000Z" } }
```

Він потребує доступу на читання до запису й відповідає `404`, коли функцію вимкнено або тип не
має шаблону.

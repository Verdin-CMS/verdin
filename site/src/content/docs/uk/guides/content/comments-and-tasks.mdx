Адміністратори можуть обговорювати запис у темах коментарів, коментувати окреме поле,
згадувати одне одного й призначати завдання з термінами виконання, не виходячи з редактора. У
цьому посібнику описано обидві можливості, хто що може робити, і admin API. У Strapi
відповідника немає.

## Перш ніж почати

- **Налаштування → Функції → Коментарі та завдання** типово ввімкнено.
- Щоб читати й писати коментарі та завдання запису, достатньо права читати його тип вмісту.
- Згаданим адміністраторам і виконавцям завдань надсилаються листи через `[email]`. З типовим
  провайдером `log` листи потрапляють лише в журнал сервера. Див.
  [довідник конфігурації](/uk/reference/configuration/).

## Коментування запису

<Steps>

1. Відкрийте запис і виберіть **Коментарі**. Кнопка показує кількість відкритих тем.
2. На вкладці **Коментарі** напишіть у полі **Новий коментар**. Введіть `@`, щоб згадати
   адміністратора.
3. Виберіть **Коментувати** або натисніть Control чи Command і Enter.

</Steps>

Щоб прокоментувати одне поле, скористайтеся кнопкою коментаря біля поля (**Коментувати поле**
і назва поля). Теми поля показуються під **Про поле** з назвою цього поля; **Показати всі**
знову показує всі теми.

У темі можна:

- **Відповісти**.
- **Вирішити** її, коли обговорення завершено, і **Відкрити знову** пізніше. Вирішені теми
  переходять до **Вирішені теми**. Вирішує тему лише її перший коментар.
- **Редагувати коментар** — для власних коментарів.
- **Видалити коментар** або **Видалити тему** — для власних коментарів. Super Admin може
  видалити будь-який коментар.

У локалізованих типах коментарі зберігаються окремо для кожної локалі й містять до 10 000
символів.

## Згадування адміністратора

Згадані адміністратори отримують лист із коментарем і посиланням на запис, якщо можуть його
читати. За згадування самого себе лист не надсилається.

## Призначення завдання

<Steps>

1. Відкрийте вкладку **Завдання** тієї самої панелі й виберіть **Нове завдання**.
2. Введіть **Назва** і, за бажання, **Опис**, **Виконавець** і **Термін виконання**. Виконавець
   має мати змогу читати запис.
3. Виберіть **Створити завдання**.

</Steps>

Виконавець отримує лист, якщо не призначив завдання сам собі. Завдання з простроченим
терміном позначаються як прострочені. Позначте завдання виконаним у його рядку.

Автор і виконавець завдання можуть змінити або завершити його. Видалити його може лише автор.
Super Admin може робити обидва з будь-яким завданням.

Щоб бачити свої відкриті завдання в усіх записах, додайте віджет **Мої завдання** на домашню
сторінку: виберіть **Налаштувати**, потім **Додати віджет**.

## Спільна робота наживо

Коли інший адміністратор додає, вирішує чи видаляє коментар або завдання в записі, який у вас
відкрито, панель повідомляє **Коментарі оновлено.** або **Завдання оновлено.** і показує зміну.

## Admin API

Усі маршрути розташовані під `/admin/api`. `uid`, `documentId` і `locale` визначають запис.

| Маршрут | Що робить |
| --- | --- |
| `GET /comments?uid=&documentId=&locale=` | Теми запису з відповідями. |
| `POST /comments` | `{ uid, documentId, locale?, field?, parentId?, body }`. `parentId` робить коментар відповіддю. |
| `PUT /comments/{id}` | `{ body }`. Лише для власних коментарів. |
| `DELETE /comments/{id}` | Власні коментарі або будь-які — для Super Admin. |
| `POST /comments/{id}/resolve`, `POST /comments/{id}/reopen` | Для першого коментаря теми. |
| `GET /tasks?uid=&documentId=&locale=` | Завдання запису. |
| `GET /tasks?mine=true&status=open` | Ваші завдання в усіх записах, які ви ще можете читати. |
| `POST /tasks` | `{ uid, documentId, locale?, title, description?, assigneeId?, dueDate? }`, де `dueDate` у форматі `YYYY-MM-DD`. |
| `PUT /tasks/{id}` | Автор або виконавець. Будь-що з `title`, `description`, `assigneeId`, `dueDate` (`null` очищає) і `status` (`open` або `done`). |
| `DELETE /tasks/{id}` | Лише автор (або Super Admin). |

У тексті коментаря згадка записується як `@[Name](user:12)`, де `12` — id адміністратора.

<Aside type="note">
Поки функцію вимкнено, маршрути відповідають `404`. Вимкнення приховує коментарі й завдання;
вони зберігаються до повторного ввімкнення.
</Aside>

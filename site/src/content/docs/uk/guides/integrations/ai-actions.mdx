Дії ШІ додають в адмін-панель чотири помічники: переклад запису з іншої локалі, написання
альтернативного тексту для зображення, підсумок довгого тексту в коротке поле й пропозиції
SEO-метаданих. Вони використовують налаштованого вами провайдера моделей (Anthropic, OpenAI
або локальний сервер на кшталт Ollama) з вашим власним ключем.

Кожна дія повертає пропозицію, що заповнює форму. Нічого не зберігається, доки редактор не
перегляне її й не збереже, і кожну дію можна скасувати.

## Налаштування

Діям ШІ потрібні і провайдер у `verdin.toml`, і ввімкнена функція.

<Steps>

1. Додайте розділ `[ai]` і передайте ключ серверу в `VERDIN_AI_KEY`:

   <Tabs syncKey="ai-provider">
   <TabItem label="Anthropic">

   ```toml title="verdin.toml"
   [ai]
   provider = "anthropic"
   # model = "claude-sonnet-5"   # the default
   ```

   </TabItem>
   <TabItem label="OpenAI">

   ```toml title="verdin.toml"
   [ai]
   provider = "openai"
   model = "gpt-4.1-mini"        # required: name the model you want
   ```

   </TabItem>
   <TabItem label="Локально (Ollama)">

   ```toml title="verdin.toml"
   [ai]
   provider = "openai-compatible"
   base_url = "http://localhost:11434/v1"
   model = "llama3.2-vision"
   ```

   Локальним серверам `VERDIN_AI_KEY` не потрібен. LM Studio, vLLM та інші сервери з
   OpenAI-сумісним API працюють так само.

   </TabItem>
   </Tabs>

   ```sh title="Terminal"
   export VERDIN_AI_KEY=sk-...
   ```

2. Перезапустіть Verdin. Він відмовляється запускатися, коли розділ неповний: немає ключа або
   немає `model` чи `base_url` там, де провайдер їх потребує.
3. У **Налаштування → Функції** увімкніть **Дії ШІ**.

</Steps>

| Ключ | Типово | Опис |
| --- | --- | --- |
| `provider` | `"none"` | `anthropic`, `openai` або `openai-compatible`. |
| `model` | `claude-sonnet-5` для `anthropic` | Модель. Обов'язкова для інших провайдерів. |
| `base_url` | Адреса провайдера | Інший ендпоінт: проксі або локальний сервер (обов'язковий для `openai-compatible`). |
| `max_tokens` | `2048` | Найдовша відповідь у токенах. |

Див. [`[ai]`](/uk/reference/configuration/). Коли функцію ввімкнено, але розділу `[ai]` немає,
адмінка показує **Дії ШІ недоступні на цьому сервері.**

Дія альтернативного тексту надсилає зображення, тож, якщо вона вам потрібна, вибирайте
модель, що приймає зображення.

## Що роблять дії

### Переклад запису

У редакторі локалізованого запису **Перекласти з _локаль_…** відкриває **Перекласти за
допомогою ШІ**. Виберіть локаль у **Перекласти з** і виберіть **Перекласти**. Текстові поля
збереженої чернетки цієї локалі (рядки, тексти, rich text, blocks і текст усередині компонентів
та динамічних зон) перекладаються поточною локаллю й замінюють ці поля у формі.

- Поля, спільні для локалей, не змінюються.
- Незбережені зміни у вихідній локалі не враховуються: спершу збережіть її.
- Markdown, HTML, URL, id і типи блоків зберігаються як є.
- Перекладені поля позначаються; перегляньте їх, а потім збережіть або виберіть
  **Скасувати переклад**.

Для цього потрібен дозвіл оновлювати запис у цільовій локалі й читати його у вихідній.

### Альтернативний текст

У медіатеці відкрийте зображення й виберіть **Створити альтернативний текст**. Модель описує
зображення (приблизно до 125 символів) мовою типової локалі й заповнює підпис, якщо він
порожній. Працює із зображеннями JPEG, PNG, WebP і GIF і надсилає формат `small` або `medium`,
якщо він є, тож великі оригінали не завантажуються до провайдера. Потрібен дозвіл на оновлення
в медіатеці (на сам файл — для **Власні файли**).

### Підсумок у поле

Текстові поля з назвами, схожими на підсумок (`description`, `summary`, `excerpt`, `abstract`,
`intro`, `introduction`, `lead`, `teaser`), отримують кнопку **Підсумувати _поле_**, коли запис
має поле rich text чи blocks або текстове поле з назвою `body`, `content`, `text` чи `article`.
У прикладі блогу **Excerpt** отримує **Підсумувати Body**. Підсумок вміщається в максимальну
довжину поля.

### Пропозиції SEO-метаданих

Компонент із текстовими атрибутами `metaTitle` і `metaDescription`, як-от
[запропонований `shared.seo`](/uk/guides/frontend/seo-and-sitemap/), отримує кнопку
**Запропонувати**. Вона заповнює мета-заголовок, опис і, якщо компонент його має, `keywords` зі
збереженої чернетки запису.

## Обмеження

- Кожен адміністратор може робити 30 запитів до ШІ на хвилину; на решту відповідь —
  **Забагато запитів до ШІ. Зачекайте хвилину і спробуйте ще раз.**
- Підсумки й SEO-пропозиції надсилають щонайбільше 40 000 символів тексту.
- Запит до провайдера спливає за тайм-аутом через 120 секунд.

## Приватність

<Aside type="caution">
Дії ШІ надсилають вміст налаштованому вами провайдерові: поля, що перекладаються, підсумовуються
чи описуються, і зображення для альтернативного тексту. Вибирайте провайдера й тариф, які ваша
організація дозволяє для такого вмісту, перевірте умови зберігання даних і розгляньте локальну
модель (`openai-compatible`) для вмісту, який не має покидати вашу мережу.
</Aside>

- Запити йдуть від сервера Verdin до провайдера; ключ ніколи не потрапляє в браузер.
- Надсилаються лише вхідні дані дії: текстові поля запису, текст для підсумку або одне
  зображення з назвою файлу. Приватні атрибути й інші записи — ні.
- Дії читають лише те, що адміністратор і так може читати, а пропозиції не зберігаються.

Адмінка показує, яка модель відповіла (**Пропозиції від _модель_ (_провайдер_).**).

Щоб дозволити ШІ-агентам поза адмінкою читати й записувати вміст, див.
[MCP-сервер](/uk/guides/integrations/mcp/).

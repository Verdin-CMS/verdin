Verdin зберігає модель вмісту й API вмісту Strapi v5, щоб фронтенди й вміст могли перейти
(див. [Міграція зі Strapi](/uk/migrate/from-strapi/)). Це не пряма заміна для *кодової бази*
Strapi: середовища виконання JavaScript немає, тож власний код переписується як плагіни
WebAssembly. На цій сторінці перелічено кожну область зі статусом станом на Verdin 0.10.0.

**Підтримується** — працює як у Strapi v5 (відмінності зазначено). **Частково** — покриває
поширені випадки; у примітці сказано, чого бракує. **Не підтримується** — відповідника немає.

## Модель вмісту

| Функція | Статус | Примітки |
| --- | --- | --- |
| Типи колекцій і поодинокі типи | Підтримується | JSON-файли схеми, близькі до Strapi (`schema/content-types/*.json`). Див. [Модель вмісту](/uk/concepts/content-model/). |
| Скалярні типи атрибутів | Підтримується | `string`, `text`, `richtext` (Markdown), `blocks`, `email`, `uid`, `integer`, `biginteger`, `float`, `decimal`, `boolean`, `date`, `time`, `datetime`, `enumeration`, `json`, `password`. `timestamp` зі Strapi імпортується як `datetime`. |
| Компоненти й динамічні зони | Підтримується | Включно з медіа та зв'язками `oneWay`/`manyWay` усередині компонентів. |
| Зв'язки | Підтримується | One/many-to-one/many, one-way і many-way, а також поліморфні `morphToOne`, `morphToMany`, `morphOne`, `morphMany`. |
| Медіаполя | Підтримується | Одиночні чи множинні, `allowedTypes`. |
| `unique` | Частково | Не для атрибутів `text`, `richtext`, `blocks` і `json`. |
| Умовні поля (`conditions`) | Підтримується | Умови JSON Logic зі Strapi 5.17; приховані поля не є обов'язковими. |
| Власні поля | Частково | Атрибути `customField` працюють; поле введення в адмінці надає [плагін](/uk/extending/plugins/) Verdin, а не React-плагіни Strapi. |
| Конструктор типів вмісту | Підтримується | Лише в режимі розробки (`verdin dev`), як у Strapi. |

## REST API

| Функція | Статус | Примітки |
| --- | --- | --- |
| CRUD-маршрути | Підтримується | `GET`/`POST /api/{pluralName}`, `GET`/`PUT`/`DELETE /api/{pluralName}/{documentId}`, поодинокі типи на `/api/{singularName}`. Відповіді містять `data` і `meta`, помилки — об'єкт `error` Strapi. |
| `filters` | Підтримується | Усі оператори Strapi: `$eq`, `$eqi`, `$ne`, `$nei`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$notIn`, `$contains`, `$notContains`, `$containsi`, `$notContainsi`, `$null`, `$notNull`, `$between`, `$startsWith(i)`, `$endsWith(i)`, `$and`, `$or`, `$not`; через зв'язки, компоненти, повторювані компоненти й динамічні зони (`__component`). |
| `sort` | Підтримується | Кілька полів, `:asc`/`:desc` і поле зв'язку to-one (`author.name:asc`). |
| `pagination` | Підтримується | `page`/`pageSize` або `start`/`limit`, `withCount`. `pageSize` обмежено `[api].max_page_size` (100). |
| `fields` | Підтримується | |
| `populate` | Підтримується | `*`, списки, вкладені об'єкти, `on` для динамічних зон, `count`. Глибина до 5; щонайбільше 1 000 заповнених записів на зв'язок. |
| `status` | Підтримується | `published` (типово) або `draft`; читання чернеток потребує дозволу `readDrafts`. |
| `locale` | Підтримується | Див. i18n нижче. |
| `hasPublishedVersion` | Підтримується | |
| Повнотекстовий пошук `_q` | Підтримується | `$containsi` за текстовими полями, як у Strapi; ранжований пошук з `[search]`. |
| Запис зв'язків | Підтримується | ID, `connect` / `disconnect` / `set`, з `position` (`before`, `after`, `start`, `end`). |
| Публікація, зняття з публікації, відкидання чернетки | Підтримується | Записи публікують, якщо немає `?status=draft`, як у Strapi v5. Verdin додає `POST /api/{pluralName}/{documentId}/actions/{publish,unpublish,discard-draft}`. |
| Формат відповідей Strapi v4 і `publicationState` | Не підтримується | Verdin говорить лише v5: плоскі атрибути, `documentId`, `status`. |
| Документ OpenAPI | Частково | На `/api/_openapi.json` (типово лише з токеном) та інтерактивний довідник на `/api/docs` замість `/documentation` плагіна документації. |

## GraphQL

| Функція | Статус | Примітки |
| --- | --- | --- |
| Запити | Підтримується | `articles`, `articles_connection` з `pageInfo`, `article(documentId)`, поодинокі типи; `filters`, `sort`, `pagination`, `status`, `locale`. Вимкнено, доки ви не ввімкнете **Налаштування → Функції → GraphQL**. |
| Мутації | Підтримується | `create…`, `update…`, `delete…` зі `status` і `locale`. |
| Компоненти, динамічні зони, медіа | Підтримується | Динамічні зони як union, медіа як `UploadFile`. |
| Поліморфні зв'язки | Частково | Повертаються як JSON, а не як типізовані union. |
| Shadow CRUD (вимкнення операцій для типу) | Підтримується | Налаштування `disabled` функції. |
| Власні резолвери й розширення схеми | Частково | Кореневі поля, які розв'язують плагіни (`[[graphql]]` у `plugin.toml`); `extensionService` немає. |
| Мутації Users & Permissions (`login`, `register`, `me`…) | Не підтримується | Використовуйте REST-маршрути. |
| Запити/мутації завантажень та i18n (`uploadFiles`, `i18NLocales`…) | Не підтримується | Використовуйте REST-маршрути (`GET /api/i18n/locales`) й адмін-панель. `localizations` у локалізованих типах підтримується. |
| Обмеження, GraphiQL | Підтримується | `maxDepth`, `maxComplexity`, перемикачі інтроспекції й пісочниці. |

## Users & Permissions (кінцеві користувачі)

Увімкніть **Налаштування → Функції → Користувачі та права**. Див. [Кінцеві користувачі](/uk/guides/auth/end-users/).

| Функція | Статус | Примітки |
| --- | --- | --- |
| `POST /api/auth/local`, `/auth/local/register` | Підтримується | Той самий формат запитів і відповідей. |
| Підтвердження ел. пошти, забутий/скидання/зміна пароля | Підтримується | `/auth/email-confirmation`, `/auth/send-email-confirmation`, `/auth/forgot-password`, `/auth/reset-password`, `/auth/change-password`. |
| Refresh tokens | Підтримується | `jwtManagement: "refresh"`, `/auth/refresh`, `/auth/logout`. |
| `/api/users`, `/users/me`, `/users/count` | Підтримується | Звичайний JSON, дозволи на `plugin::users-permissions.user`. |
| Провайдери OAuth | Частково | GitHub, Google, Microsoft, Discord, Facebook, GitLab, LinkedIn і будь-який провайдер OAuth 2; не всі шаблони Strapi. |
| Маршрути ролей і дозволів (`/api/users-permissions/roles`, `/permissions`) | Не підтримується | Керуйте ролями в **Налаштування → Кінцеві користувачі**. |
| Імпортовані користувачі | Підтримується | Хеші bcrypt продовжують працювати; під час входу їх перехешовують з Argon2id. |

## Медіатека й API завантажень

| Функція | Статус | Примітки |
| --- | --- | --- |
| `POST /api/upload` | Підтримується | Multipart `files` і `fileInfo`; `?id=` оновлює інформацію про файл або замінює файл, якщо його надіслано. |
| Прив'язка під час завантаження (`ref`, `refId`, `field`) | Не підтримується | Завантажте, потім задайте медіаполе з id файлу. |
| `GET /api/upload/files`, `/files/{id}`, `DELETE /files/{id}` | Частково | Список приймає лише `pagination[page]`, `pagination[pageSize]`, `sort` і `filters[name][$containsi]`. |
| Адаптивні формати, breakpoints | Підтримується | `thumbnail` плюс `[upload].breakpoints`. |
| Папки, фокусні точки, альтернативний текст, підписи | Підтримується | |
| Провайдери завантажень | Частково | Локальний диск і S3-сумісне сховище (AWS, R2, B2, MinIO, Tigris…). Без Cloudinary та інших пакетів провайдерів. |
| Трансформації зображень | Лише Verdin | `/uploads/<file>?preset=…` і підписані URL (локальний провайдер). |

## Інтернаціоналізація

| Функція | Статус | Примітки |
| --- | --- | --- |
| Локалізовані типи й нелокалізовані поля | Підтримується | `pluginOptions.i18n.localized`, також для окремих атрибутів. |
| `?locale=` у REST, `locale` у GraphQL | Підтримується | Невідома локаль — це `400`. |
| `localizations` у відповідях | Підтримується | Лише коли заповнено (`populate=localizations`, `populate=*`), з тими самими параметрами, що й у зв'язку. Також поле GraphQL. Admin API його пропускає. |
| `GET /api/i18n/locales` | Підтримується | Звичайний масив у форматі Strapi. Потребує `find` для `plugin::i18n.locale` (рядок **Локалі** в сітці дозволів), як `listLocales` у Strapi. `documentId` виводиться з коду локалі. Локалями керують в адмінці (**Налаштування → Інтернаціоналізація**). |

## Чернетки й публікація

| Функція | Статус | Примітки |
| --- | --- | --- |
| Чернетка й опублікована версія для кожного документа | Підтримується | Для кожної локалі. Див. [Чернетки й публікація](/uk/concepts/draft-and-publish/). |
| Відкидання чернетки | Підтримується | |
| Запланована публікація | Підтримується | Через [Релізи](/uk/guides/content/releases/). |

## Налаштування сервера

Як перенести кожен із цих елементів, див. [Перенесення власного коду](/uk/migrate/porting-custom-code/).

| Strapi | Статус | Verdin |
| --- | --- | --- |
| Хуки lifecycle, middlewares Document Service | Частково | Хуки before/after у плагінах WebAssembly, які можуть змінити або відхилити запис. Без JavaScript. |
| Власні контролери, сервіси, маршрути | Частково | Маршрути плагінів під `/api/plugins/<name>/`. |
| Policies і middlewares | Не підтримується | Дозволи й обмеження частоти вбудовані. |
| `register` / `bootstrap` | Частково | Функція запуску плагіна, що виконується, коли плагін стартує, вмикається або змінюються його налаштування; вона може наповнювати вміст і замінювати дозволи публічної ролі. |
| Cron-завдання | Частково | Завдання плагінів. |
| Document Service / Entity Service на JavaScript | Не підтримується | Середовища виконання JavaScript немає. |
| npm-плагіни з маркетплейсу Strapi | Не підтримується | |
| Вебхуки | Підтримується | Підписуються, повторюються й журналюються; `entry.draft-discard` — це `entry.discard-draft`. Див. [Вебхуки](/uk/guides/integrations/webhooks/). |
| API-токени (лише читання, повний доступ, налаштовувані) | Підтримується | Ті самі види, необов'язковий термін дії, регенерація. |
| Transfer tokens, `strapi transfer` | Не підтримується | Використовуйте `verdin export` і `verdin import verdin`. |
| Файли `strapi export` | Підтримується (імпорт) | `verdin import strapi`; зашифровані експорти не читаються. |
| `config/*.js`, `.env` | Частково | `verdin.toml` і змінні середовища. |
| Типи TypeScript | Підтримується | `verdin types`. |
| Поштові провайдери | Частково | SMTP, Resend і Postmark. |

## Адмін-панель

| Функція | Статус | Примітки |
| --- | --- | --- |
| Менеджер вмісту, медіатека, конструктор типів вмісту | Підтримується | Власна панель на Angular, а не React-адмінка Strapi. |
| Адміністратори, ролі, власні ролі | Підтримується | Вбудовані Super Admin, Editor і Author плюс власні ролі. |
| Дозволи на рівні полів і локалей | Підтримується | |
| Умови RBAC | Частково | Лише вбудована умова `is-creator`; власних умов немає. |
| Налаштування адмінки (`src/admin/app`) | Частково | Логотип, favicon, заголовок, акцентний колір і тексти в `[admin.branding]`; віджети й власні поля від плагінів. Без власних сторінок, зон ін'єкції чи React-розширень. |
| Admin API (`/admin/…`) | Не підтримується | Admin API Verdin — власний; не будуйте на API Strapi. |
| Налаштування виду редагування й списку | Підтримується | |

## Функції Enterprise

Усе у Verdin має відкритий код; у Strapi це функції Enterprise або платні.

| Функція Strapi | Статус | Примітки |
| --- | --- | --- |
| SSO | Частково | Провайдери OpenID Connect зі зіставленням груп і ролей. Без SAML та інших стратегій passport. Див. [Єдиний вхід](/uk/guides/auth/sso/). |
| Журнали аудиту | Підтримується | Див. [Журнали аудиту](/uk/guides/content/audit-logs/). |
| Процеси перевірки | Підтримується | Ролі для кожного етапу обмежують, хто переміщує записи *на* етап, а обов'язковий етап публікації діє для кожного API. Див. [Процеси перевірки](/uk/guides/content/review-workflows/). |
| Релізи | Підтримується | Заплановані або негайні. |
| Історія вмісту | Підтримується | `[history].max_versions` версій на документ. |
| Попередній перегляд і живий попередній перегляд | Підтримується | URL попереднього перегляду з короткочасними токенами, попередній перегляд поруч і [візуальне редагування](/uk/guides/frontend/visual-editing/). |
| Власні ролі адміністраторів | Підтримується | Без обмеження їхньої кількості. |

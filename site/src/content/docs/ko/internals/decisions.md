이 기록은 Verdin을 만든 설계 선택을 내린 순서대로 남겨, 코드를 바꾸자고 제안하기 전에 코드가 왜 지금처럼 되어 있는지 알 수 있게 합니다. 항목은 마일스톤 이름(M2–M4는 첫 릴리스 전의 마일스톤)을 포함해 작성된 그대로 유지하며, 28이 1을 다듬듯 나중 항목이 이전 항목을 다듬을 수 있습니다. 누군가 코드를 역공학해야 알 수 있을 결정을 내렸다면 새 행을 추가하세요.

| # | 결정 | 결과 | 근거 |
|---|---|---|---|
| 1 | 컴포넌트: JSON 대 테이블 | **JSON 컬럼** ([스토리지](/ko/internals/storage/#컴포넌트와-다이나믹-존-json-컬럼)) | 조인이 적고, 게시·버전 관리가 간단하고, 마이그레이션이 단순합니다. 반복 가능한 컴포넌트로 필터링하는 일은 드물며, 나중에 JSON 함수로 추가할 수 있습니다 |
| 2 | `decimal` JSON 인코딩 | 기본은 **숫자**, `api.decimal_as_string`으로 선택 | Strapi 호환성이 도입을 극대화하고, 필요하면 정확한 값을 쓸 수 있습니다 |
| 3 | 관리자 폼 | **Signal Forms** | signals 우선, zoneless 관리자 패널에 맞고, 스키마에서 도출한 동적 폼 트리 |
| 4 | 언어 | 코드, 문서, 커밋은 **영어** | 오픈 소스의 도달 범위 |
| 5 | Strapi REST 호환성 | **같은 파라미터와 응답 형식**. Verdin 전용 확장은 `actions/` 아래 | 프런트엔드가 최소한의 변경으로 마이그레이션 |
| 6 | 관리자 JWT 알고리즘 | HS256 | 시크릿 하나로 단순함. 외부 검증자가 생기면 EdDSA |
| 7 | 문서 ID | ULID (26자) | 정렬 가능하고 이식 가능. Strapi 자체 id는 불투명한 24자 문자열이며 클라이언트가 파싱하지 않음 |
| 8 | 스냅샷 내용 | 스키마가 아니라 물리 모델 | 이후 버전이 바뀌지 않은 스키마에서 새 테이블을 도출할 수 있음 |
| 9 | 속성 nullability | 항상 nullable. `required`는 게시할 때 검사 | 초안은 불완전해도 됨(Strapi v5 동작). 필수 필드 추가가 안전함 |
| 10 | `unique` 강제 | `(column, locale, publication_state)`에 대한 고유 인덱스 | 경쟁 조건 없음. 초안과 그 게시 버전은 값을 공유 |
| 11 | 상태 컬럼 이름 | `publication_state` | `state`는 흔한 속성 이름 |
| 12 | SQL 예약어 | 식별자를 항상 인용 | 속성 이름에 대한 임의의 차단 목록이 필요 없음 |
| 13 | DML 작성 | `sea-query` 대신 자체 빌더 | 방언별 세부 사항이 대부분을 차지(타입 있는 NULL, collation, SQLite 형식). 추상화 하나가 줄어듦 |
| 14 | `?status=draft` 없는 쓰기 | 게시(Strapi v5 REST 동작) | 기존 클라이언트와 그대로 호환 |
| 15 | 텍스트 비교 | 모든 엔진에서 기본은 정확한 일치. 대소문자 무시는 `…i` 연산자 | MySQL에서도 PostgreSQL과 같은 결과 |
| 16 | 임시 접근 제어(M2–M3) | `[api].open_access` 스위치, M4에서 제거 | 권한 기능이 생기기 전까지 기본적으로 안전 |
| 17 | "대상은 문서 하나에 속함" | 상태별로 대상을 옮겨서 강제 | 고유 인덱스는 초안과 그 게시 버전이 대상을 공유하는 것을 막게 됨 |
| 18 | 역방향(`mappedBy`) 쪽 | 읽기 전용 | 초안과 게시에서 이쪽으로 쓰면 모호함(어느 소유 버전인가?) |
| 19 | 링크 위치 | 쓸 때마다 1..n으로 다시 매김 | 부동소수점 고갈 없음. 리스트는 작음 |
| 20 | 링크 테이블 행 | `id` 기본 키 유지 | 마이그레이션 엔진과 SQLite 재구성을 위한 균일한 테이블 |
| 21 | JWT 라이브러리 | 자체 HS256(HMAC-SHA256, 상수 시간 검증, `alg` 고정) | `jsonwebtoken` 11은 RSA를 끌어오는 암호화 백엔드가 필요 |
| 22 | 플랫폼 테이블 | 콘텐츠 모델과 함께 도출 | 모든 것에 마이그레이션 메커니즘 하나 |
| 23 | 리프레시 토큰 재사용 | 유예 기간 없이 토큰 계열 전체 취소 | 단순하고 엄격함. 관리자가 다시 로그인 |
| 24 | 콘텐츠 API의 초안 | 별도 `readDrafts` 권한 | 게시된 콘텐츠를 읽는 토큰이 초안을 노출하지 않음 |
| 25 | 빌더 적용 순서 | 마이그레이션, 파일 쓰기, 앱 핫스왑 순 | 마이그레이션이 실패해도 파일과 실행 중인 앱은 그대로 |
| 26 | 관리자 쓰기 | 초안만 저장. 게시는 명시적 작업 | 편집자의 기대와 일치. 콘텐츠 API는 Strapi의 기본 게시를 유지 |
| 27 | 관리자 런타임 설정 | 인라인 스크립트가 아니라 `<meta>` 태그 | CSP에 `unsafe-inline` 스크립트가 필요 없음 |
| 28 | 컴포넌트 필드 필터 | 방언별 JSON 경로 연산자(`#>>`, `JSON_VALUE`, `json_extract`). 반복 가능한 컴포넌트와 다이나믹 존은 배열 항목에 대한 `EXISTS`(0.8) | 다이나믹 존은 `__component`로만. 항목마다 필드가 다름 |
| 29 | 관리자 i18n | 평평한 JSON 카탈로그(`admin/public/i18n`)와 FormatJS(사용자 정의 transpiler)를 통한 ICU MessageFormat을 쓰는 Transloco, 작은 `I18n` 파사드 뒤에 둠. Angular의 컴파일 타임 i18n은 쓰지 않음 | 런타임 언어 전환. Weblate/Crowdin용 표준 파일. FormatJS는 메시지를 해석하므로 엄격한 CSP에 `unsafe-eval`이 필요 없음(`@messageformat/core`는 `new Function`으로 컴파일). 키는 `en.json`에서 타입 생성, 완전성은 `npm run i18n:check`로 검사 |
| 30 | 주의 시작 | 브라우저 지역 태그의 `Intl.Locale#getWeekInfo`(en-GB ≠ en-US), 지역 테이블로 대체, 사용자 재정의 | UI 언어를 공유해도 각 사용자의 지역을 따름 |
| 31 | 대시보드 레이아웃 저장 | `vd_admin_users`의 사용자별 JSON `preferences` 컬럼(≤ 64 KiB) | 브라우저를 옮겨도 사용자를 따라감. 테마와 언어는 로그인 전에 적용되므로 `localStorage`에 둠 |
| 32 | 리프레시 쿠키 `Secure` 기본값 | `start`에서 켜짐, `dev`에서 꺼짐, 재정의 가능 | 일반 HTTP로 실행한 `verdin dev`가 모든 브라우저에서 동작. 프로덕션은 엄격하게 유지 |
| 33 | 릴리스 프로필 | Thin LTO, codegen unit 1, strip. unwinding 유지 | panic하는 핸들러가 서버를 멈추게 하면 안 됨 |
| 34 | "확인하지 않은" 문서 | 사용자별 `vd_document_views` 행. 문서가 바뀌면 편집자를 뺀 모두의 행을 삭제. SQL에서 `NOT EXISTS`로 필터링 | 페이지네이션과 개수가 정확함. 행마다 비교할 타임스탬프가 없음 |
| 35 | 투표와 설문 | 관리자 전용 협업 테이블(`vd_document_votes`, `vd_polls`, `vd_poll_votes`), 모든 콘텐츠 타입 | 모든 스키마에 투표 필드를 모델링하지 않고 제안함과 팀 결정 |
| 36 | 미디어 스토리지 | 로컬과 S3에 `object_store` | 코드 경로 하나. 스트리밍 multipart 업로드. 개발 스택과 CI에서 RustFS |
| 37 | 미디어 링크 | 관계처럼 필드별 링크 테이블 | 관계와 같은 초안·게시 의미. cascade로 링크 일관성 유지 |
| 38 | 기본 권한 업그레이드 | `vd_settings` 버전 표시, 추가 사항은 한 번만 적용 | 기존 설치가 관리자의 이후 편집을 되돌리지 않고 새 권한을 얻음 |
| 39 | 런타임 기능 | `verdin-api`의 카탈로그, `vd_settings`(`features`)의 스위치, 모든 모드에서 앱을 제자리에서 재구성(ArcSwap) | 재시작 없는 Strapi 같은 플러그인 스위치. 사용할 수 없는 기능은 계획된 버전과 함께 나열 |
| 40 | API 레퍼런스 UI | 문서가 공개일 때만 `{api}/docs`에서 Scalar(`scalar_api_reference`, 번들 내장). CSP는 해시로 인라인 부트스트랩을 허용 | 자체 호스팅(CDN, 폰트, AI 에이전트, 텔레메트리 없음). 문서는 기본적으로 토큰 전용 |
| 41 | GraphQL | 앱과 함께 만드는 `async-graphql` 동적 스키마. 인자와 선택을 REST 파라미터 트리로 변환해 같은 쿼리 파서로 파싱 | REST와 GraphQL에 걸쳐 필터, 페이지네이션, populate, 검증, 권한 규칙이 하나. 선택에서 도출한 populate가 배치 로딩을 유지 |
| 42 | 문서 이벤트 | Document Service의 리스너, 커밋 후 호출 | 부수 효과(확인 표시, 향후 웹훅)가 핸들러별 훅 없이 모든 API에 적용 |

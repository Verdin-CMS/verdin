코드를 작성하지 않고 [예제 블로그 프로젝트](https://github.com/Verdin-CMS/verdin/tree/main/examples/blog)의
콘텐츠 API를 사용해 보세요. 요청은 브라우저에서 **Server**에 고른 서버로 전송되며,
기본값은 `http://localhost:1337`입니다.

요청에 응답하려면 예제 프로젝트를 로컬에서 실행하고 요청을 허용하세요.

```sh title="Terminal"
cd examples/blog
verdin secrets > .env && echo 'VERDIN_DATABASE_URL=sqlite://data/blog.db' >> .env
mkdir -p data && verdin dev
```

- [localhost:1337/admin](http://localhost:1337/admin/)에서 첫 관리자를 만들고 글을 몇 개 추가합니다.
- **설정 → 공개 접근**에서 `find`와 `findOne`을 허용하거나,
  **Authentication**에 API 토큰을 붙여 넣습니다.
- 플레이그라운드는 이 사이트의 출처에서 실행되므로 서버가 이 출처를 받아들여야 합니다.
  `verdin.toml`의 `[api].cors_origins`에 추가하세요([설정](/ko/reference/configuration/) 참고).

직접 만든 프로젝트도 **설정 → 기능 → API 문서**에서 **공개 문서**를 켜면
`/api/docs`에서 자체 스키마에 대한 같은 레퍼런스를 제공합니다.

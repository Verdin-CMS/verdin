AI 기능은 관리자 패널에 네 가지 도우미를 추가합니다. 다른 로케일에서 항목 번역, 이미지의 대체 텍스트 작성, 긴 텍스트를
짧은 필드로 요약, SEO 메타데이터 제안입니다. 여러분이 설정한 모델 제공업체(Anthropic, OpenAI, 또는 Ollama 같은 로컬
서버)를 여러분의 키로 사용합니다.

모든 작업은 폼을 채우는 제안을 반환합니다. 편집자가 검토하고 저장하기 전까지는 아무것도 저장되지 않으며, 각 작업은
되돌릴 수 있습니다.

## 설정

AI 기능에는 `verdin.toml`의 제공업체와 켜진 기능이 모두 필요합니다.

<Steps>

1. `[ai]` 섹션을 추가하고 `VERDIN_AI_KEY`로 서버에 키를 줍니다.

   <Tabs syncKey="ai-provider">
   <TabItem label="Anthropic">

   ```toml title="verdin.toml"
   [ai]
   provider = "anthropic"
   # model = "claude-sonnet-5"   # the default
   ```

   </TabItem>
   <TabItem label="OpenAI">

   ```toml title="verdin.toml"
   [ai]
   provider = "openai"
   model = "gpt-4.1-mini"        # required: name the model you want
   ```

   </TabItem>
   <TabItem label="로컬 (Ollama)">

   ```toml title="verdin.toml"
   [ai]
   provider = "openai-compatible"
   base_url = "http://localhost:11434/v1"
   model = "llama3.2-vision"
   ```

   로컬 서버에는 `VERDIN_AI_KEY`가 필요 없습니다. LM Studio, vLLM 등 OpenAI 호환 API를 가진 서버도 같은 방식으로
   동작합니다.

   </TabItem>
   </Tabs>

   ```sh title="Terminal"
   export VERDIN_AI_KEY=sk-...
   ```

2. Verdin을 재시작합니다. 섹션이 불완전하면(키가 없거나, 제공업체가 필요로 하는 `model`이나 `base_url`이 없으면) 시작을
   거부합니다.
3. **설정 → 기능**에서 **AI 기능**을 켭니다.

</Steps>

| 키 | 기본값 | 설명 |
| --- | --- | --- |
| `provider` | `"none"` | `anthropic`, `openai`, `openai-compatible`. |
| `model` | `anthropic`이면 `claude-sonnet-5` | 모델. 다른 제공업체에서는 필수. |
| `base_url` | 제공업체의 기본값 | 다른 엔드포인트: 프록시나 로컬 서버(`openai-compatible`에서는 필수). |
| `max_tokens` | `2048` | 가장 긴 응답(토큰 단위). |

[`[ai]`](/ko/reference/configuration/)를 참고하세요. 기능은 켜져 있지만 `[ai]` 섹션이 없으면 관리자 패널에
<strong>이 서버에서는 AI 기능을 사용할 수 없습니다.</strong>가 표시됩니다.

대체 텍스트 작업은 이미지를 보내므로, 쓰려면 이미지를 받는 모델을 고르세요.

## 작업이 하는 일

### 항목 번역

로컬라이즈된 항목의 편집기에서 <strong>*로케일*에서 번역…</strong>을 선택하면 **AI로 번역**이 열립니다. **번역 출처**에서 로케일을
고르고 **번역**을 선택하세요. 그 로케일의 저장된 초안의 텍스트 필드(문자열, 텍스트, 리치 텍스트, blocks, 컴포넌트와
다이나믹 존 안의 텍스트)가 현재 로케일로 번역되어 폼의 해당 필드를 대체합니다.

- 로케일 간에 공유되는 필드는 그대로 둡니다.
- 원본 로케일의 저장하지 않은 변경은 포함되지 않습니다. 먼저 저장하세요.
- Markdown, HTML, URL, id, 블록 타입은 그대로 유지됩니다.
- 번역된 필드는 표시됩니다. 검토한 뒤 저장하거나 **번역 실행 취소**를 선택하세요.

대상 로케일에서 항목을 수정할 권한과 원본 로케일에서 읽을 권한이 필요합니다.

### 대체 텍스트 작성

미디어 라이브러리에서 이미지를 열고 **대체 텍스트 생성**을 선택합니다. 모델이 기본 로케일의 언어로 이미지를 설명하고(최대
약 125자), 캡션이 비어 있으면 캡션도 채웁니다. JPEG, PNG, WebP, GIF 이미지에서 동작하며, `small`이나 `medium` 포맷이
있으면 그것을 보내므로 큰 원본이 제공업체로 업로드되지 않습니다. 미디어 라이브러리의 수정 권한이 필요합니다
(**본인 파일**이면 해당 파일에 대해).

### 필드로 요약

요약처럼 이름 붙은 텍스트 필드(`description`, `summary`, `excerpt`, `abstract`, `intro`, `introduction`, `lead`,
`teaser`)에는 항목에 리치 텍스트나 blocks 필드, 또는 `body`, `content`, `text`, `article`이라는 텍스트 필드가 있을 때
<strong>*필드* 요약</strong> 버튼이 생깁니다. 예제 블로그에서는 **Excerpt**에 **Body 요약**이 생깁니다. 요약은 필드의 최대 길이에
맞춰집니다.

### SEO 메타데이터 제안

[제안된 `shared.seo`](/ko/guides/frontend/seo-and-sitemap/)처럼 `metaTitle`과 `metaDescription` 텍스트 속성을 가진
컴포넌트에는 **제안** 버튼이 생깁니다. 항목의 저장된 초안으로 메타 제목, 설명, 그리고 컴포넌트에 있다면 `keywords`를
채웁니다.

## 한도

- 각 관리자는 분당 AI 요청을 30번까지 할 수 있습니다. 그 이상은
  <strong>AI 요청이 너무 많습니다. 잠시 후 다시 시도하세요.</strong>로 응답합니다.
- 요약과 SEO 제안은 최대 40,000자의 텍스트를 보냅니다.
- 제공업체에 대한 요청은 120초 뒤에 타임아웃됩니다.

## 개인 정보

<Aside type="caution">
AI 기능은 설정한 제공업체로 콘텐츠를 보냅니다. 번역, 요약, 설명하는 필드와 대체 텍스트용 이미지입니다. 조직이 그 콘텐츠에
허용하는 제공업체와 요금제를 고르고, 데이터 보존 조건을 확인하고, 네트워크 밖으로 나가면 안 되는 콘텐츠에는 로컬
모델(`openai-compatible`)을 고려하세요.
</Aside>

- 요청은 Verdin 서버에서 제공업체로 갑니다. 키는 절대 브라우저에 도달하지 않습니다.
- 작업의 입력만 보냅니다: 항목의 텍스트 필드, 요약할 텍스트, 또는 이미지 하나와 그 파일 이름. private 속성과 다른 항목은
  보내지 않습니다.
- 작업은 관리자가 이미 읽을 수 있는 것만 읽으며, 제안은 저장되지 않습니다.

관리자 패널은 어떤 모델이 응답했는지 보여 줍니다(<strong>*모델*(*제공업체*)의 제안입니다.</strong>).

관리자 패널 밖의 AI 에이전트가 콘텐츠를 읽고 쓰게 하려면 [MCP 서버](/ko/guides/integrations/mcp/)를 참고하세요.

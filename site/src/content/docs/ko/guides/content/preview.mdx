미리 보기는 게시하기 전에 항목의 초안을 여러분의 사이트에서 엽니다. 편집기는 콘텐츠 타입별 URL 템플릿으로 링크를
만들고, 사이트가 그 초안 하나를 읽을 수 있게 하는 수명이 짧은 토큰을 붙입니다. 이 가이드에서는 템플릿과 사이트 쪽을
설정합니다.

미리 보기의 텍스트를 클릭해 해당 필드로 이동하려면, 그 위에 [비주얼 에디팅](/ko/guides/frontend/visual-editing/)을
추가하세요.

## 시작하기 전에

- **설정 → 기능 → 미리 보기**를 켭니다. 기본적으로 꺼져 있습니다.
- 기능 설정을 바꾸려면 **기능 관리**(`features.manage`)가 필요합니다.
- 미리 보기를 열려면 항목에 대한 읽기 권한이 필요합니다. [권한](/ko/reference/permissions/)을 참고하세요.

## 미리 보기 URL 설정

<Steps>

1. **설정 → 기능**의 **미리 보기** 카드에서 **미리 보기 URL 구성**을 선택합니다.
2. **URL 템플릿** 아래에 각 콘텐츠 타입의 초안을 보여 주는 사이트 페이지를 입력합니다. 미리 보기가 없게 하려면 타입을
   비워 두세요.
3. 선택적으로 <strong>링크 유효 기간(분)</strong>을 바꿉니다. 기본 60, 최대 10080(7일).
4. 저장합니다.

</Steps>

템플릿은 중괄호로 된 자리 표시자가 있는 `http` 또는 `https` URL입니다.

| 자리 표시자 | 채워지는 값 |
| --- | --- |
| `{slug}`, `{title}`, `{locale}`… | 초안의 최상위 필드 아무것이나. 알 수 없는 자리 표시자는 빈 값이 됩니다. |
| `{documentId}`, `{uid}` | 문서 id와 콘텐츠 타입 uid. |
| `{token}` | 미리 보기 토큰. 이 자리 표시자가 없으면 토큰은 `preview` 쿼리 파라미터로 추가됩니다. |

예제 프로젝트의 글에서는 다음 템플릿이

```text
https://example.com/blog/{slug}?locale={locale}
```

`https://example.com/blog/hello-world?locale=en&preview=<token>`이 됩니다.

같은 설정을 기능이 저장하는 JSON으로 나타내면 다음과 같습니다(`PUT /admin/api/features/preview`).

```json
{
  "enabled": true,
  "settings": {
    "urls": { "api::article": "https://example.com/blog/{slug}?locale={locale}" },
    "ttlMinutes": 60
  }
}
```

## 미리 보기 열기

항목 편집기에서 **미리 보기 열기**를 선택하면 새 탭에서 사이트의 초안이 열리고, **나란히 보기**를 선택하면 폼 옆의
패널에 **데스크톱**, **태블릿**, **모바일** 너비로 보여 줍니다. 옆 패널은 저장할 때마다 다시 로드됩니다. 계속 비어
있다면 사이트가 프레임 안에 삽입되는 것을 거부하고 있을 가능성이 큽니다. **새 탭에서 열기**를 쓰세요.

## 사이트에서 초안 읽기

미리 보기 페이지는 URL에서 토큰을 가져와 `x-verdin-preview` 헤더에 담아 콘텐츠 API로 다시 보내며 초안을 요청합니다.

<Tabs syncKey="api">
<TabItem label="REST">

```sh title="Terminal"
curl -H "x-verdin-preview: $PREVIEW_TOKEN" \
  'https://cms.example.com/api/articles/<documentId>?status=draft'
```

</TabItem>
<TabItem label="GraphQL">

미리 보기 토큰은 REST 콘텐츠 API가 읽습니다. 미리 보기 페이지에서는 REST로 초안을 가져오세요.

</TabItem>
<TabItem label="TypeScript">

```ts
import { createClient } from '@verdin/client';
import type { VerdinSchema } from './verdin-types';

const preview = createClient<VerdinSchema>({
  url: 'https://cms.example.com',
  headers: { 'x-verdin-preview': token },
});
const { data } = await preview
  .collection('articles')
  .findOne(documentId, { status: 'draft' });
```

</TabItem>
</Tabs>

같은 헤더가 싱글 타입(`GET /api/<singularName>?status=draft`)에서도 동작합니다.

토큰이 허용하는 것:

- 만료될 때까지 소지자가 초안을 포함해 그 문서 하나를 읽을 수 있게 합니다.
- 다른 문서를 읽거나, 항목을 나열하거나, 무언가를 쓸 수 없습니다.
- 미리 보기 요청에 대한 응답은 절대 캐시되지 않습니다.

<Aside type="caution">
링크를 가진 누구나 토큰이 만료될 때까지 초안을 읽을 수 있습니다. 유효 기간을 짧게 두고, 미리 보기 링크를 공개된 곳에
공유하지 마세요.
</Aside>

미리 보기 페이지는 보통 `slug` 같은 필드로 항목을 찾습니다. 토큰은 `documentId`로 읽으므로 템플릿에 `{documentId}`도
넣거나, slug에서 id를 찾는 과정을 사이트 쪽에 두세요.

## Admin API

`GET /admin/api/content/{uid}/{documentId}/preview?locale=`는 편집기 버튼의 링크를 반환합니다.

```json
{ "data": { "url": "https://example.com/blog/hello-world?locale=en&preview=…", "token": "…", "expiresAt": "2026-09-29T11:00:00.000Z" } }
```

항목에 대한 읽기 권한이 필요하며, 기능이 꺼져 있거나 타입에 템플릿이 없으면 `404`로 응답합니다.

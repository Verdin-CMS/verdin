관리자는 편집기를 떠나지 않고 댓글 스레드에서 항목을 논의하고, 필드 하나에 댓글을 달고, 서로 멘션하고, 기한이
있는 작업을 할당할 수 있습니다. 이 가이드에서는 두 기능, 누가 무엇을 할 수 있는지, admin API를 다룹니다.
Strapi에는 이에 해당하는 기능이 없습니다.

## 시작하기 전에

- **설정 → 기능 → 댓글 및 작업**은 기본적으로 켜져 있습니다.
- 항목의 콘텐츠 타입을 읽을 수 있으면 그 댓글과 작업을 읽고 쓸 수 있습니다.
- 멘션된 관리자와 작업 담당자에게는 `[email]`로 이메일을 보냅니다. 기본 `log` 프로바이더에서는 이메일이 서버
  로그에만 기록됩니다. [설정 레퍼런스](/ko/reference/configuration/)를 참고하세요.

## 항목에 댓글 달기

<Steps>

1. 항목을 열고 **댓글**을 선택합니다. 버튼에 열린 스레드 수가 표시됩니다.
2. **댓글** 탭의 **새 댓글**에 씁니다. `@`를 입력하면 관리자를 멘션할 수 있습니다.
3. **댓글 남기기**를 선택하거나, Control 또는 Command와 Enter를 누릅니다.

</Steps>

필드 하나에 댓글을 달려면 필드 옆의 댓글 버튼(**_필드 이름_에 댓글**, 필드 이름이 들어감)을 쓰세요. 필드 스레드는 그
필드의 **_필드 이름_에 대해** 아래에 표시되며, **모두 표시**는 모든 스레드를 다시 나열합니다.

스레드에서 할 수 있는 일:

- **답글**.
- 논의가 끝나면 **해결**하고, 나중에 **다시 열기**. 해결된 스레드는 **해결된 스레드**로 옮겨집니다. 스레드의 첫
  댓글에서만 해결할 수 있습니다.
- 자신의 댓글에서 **댓글 편집**.
- 자신의 댓글에서 **댓글 삭제** 또는 **스레드 삭제**. Super Admin은 모든 댓글을 삭제할 수 있습니다.

로컬라이즈된 타입에서 댓글은 로케일별로 보관되며, 최대 10,000자까지 담을 수 있습니다.

## 관리자 멘션

멘션된 관리자는 항목을 읽을 수 있다면 댓글과 항목 링크가 담긴 이메일을 받습니다. 자기 자신을 멘션하면 이메일을
보내지 않습니다.

## 작업 할당

<Steps>

1. 같은 패널의 **작업** 탭을 열고 **새 작업**을 선택합니다.
2. **제목**과, 선택적으로 **설명**, **담당자**, **기한**을 입력합니다. 담당자는 항목을 읽을 수 있어야 합니다.
3. **작업 생성**을 선택합니다.

</Steps>

담당자에게 이메일을 보냅니다. 단, 자기 자신에게 할당한 경우는 제외입니다. 기한이 지난 작업은 기한 초과로
표시됩니다. 작업 행에서 완료로 표시하세요.

작업의 생성자와 담당자는 작업을 바꾸거나 완료할 수 있습니다. 삭제는 생성자만 할 수 있습니다. Super Admin은 모든
작업에 둘 다 할 수 있습니다.

여러 항목에 걸친 자신의 열린 작업을 보려면 홈 페이지에 **내 작업** 위젯을 추가하세요. **사용자 지정**을 선택한 뒤
**위젯 추가**를 선택합니다.

## 실시간으로 함께 작업하기

다른 관리자가 여러분이 열어 둔 항목에 댓글이나 작업을 추가, 해결, 삭제하면 패널에
**댓글이 업데이트되었습니다.** 또는 <strong>작업이 업데이트되었습니다.</strong>가 표시되고 변경 사항이 보입니다.

## Admin API

모든 라우트는 `/admin/api` 아래에 있습니다. `uid`, `documentId`, `locale`로 항목을 지정합니다.

| 라우트 | 하는 일 |
| --- | --- |
| `GET /comments?uid=&documentId=&locale=` | 항목의 스레드와 답글. |
| `POST /comments` | `{ uid, documentId, locale?, field?, parentId?, body }`. `parentId`를 주면 답글이 됩니다. |
| `PUT /comments/{id}` | `{ body }`. 자신의 댓글만. |
| `DELETE /comments/{id}` | 자신의 댓글, 또는 Super Admin이면 모든 댓글. |
| `POST /comments/{id}/resolve`, `POST /comments/{id}/reopen` | 스레드의 첫 댓글에서. |
| `GET /tasks?uid=&documentId=&locale=` | 항목의 작업. |
| `GET /tasks?mine=true&status=open` | 아직 읽을 수 있는 항목들에 걸친 자신의 작업. |
| `POST /tasks` | `{ uid, documentId, locale?, title, description?, assigneeId?, dueDate? }`, `dueDate`는 `YYYY-MM-DD`. |
| `PUT /tasks/{id}` | 생성자나 담당자. `title`, `description`, `assigneeId`, `dueDate`(`null`이면 비움), `status`(`open` 또는 `done`) 중 아무것이나. |
| `DELETE /tasks/{id}` | 생성자만(또는 Super Admin). |

댓글 본문에서 멘션은 `@[Name](user:12)`로 씁니다. `12`는 관리자의 id입니다.

<Aside type="note">
기능이 꺼져 있는 동안 라우트는 `404`로 응답합니다. 끄면 댓글과 작업이 숨겨지며, 다시 켤 때를 위해 보관됩니다.
</Aside>

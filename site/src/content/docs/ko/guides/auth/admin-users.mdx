관리자는 관리자 패널에 로그인하는 사람들입니다. 사이트와 앱의 [최종 사용자](/ko/guides/auth/end-users/)와는
별개입니다. 이 가이드에서는 첫 관리자를 만들고, 다른 관리자를 초대하고, 역할을 부여하고, 잠긴 관리자가 다시
들어올 수 있게 돕습니다.

## 시작하기 전에

- Verdin에는 환경 변수 `VERDIN_ADMIN_JWT_SECRET`과 `VERDIN_TOKEN_PEPPER`가 필요합니다. `verdin secrets`로 한
  번 생성하세요.
- 관리자를 관리하려면 **사용자 관리**(`users.manage`), 역할을 관리하려면 **역할 관리**(`roles.manage`)가
  필요합니다. [권한](/ko/reference/permissions/)을 참고하세요.
- 초대와 비밀번호 재설정은 `[email]`로 이메일을 보냅니다. 기본 `log` 프로바이더에서는 링크를 포함한 이메일이
  서버 로그에 기록됩니다.

## 첫 관리자 만들기

관리자 패널(기본값 `http://localhost:1337/admin/`)을 엽니다. 관리자가 없는 동안에는 첫 관리자를 요청하며, 이
관리자가 Super Admin이 됩니다. 비밀번호는 8~128자입니다.

브라우저 없이 하려면 CLI나 API를 쓰세요.

<Tabs>
<TabItem label="CLI">

```sh title="Terminal"
verdin admin create --email you@example.com
```

비밀번호는 `VERDIN_ADMIN_PASSWORD`에서 가져오거나 표준 입력에서 읽습니다. 이 명령은 Super Admin을 만들며, 첫
관리자뿐 아니라 언제든 동작합니다.

</TabItem>
<TabItem label="API">

```sh title="Terminal"
curl -X POST http://localhost:1337/admin/api/auth/register-first-admin \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"a long password"}'
```

이 라우트는 관리자가 없을 때만 동작합니다.

</TabItem>
</Tabs>

## 관리자 초대

<Steps>

1. **설정 → 사용자**를 열고 **사용자 추가**를 선택합니다.
2. 이메일과, 선택적으로 **이름**과 **성**을 입력합니다.
3. **역할**을 하나 이상 고릅니다.
4. 초대를 보내려면 **지금 비밀번호 설정**을 끈 채로 두고, 비밀번호를 직접 정하려면 켭니다.
5. **초대**(비밀번호를 정했다면 **저장**)를 선택합니다.

</Steps>

**초대 링크** 대화 상자는 링크와 함께 이메일로 보냈는지를 보여 줍니다. 보내지 않았다면 직접 공유하세요. `log`
프로바이더에서는 항상 그렇습니다. 링크는 7일 동안 한 번 쓸 수 있습니다. 초대받은 관리자가 링크를 열고,
비밀번호를 정하면 로그인됩니다.

관리자가 한 번도 로그인하지 않았다면, 그 행의 **새 초대 링크**가 이전 링크를 대체합니다. 한 번이라도 로그인했다면
대신 비밀번호 재설정으로 접근을 되찾습니다.

## 역할

Verdin은 Strapi처럼 세 가지 역할을 만듭니다.

| 역할 | 할 수 있는 일 |
| --- | --- |
| **Super Admin** | 모든 것. 권한을 바꿀 수 없습니다. |
| **Editor** | 모든 콘텐츠를 생성, 편집, 게시, 삭제. 미디어 라이브러리 관리. 배포 실행. SEO, 리디렉션, 메뉴, 폼 관리. |
| **Author** | 콘텐츠를 만들고, 자신의 항목과 파일을 편집·삭제. 게시할 수 없습니다. |

**설정 → 역할**에서 **새 역할**로 더 만들 수 있습니다. 역할마다 다음을 고릅니다.

- **콘텐츠**: 콘텐츠 타입마다(또는 **모든 콘텐츠 타입**) **읽기**, **생성**, **수정**, **삭제**, **게시**의
  수준: **접근 불가**, **본인**(관리자가 만든 항목만), **전체**. **필드**는 작업을 일부 필드로, **언어**는 일부
  로케일로 제한합니다.
- **미디어 라이브러리**: **모든 파일** 또는 **본인 파일**에 대한 파일 작업.
- **설정**: **사용자 관리**나 **감사 로그 읽기** 같은 관리 영역에 대한 접근.
- **2단계 인증 필수**: [2단계 인증](/ko/guides/auth/two-factor/)을 참고하세요.

역할이 여러 개인 관리자는 권한의 합집합을 받습니다. 전체 목록은 [권한 레퍼런스](/ko/reference/permissions/)에
있습니다.

Super Admin 역할을 부여하거나, 다른 Super Admin을 편집, 삭제, 재설정할 수 있는 것은 Super Admin뿐입니다.

## 관리자 비활성화 또는 삭제

**설정 → 사용자**에서 관리자를 편집하고 **활성**을 끄세요. 비활성 사용자는 로그인할 수 없습니다. **삭제**는
계정을 완전히 지웁니다. 그 관리자의 댓글은 삭제된 관리자가 쓴 것으로 표시됩니다.

## 비밀번호 재설정

- **관리자가 직접 재설정:** 로그인 페이지의 <strong>비밀번호를 잊으셨나요?</strong>가 1시간 동안 유효한 링크를 이메일로
  보냅니다. 비밀번호가 바뀌면 계정의 모든 세션이 끝납니다.
- **다른 관리자가 설정:** **설정 → 사용자**에서 관리자를 편집하고 새 비밀번호를 입력합니다. 현재 비밀번호를
  유지하려면 입력란을 비워 두세요.
- **서버에서:** 아무도 로그인할 수 없을 때는 다음을 실행합니다.

  ```sh title="Terminal"
  verdin admin reset-password --email you@example.com
  ```

  비밀번호는 `VERDIN_ADMIN_PASSWORD`나 표준 입력으로 줍니다. 비밀번호를 설정하고, 계정 잠금을 풀고, 세션을
  끝냅니다. 2단계 인증은 제거하지 않습니다. 두 번째 인증 수단을 잃어버린 관리자는 다른 관리자가
  [재설정](/ko/guides/auth/two-factor/)해 주어야 합니다.

## 로그인 보호

- 비밀번호를 연속 5번 틀리면 계정이 15분 동안 잠깁니다.
- 로그인, 가입, 토큰 갱신 요청은 클라이언트 IP별로 `[admin].auth_rate_limit`(기본 분당 20회)으로 제한됩니다.
- 관리자 세션은 15분짜리 액세스 토큰이며, 30일 동안 유지되는 리프레시 쿠키로 갱신됩니다. 쿠키는
  `verdin start`에서 `Secure`입니다. `[admin].secure_cookies`를 참고하세요.

각 관리자는 **프로필**의 **세션**에서 로그인한 기기를 보고, 하나 또는 다른 기기 전부를 **로그아웃**할 수
있습니다. 비밀번호를 바꾸면 다른 모든 기기가 로그아웃됩니다.

## Admin API

로그인해서 admin API용 액세스 토큰을 받습니다.

```sh title="Terminal"
curl -X POST http://localhost:1337/admin/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"…"}'
# → { "data": { "user": {…}, "accessToken": "…", "accessTokenExpiresAt": "…" } }
```

| 라우트 | 권한 | 하는 일 |
| --- | --- | --- |
| `GET /users`, `GET /users/{id}` | `users.manage` | 역할을 포함한 관리자. |
| `POST /users` | `users.manage` | `{ email, firstname?, lastname?, roles: [ids], isActive?, password? }`. `password`가 없으면 응답의 `meta`에 `inviteUrl`과 `emailed`가 있습니다. |
| `PUT /users/{id}`, `DELETE /users/{id}` | `users.manage` | 관리자 변경 또는 삭제. |
| `POST /users/{id}/invite` | `users.manage` | 한 번도 로그인하지 않은 관리자를 위한 새 초대 링크. |
| `GET /roles`, `POST /roles`, `PUT /roles/{id}`, `DELETE /roles/{id}` | `roles.manage` | 역할과 그 권한. |
| `POST /auth/forgot-password` | 공개 | `{ email }`. 항상 `204`로 응답합니다. |
| `GET /auth/sessions`, `DELETE /auth/sessions/{id}` | 로그인 필요 | 자신의 세션. |

모든 라우트는 `/admin/api` 아래에 있습니다. [admin API](/ko/api/admin/)를 참고하세요.

<Aside type="caution">
시크릿은 절대 `verdin.toml`에 넣지 마세요. 두 시크릿은 재시작과 인스턴스에 걸쳐 바꾸지 마세요.
`VERDIN_ADMIN_JWT_SECRET`은 액세스 토큰, 최종 사용자의 JWT, 미리 보기 링크에 서명하고, `VERDIN_TOKEN_PEPPER`는
API 토큰과 두 번째 인증 수단을 보호합니다([API 토큰](/ko/guides/auth/api-tokens/) 참고).
</Aside>

**폼** 기능은 폼 서비스 없이 사이트의 폼(문의, 뉴스레터 가입, 이벤트 등록)을 처리합니다. 편집자가 관리자 패널에서
필드를 정의하고, 사이트는 이를 렌더링해 Verdin으로 제출하며, 제출 내용은 검증, 저장, 이메일 발송, CSV 내보내기를
거칩니다.

## 켜기

**설정 → 기능**에서 **폼**을 켠 뒤 **폼 관리**를 선택합니다(또는 **설정 → 폼**으로 이동). 폼을 관리하고 제출 내용을
읽으려면 기본 제공 Editor 역할이 가진 **SEO, 리디렉션, 메뉴, 폼 관리** 권한(`site.manage`)이 필요합니다.
[권한](/ko/reference/permissions/)을 참고하세요.

알림 이메일을 쓰려면 [`[email]`](/ko/reference/configuration/)에서 프로바이더를 설정하세요. 기본 `log`
프로바이더에서는 이메일이 서버 로그에만 기록됩니다.

## 폼 만들기

<Steps>

1. **설정 → 폼**에서 **새 폼**을 선택합니다.
2. 이름(예: **문의**)과 **슬러그**(`contact`)를 줍니다. 슬러그는 폼 URL의 일부입니다.
3. **필드** 탭에서 필드마다 **필드 추가**를 선택하고 **레이블**, **이름**, **유형**, **필수**, **자리 표시자**,
   **최대 길이**를 지정합니다.
4. **설정** 탭에서 다음을 설정합니다.
   - **알림**: 모든 제출 내용을 받을 이메일 주소.
   - **성공 메시지**: 제출 후 사이트에 반환되는 메시지.
   - **스팸 트랩**: 기본적으로 켜짐([스팸](#스팸) 참고).
5. 저장합니다. **연동** 탭에 공개 엔드포인트와 복사할 수 있는 예제가 표시됩니다.

</Steps>

| 유형 | 관리자 패널의 레이블 | 받는 값 |
| --- | --- | --- |
| `text` | **텍스트** | 아무 텍스트. |
| `email` | **이메일** | 이메일 주소. |
| `textarea` | **긴 텍스트** | 아무 텍스트. |
| `number` | **숫자** | 숫자로 저장되는 숫자. |
| `select` | **선택** | **옵션**(한 줄에 하나) 중 하나. |
| `checkbox` | **체크박스** | `true`, `on`, `1`, `yes`는 체크됨, 그 밖에는 체크 안 됨. 필수 체크박스는 체크되어야 합니다. |
| `date` | **날짜** | 아무 텍스트(`<input type="date">`를 쓰세요). |
| `url` | **URL** | URL. |
| `tel` | **전화번호** | 아무 텍스트. |

필드 이름은 문자로 시작하고 그 뒤에 문자, 숫자, `_`가 오며, 폼 안에서 고유합니다. 폼에는 필드가 1~50개 있습니다.
값은 최대 **최대 길이**자입니다(기본 5,000, 최대 20,000).

## 폼 렌더링

`GET /api/_forms/{slug}`는 정의를 반환하므로, 사이트가 편집자가 고른 필드를 렌더링할 수 있습니다.

```json
{
  "data": {
    "slug": "contact",
    "name": "Contact",
    "fields": [
      { "name": "email", "label": "Email", "type": "email", "required": true },
      { "name": "message", "label": "Message", "type": "textarea", "required": true, "maxLength": 2000 },
      { "name": "topic", "label": "Topic", "type": "select", "options": ["Sales", "Support"] }
    ],
    "honeypot": "_gotcha"
  }
}
```

스팸 트랩이 꺼져 있으면 `honeypot`은 `null`입니다. 정의는 1분 동안 캐시됩니다
(`Cache-Control: public, max-age=60`).

## 제출

`POST /api/_forms/{slug}`는 값을 JSON(필드, 또는 `{ "data": { … } }`)이나 일반 폼 전송
(`application/x-www-form-urlencoded`)으로 받습니다. 토큰은 필요 없습니다.

<Tabs syncKey="form">
<TabItem label="HTML 폼">

```html
<form method="post" action="https://cms.example.com/api/_forms/contact">
  <input name="email" type="email" required />
  <textarea name="message" required maxlength="2000"></textarea>
  <input name="_gotcha" tabindex="-1" autocomplete="off" aria-hidden="true" style="position:absolute;left:-9999px" />
  <button>Send</button>
</form>
```

</TabItem>
<TabItem label="fetch">

```js
const response = await fetch('https://cms.example.com/api/_forms/contact', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ data: { email, message, _gotcha: '' } }),
});
const body = await response.json();
if (response.ok) showThanks(body.data.message);
else showErrors(body.error.details.errors); // [{ path: ['email'], message: 'must be an email address' }]
```

</TabItem>
</Tabs>

| 응답 | 발생 조건 |
| --- | --- |
| `{ "data": { "message": … } }`와 함께 `201` | 받아들여졌습니다. `message`는 **성공 메시지** 또는 `Thank you!`입니다. |
| `400` `ValidationError` | 값이 없거나 잘못되었습니다. `details.errors`에 필드별 `{ path, message }`가 나열됩니다. |
| `404` | 그 슬러그의 폼이 없거나 기능이 꺼져 있습니다. |
| `413` | 제출 내용이 64 KB를 넘습니다. |
| `429` | 같은 방문자가 이 폼에 1분 동안 10번 넘게 제출했습니다. |

값은 앞뒤 공백을 잘라 내고 필드와 대조해 검사합니다. 알 수 없는 필드는 버리므로, 방문자가 요청하지 않은 데이터를
추가할 수 없습니다.

일반 HTML 폼 전송은 JSON 응답을 페이지로 받습니다. 더 나은 경험을 위해 `fetch`로 제출하고 메시지를 직접 보여 주세요.
브라우저에서 다른 출처로 제출하려면 사이트의 출처가 [`[api].cors_origins`](/ko/reference/configuration/)에 있어야
합니다.

### 스팸

**스팸 트랩**이 켜져 있으면 폼에 숨겨진 빈 `_gotcha` 필드를 추가하세요. 봇은 모든 필드를 채웁니다. `_gotcha`가 채워진
제출은 받아들여진 것처럼(`201`) 응답하고 버리므로 봇은 아무것도 알 수 없습니다. 요청 한도와 함께 쓰면 CAPTCHA 없이도
대부분의 폼 스팸을 막습니다.

## 제출 내용 읽기

폼의 **제출** 탭은 방문자가 보낸 내용을 **받은 시간**과 함께 나열합니다. 제출 내용을 삭제할 수 있고, **CSV 내보내기**는
전부 다운로드합니다.

받아들여진 모든 제출 내용은 관리자 패널의 제출 목록 링크([`[server].public_url`](/ko/reference/configuration/)로
만듦)와 함께 **알림** 주소로도 이메일로 보냅니다.

<Aside type="note">
Verdin은 각 제출의 값, 방문자의 user agent, 그리고 IP 주소 자체가 아닌 IP 주소의 키 해시를 저장합니다. 사람을 추적하지
않으면서 대량 제출을 알아챌 수 있을 정도입니다. 폼을 삭제하면 제출 내용도 삭제됩니다.
</Aside>

## Admin API

관리자 패널은 관리자의 액세스 토큰과 `site.manage`로 `/admin/api/site/forms`, `/admin/api/site/forms/{id}`, 그리고
`/admin/api/site/forms/{id}/submissions`와 `…/submissions/export`(CSV)를 씁니다. [Admin API](/ko/api/admin/)를
참고하세요.

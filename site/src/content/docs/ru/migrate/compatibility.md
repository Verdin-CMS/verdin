Verdin сохраняет модель контента и content API Strapi v5, чтобы фронтенды и контент могли
переехать (см. [Миграция со Strapi](/ru/migrate/from-strapi/)). Это не прямая замена
*кодовой базы* Strapi: среды выполнения JavaScript нет, поэтому собственный код переписывается
в виде плагинов WebAssembly. На этой странице для каждой области указан её статус на момент
Verdin 0.10.0.

**Поддерживается** — работает как в Strapi v5 (отличия указаны). **Частично** — покрывает
типичные случаи; в примечании сказано, чего не хватает. **Не поддерживается** — аналога нет.

## Модель контента

| Функция | Статус | Примечания |
| --- | --- | --- |
| Типы-коллекции и одиночные типы | Поддерживается | Файлы схемы JSON, близкие к Strapi (`schema/content-types/*.json`). См. [Модель контента](/ru/concepts/content-model/). |
| Скалярные типы атрибутов | Поддерживается | `string`, `text`, `richtext` (Markdown), `blocks`, `email`, `uid`, `integer`, `biginteger`, `float`, `decimal`, `boolean`, `date`, `time`, `datetime`, `enumeration`, `json`, `password`. `timestamp` из Strapi импортируется как `datetime`. |
| Компоненты и динамические зоны | Поддерживается | Включая медиа и связи `oneWay`/`manyWay` внутри компонентов. |
| Связи | Поддерживается | Один/много к одному/многим, односторонние, а также полиморфные `morphToOne`, `morphToMany`, `morphOne`, `morphMany`. |
| Медиаполя | Поддерживается | Один файл или несколько, `allowedTypes`. |
| `unique` | Частично | Не для атрибутов `text`, `richtext`, `blocks` и `json`. |
| Условные поля (`conditions`) | Поддерживается | Условия JSON Logic из Strapi 5.17; скрытые поля не обязательны. |
| Пользовательские поля | Частично | Атрибуты `customField` работают; поле ввода в админке предоставляет [плагин](/ru/extending/plugins/) Verdin, а не React-плагины Strapi. |
| Конструктор типов содержимого | Поддерживается | Только в режиме разработки (`verdin dev`), как в Strapi. |

## REST API

| Функция | Статус | Примечания |
| --- | --- | --- |
| Маршруты CRUD | Поддерживается | `GET`/`POST /api/{pluralName}`, `GET`/`PUT`/`DELETE /api/{pluralName}/{documentId}`, одиночные типы по `/api/{singularName}`. Ответы содержат `data` и `meta`, ошибки — объект `error` Strapi. |
| `filters` | Поддерживается | Все операторы Strapi: `$eq`, `$eqi`, `$ne`, `$nei`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$notIn`, `$contains`, `$notContains`, `$containsi`, `$notContainsi`, `$null`, `$notNull`, `$between`, `$startsWith(i)`, `$endsWith(i)`, `$and`, `$or`, `$not`; через связи, компоненты, повторяемые компоненты и динамические зоны (`__component`). |
| `sort` | Поддерживается | Несколько полей, `:asc`/`:desc` и поле связи «к одному» (`author.name:asc`). |
| `pagination` | Поддерживается | `page`/`pageSize` или `start`/`limit`, `withCount`. `pageSize` ограничен `[api].max_page_size` (100). |
| `fields` | Поддерживается | |
| `populate` | Поддерживается | `*`, списки, вложенные объекты, `on` для динамических зон, `count`. Глубина до 5; не больше 1000 подгружаемых записей на связь. |
| `status` | Поддерживается | `published` (по умолчанию) или `draft`; для чтения черновиков нужно разрешение `readDrafts`. |
| `locale` | Поддерживается | См. i18n ниже. |
| `hasPublishedVersion` | Поддерживается | |
| Полнотекстовый поиск `_q` | Поддерживается | `$containsi` по текстовым полям, как в Strapi; ранжированный поиск с `[search]`. |
| Запись связей | Поддерживается | ID, `connect` / `disconnect` / `set`, с `position` (`before`, `after`, `start`, `end`). |
| Публикация, снятие с публикации, отмена черновика | Поддерживается | Запись публикует, если нет `?status=draft`, как в Strapi v5. Verdin добавляет `POST /api/{pluralName}/{documentId}/actions/{publish,unpublish,discard-draft}`. |
| Формат ответов Strapi v4 и `publicationState` | Не поддерживается | Verdin работает только с v5: плоские атрибуты, `documentId`, `status`. |
| Документ OpenAPI | Частично | По адресу `/api/_openapi.json` (по умолчанию только по токену) и интерактивный справочник на `/api/docs` вместо `/documentation` плагина документации. |

## GraphQL

| Функция | Статус | Примечания |
| --- | --- | --- |
| Запросы | Поддерживается | `articles`, `articles_connection` с `pageInfo`, `article(documentId)`, одиночные типы; `filters`, `sort`, `pagination`, `status`, `locale`. Выключено, пока вы не включите **Настройки → Функции → GraphQL**. |
| Мутации | Поддерживается | `create…`, `update…`, `delete…` со `status` и `locale`. |
| Компоненты, динамические зоны, медиа | Поддерживается | Динамические зоны как объединения (union), медиа как `UploadFile`. |
| Полиморфные связи | Частично | Возвращаются как JSON, а не как типизированные объединения. |
| Shadow CRUD (отключение операций по типам) | Поддерживается | Настройка функции `disabled`. |
| Собственные резолверы и расширения схемы | Частично | Корневые поля, разрешаемые плагинами (`[[graphql]]` в `plugin.toml`); `extensionService` нет. |
| Мутации Users & Permissions (`login`, `register`, `me`…) | Не поддерживается | Используйте маршруты REST. |
| Запросы и мутации загрузки и i18n (`uploadFiles`, `i18NLocales`…) | Не поддерживается | Используйте маршруты REST (`GET /api/i18n/locales`) и админ-панель. `localizations` в локализованных типах поддерживается. |
| Ограничения, GraphiQL | Поддерживается | `maxDepth`, `maxComplexity`, переключатели интроспекции и песочницы. |

## Users & Permissions (конечные пользователи)

Включите **Настройки → Функции → Пользователи и права**. См.
[Конечные пользователи](/ru/guides/auth/end-users/).

| Функция | Статус | Примечания |
| --- | --- | --- |
| `POST /api/auth/local`, `/auth/local/register` | Поддерживается | Тот же формат запросов и ответов. |
| Подтверждение email, забытый пароль, сброс и смена пароля | Поддерживается | `/auth/email-confirmation`, `/auth/send-email-confirmation`, `/auth/forgot-password`, `/auth/reset-password`, `/auth/change-password`. |
| Refresh-токены | Поддерживается | `jwtManagement: "refresh"`, `/auth/refresh`, `/auth/logout`. |
| `/api/users`, `/users/me`, `/users/count` | Поддерживается | Обычный JSON, разрешения на `plugin::users-permissions.user`. |
| Провайдеры OAuth | Частично | GitHub, Google, Microsoft, Discord, Facebook, GitLab, LinkedIn и любой провайдер OAuth 2; не все пресеты Strapi. |
| Маршруты ролей и разрешений (`/api/users-permissions/roles`, `/permissions`) | Не поддерживается | Управляйте ролями в **Настройки → Конечные пользователи**. |
| Импортированные пользователи | Поддерживается | Хеши bcrypt продолжают работать; при входе они пересчитываются в Argon2id. |

## Медиатека и API загрузки

| Функция | Статус | Примечания |
| --- | --- | --- |
| `POST /api/upload` | Поддерживается | Multipart `files` и `fileInfo`; `?id=` обновляет сведения о файле или заменяет файл, если он передан. |
| Связывание при загрузке (`ref`, `refId`, `field`) | Не поддерживается | Загрузите файл, затем задайте медиаполе через id файла. |
| `GET /api/upload/files`, `/files/{id}`, `DELETE /files/{id}` | Частично | Список принимает только `pagination[page]`, `pagination[pageSize]`, `sort` и `filters[name][$containsi]`. |
| Адаптивные форматы, breakpoints | Поддерживается | `thumbnail` плюс `[upload].breakpoints`. |
| Папки, фокусные точки, альтернативный текст, подписи | Поддерживается | |
| Провайдеры загрузок | Частично | Локальный диск и S3-совместимое хранилище (AWS, R2, B2, MinIO, Tigris…). Нет Cloudinary и пакетов других провайдеров. |
| Преобразования изображений | Только в Verdin | `/uploads/<file>?preset=…` и подписанные URL (локальный провайдер). |

## Интернационализация

| Функция | Статус | Примечания |
| --- | --- | --- |
| Локализованные типы и нелокализуемые поля | Поддерживается | `pluginOptions.i18n.localized`, в том числе для отдельных атрибутов. |
| `?locale=` в REST, `locale` в GraphQL | Поддерживается | Неизвестная локаль — `400`. |
| `localizations` в ответах | Поддерживается | Только при подгрузке (`populate=localizations`, `populate=*`), с теми же параметрами, что у связи. Также поле GraphQL. Admin API его не возвращает. |
| `GET /api/i18n/locales` | Поддерживается | Простой массив в формате Strapi. Нужно `find` на `plugin::i18n.locale` (строка **Локали** в сетке разрешений), как для `listLocales` в Strapi. `documentId` выводится из кода локали. Локали управляются в админке (**Настройки → Интернационализация**). |

## Черновики и публикация

| Функция | Статус | Примечания |
| --- | --- | --- |
| Черновая и опубликованная версии документа | Поддерживается | Для каждой локали. См. [Черновики и публикация](/ru/concepts/draft-and-publish/). |
| Отмена черновика | Поддерживается | |
| Публикация по расписанию | Поддерживается | Через [Релизы](/ru/guides/content/releases/). |

## Настройка сервера

О том, как перенести каждый из этих пунктов, см. [Перенос собственного кода](/ru/migrate/porting-custom-code/).

| Strapi | Статус | Verdin |
| --- | --- | --- |
| Lifecycle-хуки, middleware Document Service | Частично | Хуки «до» и «после» в плагинах WebAssembly, которые могут изменить или отклонить запись. Без JavaScript. |
| Собственные контроллеры, сервисы, маршруты | Частично | Маршруты плагинов под `/api/plugins/<name>/`. |
| Политики и middleware | Не поддерживается | Разрешения и ограничения частоты встроены. |
| `register` / `bootstrap` | Частично | Функция запуска плагина, которая выполняется при старте плагина, его включении или изменении настроек; она может наполнять контент и заменять разрешения публичной роли. |
| Cron-задачи | Частично | Задания плагинов. |
| Document Service / Entity Service на JavaScript | Не поддерживается | Нет среды выполнения JavaScript. |
| npm-плагины из маркетплейса Strapi | Не поддерживается | |
| Вебхуки | Поддерживается | С подписью, повторными попытками и журналом; `entry.draft-discard` — это `entry.discard-draft`. См. [Вебхуки](/ru/guides/integrations/webhooks/). |
| API-токены (только чтение, полный доступ, настраиваемые) | Поддерживается | Те же виды, необязательный срок действия, перевыпуск. |
| Transfer-токены, `strapi transfer` | Не поддерживается | Используйте `verdin export` и `verdin import verdin`. |
| Файлы `strapi export` | Поддерживается (импорт) | `verdin import strapi`; зашифрованные экспорты не читаются. |
| `config/*.js`, `.env` | Частично | `verdin.toml` и переменные окружения. |
| Типы TypeScript | Поддерживается | `verdin types`. |
| Почтовые провайдеры | Частично | SMTP, Resend и Postmark. |

## Админ-панель

| Функция | Статус | Примечания |
| --- | --- | --- |
| Менеджер контента, медиатека, конструктор типов содержимого | Поддерживается | Собственная панель на Angular, а не React-админка Strapi. |
| Администраторы, роли, пользовательские роли | Поддерживается | Встроены Super Admin, Editor и Author, плюс пользовательские роли. |
| Разрешения на уровне полей и локалей | Поддерживается | |
| Условия RBAC | Частично | Только встроенное условие `is-creator`; собственных условий нет. |
| Настройка админки (`src/admin/app`) | Частично | Логотип, favicon, заголовок, акцентный цвет и тексты в `[admin.branding]`; виджеты и пользовательские поля — из плагинов. Нет собственных страниц, зон внедрения и расширений на React. |
| Admin API (`/admin/…`) | Не поддерживается | Admin API Verdin свой; не стройте решения на admin API Strapi. |
| Настройка представлений редактирования и списков | Поддерживается | |

## Функции Enterprise

Всё в Verdin — открытый исходный код; в Strapi это функции Enterprise или платные функции.

| Функция Strapi | Статус | Примечания |
| --- | --- | --- |
| SSO | Частично | Провайдеры OpenID Connect с сопоставлением групп и ролей. Нет SAML и других стратегий passport. См. [Единый вход](/ru/guides/auth/sso/). |
| Журналы аудита | Поддерживается | См. [Журналы аудита](/ru/guides/content/audit-logs/). |
| Процессы проверки | Поддерживается | Роли этапов ограничивают, кто перемещает записи *на* этап, а обязательный этап публикации действует для всех API. См. [Процессы проверки](/ru/guides/content/review-workflows/). |
| Релизы | Поддерживается | По расписанию или сразу. |
| История содержимого | Поддерживается | `[history].max_versions` версий на документ. |
| Предпросмотр и живой предпросмотр | Поддерживается | URL предпросмотра с короткоживущими токенами, предпросмотр рядом с формой и [визуальное редактирование](/ru/guides/frontend/visual-editing/). |
| Пользовательские роли администраторов | Поддерживается | Без ограничения на их число. |

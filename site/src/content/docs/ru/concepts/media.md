В медиатеке хранятся изображения, видео, аудио и другие файлы, которые использует ваш
контент. На этой странице описано, как файлы хранятся, описываются и связываются с
документами. Как отдавать изображения с изменённым размером на сайте, см. в разделе
[Изображения](/ru/guides/frontend/images/).

## Файлы

Каждая загрузка — это запись файла в формате Strapi, поэтому фронтенды, написанные для
Strapi, читают её без изменений (`formats` сокращён):

```json
{
  "id": 5,
  "documentId": "v3k…",
  "name": "harbour.jpg",
  "alternativeText": "Boats in the harbour at dawn",
  "caption": null,
  "width": 2400,
  "height": 1600,
  "focalPoint": { "x": 0.4, "y": 0.6 },
  "formats": {
    "thumbnail": { "url": "/uploads/harbour_thumbnail_4f1c.jpg", "width": 234, "height": 156 },
    "large": { "url": "/uploads/harbour_large_4f1c.jpg", "width": 1000, "height": 667 }
  },
  "hash": "harbour_4f1c",
  "ext": ".jpg",
  "mime": "image/jpeg",
  "size": 812.4,
  "url": "/uploads/harbour_4f1c.jpg",
  "previewUrl": null,
  "provider": "local",
  "provider_metadata": null,
  "createdAt": "2026-09-25T09:00:00.000Z",
  "updatedAt": "2026-09-25T09:00:00.000Z",
  "publishedAt": "2026-09-25T09:00:00.000Z"
}
```

- `size` указан в килобайтах, как в Strapi.
- MIME-тип определяется по байтам файла, а не по тому, что заявляет клиент.
- `focalPoint` отмечает часть изображения, которая должна остаться в кадре при обрезке.

У файлов нет черновиков: загруженный файл доступен сразу после сохранения.

## Медиатека

В админ-панели **Медиатека** показывает файлы с поиском, фильтрами по типу и папками.
Администраторы загружают файлы, импортируют их по URL, редактируют имя, альтернативный текст,
подпись и фокусную точку, заменяют содержимое файла с сохранением его id и видят, **где он
используется**: в медиаполях, в медиа внутри компонентов, в блоках rich text и в Markdown,
который содержит его URL.

**Папки** упорядочивают медиатеку для редакторов. Объекты файлов в ответах API их не
показывают, но при загрузке через content API можно указать id папки в `fileInfo`. Удаление
папки удаляет файлы в ней.

Доступ администраторов управляется разрешениями `media.read`, `media.create`,
`media.update` и `media.delete`. Встроенная роль Author может редактировать и удалять только
загруженные ею файлы. См. [Разрешения](/ru/concepts/permissions/).

## Медиаполя

Тип содержимого связывает файлы через атрибут `media`:

```json
"cover": { "type": "media", "allowedTypes": ["images"] },
"gallery": { "type": "media", "multiple": true, "allowedTypes": ["images", "videos"] }
```

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `multiple` | `false` | Хранить список файлов вместо одного. |
| `allowedTypes` | любой файл | Любые из `images`, `videos`, `audios` и `files` (всё остальное); проверяется при каждой записи по сохранённому MIME-типу. |

Медиаполя ведут себя как связи: у каждой версии документа свои ссылки, публикация копирует
их, а `required` проверяется при публикации. Они хранятся в отдельной таблице связей для
каждого поля. Внутри [компонентов](/ru/concepts/components-and-dynamic-zones/) вместо этого id
файлов хранятся в JSON компонента.

При записи передавайте id файлов: `5`, `{ "id": 5 }`, `[5, 6]` или `null`, чтобы очистить
поле. При чтении медиаполя возвращаются, только если их подгрузить (`populate=cover`), в виде
объектов файлов. Удаление файла убирает его из всех документов, где он использовался.

## Форматы изображений

При загрузке растрового изображения Verdin создаёт форматы Strapi в исходном формате
изображения с учётом его ориентации EXIF:

| Формат | Размер |
| --- | --- |
| `thumbnail` | Вписывается в 245 × 156 |
| `large` | 1000 px в ширину |
| `medium` | 750 px в ширину |
| `small` | 500 px в ширину |

Формат пропускается, если оригинал не больше его. `[upload].breakpoints` меняет ширины и
имена, а `responsive_formats = false` отключает форматы. `max_original_size` уменьшает
большие оригиналы при загрузке, что также удаляет их метаданные (EXIF, GPS).
`max_image_megapixels` (по умолчанию 100) отклоняет изображения, декодирование которых
потребовало бы слишком много памяти. С локальным провайдером `/uploads` также может менять
размер и формат изображений по запросу; см. [Изображения](/ru/guides/frontend/images/).

## Провайдеры хранилища

Файлы хранит провайдер, который задаётся в `[upload].provider`:

| Провайдер | Где хранит файлы | Откуда отдаёт |
| --- | --- | --- |
| `local` (по умолчанию) | В `public/uploads` (параметр `dir`) относительно проекта | По адресу `/uploads` на сервере Verdin |
| `s3` | В любом S3-совместимом бакете: AWS S3, Cloudflare R2, Backblaze B2, MinIO, RustFS… | С `public_url` бакета или CDN |

```toml title="verdin.toml"
[upload]
provider = { name = "s3", bucket = "media", region = "auto",
             endpoint = "https://<account>.r2.cloudflarestorage.com",
             public_url = "https://media.example.com" }
```

Учётные данные S3 берутся из стандартных переменных окружения `AWS_*`, а не из
`verdin.toml`. Все параметры описаны в
[справочнике по конфигурации](/ru/reference/configuration/).

Сохранённые имена имеют вид `{slug}_{random}{ext}` и никогда не меняются, поэтому URL можно
кешировать навсегда. При нескольких экземплярах Verdin используйте S3: локальные файлы есть
только на том экземпляре, который их принял.

## Безопасность

- Загрузки записываются потоком во временные файлы, а не держатся в памяти, и ограничены
  `[upload].max_file_size` (по умолчанию 200 МБ), не больше 20 файлов на запрос.
- Файлы, которые отдаются из `/uploads`, получают заголовки
  `Content-Security-Policy: sandbox` и `X-Content-Type-Options: nosniff`. Всё, что не является
  изображением, видео, аудио, PDF или простым текстом, отдаётся как загрузка, поэтому
  загруженный файл HTML или SVG не может выполнять скрипты на вашем домене. В S3 объекты таких
  типов тоже сохраняются как загрузки.

## Медиа через content API

У content API есть маршруты загрузки Strapi, которые проверяются по правам на **Медиатеку**
(`plugin::upload`):

| Маршрут | Право |
| --- | --- |
| `POST /api/upload` (multipart `files`, необязательный `fileInfo`) | `create` |
| `POST /api/upload?id={id}` (новый `fileInfo`, при необходимости новый файл) | `update` |
| `GET /api/upload/files` | `find` |
| `GET /api/upload/files/{id}` | `findOne` |
| `DELETE /api/upload/files/{id}` | `delete` |

Как и в Strapi, они отвечают обычными объектами файлов и массивами, без обёртки `data`. См.
[REST API](/ru/api/rest/#медиатека). Изменения отправляют события `media.create`,
`media.update` и `media.delete` [вебхуков](/ru/api/webhooks/) и
[реального времени](/ru/api/realtime/).

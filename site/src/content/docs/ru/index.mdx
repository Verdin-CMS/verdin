## Со Strapi за три команды

Экспортируйте проект Strapi, импортируйте его в новый проект Verdin и запустите. Переносятся
типы содержимого, записи с черновиками и локалями, связи и медиатека; content API сохраняет
свою форму, поэтому фронтенд продолжает работать.

```sh title="Terminal"
npx strapi export --no-encrypt -f my-export        # в проекте Strapi
verdin new my-site && cd my-site && verdin import strapi ../my-export.tar.gz
verdin dev                                         # http://localhost:1337/admin
```

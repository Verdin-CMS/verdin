Функция **Меню** даёт редакторам именованные деревья навигации (шапка, подвал, боковая
панель) со ссылками на страницы, записи или другие сайты. Ваш сайт запрашивает меню по slug и
выводит его; ссылки на записи учитывают их статус публикации и путь.

В Strapi для этого обычно нужен плагин навигации или самодельный тип содержимого для меню; в
Verdin это встроено.

## Включите функцию

В **Настройки → Функции** включите **Меню**, затем выберите **Управление меню** (или
перейдите в **Настройки → Меню**). Для управления меню нужно разрешение **Управление SEO,
редиректами, меню и формами** (`site.manage`), которое есть у встроенной роли Editor. См.
[Разрешения](/ru/reference/permissions/).

Чтобы ссылаться на записи по пути, настройте также шаблоны путей в разделе
[SEO и карта сайта](/ru/guides/frontend/seo-and-sitemap/).

## Соберите меню

<Steps>

1. В **Настройки → Меню** выберите **Новое меню**.
2. Задайте название (например, **Главная навигация**) и **Slug** (`main`): строчные буквы,
   цифры и дефисы. Сайты запрашивают меню по его slug.
3. Выберите **Добавить элемент** и заполните его:
   - **Метка**: текст ссылки, до 255 символов.
   - **Ссылается на**: **URL**, **Запись** или **Ничего (заголовок)**.
   - **URL**: путь (`/about`), якорь (`#team`) или ссылка `http(s)`, `mailto:` или `tel:`.
   - Для записи выберите **Выбрать запись**: укажите **Тип содержимого**, если можно
     связывать несколько, найдите запись и выберите её.
   - **Открывается в**: **Той же вкладке** или **Новой вкладке**.
4. Перетаскивайте элементы, чтобы менять порядок и вложенность, или используйте их кнопки. С
   клавиатуры на ручке перетаскивания: Alt+↑ и Alt+↓ перемещают элемент, Alt+→ вкладывает его
   в элемент выше, Alt+← выносит наружу.
5. Сохраните.

</Steps>

В меню не больше 5 уровней и 500 элементов.

## Запросите меню

Сайты читают меню из `GET /api/_menus/{slug}` без токена. Для локализованного контента
добавьте `?locale=`:

```sh title="Terminal"
curl 'https://cms.example.com/api/_menus/main?locale=fr'
```

```json
{
  "data": {
    "slug": "main",
    "name": "Main navigation",
    "items": [
      { "id": "a1", "label": "Blog", "url": "/blog" },
      {
        "id": "a2",
        "label": "Topics",
        "children": [
          {
            "id": "a3",
            "label": "Rust",
            "entry": { "uid": "api::category", "documentId": "hx2n8r3w…", "path": "/fr/topics/rust" },
            "url": "/fr/topics/rust"
          }
        ]
      },
      { "id": "a4", "label": "Contact", "url": "mailto:hello@example.com", "target": "_blank" }
    ]
  }
}
```

Как разрешаются ссылки на записи:

- Запись, которая не опубликована в запрошенной локали, исключается из меню (вместе с
  дочерними элементами). Черновики через меню никогда не утекают.
- `entry.path` строится по шаблону типа из [SEO и карта сайта](/ru/guides/frontend/seo-and-sitemap/),
  в который подставляются поля записи и локаль. Он равен `null`, если у типа нет шаблона или
  запись его не заполняет.
- Если у элемента нет собственного `url`, он получает путь в качестве `url`, поэтому
  большинству сайтов достаточно читать `url`.

Без `locale` записи читаются в локали по умолчанию. Ответ отправляется с
`Cache-Control: public, max-age=60`.

## Выведите меню

```tsx title="Nav.tsx"
type Item = { label: string; url?: string; target?: '_self' | '_blank'; children?: Item[] };

export async function Nav({ locale }: { locale: string }) {
  const response = await fetch(`${process.env.VERDIN_URL}/api/_menus/main?locale=${locale}`);
  const { data } = await response.json();
  return <ul>{data.items.map((item: Item) => <NavItem key={item.label} item={item} />)}</ul>;
}

function NavItem({ item }: { item: Item }) {
  return (
    <li>
      {item.url ? <a href={item.url} target={item.target}>{item.label}</a> : <span>{item.label}</span>}
      {item.children?.length ? <ul>{item.children.map((child) => <NavItem key={child.label} item={child} />)}</ul> : null}
    </li>
  );
}
```

<Aside type="note">
После удаления меню `/api/_menus/{slug}` отвечает `404`, как и при выключении функции.
Обрабатывайте это на сайте, например не выводя навигацию.
</Aside>

## Admin API

Админ-панель использует `/admin/api/site/menus` (`GET`, `POST`) и
`/admin/api/site/menus/{id}` (`GET`, `PUT`, `DELETE`) с токеном доступа администратора и
`site.manage`. См. [Admin API](/ru/api/admin/).

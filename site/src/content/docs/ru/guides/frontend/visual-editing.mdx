Визуальное редактирование превращает страницу предпросмотра в карту админ-панели: редактор
наводит курсор на заголовок, нажимает **Edit**, и открывается запись с фокусом на этом поле.
Оно строится поверх [предпросмотра](/ru/guides/content/preview/): сначала настройте URL
предпросмотра, затем добавьте на страницу предпросмотра две части, описанные ниже.

Verdin прячет в каждый возвращаемый текст небольшую невидимую карту источника (этот приём
называют *stega*), а скрипт наложения находит такие тексты на странице. В ваших компонентах
ничего не меняется: размеченный текст отображается как любой другой.

## Настройка

<Steps>

1. Включите **Предпросмотр** в **Настройки → Функции**, выберите **Настроить URL
   предпросмотра** и задайте каждому типу содержимого URL страницы, которая его выводит.
   Раздел **Визуальное редактирование** того же диалога показывает тег скрипта и заголовок
   для вашего сервера. См. [Предпросмотр](/ru/guides/content/preview/).

2. На странице предпросмотра запрашивайте контент с токеном и заголовком
   `x-verdin-stega: true`. Токен — это токен предпросмотра из URL предпросмотра
   (`?preview=…`, отправляется обратно как `x-verdin-preview`) или API-токен:

   ```js
   const response = await fetch(`${CMS}/api/articles/${documentId}?status=draft&populate=*`, {
     headers: {
       'x-verdin-preview': previewToken, // or Authorization: Bearer <API token>
       'x-verdin-stega': 'true',
     },
   });
   ```

3. Загрузите наложение на той же странице:

   ```html
   <script src="https://cms.example.com/admin/api/visual-editing.js" defer></script>
   ```

   Путь следует [`[admin].path`](/ru/reference/configuration/): `{path}/api/visual-editing.js`.

</Steps>

С [типизированным клиентом](/ru/guides/frontend/typed-client/) передайте оба заголовка в
`headers`:

```ts
const preview = createClient<VerdinSchema>({
  url: CMS,
  headers: { 'x-verdin-preview': previewToken, 'x-verdin-stega': 'true' },
});
const { data } = await preview.collection('articles').findOne(documentId, {
  status: 'draft',
  populate: '*',
});
```

Карты источника добавляются только к ответам REST, а не GraphQL: читайте контент
предпросмотра через REST API.

Наведите курсор на размеченный текст на странице: он получит зелёную обводку и кнопку
**Edit**. Внутри предпросмотра «рядом» в админке (**Открыть предпросмотр** → **Рядом**)
кнопка просит админку открыть поле прямо там. Если страница открыта отдельно, кнопка
открывает запись в новой вкладке.

<Aside type="note">
Карты источника добавляются только к запросам `GET`, которые отправляют
`x-verdin-stega: true` **и** токен (`Authorization` или `x-verdin-preview`). Публичный трафик
и всё, что кеширует ваш CDN, никогда их не содержат, а размеченные ответы отправляются с
`Cache-Control: private, no-store`.
</Aside>

## Что размечается

| Размечается | Не размечается |
| --- | --- |
| Атрибуты `string`, `text` и `richtext` | `uid`, `email`, `password`, `enumeration` |
| Первый текст каждого блока атрибута `blocks` | Числа, логические значения, даты, JSON |
| То же внутри компонентов и динамических зон (`seo.metaTitle`, `blocks.2.title`) | Пустые строки |
| Подгруженные связи, указывающие на связанную запись | Медиаполя |

Наложение также читает метки в атрибутах `alt` и `title`, поэтому размеченный текст, который
вы помещаете в один из них (например, поле подписи в качестве `alt`), остаётся кликабельным.

## Удаляйте метки там, где текст — это данные

Метки — это невидимые символы, добавленные в конец текста. Там, где вы используете значение
как данные, а не показываете его (ключ, URL, сравнение, проверка длины `<title>`), сначала
удалите их:

```js
const clean = (text) => text.replace(/⁤[​-‍⁠]*⁣/g, '');

if (clean(article.category.name) === 'News') { /* … */ }
```

Поля, которые по своей природе являются данными, например slug типа `uid` и перечисления,
никогда не размечаются, поэтому маршрутизация по `slug` работает как есть.

## Как кодируется метка

Для инструментов, которые читают метки сами: метка — это U+2064, затем каждый байт UTF-8
строки

```json
{"origin":"verdin","href":"https://cms.example.com/admin/content/api::article/<documentId>?locale=en&field=seo.metaTitle"}
```

в виде четырёх цифр в системе счисления по основанию 4 (старшая первой), записанных символами
U+200B, U+200C, U+200D и U+2060, затем U+2063. URL админки берётся из
[`[server].public_url`](/ru/reference/configuration/) и `[admin].path`. Наложение отправляет
`{ type: 'verdin:edit', href }` родительскому окну через `postMessage`; админка реагирует на
это, только если сообщение пришло с origin URL предпросмотра.

Действия ИИ добавляют в админ-панель четырёх помощников: перевод записи с другой локали,
альтернативный текст для изображения, краткое изложение длинного текста в короткое поле и
предложение SEO-метаданных. Они используют настроенного вами провайдера моделей (Anthropic,
OpenAI или локальный сервер, например Ollama) с вашим собственным ключом.

Каждое действие возвращает предложение, которое заполняет форму. Ничего не сохраняется, пока
редактор не проверит результат и не сохранит его, и каждое действие можно отменить.

## Настройка

Для действий ИИ нужны и провайдер в `verdin.toml`, и включённая функция.

<Steps>

1. Добавьте раздел `[ai]` и передайте ключ серверу в `VERDIN_AI_KEY`:

   <Tabs syncKey="ai-provider">
   <TabItem label="Anthropic">

   ```toml title="verdin.toml"
   [ai]
   provider = "anthropic"
   # model = "claude-sonnet-5"   # the default
   ```

   </TabItem>
   <TabItem label="OpenAI">

   ```toml title="verdin.toml"
   [ai]
   provider = "openai"
   model = "gpt-4.1-mini"        # required: name the model you want
   ```

   </TabItem>
   <TabItem label="Локальный (Ollama)">

   ```toml title="verdin.toml"
   [ai]
   provider = "openai-compatible"
   base_url = "http://localhost:11434/v1"
   model = "llama3.2-vision"
   ```

   Локальным серверам `VERDIN_AI_KEY` не нужен. LM Studio, vLLM и другие серверы с
   OpenAI-совместимым API работают так же.

   </TabItem>
   </Tabs>

   ```sh title="Terminal"
   export VERDIN_AI_KEY=sk-...
   ```

2. Перезапустите Verdin. Он не запустится, если раздел неполный: нет ключа или нет `model`
   либо `base_url` там, где они нужны провайдеру.
3. В **Настройки → Функции** включите **Действия ИИ**.

</Steps>

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `provider` | `"none"` | `anthropic`, `openai` или `openai-compatible`. |
| `model` | `claude-sonnet-5` для `anthropic` | Модель. Для остальных провайдеров обязательна. |
| `base_url` | Адрес провайдера | Другой эндпоинт: прокси или локальный сервер (обязателен для `openai-compatible`). |
| `max_tokens` | `2048` | Максимальная длина ответа в токенах. |

См. [`[ai]`](/ru/reference/configuration/). Если функция включена, но раздела `[ai]` нет,
админка показывает **Действия ИИ недоступны на этом сервере.**

Действие для альтернативного текста отправляет изображения, поэтому, если оно вам нужно,
выберите модель, которая принимает изображения.

## Что делают действия

### Перевод записи

В редакторе локализованной записи **Перевести с _локали_…** открывает **Перевести с помощью
ИИ**. Выберите локаль в поле **Перевести с** и нажмите **Перевести**. Текстовые поля
сохранённого черновика этой локали (строки, тексты, rich text, blocks и текст внутри
компонентов и динамических зон) переводятся на текущую локаль и заменяют эти поля в форме.

- Поля, общие для всех локалей, не трогаются.
- Несохранённые изменения в исходной локали не учитываются: сначала сохраните её.
- Markdown, HTML, URL, id и типы блоков сохраняются как есть.
- Переведённые поля помечаются; проверьте их, затем сохраните или выберите **Отменить
  перевод**.

Для этого нужно разрешение на изменение записи в целевой локали и на её чтение в исходной.

### Альтернативный текст

В медиатеке откройте изображение и выберите **Сгенерировать альтернативный текст**. Модель
описывает изображение (примерно до 125 символов) на языке локали по умолчанию и заполняет
подпись, если она пуста. Работает с изображениями JPEG, PNG, WebP и GIF и отправляет формат
`small` или `medium`, если он есть, чтобы большие оригиналы не загружались к провайдеру.
Нужно разрешение на изменение в медиатеке (на сам файл — для **Свои файлы**).

### Краткое изложение в поле

Текстовые поля, названные как краткое содержание (`description`, `summary`, `excerpt`,
`abstract`, `intro`, `introduction`, `lead`, `teaser`), получают кнопку **Кратко изложить
_поле_**, если у записи есть поле rich text или blocks либо текстовое поле с именем `body`,
`content`, `text` или `article`. В примере блога у **Excerpt** появляется **Кратко изложить
Body**. Краткое содержание укладывается в максимальную длину поля.

### Предложение SEO-метаданных

Компонент с текстовыми атрибутами `metaTitle` и `metaDescription`, например
[предлагаемый `shared.seo`](/ru/guides/frontend/seo-and-sitemap/), получает кнопку
**Предложить**. Она заполняет мета-заголовок, описание и, если в компоненте есть такое поле,
`keywords` по сохранённому черновику записи.

## Ограничения

- Каждый администратор может сделать 30 запросов к ИИ в минуту; на остальные приходит ответ
  **Слишком много запросов к ИИ. Подождите минуту и попробуйте снова.**
- Краткое изложение и предложения SEO отправляют не больше 40 000 символов текста.
- Запрос к провайдеру прерывается по тайм-ауту через 120 секунд.

## Конфиденциальность

<Aside type="caution">
Действия ИИ отправляют контент выбранному провайдеру: переводимые, излагаемые или
описываемые поля и изображения для альтернативного текста. Выбирайте провайдера и тариф,
которые ваша организация разрешает для такого контента, проверьте условия хранения данных и
рассмотрите локальную модель (`openai-compatible`) для контента, который не должен покидать
вашу сеть.
</Aside>

- Запросы идут от сервера Verdin к провайдеру; ключ никогда не попадает в браузер.
- Отправляются только входные данные действия: текстовые поля записи, текст для изложения или
  одно изображение с именем файла. Приватные атрибуты и другие записи не отправляются.
- Действия читают только то, что администратор и так может читать, а предложения не
  сохраняются.

Админка показывает, какая модель ответила (**Предложено моделью _model_ (_provider_).**).

Чтобы ИИ-агенты вне админки могли читать и записывать контент, см.
[MCP-сервер](/ru/guides/integrations/mcp/).

Администраторы могут обсуждать запись в темах комментариев, комментировать отдельное поле,
упоминать друг друга и назначать задачи со сроками, не выходя из редактора. В этом
руководстве описаны обе возможности, кто что может делать и admin API. В Strapi аналога нет.

## Перед началом

- **Настройки → Функции → Комментарии и задачи** по умолчанию включено.
- Чтобы читать и писать комментарии и задачи записи, достаточно права на чтение её типа
  содержимого.
- Упомянутые администраторы и исполнители задач получают письма через `[email]`. С
  провайдером `log` по умолчанию письма попадают только в лог сервера. См.
  [справочник по конфигурации](/ru/reference/configuration/).

## Прокомментируйте запись

<Steps>

1. Откройте запись и выберите **Комментарии**. Кнопка показывает число открытых тем.
2. На вкладке **Комментарии** напишите текст в поле **Новый комментарий**. Введите `@`, чтобы
   упомянуть администратора.
3. Выберите **Отправить** или нажмите Control или Command и Enter.

</Steps>

Чтобы прокомментировать одно поле, используйте кнопку комментария рядом с полем
(**Комментировать поле** и имя поля). Темы по полю показываются в разделе **О поле** с именем
поля; **Показать все** снова выводит все темы.

В теме можно:

- **Ответить**.
- **Решить** тему, когда обсуждение закончено, и позже **Открыть снова**. Решённые темы
  переходят в **Решённые темы**. Решает тему только её первый комментарий.
- **Изменить комментарий** — для своих комментариев.
- **Удалить комментарий** или **Удалить тему** — для своих комментариев. Super Admin может
  удалить любой комментарий.

Для локализованных типов комментарии хранятся отдельно для каждой локали и могут содержать до
10 000 символов.

## Упомяните администратора

Упомянутые администраторы получают письмо с комментарием и ссылкой на запись, если могут её
читать. За упоминание самого себя письмо не отправляется.

## Назначьте задачу

<Steps>

1. Откройте вкладку **Задачи** той же панели и выберите **Новая задача**.
2. Введите **Заголовок** и, при желании, **Описание**, **Ответственного** и **Срок
   выполнения**. Ответственный должен иметь право читать запись.
3. Выберите **Создать задачу**.

</Steps>

Ответственный получает письмо, если только не назначил задачу сам себе. Задачи с истёкшим
сроком помечаются как просроченные. Отметить задачу выполненной можно в её строке.

Создатель и ответственный могут менять или завершать задачу. Удалить её может только
создатель. Super Admin может делать и то и другое с любой задачей.

Чтобы видеть свои открытые задачи по всем записям, добавьте на главную страницу виджет
**Мои задачи**: выберите **Настроить**, затем **Добавить виджет**.

## Совместная работа в реальном времени

Когда другой администратор добавляет, решает или удаляет комментарий или задачу в открытой у
вас записи, панель сообщает **Комментарии обновлены.** или **Задачи обновлены.** и показывает
изменение.

## Admin API

Все маршруты находятся под `/admin/api`. `uid`, `documentId` и `locale` указывают запись.

| Маршрут | Что делает |
| --- | --- |
| `GET /comments?uid=&documentId=&locale=` | Темы записи с ответами. |
| `POST /comments` | `{ uid, documentId, locale?, field?, parentId?, body }`. `parentId` делает комментарий ответом. |
| `PUT /comments/{id}` | `{ body }`. Только свои комментарии. |
| `DELETE /comments/{id}` | Свои комментарии или любые для Super Admin. |
| `POST /comments/{id}/resolve`, `POST /comments/{id}/reopen` | Для первого комментария темы. |
| `GET /tasks?uid=&documentId=&locale=` | Задачи записи. |
| `GET /tasks?mine=true&status=open` | Ваши задачи по всем записям, которые вы ещё можете читать. |
| `POST /tasks` | `{ uid, documentId, locale?, title, description?, assigneeId?, dueDate? }`, где `dueDate` в формате `YYYY-MM-DD`. |
| `PUT /tasks/{id}` | Создатель или ответственный. Любые из `title`, `description`, `assigneeId`, `dueDate` (`null` очищает их) и `status` (`open` или `done`). |
| `DELETE /tasks/{id}` | Только создатель (или Super Admin). |

В тексте комментария упоминание записывается как `@[Name](user:12)`, где `12` — id
администратора.

<Aside type="note">
Пока функция выключена, маршруты отвечают `404`. Выключение скрывает комментарии и задачи; они
сохраняются до повторного включения.
</Aside>

Сводка для редакторов — это ежедневное письмо, в котором каждый администратор узнаёт, сколько
записей каждого типа содержимого изменилось с момента его последнего просмотра. Она выключена
для всех, пока каждый администратор не включит её сам. В этом руководстве описаны сторона
админки, настройки сервера и работа с несколькими экземплярами.

## Как работает «непросмотренное»

Запись становится для вас непросмотренной, когда её меняет кто-то другой через любой API. Она
снова считается просмотренной, как только вы её откроете. Эти же отметки управляют значками
**Новых** в боковой панели (их можно выключить через **Показывать значки новых элементов**) и
виджетом **Ещё не просмотренные** на главной странице.

## Включите сводку

<Steps>

1. Откройте свой **Профиль** (или меню настроек в верхней панели).
2. В разделе **Предпочтения** включите **Ежедневное письмо о непросмотренных изменениях**.

</Steps>

Переключатель задаёт в вашей учётной записи настройку `"digest": "daily"`
(`PUT /admin/api/users/me/preferences`). Выключается она так же.

Что вы получаете:

- Сообщение с числом непросмотренных записей по каждому типу содержимого, который вы можете
  читать, и ссылкой на админ-панель.
- Ничего в дни, когда нового нет.
- Только пока ваша учётная запись активна.

## Настройки сервера

Сводка отправляется в `[digest].hour_utc` через `[email]`:

```toml title="verdin.toml"
[email]
provider = "smtp"
from = "Verdin <no-reply@example.com>"

[email.smtp]
host = "smtp.example.com"

[digest]
hour_utc = 7    # 0–23, UTC; 8 by default
```

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `[digest].enabled` | `true` | Отправлять сводку с этого экземпляра. |
| `[digest].hour_utc` | `8` | Час (UTC), в который уходит сводка. |

Ссылка в письме использует `[server].public_url`; задайте его, когда Verdin работает за
прокси. С почтовым провайдером `log` по умолчанию сообщения только записываются в лог
сервера. См. [справочник по конфигурации](/ru/reference/configuration/).

## Несколько экземпляров

Каждый экземпляр с `[digest].enabled = true` пытается отправить сводку в заданный час. Первый,
кто забронирует день в базе данных, отправляет её, а остальные этот день пропускают, поэтому
администраторы получают одно письмо. Чтобы задание выполнялось на известном экземпляре,
задайте `enabled = false` на остальных:

```sh title="Terminal"
VERDIN_DIGEST__ENABLED=false verdin start
```

<Aside type="note">
Сводка — дополнение Verdin; в Strapi аналога нет.
</Aside>

Предпросмотр открывает черновик записи на вашем собственном сайте до публикации. Редактор
строит ссылку по шаблону URL для каждого типа содержимого и добавляет короткоживущий токен,
который позволяет сайту прочитать именно этот черновик. В этом руководстве настраиваются
шаблоны и сторона сайта.

Чтобы щёлкать по тексту в предпросмотре и переходить к его полю, добавьте поверх этого
[визуальное редактирование](/ru/guides/frontend/visual-editing/).

## Перед началом

- Включите **Настройки → Функции → Предпросмотр**. По умолчанию функция выключена.
- Для изменения настроек функции нужно **Управление функциями** (`features.manage`).
- Для открытия предпросмотра нужен доступ на чтение к записи. См.
  [Разрешения](/ru/reference/permissions/).

## Настройте URL предпросмотра

<Steps>

1. На карточке **Предпросмотр** в **Настройки → Функции** выберите **Настроить URL
   предпросмотра**.
2. В разделе **Шаблоны URL** укажите страницу сайта, которая показывает черновик каждого типа
   содержимого. Оставьте тип пустым, чтобы у него не было предпросмотра.
3. При желании измените **Срок действия ссылки (минуты)**: по умолчанию 60, не больше 10080
   (7 дней).
4. Сохраните.

</Steps>

Шаблон — это URL `http` или `https` с подстановками в фигурных скобках:

| Подстановка | Заменяется на |
| --- | --- |
| `{slug}`, `{title}`, `{locale}`… | Любое поле верхнего уровня черновика. Неизвестные подстановки становятся пустыми. |
| `{documentId}`, `{uid}` | Id документа и UID типа содержимого. |
| `{token}` | Токен предпросмотра. Без этой подстановки токен добавляется как параметр запроса `preview`. |

Для статей из примера:

```text
https://example.com/blog/{slug}?locale={locale}
```

даёт `https://example.com/blog/hello-world?locale=en&preview=<token>`.

Те же настройки в JSON, как их хранит функция (`PUT /admin/api/features/preview`):

```json
{
  "enabled": true,
  "settings": {
    "urls": { "api::article": "https://example.com/blog/{slug}?locale={locale}" },
    "ttlMinutes": 60
  }
}
```

## Откройте предпросмотр

В редакторе записи выберите **Открыть предпросмотр**, чтобы открыть черновик на сайте в новой
вкладке, или **Рядом**, чтобы показать его на панели рядом с формой с шириной **Настольный**,
**Планшет** и **Мобильный**. Боковая панель перезагружается после каждого сохранения. Если она
остаётся пустой, ваш сайт, вероятно, запрещает встраивание во фрейм: используйте **Открыть в
новой вкладке**.

## Чтение черновика на сайте

Страница предпросмотра берёт токен из URL и отправляет его обратно в content API в заголовке
`x-verdin-preview`, запрашивая черновик:

<Diagram
  caption="Запрос предпросмотра"
  code={`sequenceDiagram
  participant E as Редактор
  participant V as Verdin
  participant S as Ваш сайт
  E->>V: Открыть предпросмотр
  V-->>E: URL с токеном предпросмотра
  E->>S: GET /blog/hello-world?preview=token
  S->>V: GET /api/articles/documentId?status=draft<br/>x-verdin-preview: token
  V-->>S: черновик`}
/>

<Tabs syncKey="api">
<TabItem label="REST">

```sh title="Terminal"
curl -H "x-verdin-preview: $PREVIEW_TOKEN" \
  'https://cms.example.com/api/articles/<documentId>?status=draft'
```

</TabItem>
<TabItem label="GraphQL">

Токен предпросмотра читает REST content API. На странице предпросмотра запрашивайте черновик
через REST.

</TabItem>
<TabItem label="TypeScript">

```ts
import { createClient } from '@verdin/client';
import type { VerdinSchema } from './verdin-types';

const preview = createClient<VerdinSchema>({
  url: 'https://cms.example.com',
  headers: { 'x-verdin-preview': token },
});
const { data } = await preview
  .collection('articles')
  .findOne(documentId, { status: 'draft' });
```

</TabItem>
</Tabs>

Тот же заголовок работает для одиночных типов (`GET /api/<singularName>?status=draft`).

Что даёт токен:

- Он позволяет своему владельцу читать один этот документ, включая черновики, пока не истечёт.
- Он не может читать другие документы, получать списки записей или что-либо записывать.
- Ответы на запросы предпросмотра никогда не кешируются.

<Aside type="caution">
Любой, у кого есть ссылка, может читать черновик, пока токен не истечёт. Делайте срок
действия коротким и не публикуйте ссылки предпросмотра в открытых местах.
</Aside>

Обычно страница предпросмотра ищет запись по полю вроде `slug`. Поскольку токен читает по
`documentId`, добавьте в шаблон и `{documentId}` или сопоставляйте slug и id на своей
стороне.

## Admin API

`GET /admin/api/content/{uid}/{documentId}/preview?locale=` возвращает ссылку для кнопки
редактора:

```json
{ "data": { "url": "https://example.com/blog/hello-world?locale=en&preview=…", "token": "…", "expiresAt": "2026-09-29T11:00:00.000Z" } }
```

Для этого нужен доступ на чтение к записи; если функция выключена или у типа нет шаблона,
ответ — `404`.

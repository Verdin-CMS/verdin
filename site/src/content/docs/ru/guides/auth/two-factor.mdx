Двухфакторная аутентификация добавляет после пароля второй шаг: 6-значный код из
приложения-аутентификатора или ключ доступа (отпечаток пальца, лицо, блокировка экрана или
ключ безопасности). В этом руководстве вы настроите оба способа, сделаете их обязательными для
роли и узнаете, что делать, если администратор их потерял. В Strapi встроенного аналога нет.

Двухфакторная аутентификация предназначена для администраторов.
[Конечные пользователи](/ru/guides/auth/end-users/) входят по паролю или через провайдера
OAuth.

## Перед началом

- Включать отдельную функцию не нужно: каждый администратор может настроить второй фактор в
  своём профиле.
- Ключи доступа привязаны к адресу админ-панели. Задайте `[server].public_url` — адрес,
  который открывают администраторы, например `https://cms.example.com`. Браузеры предлагают
  ключи доступа только по `https://` (и на `localhost`).
- Не меняйте `VERDIN_TOKEN_PEPPER`: им защищены секреты аутентификаторов и резервные коды, и
  его смена делает их непригодными.

## Настройте приложение-аутентификатор

<Steps>

1. Откройте свой **Профиль** и найдите **Двухфакторная аутентификация**.
2. В разделе **Приложение-аутентификатор** выберите **Настроить** и подтвердите пароль.
3. Отсканируйте QR-код приложением, например 1Password, Google Authenticator или Authy. Если
   отсканировать не получается, введите ключ настройки, показанный под кодом.
4. Введите **6-значный код** из приложения и выберите **Включить**.
5. Сохраните **резервные коды**, которые показывает Verdin: **Скачайте** или скопируйте их,
   затем выберите **Я их сохранил**.

</Steps>

Коды следуют стандартной схеме TOTP (шаги по 30 секунд, SHA-1, 6 цифр). Код из предыдущего
или следующего шага тоже принимается, чтобы учесть расхождение часов. Если коды отклоняются,
проверьте время на устройстве.

## Добавьте ключ доступа

<Steps>

1. В разделе **Ключи доступа** выберите **Добавить ключ доступа**.
2. Дайте ему **Название**, например «MacBook Touch ID», и подтвердите пароль.
3. Следуйте подсказке браузера.

</Steps>

Можно зарегистрировать до 20 ключей доступа и удалять их кнопкой **Удалить**. Ключи доступа —
это второй фактор после пароля, а не его замена.

## Резервные коды

При настройке первого фактора вы получаете 10 резервных кодов. Каждый позволяет войти один
раз, если вы потеряли приложение или ключи доступа. Профиль показывает, сколько их осталось;
**Сгенерировать новые коды** заменяет их все (старые перестают работать).

<Aside type="caution">
Коды показываются один раз. Храните их в менеджере паролей или офлайн, но не рядом с
устройством, на котором стоит аутентификатор.
</Aside>

## Вход со вторым фактором

После пароля страница входа просит **Код аутентификации**. Выберите **Использовать ключ
доступа** или **Использовать резервный код**, чтобы сменить способ. На завершение даётся 5
минут; после этого введите пароль заново.

## Требуйте двухфакторную аутентификацию для роли

<Steps>

1. Откройте **Настройки → Роли** и нужную роль.
2. Включите **Требовать двухфакторную аутентификацию** и сохраните.

</Steps>

Участникам без второго фактора при входе предлагается его настроить. Пока они этого не
сделают, им доступен только профиль. В **Настройки → Пользователи** в их строке отображается
**Нет 2FA**; у администраторов со вторым фактором — **2FA**.

Пока ваша роль требует второй фактор, Verdin не даст удалить последний из них: добавьте ключ
доступа, прежде чем отключать приложение, или другой фактор, прежде чем удалять единственный
ключ доступа.

## Сброс второго фактора другого администратора

Если администратор потерял устройство и резервные коды:

<Steps>

1. Откройте **Настройки → Пользователи** и найдите администратора.
2. Выберите **Сбросить двухфакторную аутентификацию** и подтвердите.

</Steps>

Это удаляет его приложение-аутентификатор, ключи доступа и резервные коды, и он входит только
по паролю. Если его роль требует двухфакторной аутентификации, её нужно настроить заново. Для
этого нужно **Управление пользователями**; сбросить другого Super Admin может только Super
Admin.

`verdin admin reset-password` сбрасывает только пароль, а не второй фактор.

## Единый вход

У администраторов, которые входят через [единый вход](/ru/guides/auth/sso/), тоже
спрашивается второй фактор Verdin, если у провайдера не включено **Провайдер требует MFA**.

## Admin API

Все маршруты находятся под `/admin/api`. Маршруты, которые меняют факторы, принимают ваш
`password`.

| Маршрут | Что делает |
| --- | --- |
| `POST /auth/login` | При наличии второго фактора вместо сессии отвечает `{ twoFactorRequired: true, twoFactorToken, methods }`. |
| `POST /auth/login/two-factor` | `{ twoFactorToken, code }` (TOTP или резервный код) или `{ twoFactorToken, challengeToken, credential }` для ключа доступа. Возвращает сессию. |
| `POST /auth/login/passkey/options` | `{ twoFactorToken }`: челлендж ключа доступа. |
| `GET /auth/two-factor` | Ваши факторы: `totp`, `passkeys`, `recoveryCodesLeft`, `required`. |
| `POST /auth/two-factor/totp/setup`, `/totp/enable`, `/totp/disable` | Настроить (пароль), включить (код) и выключить (пароль) приложение-аутентификатор. |
| `POST /auth/two-factor/recovery-codes` | Новые резервные коды. |
| `POST /auth/two-factor/passkeys/options`, `POST /auth/two-factor/passkeys`, `DELETE /auth/two-factor/passkeys/{id}` | Регистрация и удаление ключей доступа. |
| `DELETE /users/{id}/two-factor` | Сбросить факторы другого администратора (`users.manage`). |

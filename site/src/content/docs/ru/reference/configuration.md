Конфигурация многослойная: **встроенные значения по умолчанию ← `verdin.toml` ← окружение**.
Файл необязателен; у каждого ключа есть значение по умолчанию. Неизвестные ключи отклоняются,
поэтому опечатка приводит к ошибке при запуске, а не игнорируется.

- Любой ключ можно переопределить через `VERDIN_<SECTION>__<KEY>` (два подчёркивания),
  например `VERDIN_SERVER__PORT=8080` или `VERDIN_ADMIN__SECURE_COOKIES=false`. Для вложенных
  таблиц добавляется ещё один `__`: `VERDIN_ADMIN__BRANDING__TITLE=ACME`. Неизвестные ключи
  отклоняются и здесь, поэтому любая переменная, которая начинается с `VERDIN_` и содержит
  `__`, должна указывать на существующий ключ.
- `VERDIN_DATABASE_URL` — сокращение для `database.url`.
- Файл — это `verdin.toml` в рабочем каталоге или путь, заданный через `-c, --config` или
  `VERDIN_CONFIG`. Относительные пути в нём (схема, плагины, загрузки, файлы SQLite)
  разрешаются относительно каталога файла.
- Файл `.env` рядом с конфигурацией загружается первым; переменные, уже заданные в
  окружении, имеют приоритет.

Секреты никогда не читаются из `verdin.toml`; см. [Переменные окружения](#переменные-окружения).

## `[server]`

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `host` | `"0.0.0.0"` | Адрес, на котором слушает сервер. |
| `port` | `1337` | Порт, на котором слушает сервер. |
| `public_url` | не задан | Адрес, по которому браузеры обращаются к серверу, например `"https://cms.example.com"`. Используется для ссылок в письмах и callback SSO; по умолчанию `http://localhost:{port}`. |
| `body_limit` | `"1mb"` | Максимальное тело обычных запросов к API (у загрузок свой лимит). Число байт или строка с `b`, `kb`, `mb` или `gb`. |
| `request_timeout_secs` | `30` | Ограничение времени обычных запросов к API. |
| `sync_interval_secs` | `10` | Как часто подхватывать настройки, изменённые другими экземплярами (функции, переключатели плагинов, локали, процессы проверки); `0` отключает (один экземпляр). |
| `trusted_proxies` | `[]` | Обратные прокси (IP или диапазоны CIDR, например `["10.0.0.0/8"]`), чей `X-Forwarded-For` указывает клиента. Ограничения частоты и журналы аудита используют этот адрес; без этого все клиенты за прокси делят один адрес. |

## `[api]`

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `prefix` | `"/api"` | Путь, под которым доступен content API. Должен начинаться с `/` и не заканчиваться им. |
| `default_page_size` | `25` | Размер страницы, если запрос его не задаёт. От 1 до `max_page_size`. |
| `max_page_size` | `100` | Максимальный размер страницы, который может запросить клиент. |
| `decimal_as_string` | `false` | Сериализовать decimal как строки (точно), а не как числа (совместимо со Strapi). |
| `public_rate_limit` | `0` | Запросов в минуту на IP клиента без токена (`0` — без ограничений). |
| `token_rate_limit` | `0` | Запросов в минуту на API-токен или конечного пользователя (`0` — без ограничений). |
| `cache_ttl_secs` | `0` | Сколько хранить анонимные чтения в памяти (`0` — без кеша); изменения очищают кеш. |
| `cache_entries` | `1000` | Максимальное число закешированных ответов. |
| `cors_origins` | `[]` | Origin браузеров, которым разрешено вызывать content API и GraphQL с другого сайта (`["https://www.example.com"]`: схема, хост и порт, без пути), или `["*"]` для любых (только отдельно: `*` нельзя сочетать с origin). Пусто — из браузера их могут вызывать только страницы того же origin. Admin API никогда не принимает кросс-доменные вызовы. |

## `[upload]`

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `provider` | `{ name = "local", dir = "public/uploads" }` | Где хранятся файлы; см. ниже. |
| `max_file_size` | `209715200` | Максимальный размер принимаемого файла в байтах (200 МБ). |
| `responsive_formats` | `true` | Создавать адаптивные форматы для растровых изображений. |
| `breakpoints` | large 1000, medium 750, small 500 | Адаптивные форматы в виде таблиц `{ name, width }` (`breakpoints` из Strapi). Форматы шире изображения пропускаются. |
| `max_image_megapixels` | `100` | Ограничение декодирования от бомб декомпрессии, в мегапикселях. |
| `max_original_size` | не задан | Растровые оригиналы больше этого числа пикселей (по любой стороне) уменьшаются при загрузке, что также удаляет их метаданные (EXIF, GPS). Не задано — оригиналы сохраняются как отправлены. |

```toml
[upload]
breakpoints = [{ name = "large", width = 1000 }, { name = "small", width = 500 }]
```

### Локальный провайдер

Файлы в `dir` (относительно проекта), которые Verdin отдаёт по адресу `/uploads`.

```toml
[upload]
provider = { name = "local", dir = "public/uploads" }
```

### `[upload.transforms]`

Преобразования изображений локальных файлов: `/uploads/<file>?preset=thumb` или
`?w=&h=&fit=&format=&q=` с подписью. Результаты кешируются на диске и сбрасываются при
изменении файла (включая его фокусную точку). Обрезка cover сохраняет фокусную точку файла
в кадре; изображения никогда не увеличиваются. Преобразовывать можно JPEG, PNG, WebP, TIFF и
BMP (но не GIF, которые могут быть анимированными).

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `enabled` | `true` | Выполнять преобразования. |
| `presets` | `{}` | Именованные преобразования, разрешённые всегда: `{ w, h, fit, format, q }`. |
| `allow_arbitrary` | `false` | Принимать любые параметры без подписи. Каждый отдельный URL выполняется и кешируется, поэтому только для доверенных сетей. |
| `max_size` | `4096` | Максимальные `w` или `h` в пикселях. |
| `cache_dir` | `".cache/transforms"` | Где хранятся результаты (относительно проекта; можно безопасно удалять). |

Параметры: `w`, `h` (пиксели), `fit` (`cover`, по умолчанию, обрезает по области; `inside`
вписывает в неё; `fill` растягивает), `format` (`jpeg`, `png`, `webp`; WebP выводится без
потерь) и `q` (качество JPEG, 1–100, по умолчанию 80).

```toml
[upload.transforms.presets]
thumb = { w = 300, h = 300 }
hero = { w = 1600, h = 600, format = "webp" }
```

**Подписанные URL.** Когда задан `VERDIN_IMAGE_SECRET`, `s` — это HMAC-SHA256 в hex от
`<file>?<canonical query>`, где каноническая строка запроса перечисляет параметры со
значениями не по умолчанию, отсортированные по имени (`fit`, `format`, `h`, `q`, `w`;
`fit=cover` опускается):

```js
import { createHmac } from 'node:crypto';
const s = createHmac('sha256', process.env.VERDIN_IMAGE_SECRET)
  .update('photo_1a2b.jpg?format=webp&w=800')
  .digest('hex');
const url = `/uploads/photo_1a2b.jpg?format=webp&w=800&s=${s}`;
```

### Провайдер S3

Любой S3-совместимый сервис (AWS, Cloudflare R2, MinIO, Backblaze B2…). Учётные данные
берутся из стандартных переменных окружения `AWS_*` (`AWS_ACCESS_KEY_ID`,
`AWS_SECRET_ACCESS_KEY`).

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `bucket` | обязательный | Имя бакета. |
| `region` | не задан | Регион бакета. |
| `endpoint` | не задан | Собственный эндпоинт для сервисов не от AWS, например `https://<account>.r2.cloudflarestorage.com`. |
| `public_url` | обязательный | Публичный базовый URL бакета или его CDN; файлы указываются как `{public_url}/{key}`. |
| `prefix` | `""` | Префикс ключей внутри бакета. |
| `path_style` | `false` | Запросы в стиле path (MinIO и большинство размещаемых у себя сервисов). |

```toml
[upload]
provider = { name = "s3", bucket = "media", region = "auto",
             endpoint = "https://<account>.r2.cloudflarestorage.com",
             public_url = "https://media.example.com" }
```

## `[ai]`

Действия ИИ в админке (при включённой функции **Действия ИИ** в Настройки → Функции):
перевод записи на другую локаль, альтернативный текст для изображений, краткое изложение
текста, предложение SEO-метаданных. Они возвращают предложения; без редактора ничего не
сохраняется. Ключ читается из `VERDIN_AI_KEY` (локальным серверам он не нужен).

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `provider` | `"none"` | `anthropic`, `openai` или `openai-compatible` (Ollama, LM Studio, vLLM…). |
| `model` | `claude-sonnet-5` для `anthropic` | Модель; для остальных провайдеров обязательна. |
| `base_url` | адрес провайдера | Другой эндпоинт, например `http://localhost:11434/v1`. |
| `max_tokens` | `2048` | Максимальная длина ответа. |

```toml
[ai]
provider = "anthropic"
```

Каждый администратор может сделать 30 запросов к ИИ в минуту. Контент и изображения
отправляются провайдеру: выбирайте того, которого разрешает ваша организация.

## `[cdn]`

Очищает кеши CDN, когда контент меняется публично. Ответы content API помечаются тегами `vd`
и `vd-<singularName>` (заголовки `Cache-Tag` и `Surrogate-Key`).

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `provider` | `"none"` | `cloudflare`, `fastly` или `webhook`. |
| `zone_id` | не задан | Зона Cloudflare (очистка по тегу). |
| `service_id` | не задан | Сервис Fastly (очистка по surrogate key). |
| `url` | не задан | `webhook`: получает `POST { "tags": [...] }`. |
| `debounce_ms` | `1000` | Сколько собирать изменения перед очисткой. |

API-токен читается из `VERDIN_CDN_TOKEN` (отправляется вебхукам как bearer-токен).

## `[search]`

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `enabled` | `false` | Ранжировать `_q` полнотекстовым индексом (Tantivy) вместо `$containsi`. |
| `dir` | `"data/search"` | Каталог индекса относительно проекта. Если его удалить, индекс перестроится при следующем запуске. |
| `memory_mb` | `50` | Бюджет памяти на индексирование. |

Индекс хранится на диске экземпляра и отслеживает записи этого экземпляра: при нескольких
экземплярах держите поиск на одном (или перестраивайте индекс после деплоя).

## Переменные окружения

Помимо переопределений `VERDIN_<SECTION>__<KEY>`, Verdin читает такие переменные:

| Переменная | Описание |
| --- | --- |
| `VERDIN_CONFIG` | Путь к файлу конфигурации (то же, что `--config`). |
| `VERDIN_DATABASE_URL` | Сокращение для `database.url`. |
| `VERDIN_ADMIN_JWT_SECRET` | Подписывает токены сессий администраторов. Обязательна, не короче 32 байт; сгенерируйте через `verdin secrets`. |
| `VERDIN_TOKEN_PEPPER` | Ключ хеша для хранимых токенов. Обязательна, не короче 32 байт; сгенерируйте через `verdin secrets`. |
| `VERDIN_ADMIN_PASSWORD` | Пароль для `verdin admin create` и `verdin admin reset-password` (иначе читается из stdin); см. [справочник по командной строке](/ru/reference/cli/). |
| `VERDIN_EMAIL_SMTP_PASSWORD` | Пароль SMTP. |
| `VERDIN_EMAIL_API_KEY` | API-ключ провайдеров Resend и Postmark. |
| `VERDIN_SSO_<ID>_SECRET` | Секрет клиента провайдера SSO; `<ID>` — id провайдера заглавными буквами, с `_` вместо `-` (см. [Единый вход](/ru/guides/auth/sso/)). |
| `VERDIN_OAUTH_<PROVIDER>_SECRET` | Секрет клиента провайдера OAuth для конечных пользователей, именуется так же, как для SSO (см. [Конечные пользователи](/ru/guides/auth/end-users/)). |
| `VERDIN_AI_KEY` | API-ключ провайдера `[ai]`. |
| `VERDIN_CDN_TOKEN` | API-токен провайдера `[cdn]`. |
| `VERDIN_IMAGE_SECRET` | Подписывает URL преобразований изображений (см. [`[upload.transforms]`](#uploadtransforms)). |
| `VERDIN_METRICS_TOKEN` | Bearer-токен для сбора `/_metrics`, когда задано `[metrics].enabled`; имеет приоритет над `[metrics].token`. |
| `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` | Учётные данные провайдера загрузок S3. |
| `RUST_LOG` | Фильтр логов; имеет приоритет над `[log].level`. |

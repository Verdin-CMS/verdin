В этом журнале записаны проектные решения, которые сформировали Verdin, в порядке их принятия, чтобы вы могли понять, почему код устроен именно так, прежде чем предлагать его изменить. Записи сохраняются в том виде, в каком были написаны, включая названия этапов (M2–M4 — этапы до первых релизов); более поздняя запись может уточнять более раннюю, как 28 уточняет 1. Добавляйте новую строку, когда принимаете решение, которое иначе кому-то пришлось бы восстанавливать по коду.

| № | Решение | Итог | Обоснование |
|---|---|---|---|
| 1 | Компоненты: JSON или таблицы | **Колонка JSON** ([хранение](/ru/internals/storage/#компоненты-и-динамические-зоны-колонка-json)) | Меньше JOIN, тривиальные публикация и версионирование, более простые миграции. Фильтрация по повторяемым компонентам нужна редко; её можно добавить позже через JSON-функции |
| 2 | Кодирование `decimal` в JSON | По умолчанию **число**, `api.decimal_as_string` по желанию | Совместимость со Strapi максимизирует принятие; точные значения доступны, когда нужны |
| 3 | Формы админки | **Signal Forms** | Подходят админке на сигналах без zone.js; динамические деревья форм выводятся из схемы |
| 4 | Язык | **Английский** для кода, документации и коммитов | Охват open source |
| 5 | Совместимость с REST Strapi | **Те же параметры и формат ответов**; расширения только для Verdin — в `actions/` | Фронтенды мигрируют с минимальными изменениями |
| 6 | Алгоритм JWT админки | HS256 | Один секрет, просто; EdDSA, если когда-нибудь появятся внешние проверяющие |
| 7 | Id документов | ULID (26 символов) | Сортируемые и переносимые; собственные id Strapi — непрозрачные строки из 24 символов, клиенты их никогда не разбирают |
| 8 | Содержимое снимка | Физическая модель, а не схема | Будущие версии могут выводить новые таблицы из неизменённой схемы |
| 9 | Допустимость NULL в атрибутах | Всегда NULL допустим; `required` проверяется при публикации | Черновики могут быть неполными (поведение Strapi v5); добавление обязательных полей безопасно |
| 10 | Обеспечение `unique` | Уникальный индекс по `(column, locale, publication_state)` | Без гонок; черновики и их опубликованная версия делят значения |
| 11 | Имя колонки состояния | `publication_state` | `state` — распространённое имя атрибута |
| 12 | Зарезервированные слова SQL | Идентификаторы всегда в кавычках | Никакого произвольного чёрного списка имён атрибутов |
| 13 | Построение DML | Собственный построитель вместо `sea-query` | Преобладают детали диалектов (типизированные NULL, сопоставления, форматы SQLite); на одну абстракцию меньше |
| 14 | Запись без `?status=draft` | Публикация (поведение REST в Strapi v5) | Совместимость без изменений для существующих клиентов |
| 15 | Сравнение текста | По умолчанию точное во всех СУБД; операторы `…i` — без учёта регистра | Одинаковые результаты в MySQL и PostgreSQL |
| 16 | Временное управление доступом (M2–M3) | Переключатель `[api].open_access`, удалён в M4 | Безопасность по умолчанию, пока не появились разрешения |
| 17 | «Цель принадлежит одному документу» | Обеспечивается перемещением цели, отдельно для каждого состояния | Уникальный индекс запретил бы черновику и его опубликованной версии делить цель |
| 18 | Обратные стороны (`mappedBy`) | Только для чтения | Запись через них неоднозначна при черновиках и публикации (какая версия владельца?) |
| 19 | Позиции ссылок | Перенумерация 1..n при каждой записи | Не исчерпываются дробные числа; списки небольшие |
| 20 | Строки таблиц связей | Сохраняется первичный ключ `id` | Единообразные таблицы для движка миграций и пересборки в SQLite |
| 21 | Библиотека JWT | Собственный HS256 (HMAC-SHA256, проверка за постоянное время, фиксированный `alg`) | `jsonwebtoken` 11 требует криптографического бэкенда, который тянет RSA |
| 22 | Таблицы платформы | Выводятся вместе с моделью контента | Один механизм миграций для всего |
| 23 | Повторное использование refresh-токена | Отзыв всего семейства, без льготного окна | Просто и строго; администратор входит заново |
| 24 | Черновики через content API | Отдельное право `readDrafts` | Токены, читающие опубликованный контент, не раскрывают черновики |
| 25 | Порядок применения в конструкторе | Миграция, затем запись файлов, затем горячая подмена приложения | Неудачная миграция оставляет файлы и работающее приложение нетронутыми |
| 26 | Запись из админки | Сохраняются только черновики; публикация — явное действие | Соответствует ожиданиям редакторов; content API сохраняет публикацию по умолчанию, как в Strapi |
| 27 | Конфигурация админки во время выполнения | Тег `<meta>`, а не встроенный скрипт | CSP остаётся без скриптов `unsafe-inline` |
| 28 | Фильтры по полям компонентов | Операторы JSON-путей для каждого диалекта (`#>>`, `JSON_VALUE`, `json_extract`); `EXISTS` по элементам массива для повторяемых компонентов и динамических зон (0.8) | Динамические зоны — только по `__component`: у их элементов разные поля |
| 29 | i18n админки | Transloco с плоскими JSON-каталогами (`admin/public/i18n`) и ICU MessageFormat через FormatJS (собственный транспайлер) за небольшим фасадом `I18n`; не i18n Angular на этапе компиляции | Переключение языка во время выполнения; стандартные файлы для Weblate/Crowdin; FormatJS интерпретирует сообщения, поэтому строгой CSP не нужен `unsafe-eval` (`@messageformat/core` компилирует через `new Function`); ключи типизируются по `en.json`, полнота проверяется `npm run i18n:check` |
| 30 | Начало недели | `Intl.Locale#getWeekInfo` для регионального тега браузера (en-GB ≠ en-US), запасная таблица регионов, пользовательское переопределение | Следует региону каждого пользователя, даже когда язык интерфейса общий |
| 31 | Хранение раскладки главной панели | JSON-колонка `preferences` для каждого пользователя в `vd_admin_users` (≤ 64 КиБ) | Следует за пользователем между браузерами; тема и язык остаются в `localStorage`, потому что применяются до входа |
| 32 | `Secure` для refresh-cookie по умолчанию | Включено в `start`, выключено в `dev`, можно переопределить | `verdin dev` по обычному HTTP работает во всех браузерах; продакшен остаётся строгим |
| 33 | Профиль релиза | Thin LTO, 1 codegen unit, strip; раскрутка стека сохранена | Паника в обработчике не должна ронять сервер |
| 34 | «Непросмотренные» документы | Строки `vd_document_views` для каждого пользователя, удаляемые для всех, кроме редактора, при изменении документа; фильтрация через `NOT EXISTS` в SQL | Пагинация и подсчёт остаются точными; не нужно сравнивать временные метки для каждой строки |
| 35 | Голосования и опросы | Таблицы совместной работы только для админки (`vd_document_votes`, `vd_polls`, `vd_poll_votes`), для любого типа содержимого | Ящики предложений и командные решения без моделирования полей голосования в каждой схеме |
| 36 | Хранилище медиа | `object_store` для локального хранилища и S3 | Один путь кода; потоковые multipart-загрузки; RustFS в dev-окружении и CI |
| 37 | Ссылки на медиа | Таблицы связей для каждого поля, как у связей | Та же семантика черновиков и публикации, что и у связей; каскады поддерживают согласованность ссылок |
| 38 | Обновление встроенных разрешений | Маркер версии в `vd_settings`, дополнения применяются один раз | Существующие установки получают новые разрешения, не отменяя последующих правок администратора |
| 39 | Функции во время выполнения | Каталог в `verdin-api`, переключатели в `vd_settings` (`features`), приложение пересобирается на месте (ArcSwap) в любом режиме | Переключатели плагинов как в Strapi, без перезапусков; недоступные функции перечисляются с запланированной версией |
| 40 | Интерфейс справочника API | Scalar (`scalar_api_reference`, бандл встроен) по адресу `{api}/docs`, только когда документ публичный; CSP разрешает его встроенный загрузчик по хешу | Размещается у себя (без CDN, шрифтов, ИИ-агента и телеметрии); по умолчанию документ доступен только по токену |
| 41 | GraphQL | Динамическая схема `async-graphql`, собираемая вместе с приложением; аргументы и выборки переводятся в дерево параметров REST и разбираются тем же парсером запросов | Одни правила для фильтров, пагинации, populate, валидации и разрешений в REST и GraphQL; populate, выведенный из выборки, сохраняет пакетную загрузку |
| 42 | События документов | Слушатели в Document Service, вызываемые после фиксации | Побочные эффекты (отметки просмотра, будущие вебхуки) применяются ко всем API без хуков в каждом обработчике |

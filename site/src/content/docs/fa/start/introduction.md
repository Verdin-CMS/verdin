Verdin یک CMS هدلس (headless) متن‌باز است که با Rust نوشته شده است. شما نوع‌های محتوا را
مدل می‌کنید، ویراستارانتان در یک پنل مدیریت می‌نویسند و منتشر می‌کنند، و سایت‌ها و
اپلیکیشن‌هایتان محتوا را از طریق یک API از نوع REST یا GraphQL می‌خوانند. Verdin صفحه رندر
نمی‌کند: این کار فرانت‌اند شماست.

Verdin بازنویسی [Strapi v5](https://strapi.io) است: قالب طرح‌واره (schema) و API محتوا همان
شکل را دارند، پس یک پروژهٔ Strapi و فرانت‌اند آن با تغییرات اندک منتقل می‌شوند.

## برای چه کسانی است

- **توسعه‌دهندگانی که سایت یا اپلیکیشن می‌سازند** و یک CMS می‌خواهند که بتوان آن را به‌صورت
  یک فرایند اجرا کرد، مدل محتوا را در git نگه داشت و از هر فرانت‌اندی خواند: Astro، Next.js،
  یک اپلیکیشن موبایل.
- **تیم‌هایی که روی Strapi هستند** و همان API را با ردپای کوچک‌تر می‌خواهند، یا به
  قابلیت‌هایی نیاز دارند که Strapi برای طرح‌های پولی نگه می‌دارد. Verdin نسخهٔ سازمانی ندارد:
  SSO، گزارش‌های حسابرسی، گردش‌کار بازبینی و بسته‌های انتشار بخشی از پروژهٔ متن‌باز هستند.
- **ویراستاران**، که پیش‌نویس، انتشار، تاریخچه و پیش‌نمایش را در یک پنل مدیریت در دسترس به
  18 زبان در اختیار دارند.

## چه چیزهایی در بسته است

یک فایل اجرایی، `verdin`، هم سرور است، هم ابزار خط فرمان و هم پنل مدیریت.
در محیط تولید نه runtime مربوط به Node.js وجود دارد و نه `node_modules`.

| حوزه | آنچه به دست می‌آورید |
| --- | --- |
| پایگاه‌های داده | PostgreSQL 14+، MySQL 8.4+، MariaDB 10.11+ و SQLite، همه با یک مجموعه تست مشترک. |
| مدل محتوا | نوع‌های مجموعه‌ای، نوع‌های تکی، کامپوننت‌ها، ناحیه‌های پویا (dynamic zone)، روابط، رسانه، متن غنی به Markdown یا قالب blocks در Strapi. طرح‌واره مجموعه‌ای از فایل‌های JSON در پروژهٔ شماست. |
| تغییرات طرح‌واره | هر تغییر به یک برنامهٔ مهاجرت با سطح ریسک و SQL دقیق تبدیل می‌شود. گام‌های مخرب فقط وقتی اجرا می‌شوند که اجازه دهید. |
| APIها | REST زیر `/api` با پارامترهای Strapi v5 (`filters`، `populate`، `sort`، `pagination`)، یک نقطهٔ پایانی اختیاری GraphQL، یک سند OpenAPI و یک کلاینت تایپ‌شدهٔ TypeScript. |
| ویرایش | پیش‌نویس و انتشار، محتوای بومی‌سازی‌شده، تاریخچهٔ محتوا، بسته‌های انتشار، گردش‌کار بازبینی، نظرها و وظیفه‌ها، حضور زنده، پیش‌نمایش و ویرایش دیداری روی سایت خودتان. |
| دسترسی | نقش‌های مدیر تا سطح فیلد و زبان، توکن‌های API، مجوزهای دسترسی عمومی، SSO با OpenID Connect، ورود دومرحله‌ای با کلید دسترسی (passkey)، گزارش‌های حسابرسی. |
| قابلیت‌های سایت | جستجوی تمام‌متن، نقشهٔ سایت (sitemap)، تغییرمسیرها، منوها و فرم‌ها، وب‌هوک‌ها، به‌روزرسانی‌های بلادرنگ. |
| گسترش | افزونه‌های WebAssembly که به نوشتن‌ها هوک می‌شوند، مسیر و کار (job) اضافه می‌کنند و ویجت‌های پنل مدیریت و فیلدهای سفارشی می‌آورند، محدود به قابلیت‌هایی که اعلام می‌کنند. |

## نسبت آن با Strapi v5

**یکسان:**

- فایل‌های طرح‌واره از قالب Strapi استفاده می‌کنند: `schema/content-types/<singularName>.json` و
  `schema/components/<category>/<name>.json`.
- API محتوای REST: مسیرها، قالب پاسخ تخت با `documentId`، پارامترها و عملگرهای کوئری،
  معنای نوشتن (یک `POST` یا `PUT` منتشر می‌کند مگر اینکه `?status=draft` بفرستید)، بدنهٔ خطاها.
- طرح‌وارهٔ GraphQL همان شکل افزونهٔ GraphQL در Strapi v5 را دارد.
- کاربران نهایی (ثبت‌نام، ورود، OAuth، نقش‌ها) از API `users-permissions` پیروی می‌کنند.

**متفاوت:**

- **تغییرات طرح‌واره مهاجرت‌های برنامه‌ریزی‌شده هستند.** Verdin فایل‌های طرح‌واره را با
  پایگاه داده مقایسه می‌کند و گام‌ها را پیش از اجرا به شما نشان می‌دهد. `verdin start` تا وقتی
  پایگاه داده از طرح‌واره عقب باشد، از اجرا خودداری می‌کند.
- **سازندهٔ نوع محتوا فقط در حالت توسعه اجرا می‌شود.** در محیط تولید، طرح‌واره از مخزن شما
  می‌آید.
- **افزونه‌ها WebAssembly هستند، نه JavaScript.** افزونه‌های Strapi و کنترلرها، سرویس‌ها یا
  فایل‌های lifecycle سفارشی در `src/` در Verdin اجرا نمی‌شوند.
- **پایگاه داده با Strapi مشترک نیست.** یک پروژهٔ Strapi را با `verdin import strapi` منتقل
  می‌کنید که به هر سند یک شناسهٔ تازه می‌دهد.
- **چند امکان اضافه نسبت به REST**: کنش‌های انتشار و لغو انتشار
  (`POST /api/<route>/<documentId>/actions/publish`)، و کامپوننتی که populate شده به‌طور کامل
  برمی‌گردد، همراه با کامپوننت‌های تودرتو.

[سازگاری با Strapi](/fa/migrate/compatibility/) تفاوت‌ها را با جزئیات فهرست می‌کند.

## چه زمانی از آن استفاده نکنید

- **به افزونه‌های Strapi یا کد سرور سفارشی به JavaScript وابسته‌اید.** Verdin نمی‌تواند آن‌ها
  را اجرا کند؛ باید آن‌ها را به‌صورت افزونهٔ WebAssembly بازنویسی کنید یا منطق را به جای
  دیگری ببرید.
- **به یک نسخهٔ پایدار 1.0 نیاز دارید.** Verdin در نسخهٔ 0.10 است: نسخه‌های minor هنوز
  ممکن است پیکربندی و رفتار را تغییر دهند. پیش از هر کدام [ارتقا](/fa/migrate/upgrading/)
  را بخوانید.
- **می‌خواهید CMS صفحه‌هایتان را رندر کند.** Verdin هدلس است؛ آن را با یک فریم‌ورک
  فرانت‌اند یا یک مولد سایت ایستا همراه کنید.
- **یک سرویس مدیریت‌شده می‌خواهید.** Verdin خودمیزبان است: فایل باینری یا ایمیج Docker را
  روی زیرساخت خودتان اجرا می‌کنید.

پیش‌نمایش، پیش‌نویس یک مدخل را پیش از انتشار روی سایت خودتان باز می‌کند. ویرایشگر از روی یک
الگوی URL برای هر نوع محتوا پیوندی می‌سازد و توکنی کوتاه‌مدت به آن اضافه می‌کند که به سایت شما
اجازه می‌دهد فقط همان پیش‌نویس را بخواند. این راهنما الگوها و بخش سمت سایت را راه‌اندازی می‌کند.

برای کلیک روی متن در پیش‌نمایش و پرش به فیلد آن، [ویرایش دیداری](/fa/guides/frontend/visual-editing/)
را روی این قابلیت اضافه کنید.

## پیش از شروع

- **تنظیمات ← قابلیت‌ها ← پیش‌نمایش** را روشن کنید. به‌طور پیش‌فرض خاموش است.
- تغییر تنظیمات این قابلیت به **مدیریت قابلیت‌ها** (`features.manage`) نیاز دارد.
- باز کردن یک پیش‌نمایش به دسترسی خواندن مدخل نیاز دارد.
  [مجوزها](/fa/reference/permissions/) را ببینید.

## تنظیم نشانی‌های پیش‌نمایش

<Steps>

1. روی کارت **پیش‌نمایش** در **تنظیمات ← قابلیت‌ها**، **پیکربندی نشانی‌های پیش‌نمایش** را انتخاب کنید.
2. زیر **الگوهای نشانی**، صفحه‌ای از سایت خود را وارد کنید که پیش‌نویس هر نوع محتوا را نشان
   می‌دهد. برای اینکه یک نوع پیش‌نمایش نداشته باشد، آن را خالی بگذارید.
3. در صورت تمایل، **طول عمر پیوند (دقیقه)** را تغییر دهید: به‌طور پیش‌فرض 60، حداکثر 10080 (7 روز).
4. ذخیره کنید.

</Steps>

الگو یک URL با `http` یا `https` است که جانگهدارهایی داخل آکولاد دارد:

| جانگهدار | با چه چیزی پر می‌شود |
| --- | --- |
| `{slug}`، `{title}`، `{locale}`… | هر فیلد سطح بالای پیش‌نویس. جانگهدارهای ناشناخته خالی می‌شوند. |
| `{documentId}`، `{uid}` | شناسهٔ سند و uid نوع محتوا. |
| `{token}` | توکن پیش‌نمایش. بدون این جانگهدار، توکن به‌صورت پارامتر کوئری `preview` اضافه می‌شود. |

برای مقاله‌های پروژهٔ نمونه:

```text
https://example.com/blog/{slug}?locale={locale}
```

نتیجه `https://example.com/blog/hello-world?locale=en&preview=<token>` است.

همین تنظیمات به‌صورت JSON، همان‌طور که قابلیت ذخیره می‌کند (`PUT /admin/api/features/preview`):

```json
{
  "enabled": true,
  "settings": {
    "urls": { "api::article": "https://example.com/blog/{slug}?locale={locale}" },
    "ttlMinutes": 60
  }
}
```

## باز کردن یک پیش‌نمایش

در ویرایشگر مدخل، **باز کردن پیش‌نمایش** را انتخاب کنید تا پیش‌نویس روی سایت شما در یک زبانهٔ
جدید باز شود، یا **کنار هم** را تا در پنلی کنار فرم با عرض‌های **دسکتاپ**، **تبلت** و **موبایل**
نشان داده شود. پنل کناری پس از هر ذخیره دوباره بارگذاری می‌شود. اگر خالی بماند، احتمالاً سایت
شما اجازهٔ نمایش در frame را نمی‌دهد: از **باز کردن در زبانهٔ جدید** استفاده کنید.

## خواندن پیش‌نویس در سایت

صفحهٔ پیش‌نمایش شما توکن را از URL می‌گیرد و آن را در سرآیند `x-verdin-preview` به content API
برمی‌گرداند و پیش‌نویس را درخواست می‌کند:

<Diagram
  caption="یک درخواست پیش‌نمایش"
  code={`sequenceDiagram
  participant E as ویرایشگر
  participant V as Verdin
  participant S as سایت شما
  E->>V: باز کردن پیش‌نمایش
  V-->>E: URL همراه با توکن پیش‌نمایش
  E->>S: GET /blog/hello-world?preview=token
  S->>V: GET /api/articles/documentId?status=draft<br/>x-verdin-preview: token
  V-->>S: پیش‌نویس`}
/>

<Tabs syncKey="api">
<TabItem label="REST">

```sh title="Terminal"
curl -H "x-verdin-preview: $PREVIEW_TOKEN" \
  'https://cms.example.com/api/articles/<documentId>?status=draft'
```

</TabItem>
<TabItem label="GraphQL">

توکن پیش‌نمایش توسط REST content API خوانده می‌شود. در صفحهٔ پیش‌نمایش، پیش‌نویس را از طریق
REST دریافت کنید.

</TabItem>
<TabItem label="TypeScript">

```ts
import { createClient } from '@verdin/client';
import type { VerdinSchema } from './verdin-types';

const preview = createClient<VerdinSchema>({
  url: 'https://cms.example.com',
  headers: { 'x-verdin-preview': token },
});
const { data } = await preview
  .collection('articles')
  .findOne(documentId, { status: 'draft' });
```

</TabItem>
</Tabs>

همین سرآیند روی نوع‌های تکی هم کار می‌کند (`GET /api/<singularName>?status=draft`).

آنچه توکن اجازه می‌دهد:

- به دارندهٔ آن اجازه می‌دهد تا زمان انقضا، فقط همان یک سند را، از جمله پیش‌نویس‌ها، بخواند.
- نمی‌تواند سندهای دیگر را بخواند، مدخل‌ها را فهرست کند یا چیزی بنویسد.
- پاسخ درخواست‌های پیش‌نمایش هرگز کش نمی‌شوند.

<Aside type="caution">
هر کسی که پیوند را داشته باشد تا انقضای توکن می‌تواند پیش‌نویس را بخواند. طول عمر را کوتاه نگه
دارید و پیوندهای پیش‌نمایش را در جاهای عمومی به اشتراک نگذارید.
</Aside>

صفحهٔ پیش‌نمایش شما معمولاً مدخل را با فیلدی مانند `slug` پیدا می‌کند. از آنجا که توکن بر اساس
`documentId` می‌خواند، `{documentId}` را هم در الگو بگذارید، یا نگاشت slug به شناسه را در سمت
خودتان نگه دارید.

## Admin API

`GET /admin/api/content/{uid}/{documentId}/preview?locale=` پیوند دکمهٔ ویرایشگر را برمی‌گرداند:

```json
{ "data": { "url": "https://example.com/blog/hello-world?locale=en&preview=…", "token": "…", "expiresAt": "2026-09-29T11:00:00.000Z" } }
```

این مسیر به دسترسی خواندن مدخل نیاز دارد و وقتی قابلیت خاموش باشد یا نوع الگویی نداشته باشد،
پاسخ `404` می‌دهد.

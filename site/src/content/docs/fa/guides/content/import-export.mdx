فهرست هر نوع محتوا در پنل مدیریت، مدخل‌هایش را به CSV یا JSON خروجی می‌دهد و آن‌ها را از همان
نوع فایل دوباره درون‌ریزی می‌کند: برای اصلاح تعداد زیادی مدخل در یک صفحه‌گسترده، بارگذاری یک
کاتالوگ محصول، یا کپی مدخل‌ها بین پروژه‌ها. این راهنما هر دو جهت و قالب فایل را پوشش می‌دهد.

این برای مدخل‌های یک نوع محتوا در هر بار است. برای جابه‌جا کردن کل یک پروژه،
[`verdin export` و `verdin import verdin`](/fa/reference/cli/) را ببینید. برای آمدن از Strapi،
[مهاجرت از Strapi](/fa/migrate/from-strapi/) را ببینید.

## پیش از شروع

- خروجی گرفتن به دسترسی خواندن آن نوع محتوا نیاز دارد. فقط فیلدهایی که نقش شما می‌تواند بخواند
  خروجی گرفته می‌شوند.
- درون‌ریزی به دسترسی ایجاد، به‌روزرسانی یا هر دو نیاز دارد: ردیف‌هایی که مدخل ایجاد می‌کنند به
  ایجاد و ردیف‌هایی که به‌روزرسانی می‌کنند به به‌روزرسانی نیاز دارند. انتشار ردیف‌های
  درون‌ریزی‌شده به مجوز انتشار هم نیاز دارد. [مجوزها](/fa/reference/permissions/) را ببینید.

## خروجی گرفتن از مدخل‌ها

<Steps>

1. فهرست نوع محتوا را باز کنید و آن را همان‌طور که خروجی را می‌خواهید تنظیم کنید: فیلترها،
   جستجو، مرتب‌سازی، وضعیت و زبان.
2. **خروجی گرفتن** و سپس **خروجی CSV** یا **خروجی JSON** را انتخاب کنید.

</Steps>

فایل شامل مدخل‌هایی است که فهرست نشان می‌دهد، با فیلترها، جستجو و مرتب‌سازی آن، در همهٔ
صفحه‌ها، تا 50,000 مدخل. هر ردیف با `documentId` شروع می‌شود و فیلدها پس از آن می‌آیند.

## درون‌ریزی مدخل‌ها

<Steps>

1. فهرست نوع محتوا را باز کنید و **درون‌ریزی** را انتخاب کنید.
2. یک **فایل** انتخاب کنید: یک فایل `.csv` با ردیف سرآیند، یا یک فایل `.json` حاوی فهرستی از
   اشیا، تا 1 MB.
3. زیر **ستون‌ها**، فیلدی را که هر ستون به آن می‌رود انتخاب کنید. ستون‌هایی که هم‌نام یک فیلد
   هستند از قبل تطبیق داده شده‌اند. برای کنار گذاشتن یک ستون **نادیده گرفتن** را انتخاب کنید، و
   برای ستونی که مدخل‌های موجود را مشخص می‌کند **شناسهٔ سند (به‌روزرسانی)** را.
4. در صورت تمایل، **انتشار مدخل‌های درون‌ریزی‌شده** را روشن کنید. در غیر این صورت به‌عنوان
   پیش‌نویس ذخیره می‌شوند.
5. **بررسی** را انتخاب کنید. Verdin همهٔ ردیف‌ها را، از جمله قیدها و ارجاع‌ها، بدون نوشتن هیچ
   چیزی بررسی می‌کند و ردیف‌هایی را که ایجاد، به‌روزرسانی یا رد خواهد کرد گزارش می‌دهد.
6. در صورت نیاز فایل را اصلاح کنید، سپس **درون‌ریزی** را انتخاب کنید.

</Steps>

ردیف‌ها چگونه نوشته می‌شوند:

- ردیفی که `documentId` دارد همان مدخل را به‌روزرسانی می‌کند؛ بقیه مدخل‌های جدید می‌سازند.
- ردیف‌ها یکی‌یکی نوشته می‌شوند. ردیفی که شکست بخورد همراه با فیلد و مشکلش گزارش و رد می‌شود؛
  بقیه همچنان نوشته می‌شوند.
- گزارش تا 100 ردیف دارای خطا و ستون‌هایی را که با هیچ فیلدی تطبیق نیافتند فهرست می‌کند.
- هر درون‌ریزی حداکثر 5,000 ردیف می‌پذیرد. فایل‌های بزرگ‌تر را تقسیم کنید.
- مدخل‌ها در زبان فعلی فهرست نوشته می‌شوند.

<Aside type="caution">
درون‌ریزی ردیف‌های شما را از همان اعتبارسنجی ویرایشگر عبور می‌دهد، اما قابل بازگشت نیست. ابتدا
**بررسی** را اجرا کنید، و پیش از یک به‌روزرسانی بزرگ از فهرست خروجی بگیرید تا بتوانید آن را
بازیابی کنید. وقتی [تاریخچهٔ محتوا](/fa/guides/content/content-history/) روشن باشد، هر مدخل
به‌روزرسانی‌شده نسخهٔ قبلی خود را نگه می‌دارد.
</Aside>

## قالب فایل

فیلدها همان شکل‌های قالب نوشتن content API را دارند:

| فیلد | مقدار |
| --- | --- |
| متن، اعداد، مقادیر بولی، تاریخ‌ها | مانند API (`true`/`false`، تاریخ‌های ISO 8601). |
| روابط | `documentId`های مدخل‌های مرتبط. |
| رسانه | شناسهٔ فایل‌ها در کتابخانهٔ رسانه. |
| روابط چندریختی (polymorphic) | `uid:documentId`، برای مثال `api::article:k3v9…`. |
| کامپوننت‌ها، ناحیه‌های پویا، بلوک‌ها و JSON | JSON. |

در CSV، فهرست‌ها (چند رابطه یا چند فایل) با `|` به هم وصل می‌شوند.

```csv title="articles.csv"
documentId,title,slug,featured,tags
,Hello world,hello-world,true,t1a2b3|t4c5d6
k3v9x8…,Updated title,updated-title,false,
```

همین ردیف‌ها به‌صورت JSON:

```json title="articles.json"
[
  { "title": "Hello world", "slug": "hello-world", "featured": true, "tags": ["t1a2b3", "t4c5d6"] },
  { "documentId": "k3v9x8…", "title": "Updated title", "slug": "updated-title", "featured": false }
]
```

خروجی یک فهرست همیشه فایل درون‌ریزی معتبری برای همان نوع محتوا است.

## Admin API

- `GET /admin/api/content/{uid}/export?format=csv` (یا `json`) پارامترهای کوئری فهرست را
  می‌پذیرد: `filters`، `_q`، `sort`، `status` و `locale`.
- `POST /admin/api/content/{uid}/import?locale=` محتوای فایل را به‌صورت یک رشته می‌پذیرد:

```json
{
  "format": "csv",
  "data": "title,slug\nHello world,hello-world\n",
  "mapping": { "slug": "slug", "notes": null },
  "dryRun": true,
  "publish": false
}
```

`mapping` یک ستون را به یک فیلد نگاشت می‌کند؛ `null` آن ستون را نادیده می‌گیرد، و ستون‌های
نگاشت‌نشده نام خود را نگه می‌دارند. بدنهٔ درخواست با `[server].body_limit` (به‌طور پیش‌فرض
1 MB) محدود می‌شود.

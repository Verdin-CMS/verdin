ویرایش دیداری صفحهٔ پیش‌نمایش شما را به نقشه‌ای از پنل مدیریت تبدیل می‌کند: ویراستار نشانگر
را روی یک سرعنوان می‌برد، روی **ویرایش** کلیک می‌کند و مدخل با تمرکز روی همان فیلد باز می‌شود.
این قابلیت بر پایهٔ [پیش‌نمایش](/fa/guides/content/preview/) ساخته شده است: ابتدا نشانی‌های
پیش‌نمایش را تنظیم کنید، سپس دو بخش زیر را به صفحهٔ پیش‌نمایش اضافه کنید.

Verdin در هر متنی که برمی‌گرداند یک source map کوچک و نامرئی پنهان می‌کند (روشی که به
*stega* معروف است) و یک اسکریپت overlay این متن‌ها را در صفحه پیدا می‌کند. در کامپوننت‌های شما
چیزی تغییر نمی‌کند: متن نشانه‌گذاری‌شده مثل هر متن دیگری نمایش داده می‌شود.

## راه‌اندازی

<Steps>

1. در **تنظیمات ← قابلیت‌ها**، **پیش‌نمایش** را روشن کنید، **پیکربندی نشانی‌های پیش‌نمایش** را
   انتخاب کنید و به هر نوع محتوا نشانی صفحه‌ای را بدهید که آن را نمایش می‌دهد. بخش
   **ویرایش دیداری** در همین پنجره، تگ script و سرآیند مورد نیاز سرور شما را نشان می‌دهد.
   [پیش‌نمایش](/fa/guides/content/preview/) را ببینید.

2. در صفحهٔ پیش‌نمایش، محتوا را با یک توکن و سرآیند `x-verdin-stega: true` دریافت کنید.
   توکن، توکن پیش‌نمایش موجود در نشانی پیش‌نمایش است (`?preview=…` که به‌صورت
   `x-verdin-preview` برگردانده می‌شود) یا یک توکن API:

   ```js
   const response = await fetch(`${CMS}/api/articles/${documentId}?status=draft&populate=*`, {
     headers: {
       'x-verdin-preview': previewToken, // or Authorization: Bearer <API token>
       'x-verdin-stega': 'true',
     },
   });
   ```

3. overlay را در همان صفحه بارگذاری کنید:

   ```html
   <script src="https://cms.example.com/admin/api/visual-editing.js" defer></script>
   ```

   مسیر از [`[admin].path`](/fa/reference/configuration/) پیروی می‌کند: `{path}/api/visual-editing.js`.

</Steps>

با [کلاینت تایپ‌شده](/fa/guides/frontend/typed-client/)، هر دو سرآیند را در `headers` بدهید:

```ts
const preview = createClient<VerdinSchema>({
  url: CMS,
  headers: { 'x-verdin-preview': previewToken, 'x-verdin-stega': 'true' },
});
const { data } = await preview.collection('articles').findOne(documentId, {
  status: 'draft',
  populate: '*',
});
```

source mapها فقط به پاسخ‌های REST اضافه می‌شوند، نه به GraphQL: محتوای پیش‌نمایش را از طریق
REST API بخوانید.

نشانگر را روی متن نشانه‌گذاری‌شده در صفحه ببرید: یک حاشیهٔ سبز و یک دکمهٔ **ویرایش** می‌گیرد.
درون پیش‌نمایش کنار هم پنل مدیریت (**باز کردن پیش‌نمایش** ← **کنار هم**)، این دکمه از پنل
مدیریت می‌خواهد فیلد را همان‌جا باز کند. وقتی صفحه به‌تنهایی باز است، دکمه مدخل را در یک زبانهٔ
جدید باز می‌کند.

<Aside type="note">
source mapها فقط به درخواست‌های `GET` اضافه می‌شوند که `x-verdin-stega: true` **و** یک توکن
(`Authorization` یا `x-verdin-preview`) بفرستند. ترافیک عمومی و هر چیزی که CDN شما کش کند هرگز
آن‌ها را ندارد، و پاسخ‌های نشانه‌گذاری‌شده با `Cache-Control: private, no-store` ارسال می‌شوند.
</Aside>

## چه چیزهایی نشانه‌گذاری می‌شوند

| نشانه‌گذاری می‌شود | نشانه‌گذاری نمی‌شود |
| --- | --- |
| ویژگی‌های `string`، `text` و `richtext` | `uid`، `email`، `password`، `enumeration` |
| اولین متن هر بلوک از یک ویژگی `blocks` | اعداد، مقادیر بولی، تاریخ‌ها، JSON |
| همین موارد درون کامپوننت‌ها و ناحیه‌های پویا (`seo.metaTitle`، `blocks.2.title`) | رشته‌های خالی |
| روابط populate‌شده، که به مدخل مرتبط اشاره می‌کنند | فیلدهای رسانه |

overlay نشانه‌ها را در ویژگی‌های `alt` و `title` هم می‌خواند؛ بنابراین متن نشانه‌گذاری‌شده‌ای که
در یکی از آن‌ها بگذارید (مثلاً فیلد زیرنویسی که به‌عنوان `alt` استفاده می‌شود) قابل کلیک می‌ماند.

## حذف نشانه‌ها جایی که متن داده است

نشانه‌ها نویسه‌هایی نامرئی هستند که به انتهای متن اضافه می‌شوند. جایی که یک مقدار را به‌عنوان
داده به کار می‌برید و نه برای نمایش (یک کلید، یک URL، یک مقایسه، بررسی طول `<title>`)، ابتدا
آن‌ها را حذف کنید:

```js
const clean = (text) => text.replace(/⁤[​-‍⁠]*⁣/g, '');

if (clean(article.category.name) === 'News') { /* … */ }
```

فیلدهایی که ذاتاً داده هستند، مانند slugهای `uid` و enumerationها، هرگز نشانه‌گذاری نمی‌شوند؛
بنابراین مسیریابی بر اساس `slug` بدون تغییر کار می‌کند.

## یک نشانه چگونه کدگذاری می‌شود

برای ابزارهایی که خودشان نشانه‌ها را می‌خوانند: یک نشانه با U+2064 شروع می‌شود، سپس هر بایت UTF-8 از

```json
{"origin":"verdin","href":"https://cms.example.com/admin/content/api::article/<documentId>?locale=en&field=seo.metaTitle"}
```

به‌صورت چهار رقم در مبنای 4 (پرارزش‌ترین رقم اول) که با U+200B، U+200C، U+200D و U+2060 نوشته
می‌شوند، و در پایان U+2063. نشانی پنل مدیریت از [`[server].public_url`](/fa/reference/configuration/)
و `[admin].path` می‌آید. overlay با `postMessage` پیام `{ type: 'verdin:edit', href }` را به
پنجرهٔ والد می‌فرستد؛ پنل مدیریت فقط وقتی به آن عمل می‌کند که از origin نشانی پیش‌نمایش آمده باشد.

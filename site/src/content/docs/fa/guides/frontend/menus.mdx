قابلیت **منوها** به ویراستاران درخت‌های ناوبری نام‌دار (سرصفحه، پاصفحه، نوار کناری) می‌دهد
که به صفحه‌ها، مدخل‌ها یا سایت‌های دیگر پیوند می‌دهند. سایت شما یک منو را با slug آن دریافت و
نمایش می‌دهد؛ پیوندهای مدخل از وضعیت انتشار و مسیر آن مدخل پیروی می‌کنند.

در Strapi این کار معمولاً به یک افزونهٔ ناوبری یا یک نوع محتوای منوی دست‌ساز نیاز دارد؛ در
Verdin به‌صورت داخلی وجود دارد.

## روشن کردن

در **تنظیمات ← قابلیت‌ها**، **منوها** را روشن کنید و سپس **مدیریت منوها** را انتخاب کنید (یا
به **تنظیمات ← منوها** بروید). مدیریت منوها به مجوز **مدیریت SEO، تغییرمسیرها، منوها و فرم‌ها**
(`site.manage`) نیاز دارد که نقش داخلی Editor آن را دارد.
[مجوزها](/fa/reference/permissions/) را ببینید.

برای پیوند دادن مدخل‌ها با مسیرشان، الگوهای مسیر را هم در [SEO و نقشهٔ سایت](/fa/guides/frontend/seo-and-sitemap/) تنظیم کنید.

## ساخت یک منو

<Steps>

1. در **تنظیمات ← منوها**، **منوی جدید** را انتخاب کنید.
2. به آن یک نام (مثلاً **ناوبری اصلی**) و یک **Slug** (`main`) بدهید: حروف کوچک، ارقام و
   خط تیره. سایت‌ها منو را با slug آن دریافت می‌کنند.
3. **افزودن مورد** را انتخاب کنید و مورد را پر کنید:
   - **برچسب**: متن پیوند، حداکثر 255 نویسه.
   - **پیوند به**: **یک نشانی**، **یک مدخل** یا **هیچ‌کدام (یک سرعنوان)**.
   - **نشانی**: یک مسیر (`/about`)، یک لنگر (`#team`)، یا یک پیوند `http(s)`، `mailto:` یا
     `tel:`.
   - برای یک مدخل، **انتخاب مورد** را انتخاب کنید: اگر چند نوع قابل پیوند باشند **نوع محتوا**
     را برگزینید، مدخل‌ها را جستجو کنید و یکی را انتخاب کنید.
   - **باز شدن در**: **همان زبانه** یا **زبانهٔ جدید**.
4. موارد را بکشید تا مرتب و تودرتو شوند، یا از دکمه‌هایشان استفاده کنید. با صفحه‌کلید، روی
   دستگیرهٔ کشیدن: Alt+↑ و Alt+↓ مورد را جابه‌جا می‌کنند، Alt+→ آن را زیر مورد بالایی
   تودرتو می‌کند و Alt+← آن را بیرون می‌آورد.
5. ذخیره کنید.

</Steps>

هر منو حداکثر 5 سطح و 500 مورد دارد.

## دریافت یک منو

سایت‌ها یک منو را بدون توکن از `GET /api/_menus/{slug}` می‌خوانند. برای محتوای بومی‌سازی‌شده
`?locale=` را اضافه کنید:

```sh title="Terminal"
curl 'https://cms.example.com/api/_menus/main?locale=fr'
```

```json
{
  "data": {
    "slug": "main",
    "name": "Main navigation",
    "items": [
      { "id": "a1", "label": "Blog", "url": "/blog" },
      {
        "id": "a2",
        "label": "Topics",
        "children": [
          {
            "id": "a3",
            "label": "Rust",
            "entry": { "uid": "api::category", "documentId": "hx2n8r3w…", "path": "/fr/topics/rust" },
            "url": "/fr/topics/rust"
          }
        ]
      },
      { "id": "a4", "label": "Contact", "url": "mailto:hello@example.com", "target": "_blank" }
    ]
  }
}
```

پیوندهای مدخل این‌گونه حل می‌شوند:

- مدخلی که در زبان درخواست‌شده منتشر نشده باشد، (همراه با فرزندانش) از منو کنار گذاشته
  می‌شود. منوها هرگز پیش‌نویس‌ها را فاش نمی‌کنند.
- `entry.path` از الگوی آن نوع در [SEO و نقشهٔ سایت](/fa/guides/frontend/seo-and-sitemap/) می‌آید
  که با فیلدهای مدخل و زبان پر می‌شود. اگر نوع الگویی نداشته باشد یا مدخل آن را پر نکند،
  مقدار آن `null` است.
- وقتی مورد `url` مخصوص خود را ندارد، مسیر را به‌عنوان `url` می‌گیرد؛ بنابراین بیشتر سایت‌ها
  فقط لازم است `url` را بخوانند.

بدون `locale`، مدخل‌ها در زبان پیش‌فرض خوانده می‌شوند. پاسخ با
`Cache-Control: public, max-age=60` ارسال می‌شود.

## نمایش منو

```tsx title="Nav.tsx"
type Item = { label: string; url?: string; target?: '_self' | '_blank'; children?: Item[] };

export async function Nav({ locale }: { locale: string }) {
  const response = await fetch(`${process.env.VERDIN_URL}/api/_menus/main?locale=${locale}`);
  const { data } = await response.json();
  return <ul>{data.items.map((item: Item) => <NavItem key={item.label} item={item} />)}</ul>;
}

function NavItem({ item }: { item: Item }) {
  return (
    <li>
      {item.url ? <a href={item.url} target={item.target}>{item.label}</a> : <span>{item.label}</span>}
      {item.children?.length ? <ul>{item.children.map((child) => <NavItem key={child.label} item={child} />)}</ul> : null}
    </li>
  );
}
```

<Aside type="note">
حذف یک منو باعث می‌شود `/api/_menus/{slug}` پاسخ `404` بدهد؛ خاموش کردن قابلیت هم همین اثر را
دارد. این حالت را در سایت خود مدیریت کنید، مثلاً با نمایش ندادن ناوبری.
</Aside>

## Admin API

پنل مدیریت از `/admin/api/site/menus` (`GET`، `POST`) و
`/admin/api/site/menus/{id}` (`GET`، `PUT`، `DELETE`) استفاده می‌کند، با توکن دسترسی یک مدیر و
مجوز `site.manage`. [Admin API](/fa/api/admin/) را ببینید.

هذه الصفحة هي العقد الكامل بين Verdin والإضافة: ملف manifest، وما يرسله Verdin
إلى كل دالة مُصدَّرة وما يتوقعه في المقابل، ودوال المضيف التي يمكن للوحدة
استدعاؤها. للمقدمة، راجع [الإضافات](/ar/extending/plugins/)؛ ولمثال عملي،
[درس الإضافات](/ar/extending/plugin-tutorial/).

## مجلد الإضافة

كل إضافة مجلد تحت `[plugins].path` (افتراضيًا `plugins/`، بجوار
`verdin.toml`):

| الملف | مطلوب | المحتويات |
| --- | --- | --- |
| `plugin.toml` | نعم | ملف manifest. |
| `plugin.wasm` | نعم | الوحدة (أو مسار آخر عبر `wasm`). |
| `admin/` | لا | ملفات تحمّلها لوحة الإدارة: وحدة `admin.script` وأصولها. |

عند بدء التشغيل يحمّل Verdin كل مجلد يحتوي على `plugin.toml`، بترتيب الأسماء.
يُتخطّى المجلد، ويُدرج مع السبب في **الإعدادات ← الإضافات**، عندما يكون
ملف manifest الخاص به غير صالح، أو تكون وحدته مفقودة، أو تملك إضافة أخرى `name` نفسه.

## ملف manifest

```toml title="plugins/slugs/plugin.toml"
name = "slugs"
version = "1.0.0"
description = "Slugs from titles, and a color field"

[capabilities]
read = ["api::article"]
write = ["api::tag"]
http = ["api.example.com"]
kv = true
public_permissions = true

[limits]
timeout_ms = 5000
memory_mb = 64

[[hooks]]
on = "beforeCreate"
uid = "api::article"
function = "before_write"

[routes]
function = "handle"

[[jobs]]
schedule = "*/15 * * * *"
function = "refresh"

[startup]
function = "seed"
timeout_ms = 30000

[[graphql]]
name = "slugStats"
function = "stats"

[admin]
script = "index.js"

[[admin.widgets]]
id = "stats"
title = "Slug stats"
element = "slugs-stats"

[[admin.fields]]
id = "color"
title = "Color"
element = "slugs-color"
type = "string"

[[settings]]
key = "separator"
label = "Separator"
type = "select"
options = ["-", "_"]
default = "-"
```

المفاتيح غير المعروفة أخطاء، في كل جدول.

### مفاتيح المستوى الأعلى

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `name` | مطلوب | معرّف الإضافة في عناوين URL والإعدادات والحقول المخصصة: أحرف صغيرة وأرقام و`-`، يبدأ بحرف، بحد أقصى 64 حرفًا. |
| `version` | مطلوب | يُعرض في لوحة الإدارة وفي السجل. |
| `description` | غير معيَّن | يُعرض في **الإعدادات ← الإضافات**. |
| `wasm` | `"plugin.wasm"` | الوحدة، نسبةً إلى مجلد الإضافة (بلا `..`، وليس مسارًا مطلقًا). |
| `wasi` | `false` | يمنح الوحدة WASI: ساعة وأرقامًا عشوائية. بلا ملفات أو مقابس في الحالتين. |

### `[capabilities]`

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `read` | `[]` | أنواع المحتوى التي يمكن لـ `verdin_content` قراءتها (`findMany`، `findOne`): قيم uid مثل `api::article`، أو `"*"` للكل. |
| `write` | `[]` | أنواع المحتوى التي يمكنها تنفيذ `create` و`update` و`delete` و`publish` و`unpublish` عليها. يتضمن `read`. |
| `http` | `[]` | المضيفون الذين يمكن للوحدة إرسال طلبات HTTP إليهم: `api.example.com`، أو `*.example.com`. |
| `kv` | `false` | تخزين المفتاح-القيمة الخاص بالإضافة (`verdin_kv_get`، `verdin_kv_set`). |
| `public_permissions` | `false` | قراءة صلاحيات API المحتوى للدور العام واستبدالها (`verdin_public_permissions`). |

تحدّ القدرات استدعاءات المضيف فقط. تعمل الخطافات على الأنواع التي تسمّيها مهما قال `read`،
ويمكن لأي شخص الوصول إلى المسارات.

### `[limits]`

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `timeout_ms` | `5000` | الحد الزمني لاستدعاء واحد، بالمللي ثانية. |
| `memory_mb` | `64` | أكبر ذاكرة للوحدة، بالميغابايت. |

يجب أن يكون كلاهما موجبًا.

### `[[hooks]]`

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `on` | مطلوب | الحدث، أدناه. |
| `uid` | `"*"` | نوع المحتوى (`api::article`)، أو `"*"` للكل. |
| `function` | مطلوب | الدالة المُصدَّرة المراد استدعاؤها. |

الأحداث:

| قبل الكتابة | بعد الكتابة |
| --- | --- |
| `beforeCreate` | `afterCreate` |
| `beforeUpdate` | `afterUpdate` |
| `beforeDelete` | `afterDelete` |
| `beforePublish` | `afterPublish` |
| `beforeUnpublish` | `afterUnpublish` |
| `beforeDiscardDraft` | `afterDiscardDraft` |

الأسماء هي أسماء دورة الحياة في Strapi. تعمل الخطافات على عمليات الكتابة من لوحة الإدارة وواجهتي REST
وGraphQL وحزم النشر، لكن لا تعمل على عمليات الكتابة التي تجريها أوامر `verdin import`.
أما عمليات الكتابة التي تجريها الإضافات فتشغّل خطافات after ولا تشغّل خطافات before (راجع
[عمليات الكتابة التي تجريها الإضافات](#عمليات-الكتابة-التي-تجريها-الإضافات)).

### `[routes]`

| المفتاح | الوصف |
| --- | --- |
| `function` | الدالة المُصدَّرة التي تقدّم كل طلب إلى `/api/plugins/<name>` و`/api/plugins/<name>/…`، بأي طريقة. |

يتبع المسار `[api].prefix`.

### `[[jobs]]`

| المفتاح | الوصف |
| --- | --- |
| `schedule` | تعبير Cron، بتوقيت UTC، مع ثوانٍ اختيارية: `*/15 * * * *`، `0 0 3 * * *`. |
| `function` | الدالة المُصدَّرة المراد استدعاؤها. |

### `[startup]`

دالة تعمل عند بدء الإضافة: ما يفعله مشروع Strapi في `bootstrap`
(التهيئة بمحتوى أولي، وضبط الدور العام).

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `function` | مطلوب | الدالة المُصدَّرة المراد استدعاؤها. |
| `timeout_ms` | `30000` | حد وقتها الخاص، بالميلي ثانية (قد تستغرق التهيئة بالمحتوى وقتًا أطول من خطاف). يجب أن يكون موجبًا. |

راجع [دالة البدء](#دالة-البدء) لمعرفة متى تعمل.

### `[[graphql]]`

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `name` | مطلوب | اسم الحقل: يبدأ بحرف صغير، ثم أحرف وأرقام و`_`. |
| `function` | مطلوب | الدالة المُصدَّرة التي تحلّه. |
| `mutation` | `false` | يضيف الحقل إلى `Mutation` بدلًا من `Query`. |
| `description` | غير معيَّن | وصف الحقل في المخطط. |

يضيف كل مدخل `name(args: JSON): JSON`. الاسم الذي يستخدمه نوع محتوى بالفعل، أو
الذي أخذته إضافة أخرى أولًا، يُتخطّى مع تحذير في السجل.

### `[admin]`

| المفتاح | الوصف |
| --- | --- |
| `script` | وحدة ES تحت `admin/` تعرّف العناصر المخصصة (بلا `..`، وليس مسارًا مطلقًا). |
| `[[admin.widgets]]` | أنواع أدوات لوحة المعلومات: `id`، `title`، `element`، و`description` اختياري. |
| `[[admin.fields]]` | الحقول المخصصة: `id`، `title`، `element`، `type` (نوع السمة التي تُخزَّن القيمة بها، مثل `string` أو `json`)، و`description` اختياري. |

`element` اسم عنصر مخصص: أحرف صغيرة وأرقام و`-`، مع `-` واحدة
على الأقل (`slugs-color`).

### `[[settings]]`

يعلن نموذج **الإعدادات ← الإضافات ← الإعدادات**. بدون أي مدخل، تكون الإعدادات
كائن JSON حرًا.

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `key` | مطلوب | المفتاح في كائن الإعدادات: أحرف وأرقام و`_`، لا يبدأ برقم، وفريد. |
| `label` | مطلوب | تسمية النموذج. |
| `type` | `"string"` | `string` أو `text` أو `url` أو `number` أو `integer` أو `boolean` أو `select`. |
| `description` | غير معيَّن | نص مساعدة تحت الحقل. |
| `required` | `false` | يلزم وجود قيمة (غير فارغة للنص)، ما لم يوجد `default`. |
| `options` | `[]` | خيارات `select` (مطلوبة له). |
| `default` | غير معيَّن | يُستخدم عندما يكون المفتاح مفقودًا أو `null`. يجب أن يلائم الحقل. |
| `min`، `max` | غير معيَّن | حدود قيم `number` و`integer`؛ وحدود الطول لـ `string` و`text`. |

قيم `url` فارغة أو عناوين `http(s)://`. مع وجود نموذج، يرفض الخادم الإعدادات ذات
المفاتيح غير المعروفة، أو الأنواع الخاطئة، أو القيم خارج الحدود، أو القيم المطلوبة المفقودة (400).

## الدوال المُصدَّرة

تأخذ كل دالة مُصدَّرة مستند JSON واحدًا وتعيد واحدًا (أو لا شيء). يُحسب
المخرج الفارغ على أنه `null`؛ والمخرج الذي ليس JSON يُحسب إخفاقًا.

### خطافات before

المدخل:

```json
{
  "event": "beforeUpdate",
  "uid": "api::article",
  "documentId": "01m3p88ry359w82nsx496mep5t",
  "locale": "en",
  "data": { "title": "Hello" }
}
```

| الحقل | الوصف |
| --- | --- |
| `event` | حدث الخطاف. |
| `uid` | نوع المحتوى. |
| `documentId` | المستند، أو `null` في `beforeCreate`. |
| `locale` | في الأنواع المترجمة، اللغة المكتوبة (اللغة الافتراضية عندما لا يسمّي الطلب لغة)؛ و`null` في الأنواع الأخرى. |
| `data` | البيانات التي تُكتب، كما أرسلها الطلب: عند الإنشاء والتحديث. و`null` للأحداث الأخرى. عند التحديث، الحقول المرسلة فقط. |

المخرج:

| المخرج | الأثر |
| --- | --- |
| `{ "data": { … } }` | يستبدل البيانات المكتوبة. ويُتحقق منها كما يُتحقق من الأصل. |
| `{ "error": "message" }` | يرفض الكتابة: يحصل المستدعي على 400 مع الرسالة. |
| `{}` أو أي شيء آخر | تستمر الكتابة دون تغيير. |

عندما تتطابق عدة خطافات، تُنفَّذ بترتيب الإضافات (أسماء المجلدات)، ثم بترتيب ملف manifest؛
ويرى كل منها البيانات التي أعادها السابق. الخطاف الذي يفشل (trap، أو انتهاء مهلة، أو مخرج
غير صالح) يُسجَّل ويُتخطّى: وتستمر الكتابة.

### خطافات after

المدخل: `{ "event", "uid", "documentId", "locale" }`، يُرسل بعد اعتماد الكتابة.
يُتجاهل المخرج؛ وتُسجَّل الإخفاقات. اقرأ الإدخال بـ `verdin_content` إن كنت
تحتاج إلى حقوله (مع القدرة `read`).

### المسارات

المدخل:

```json
{
  "method": "GET",
  "path": "/stats",
  "query": "page=2&sort=title",
  "headers": { "accept": "application/json", "user-agent": "curl/8.7.1" },
  "body": "",
  "actor": { "kind": "public" }
}
```

| الحقل | الوصف |
| --- | --- |
| `method` | طريقة HTTP. |
| `path` | المسار بعد `/api/plugins/<name>`، ويبدأ بـ `/` (`/` لجذر الإضافة). |
| `query` | سلسلة الاستعلام الخام، دون `?` (فارغة عند عدم وجودها). |
| `headers` | فقط `content-type` و`accept` و`user-agent` و`accept-language`، عند وجودها. |
| `body` | جسم الطلب كسلسلة نصية (يُستبدل UTF-8 غير الصالح). |
| `actor` | من يستدعي: `{ "kind": "public" }`، أو `{ "kind": "token", "id": 3 }` (رمز API) أو `{ "kind": "user", "id": 12 }` (مستخدم نهائي مسجّل الدخول). |

تُرفض ترويسة `Authorization` برمز غير صالح بـ 401 قبل استدعاء
الإضافة. لا تُطبَّق صلاحيات الوصول العام ورموز API: تحقق من `actor` بنفسك.

المخرج:

| الحقل | الافتراضي | الوصف |
| --- | --- | --- |
| `status` | `200` | حالة HTTP. |
| `headers` | لا شيء | ترويسات الاستجابة. لا يُحتفظ إلا بـ `content-type` و`cache-control` و`location` و`etag` و`last-modified` و`content-disposition`. |
| `body` | فارغ | تُرسل السلسلة النصية كما هي (`text/plain` ما لم تعيّن `content-type`)؛ وتُرسل أي قيمة JSON أخرى بنوع `application/json`. |

الإضافة المعطّلة أو غير المعروفة، أو التي لا تحتوي على `[routes]`، تجيب بـ 404. والاستدعاء الفاشل
يجيب بـ 502 مع `{ "data": null, "error": { "status": 502, "name": "PluginError", … } }`.
تتشارك المسارات مع API المحتوى `[server].body_limit` و`[server].request_timeout_secs`.

### المهام

المدخل: `{ "scheduledAt": "2026-09-29T03:00:00+00:00" }`، الوقت الذي جُدول له
التشغيل. يُتجاهل المخرج؛ وتُسجَّل الإخفاقات. لا تعمل المهام إلا ما دامت الإضافة مفعّلة،
وفقط على النسخ التي فيها `[plugins].run_jobs = true`. التشغيل الذي فات أثناء توقف الخادم
لا يُعوَّض.

### دالة البدء

المدخل: `{ "reason": "start" | "enabled" | "settings" }`:

| `reason` | متى |
| --- | --- |
| `start` | بدأ الخادم والإضافة مفعّلة. |
| `enabled` | فُعّلت الإضافة (هنا، أو على نسخة أخرى والتُقط ذلك هنا). |
| `settings` | تغيّرت إعداداتها وهي مفعّلة (حُفظت هنا، أو التُقطت من نسخة أخرى). |

المخرج: `{ "error": "message" }` يُعدّ إخفاقًا؛ وأي شيء آخر (`{}`، فارغ) يُعدّ
نجاحًا. يذهب الإخفاق (trap، أو انتهاء المهلة، أو `{ error }`) إلى سجل الإضافة وسجل
الخادم؛ وتبقى الإضافة مفعّلة، وتعمل الدالة مجددًا عند البدء أو التفعيل أو
تغيّر الإعدادات التالي.

تعمل الدالة في الخلفية، بعد أن يصبح الخادم جاهزًا، فتُقدَّم الطلبات
في الأثناء. وتعمل على نسخة وحدة خاصة بها بـ `[startup].timeout_ms`، فلا تعطّل
التهيئة البطيئة خطافات الإضافة ومساراتها. وتعمل خطافات after التي تطلقها عمليات كتابتها
بعد عودتها (راجع [عمليات الكتابة التي تجريها الإضافات](#عمليات-الكتابة-التي-تجريها-الإضافات)).
ولا تتشارك ذاكرة الوحدة مع النسخة العادية للإضافة: احتفظ بالحالة في
`verdin_kv_set` أو في المحتوى.

مع عدة نسخ، لا تشغّل دوال البدء إلا النسخ التي فيها `[plugins].run_jobs = true`
(نسخة واحدة، عندما تتبع [نصيحة التوسّع](/ar/deploy/scaling/)): فهي تعمل على
قاعدة البيانات المشتركة، فتكفي مرة واحدة. اكتب الدالة بحيث لا يضر تشغيلها مجددًا:
ابحث عما تهيّئه قبل إنشائه.

### حقول GraphQL

المدخل: `{ "args": …, "actor": … }`، حيث `args` هو وسيط `args` الخاص بالحقل (أي JSON، أو
`null`) و`actor` كما في المسارات. المخرج هو قيمة الحقل. الإخفاق، أو
الإضافة المعطّلة، يجيب بخطأ GraphQL برمز `PLUGIN_ERROR`. كما في المسارات،
تتحقق الإضافة من الوصول.

## دوال المضيف

استوردها من فضاء الأسماء `extism:host/user` (`extern "ExtismHost"` في Rust). تأخذ
JSON وتعيده كسلاسل نصية؛ ويتولى `Json<Value>` في `extism-pdk` التحويل.

| الدالة | المدخل | المخرج |
| --- | --- | --- |
| `verdin_log` | `{ "level": "info" \| "warn" \| "error", "message": "…" }` | لا شيء |
| `verdin_content` | طلب محتوى (أدناه) | النتيجة، أو `{ "error": "…" }` |
| `verdin_kv_get` | المفتاح، كسلسلة نصية عادية | قيمة JSON المخزّنة، أو `null` |
| `verdin_kv_set` | `{ "key": "…", "value": … }` | لا شيء |
| `verdin_config` | لا شيء | كائن الإعدادات، مع ملء القيم الافتراضية المعلنة |
| `verdin_public_permissions` | `{ "op": "get" }` أو `{ "op": "set", "permissions": [...] }` | `{ "permissions": [...] }`، أو `{ "error": "…" }` |

الوحدة التي تستورد دالة مضيف لا يملكها الخادم (إصدار أقدم من Verdin) لا يمكن
تحميلها: يفشل كل استدعاء لها بـ `unknown import` في سجل الخادم.

### `verdin_log`

يكتب في سجل الخادم (مع اسم الإضافة) وفي سجل الإضافة في **الإعدادات ←
الإضافات ← السجلات**. تُحسب المستويات الأخرى على أنها `info`. يحتفظ سجل الإضافة بآخر 200
رسالة، كل منها مقطوعة عند 2,000 حرف، في الذاكرة.

### `verdin_content`

```json
{ "op": "findMany", "uid": "api::article", "query": { "filters": { "title": { "$eq": "x" } }, "sort": ["title"] } }
```

| الحقل | يستخدمه | الوصف |
| --- | --- | --- |
| `op` | الكل | `findMany` أو `findOne` أو `create` أو `update` أو `delete` أو `publish` أو `unpublish`. |
| `uid` | الكل | نوع المحتوى. يجب أن يكون ضمن القدرات. |
| `documentId` | `findOne`، `update`، `delete`، `publish`، `unpublish` | المستند. |
| `query` | `findMany`، `findOne` | معاملات REST API ككائن JSON: `filters`، `sort`، `fields`، `populate`، `pagination`، `status`. |
| `data` | `create`، `update` | الحقول المراد كتابتها، كما في `data` لطلب REST. |
| `status` | `create`، `update` | `"draft"` يحفظ مسودة. وإلا تُنشر الكتابة، مثل كتابة REST دون `?status=draft`. |
| `locale` | الكل | اللغة المراد قراءتها أو كتابتها. |

النتائج:

| `op` | النتيجة |
| --- | --- |
| `findMany` | `{ "documents": [...], "meta": { "pagination": {…} } }` |
| `findOne` | `{ "document": {…} }` (`null` عند عدم العثور عليه) |
| `create`، `update` | `{ "documentId": "…" }` |
| `delete` | `{ "deleted": true }` |
| `publish` | `{ "published": true }` |
| `unpublish` | `{ "unpublished": true }` |

الاستدعاء خارج القدرات، أو العملية غير المعروفة، أو خطأ التحقق، أو المستند
المفقود، يجيب بـ `{ "error": "…" }` بدلًا من ذلك. تعيد القراءات النسخ المنشورة ما لم
يطلب الاستعلام `"status": "draft"`.

#### عمليات الكتابة التي تجريها الإضافات

تتخطى عمليات الكتابة عبر `verdin_content` خطافات **before** لكل الإضافات، فلا تستطيع الإضافة
الدوران في حلقة على تغييراتها هناك، ولا تنطبق عليها القواعد التي تضعها في خطافات before
(القيم الافتراضية، والفحوص). أما كل شيء آخر فيُطبَّق: التحقق، ومراحل المراجعة،
والـ webhooks، والسجل، وسجل التدقيق، وخطافات **after** لكل الإضافات، بما فيها الإضافة
الكاتبة.

لا تعمل خطافات after التي تطلقها عمليات كتابة الإضافة داخل الكتابة: تُوضع في طابور وتعمل
بعد أن يعود استدعاء الإضافة (المسار، أو المهمة، أو محلّل GraphQL، أو الخطاف، أو دالة البدء)
ويحرّر نسخة الإضافة، وقبل إرسال استجابة المسار. فتستطيع الإضافة أن تكتب نوعًا لها خطافات
after عليه، وتعمل السلاسل عبر عدة إضافات.

- الخطافات التي تكتب تطلق خطافات أخرى، **بعمق `4` مستويات على الأكثر** (الكتابة من REST أو
  GraphQL هي المستوى 1). تُتخطى الخطافات الأعمق مع تحذير في سجل الإضافة، مما
  يمنع خطافًا يكتب النوع الذي يستمع إليه من الدوران إلى الأبد.
- تتوقف دوال المضيف (`verdin_content` و`verdin_public_permissions` ومخزن المفتاح-القيمة)
  عند حد وقت الاستدعاء وتعيد خطأ إلى الوحدة، وينتظر المستدعي إضافة مشغولة
  حد الوقت زائد 10 ثوانٍ على الأكثر. فلا يستطيع استدعاء عالق أن يُبقي
  الإضافة، أو إيقافًا سلسًا، معلّقًا إلى الأبد.

### `verdin_kv_get` و`verdin_kv_set`

مخزن مفتاح-قيمة لكل إضافة، في قاعدة بيانات Verdin، تتشاركه كل النسخ. المفاتيح من 1 إلى
255 بايت؛ والقيم أي JSON. تعيين `null` يحذف المفتاح. بدون القدرة `kv`،
تعيد القراءات `null` وتُتجاهل الكتابات.

### `verdin_config`

يعيد الإعدادات المحفوظة في **الإعدادات ← الإضافات**، مع ملء `default` لكل إعداد
معلن للمفاتيح المفقودة. `{}` عندما لا يكون هناك شيء محفوظ.

### `verdin_public_permissions`

يقرأ صلاحيات API المحتوى للدور العام أو يستبدلها، وهي ما تحرّره **الإعدادات ← الوصول
العام**. يحتاج إلى القدرة `public_permissions`؛ وبدونها يجيب كل استدعاء
بـ `{ "error": "…" }`.

```json
{ "op": "set", "permissions": [
  { "subject": "api::article", "action": "find" },
  { "subject": "api::article", "action": "findOne" },
  { "subject": "api::comment", "action": "create" }
] }
```

| `op` | الأثر |
| --- | --- |
| `get` | لا شيء؛ يعيد الصلاحيات الحالية. |
| `set` | يستبدل **كل** الصلاحيات العامة بـ `permissions` (القائمة الفارغة تزيلها كلها). |

يجيب كلاهما بـ `{ "permissions": [{ "subject", "action" }, …] }`، مرتّبة. `subject` هو
uid نوع محتوى، أو `plugin::upload` (مكتبة الوسائط)، أو `plugin::users-permissions.user`
(المستخدمون النهائيون عبر API المحتوى)، أو `plugin::i18n.locale` (`find` فقط). و`action` هو
`find` أو `findOne` أو `create` أو `update` أو `delete` أو `publish` أو `readDrafts` (الأخيران
لا ينطبقان على الرفع والمستخدمين النهائيين). تُفحص مثل شبكة منح الإدارة: الموضوع
أو الإجراء غير المعروف، أو الذي لا ينطبق، يجيب بـ `{ "error": "…" }` ولا
يغيّر شيئًا. يُكتب كل `set` في سجل الخادم.

### HTTP

مع المضيفين المدرجين في `http`، استخدم دعم HTTP في Extism (`extism_pdk::http::request` في
Rust). تفشل الطلبات إلى المضيفين الآخرين.

## نقاط التوسيع في لوحة الإدارة

تطلب لوحة الإدارة من الخادم امتدادات الإضافات المفعّلة وتستورد كل
`admin.script` مرة واحدة، كوحدة ES، من `/admin/plugins/<name>/<script>` (تحت
`[admin].path`). تُقدَّم الملفات الموجودة تحت مجلد `admin/` الخاص بالإضافة هناك ما دامت
الإضافة مفعّلة، مع `X-Content-Type-Options: nosniff` و`Cache-Control: no-cache`.
يجب أن تعرّف الوحدة العناصر المخصصة التي يسمّيها ملف manifest؛ والعنصر الذي لا يُعرَّف خلال
3 ثوانٍ يُستبعد.

### الأدوات

كل مدخل `[[admin.widgets]]` نوع أداة يمكن للمسؤولين إضافته إلى لوحة المعلومات. يتلقى
العنصر خاصية `context`:

| الخاصية | الوصف |
| --- | --- |
| `apiBase` | أساس API المحتوى، مثل `/api`. |
| `adminApiBase` | أساس API الإدارة، مثل `/admin/api`. |
| `fetch(path, init)` | `fetch` ببيانات اعتماد المسؤول المسجّل الدخول. تُحَلّ المسارات النسبية نسبةً إلى `adminApiBase`؛ ويُحتفظ بالمسارات تحت أي من الأساسين وبعناوين URL المطلقة كما هي. |

```js title="plugins/slugs/admin/index.js"
class SlugStats extends HTMLElement {
  set context(context) {
    // Admin API, with the admin's session.
    context.fetch('auth/me').then((response) => response.json())
      .then(({ data }) => { this.textContent = `Hello ${data.firstname ?? data.email}`; });
    // The plugin's own route, on the content API: sent without the admin's session.
    context.fetch(`${context.apiBase}/plugins/slugs/stats`).then((response) => response.json())
      .then((stats) => { this.title = JSON.stringify(stats); });
  }
}
customElements.define('slugs-stats', SlugStats);
```

يرسل `context.fetch` جلسة المسؤول مع طلبات API الإدارة فقط. أما المسارات تحت
`context.apiBase` (API المحتوى، بما فيه مسارات إضافتك) فتذهب بدونها، لأن
API المحتوى لا يقبل جلسات المسؤولين؛ ويُجاب عنها بصلاحيات
الدور العام. قبل 0.10 كان يرسل الجلسة هناك أيضًا وكانت تلك الطلبات تفشل؛ والأدوات
المكتوبة لـ 0.9 التي تستدعي `fetch` العادي تستمر في العمل.

### الحقول المخصصة

كل مدخل `[[admin.fields]]` حقل يمكن للسمات استخدامه بـ
`"customField": "plugin::<name>.<id>"`؛ ويجب أن يطابق `type` السمة طريقة تخزين الحقل
لقيمته. يعرضه **منشئ أنواع المحتوى**. يتلقى العنصر:

| الخاصية | الوصف |
| --- | --- |
| `value` | القيمة الحالية. |
| `disabled` | ما إذا كان التحرير معطّلًا. |
| `attribute` | تعريف السمة من المخطط. |
| `locale` | اللغة قيد التحرير. |

يبلّغ عن قيمة جديدة بحدث `change` يكون `detail` فيه هو القيمة (أو، دون
`detail`، عبر خاصية `value` الخاصة به). عندما تكون الإضافة معطّلة أو يكون عنصرها
مفقودًا، يعرض المحرر حقل الإدخال العادي لنوع التخزين. راجع
[أنواع السمات](/ar/reference/attribute-types/).

## بيئة التشغيل والحدود

| الحد | القيمة |
| --- | --- |
| الوقت لكل استدعاء | `[limits].timeout_ms`، افتراضيًا 5,000 ms (و`[startup].timeout_ms`، افتراضيًا 30,000 ms، لدالة البدء) |
| الذاكرة | `[limits].memory_mb`، افتراضيًا 64 MB |
| التزامن | استدعاء واحد في كل مرة لكل إضافة؛ تنتظر الاستدعاءات بعضها (وتعمل دالة البدء بجانبها) |
| نسخة الوحدة | واحدة لكل إضافة، تُبنى عند أول استخدام؛ وتُعاد بناؤها بعد فشل استدعاء (تضيع ذاكرتها). وتحصل دالة البدء على نسخة جديدة في كل تشغيل |
| السجل | 200 رسالة لكل إضافة، 2,000 حرف لكل منها، في الذاكرة |
| مفاتيح KV | من 1 إلى 255 بايت |
| ترويسات طلب المسار | `content-type`، `accept`، `user-agent`، `accept-language` |
| ترويسات استجابة المسار | `content-type`، `cache-control`، `location`، `etag`، `last-modified`، `content-disposition` |

تُطبَّق التغييرات على ملف manifest أو الوحدة بعد إعادة التشغيل؛ وتُطبَّق المفاتيح والإعدادات
فورًا. تتطلب إدارة الإضافات `plugins.manage` (راجع
[مرجع الصلاحيات](/ar/reference/permissions/)).

## المقاييس

مع تفعيل [`[metrics]`](/ar/deploy/monitoring/)، يبلّغ `/_metrics` عن كل استدعاء وصل إلى
دالة مُصدَّرة:

| المقياس | النوع | التسميات | المعنى |
| --- | --- | --- | --- |
| `verdin_plugin_call_duration_seconds` | histogram | `plugin`، `kind`، `function` | الوقت الذي استغرقته دوال الإضافات. فئات من 5 ms إلى 10 s. |
| `verdin_plugin_call_errors_total` | counter | `plugin`، `kind`، `function` | الاستدعاءات التي فشلت: trap، أو انتهاء المهلة، أو مخرجات ليست JSON، أو `{ error }` من دالة البدء. |

`kind` هو `hook` أو `route` أو `job` أو `startup` أو `graphql`. خطاف before الذي يرفض
كتابة بـ `{ error }` قدّم إجابة، فلا يُعدّ إخفاقًا. لا تُسجَّل الاستدعاءات
إلى دالة لا تُصدّرها الوحدة، فتبقى التسميات محدودة بالإضافات
المثبّتة. تظهر السلاسل بعد أول استدعاء للإضافة؛ وتعدّ كل نسخة استدعاءاتها
الخاصة.

التهيئة طبقات: **القيم الافتراضية المدمجة ← `verdin.toml` ← البيئة**. الملف
اختياري؛ ولكل مفتاح قيمة افتراضية. تُرفض المفاتيح غير المعروفة، فيفشل الخطأ الإملائي
عند البدء بدلًا من تجاهله.

- تجاوز أي مفتاح بـ `VERDIN_<SECTION>__<KEY>` (شرطتان سفليتان)، مثلًا
  `VERDIN_SERVER__PORT=8080` أو `VERDIN_ADMIN__SECURE_COOKIES=false`. تأخذ الجداول المتداخلة
  `__` إضافية: `VERDIN_ADMIN__BRANDING__TITLE=ACME`. تُرفض المفاتيح غير المعروفة هنا أيضًا،
  لذا يجب أن يسمّي أي متغير يبدأ بـ `VERDIN_` ويحتوي على `__` مفتاحًا حقيقيًا.
- `VERDIN_DATABASE_URL` اختصار لـ `database.url`.
- الملف هو `verdin.toml` في مجلد العمل، أو المسار المعطى بـ
  `-c, --config` أو `VERDIN_CONFIG`. تُحَلّ المسارات النسبية فيه (المخطط، والإضافات، والملفات المرفوعة،
  وملفات SQLite) نسبةً إلى مجلد الملف.
- يُحمَّل ملف `.env` المجاور للتهيئة أولًا؛ والمتغيرات المعيّنة بالفعل في
  البيئة لها الأولوية.

لا تُقرأ الأسرار أبدًا من `verdin.toml`؛ راجع [متغيرات البيئة](#متغيرات-البيئة).

## `[server]`

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `host` | `"0.0.0.0"` | العنوان الذي يُستمع عليه. |
| `port` | `1337` | المنفذ الذي يُستمع عليه. |
| `public_url` | غير معيَّن | حيث تصل المتصفحات إلى الخادم، مثل `"https://cms.example.com"`. يُستخدم للروابط في رسائل البريد واستدعاءات SSO؛ وافتراضيًا `http://localhost:{port}`. |
| `body_limit` | `"1mb"` | أكبر جسم طلب لطلبات الـ API العادية (لعمليات الرفع حدها الخاص). عدد من البايتات أو سلسلة مع `b` أو `kb` أو `mb` أو `gb`. |
| `request_timeout_secs` | `30` | الحد الزمني لطلبات الـ API العادية. |
| `sync_interval_secs` | `10` | عدد مرات التقاط الإعدادات التي غيّرتها نسخ أخرى (الميزات، ومفاتيح الإضافات، واللغات، ومسارات المراجعة)؛ و`0` يوقفها (نسخة واحدة). |
| `trusted_proxies` | `[]` | الوكلاء العكسيون (عناوين IP أو نطاقات CIDR، مثل `["10.0.0.0/8"]`) الذين يسمّي `X-Forwarded-For` الخاص بهم العميل. تستخدم حدود المعدل وسجلات التدقيق ذلك العنوان؛ وبدونه، يتشارك كل العملاء خلف الوكيل عنوانًا واحدًا. |

### الموفّر المحلي

الملفات تحت `dir` (نسبةً إلى المشروع)، يقدّمها Verdin على `/uploads`.

```toml
[upload]
provider = { name = "local", dir = "public/uploads" }
```

### `[upload.transforms]`

تحويلات الصور للملفات المحلية: `/uploads/<file>?preset=thumb`، أو
`?w=&h=&fit=&format=&q=` مع توقيع. تُخزَّن الرسوم مؤقتًا على القرص وتُسقط
عندما يتغير الملف (بما في ذلك نقطة تركيزه). تُبقي عمليات القص بـ cover نقطة تركيز الملف
ظاهرة؛ ولا تُكبَّر الصور أبدًا. يمكن تحويل JPEG وPNG وWebP وTIFF وBMP
(لا GIF، التي قد تكون متحركة).

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `enabled` | `true` | تقديم التحويلات. |
| `presets` | `{}` | تحويلات مسمّاة، مسموح بها دائمًا: `{ w, h, fit, format, q }`. |
| `allow_arbitrary` | `false` | قبول أي معاملات دون توقيع. يُرسم كل عنوان URL مختلف ويُخزَّن مؤقتًا، لذا للشبكات الموثوقة فقط. |
| `max_size` | `4096` | أكبر `w` أو `h`، بالبكسل. |
| `cache_dir` | `".cache/transforms"` | مكان الاحتفاظ بالرسوم (نسبةً إلى المشروع؛ وحذفه آمن). |

المعاملات: `w` و`h` (بالبكسل)، و`fit` (`cover`، الافتراضي، يقص إلى المربع؛ و`inside`
يلائمه داخله؛ و`fill` يمطّه)، و`format` (`jpeg`، `png`، `webp`؛ ومخرج WebP
بلا فقد) و`q` (جودة JPEG، من 1 إلى 100، افتراضيًا 80).

```toml
[upload.transforms.presets]
thumb = { w = 300, h = 300 }
hero = { w = 1600, h = 600, format = "webp" }
```

**عناوين URL الموقّعة.** مع تعيين `VERDIN_IMAGE_SECRET`، يكون `s` هو HMAC-SHA256 بترميز hex لـ
`<file>?<canonical query>`، حيث يسرد الاستعلام القانوني المعاملات غير الافتراضية
مرتّبة حسب الاسم (`fit`، `format`، `h`، `q`، `w`؛ مع حذف `fit=cover`):

```js
import { createHmac } from 'node:crypto';
const s = createHmac('sha256', process.env.VERDIN_IMAGE_SECRET)
  .update('photo_1a2b.jpg?format=webp&w=800')
  .digest('hex');
const url = `/uploads/photo_1a2b.jpg?format=webp&w=800&s=${s}`;
```

### موفّر S3

أي خدمة متوافقة مع S3 (AWS، Cloudflare R2، MinIO، Backblaze B2…). تأتي بيانات الاعتماد
من متغيرات البيئة القياسية `AWS_*` (`AWS_ACCESS_KEY_ID`،
`AWS_SECRET_ACCESS_KEY`).

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `bucket` | مطلوب | اسم الحاوية. |
| `region` | غير معيَّن | منطقة الحاوية. |
| `endpoint` | غير معيَّن | نقطة نهاية مخصصة للخدمات غير AWS، مثل `https://<account>.r2.cloudflarestorage.com`. |
| `public_url` | مطلوب | عنوان URL الأساسي العام للحاوية أو الـ CDN الخاص بها؛ تُربط الملفات على شكل `{public_url}/{key}`. |
| `prefix` | `""` | بادئة المفاتيح داخل الحاوية. |
| `path_style` | `false` | طلبات بنمط المسار (MinIO ومعظم الخدمات المستضافة ذاتيًا). |

```toml
[upload]
provider = { name = "s3", bucket = "media", region = "auto",
             endpoint = "https://<account>.r2.cloudflarestorage.com",
             public_url = "https://media.example.com" }
```

## `[ai]`

إجراءات الذكاء الاصطناعي في لوحة الإدارة (مع تفعيل ميزة **إجراءات الذكاء الاصطناعي** في الإعدادات ← الميزات): ترجمة
إدخال إلى لغة أخرى، وكتابة نص بديل للصور، وتلخيص النص، واقتراح بيانات SEO
الوصفية. وهي تعيد اقتراحات؛ ولا يُحفظ شيء دون المحرر. يُقرأ المفتاح
من `VERDIN_AI_KEY` (لا تحتاج الخوادم المحلية إلى أي مفتاح).

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `provider` | `"none"` | `anthropic` أو `openai` أو `openai-compatible` (Ollama، LM Studio، vLLM…). |
| `model` | `claude-sonnet-5` لـ `anthropic` | النموذج؛ مطلوب للموفّرين الآخرين. |
| `base_url` | الخاص بالموفّر | نقطة نهاية أخرى، مثل `http://localhost:11434/v1`. |
| `max_tokens` | `2048` | أطول إجابة. |

```toml
[ai]
provider = "anthropic"
```

يستطيع كل مسؤول إجراء 30 طلبًا للذكاء الاصطناعي في الدقيقة. يُرسل المحتوى والصور إلى
الموفّر: اختر موفّرًا تسمح به مؤسستك.

## `[cdn]`

يفرّغ ذاكرات CDN المؤقتة عندما يتغير المحتوى علنًا. توسم استجابات API المحتوى
بـ `vd` و`vd-<singularName>` (ترويستا `Cache-Tag` و`Surrogate-Key`).

| المفتاح | الافتراضي | الوصف |
| --- | --- | --- |
| `provider` | `"none"` | `cloudflare` أو `fastly` أو `webhook`. |
| `zone_id` | غير معيَّن | منطقة Cloudflare (التفريغ حسب الوسم). |
| `service_id` | غير معيَّن | خدمة Fastly (التفريغ حسب surrogate key). |
| `url` | غير معيَّن | `webhook`: يستقبل `POST { "tags": [...] }`. |
| `debounce_ms` | `1000` | التغييرات المجمّعة قبل التفريغ. |

يُقرأ رمز الـ API من `VERDIN_CDN_TOKEN` (ويُرسل كرمز bearer إلى الـ webhooks).

## متغيرات البيئة

إلى جانب تجاوزات `VERDIN_<SECTION>__<KEY>`، يقرأ Verdin هذه المتغيرات:

| المتغير | الوصف |
| --- | --- |
| `VERDIN_CONFIG` | مسار ملف التهيئة (مثل `--config`). |
| `VERDIN_DATABASE_URL` | اختصار لـ `database.url`. |
| `VERDIN_ADMIN_JWT_SECRET` | يوقّع رموز جلسات الإدارة. مطلوب، 32 بايت على الأقل؛ ولّده بـ `verdin secrets`. |
| `VERDIN_TOKEN_PEPPER` | تجزئة بمفتاح للرموز المخزّنة. مطلوب، 32 بايت على الأقل؛ ولّده بـ `verdin secrets`. |
| `VERDIN_ADMIN_PASSWORD` | كلمة المرور لـ `verdin admin create` و`verdin admin reset-password` (وإلا تُقرأ من stdin)؛ راجع [مرجع سطر الأوامر](/ar/reference/cli/). |
| `VERDIN_EMAIL_SMTP_PASSWORD` | كلمة مرور SMTP. |
| `VERDIN_EMAIL_API_KEY` | مفتاح API لموفّري Resend وPostmark. |
| `VERDIN_SSO_<ID>_SECRET` | سرّ العميل لموفّر SSO؛ و`<ID>` هو معرّف الموفّر بأحرف كبيرة مع `-` كـ `_` (راجع [تسجيل الدخول الموحّد](/ar/guides/auth/sso/)). |
| `VERDIN_OAUTH_<PROVIDER>_SECRET` | سرّ العميل لموفّر OAuth للمستخدمين النهائيين، مسمّى مثل متغيرات SSO (راجع [المستخدمون النهائيون](/ar/guides/auth/end-users/)). |
| `VERDIN_AI_KEY` | مفتاح API لموفّر `[ai]`. |
| `VERDIN_CDN_TOKEN` | رمز API لموفّر `[cdn]`. |
| `VERDIN_IMAGE_SECRET` | يوقّع عناوين URL لتحويلات الصور (راجع [`[upload.transforms]`](#uploadtransforms)). |
| `VERDIN_METRICS_TOKEN` | رمز bearer لعمليات جمع `/_metrics` عند `[metrics].enabled`؛ ويتغلب على `[metrics].token`. |
| `AWS_ACCESS_KEY_ID`، `AWS_SECRET_ACCESS_KEY` | بيانات اعتماد موفّر الرفع S3. |
| `RUST_LOG` | مرشّح السجلات؛ وله الأولوية على `[log].level`. |

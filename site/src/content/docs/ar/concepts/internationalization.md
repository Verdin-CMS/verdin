يحتفظ التدويل (i18n) بمحتوى المستند بعدة لغات. تشرح هذه الصفحة
النموذج: اللغات، والحقول المترجمة والمشتركة، وكيف تختار عمليات القراءة والكتابة
اللغة. لسير عمل المحرر، راجع
[ترجمة المحتوى](/ar/guides/content/localizing-content/).

## اللغات

تُسرد لغات المشروع في **الإعدادات ← التدويل** (الصلاحية
`locales.manage`). يضيف التشغيل الأول الإنجليزية (`en`) لغةً افتراضية.

- هناك دائمًا لغة افتراضية واحدة. تستخدمها الطلبات التي لا تسمّي لغة، ولا يمكن
  حذفها.
- الرموز لغة من حرفين أو ثلاثة أحرف صغيرة، متبوعة اختياريًا بوسوم فرعية:
  `en`، `fr`، `pt-BR`، `zh-Hans`.

:::caution
حذف لغة يحذف أيضًا كل نسخة مكتوبة بها.
:::

## أنواع المحتوى المترجمة

يكون نوع المحتوى مترجمًا عندما ينص مخططه على ذلك. عندئذ يكون لكل مستند نسخة واحدة لكل
لغة، وكلها تتشارك `documentId`:

```json title="schema/content-types/article.json (excerpt)"
{
  "kind": "collectionType",
  "singularName": "article",
  "pluralName": "articles",
  "displayName": "Article",
  "options": { "draftAndPublish": true },
  "pluginOptions": { "i18n": { "localized": true } },
  "attributes": {
    "title": { "type": "string", "required": true },
    "readingTime": { "type": "integer", "pluginOptions": { "i18n": { "localized": false } } }
  }
}
```

مع [المسودة والنشر](/ar/concepts/draft-and-publish/)، لكل لغة مسودتها ونسختها
المنشورة، فيمكن نشر الترجمة الفرنسية قبل النص الإنجليزي أو بعده.
الأنواع التي لا تحمل `pluginOptions.i18n.localized` غير مترجمة وتتجاهل معاملات
`locale`.

## ما الذي يُترجم

في النوع المترجم، كل سمة مترجمة ما لم تنص على
`"pluginOptions": { "i18n": { "localized": false } }`. مثل هذا الحقل **المشترك** له قيمة واحدة
للمستند بأكمله:

- حفظ حقل مشترك في لغة واحدة يكتبه في مسودات كل اللغات.
- نشر لغة ينسخ حقولها المشتركة إلى النسخ المنشورة في اللغات
  الأخرى.
- ينطبق هذا على العلاقات والوسائط أيضًا: العلاقة المشتركة تربط المستندات نفسها في
  كل لغة.

تتبع حقول النظام النسخة: لكل لغة `createdAt` و`updatedAt` و
`publishedAt` خاصة بها. قيم `unique` و`uid` فريدة لكل لغة، فيمكن لترجمتين أن تتشاركا
الـ slug نفسه.

## العلاقات بين الأنواع المترجمة

تربط العلاقات المستندات، لا النسخ (راجع
[العلاقات](/ar/concepts/relations/#مرتبطة-بالمستند-لا-بالصف))، لذا تُختار اللغة
عند القراءة:

- عندما يكون النوعان مترجمين، تعرض المقالة الفرنسية النسخة الفرنسية من
  تصنيفها. وتتطابق عوامل التصفية عبر العلاقة في اللغة نفسها.
- عندما يكون النوع الهدف غير مترجم، ترى كل اللغات الهدف نفسه.

## اختيار اللغة في الواجهات

يأخذ REST وAPI الإدارة `locale` كمعامل استعلام، بصيغة Strapi v5؛ ويأخذ GraphQL
الوسيط `locale`:

```http
GET /api/articles?locale=fr
PUT /api/articles/{documentId}?locale=fr
DELETE /api/articles/{documentId}?locale=fr
```

```graphql
query {
  articles(locale: "fr") {
    documentId
    title
  }
}
```

- بدون `locale`، تقرأ الطلبات وتكتب اللغة الافتراضية.
- `PUT` بلغة لا يملكها المستند بعد ينشئ تلك النسخة.
- `DELETE` يحذف النسخة في اللغة المطلوبة فقط. تُحذف الروابط التي تشير إلى
  المستند عندما لا تبقى أي لغة.
- تتضمن استجابات REST للأنواع المترجمة `locale`. اللغة غير المعروفة خطأ `400`.
- تسجّل حمولات الـ webhook وأحداث الوقت الفعلي وسجل المحتوى لغة النسخة
  التي تغيّرت.

## الصلاحيات لكل لغة

يمكن لأدوار الإدارة حصر صلاحيات المحتوى في بعض اللغات، فيستطيع محرر فرنسي قراءة
النسخ الفرنسية أو تغييرها فقط. راجع [الصلاحيات](/ar/concepts/permissions/#صلاحيات-الحقول-واللغات).
تنطبق صلاحيات API المحتوى (الوصول العام، ورموز API، وأدوار المستخدمين النهائيين) على كل لغة.

## مقارنة مع Strapi

يطابق النموذج والمعاملات i18n في Strapi v5: الأنواع المترجمة، وحقول `localized: false`،
و`?locale=`، واللغة الافتراضية. في Verdin، i18n جزء من النواة ومفعّل دائمًا:
تفعّله لكل نوع محتوى في المخطط.

تتيح ميزة المسودة والنشر للمحررين العمل على مستند دون تغيير ما يعرضه موقعك،
ثم النشر عندما يصبح جاهزًا. تشرح هذه الصفحة النموذج: المستندات، والنسخ،
والإجراءات التي تنقل المحتوى بينها، وكيف يتعامل معها كل API. وهي تعمل كما في
Strapi v5.

فعّلها لكل نوع محتوى في مخططه:

```json title="schema/content-types/article.json (excerpt)"
"options": { "draftAndPublish": true }
```

تكون معطّلة عندما يغيب `options.draftAndPublish`.

## المستندات والنسخ

**المستند** إدخال واحد، يُعرَّف بـ `documentId` الخاص به. مع المسودة والنشر، يكون
للمستند ما يصل إلى **نسختين**:

- **مسودة**، يغيّرها كل تعديل، و
- نسخة **منشورة**، يقدّمها API المحتوى افتراضيًا.

في نوع [مترجم](/ar/concepts/internationalization/)، لكل لغة مسودتها ونسختها
المنشورة، وكلها تتشارك `documentId`.

للأنواع التي لا تستخدم المسودة والنشر نسخة واحدة لكل لغة، وهي منشورة
دائمًا: كل كتابة تغيّر ما يراه القرّاء.

## الحالات

تعرض لوحة الإدارة حالة كل إدخال في القائمة وفي المحرر:

| الحالة | المسودة | النسخة المنشورة | ما يراه قرّاء المحتوى المنشور |
| --- | --- | --- | --- |
| **مسودة** | نعم | لا يوجد | لا شيء: المستند غير مرئي. |
| **منشور** | مطابقة للمنشورة | نعم | النسخة المنشورة. |
| **معدّل** | تغيّرت منذ آخر نشر | نعم | النسخة المنشورة، دون التغييرات الجديدة. |

تنقل الإجراءات المستند بين هذه الحالات:

| الإجراء | الأثر | من ← إلى |
| --- | --- | --- |
| الحفظ | يكتب المسودة. | مسودة ← مسودة، منشور ← معدّل |
| **نشر** | ينسخ المسودة إلى النسخة المنشورة، وينشئها إن لزم. | مسودة أو معدّل ← منشور |
| **إلغاء النشر** | يحذف النسخة المنشورة؛ وتبقى المسودة. | منشور أو معدّل ← مسودة |
| **تجاهل التغييرات** | يستبدل المسودة بنسخة من النسخة المنشورة. | معدّل ← منشور |
| الحذف | يزيل كل النسخ (للغة المطلوبة، في الأنواع المترجمة). | أي حالة ← يختفي |

يجري النشر في معاملة (transaction) واحدة. يتحقق من حقول `required` ومن
[القواعد عبر الحقول](/ar/concepts/content-model/#التحقق-عبر-الحقول) الخاصة بالنوع على المسودة؛
والفحص الفاشل لا ينشر شيئًا. يمكن أن تكون المسودات غير مكتملة وأن تخالف تلك القواعد حتى ذلك الحين.

`publishedAt` هو `null` في المسودات. وتحمل النسخة المنشورة وقت آخر
نشر لها.

## العلاقات والوسائط تتبع النسخة

لكل نسخة روابط العلاقات والوسائط الخاصة بها، والنشر ينسخ روابط المسودة
إلى النسخة المنشورة. تشير الروابط إلى مستندات، وتُحَلّ في النسخة المقروءة:
تعرض المقالة المنشورة النسخة المنشورة من تصنيفها، وتعرض المسودة
مسودة التصنيف. إذا أُلغي نشر التصنيف، يختفي من المقالة المنشورة
حتى يُنشر من جديد، دون إعادة كتابة أي رابط. راجع
[العلاقات](/ar/concepts/relations/#مرتبطة-بالمستند-لا-بالصف).

المكوّنات والمناطق الديناميكية جزء من الصف، لذا ينسخها النشر كما هي.

## قراءة المسودات والمحتوى المنشور

| الـ API | يقرأ افتراضيًا | لقراءة المسودات |
| --- | --- | --- |
| [REST](/ar/api/rest/#الحالة) | النسخ المنشورة | `?status=draft`، الذي يتطلب صلاحية **قراءة المسودات** |
| [GraphQL](/ar/api/graphql/) | النسخ المنشورة | `status: DRAFT`، بالصلاحية نفسها |
| [API الإدارة](/ar/api/admin/) | المسودات | `?status=published` |

قراءة المسودات صلاحية مستقلة (`readDrafts`) حتى لا يستطيع رمزٌ يقرأ محتوى موقعك
قراءة العمل غير المنشور. رموز API للقراءة فقط لا تقرأ المسودات أبدًا.

للتمييز بين المستندات حسب ما إذا كانت قد نُشرت يومًا، صفِّ بـ
`hasPublishedVersion`: يسرد `?status=draft&hasPublishedVersion=false` المستندات التي
لم تُنشر قط.

## الكتابة عبر الواجهات

تتبع الواجهات Strapi v5 في الكتابة:

- **REST وGraphQL**: تكتب `create` و`update` المسودة **وتنشرها**، ما لم
  يطلب الطلب `status=draft` (`status: DRAFT` في GraphQL). النشر الفاشل يتراجع عن
  الطلب بأكمله.
- **لوحة الإدارة وAPI الإدارة**: تحفظان المسودات فقط. النشر دائمًا إجراء
  صريح.

لدى REST API أيضًا إجراءات صريحة، لا يوفرها Strapi عبر REST:

```http
POST /api/articles/{documentId}/actions/publish
POST /api/articles/{documentId}/actions/unpublish
POST /api/articles/{documentId}/actions/discard-draft
```

تتطلب صلاحية **نشر** على النوع. راجع [REST API](/ar/api/rest/#الإجراءات).

## ميزات أخرى تنشر

- تجمع [حزم النشر](/ar/guides/content/releases/) المستندات وتنشرها أو تلغي نشرها
  معًا، الآن أو في تاريخ محدد.
- يمكن لـ[مسارات المراجعة](/ar/guides/content/review-workflows/) أن تشترط مرحلة قبل أن
  يُسمح بنشر المستند.
- يرسل النشر وإلغاء النشر [أحداث الـ webhook](/ar/api/webhooks/) `entry.publish` و`entry.unpublish`
  و[أحداث الوقت الفعلي](/ar/api/realtime/). وترسل عمليات حفظ المسودة
  `entry.update`، الذي لا يتلقاه عبر الوقت الفعلي إلا المستدعون المسموح لهم بقراءة المسودات.

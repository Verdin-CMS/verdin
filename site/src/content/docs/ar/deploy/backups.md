تعيش بيانات مشروع Verdin في مكانين: **قاعدة البيانات** (المحتوى، والمسؤولون، والأدوار،
والرموز، والإعدادات، والسجل، وسجلات التدقيق) و**تخزين الوسائط** (ملفات
مكتبة الوسائط، على القرص أو في حاوية). ملفات المخطط موجودة في مستودعك. انسخ
المخزنين احتياطيًا؛ ويضيف `verdin export` أرشيفًا محمولًا للمحتوى.

| الطريقة | تحتوي على | استخدمها لـ |
| --- | --- | --- |
| تفريغ قاعدة البيانات + نسخة من الوسائط | كل شيء | التعافي من الكوارث للمشروع نفسه |
| `verdin export` | المخطط، واللغات، والوسائط، وكل نسخة من كل إدخال | نقل المحتوى إلى نسخة أخرى أو محرك قاعدة بيانات آخر؛ ونسخة إضافية محمولة |

## تفريغات قاعدة البيانات

استخدم أدوات قاعدة بياناتك نفسها، أو النسخ الاحتياطية التلقائية لدى موفّرك:

```sh frame="terminal"
# PostgreSQL
pg_dump --format=custom --file=verdin-$(date +%F).dump "$VERDIN_DATABASE_URL"

# MySQL / MariaDB
mysqldump --single-transaction --routines -h <host> -u <user> -p <database> > verdin-$(date +%F).sql

# SQLite: نسخة متسقة أثناء عمل الخادم
sqlite3 /data/verdin.db ".backup '/backups/verdin-$(date +%F).db'"
```

لا تنسخ ملف SQLite قيد التشغيل بـ `cp`: استخدم `.backup` (أو أوقف الخادم أولًا).

يحتوي التفريغ على تجزئات كلمات المرور وتجزئات رموز API والحقول الخاصة. شفّره
واحفظه بعيدًا عن الخوادم التي يحميها. لاستعادته، تحتاج أيضًا إلى
`VERDIN_TOKEN_PEPPER` و`VERDIN_ADMIN_JWT_SECRET` نفسيهما: بدون الـ pepper، تتوقف رموز API
ورموز تطبيقات المصادقة الخاصة بالمسؤولين عن العمل.

## تخزين الوسائط

- **الموفّر المحلي**: انسخ مجلد الرفع (`[upload].provider.dir`،
  و`/data/uploads` في صورة Docker) بنسخك الاحتياطي المعتاد للملفات، بعد تفريغ
  قاعدة البيانات حتى لا يكون أي ملف يشير إليه التفريغ مفقودًا.
- **موفّر S3**: فعّل إدارة الإصدارات (versioning) أو النسخ المتماثل على الحاوية، أو انسخها بأدوات
  موفّرك.

يمكن إعادة بناء ذاكرة التخزين المؤقت لتحويلات الصور وفهرس البحث ولا يحتاجان إلى نسخ احتياطي.

## `verdin export`

يكتب `verdin export` مخطط المشروع ومحتواه ووسائطه في ملف `.tar.gz` واحد، و
يستعيده `verdin import verdin` في المشروع نفسه أو في نسخة أخرى، على أي
محرك قاعدة بيانات.

```sh frame="terminal"
verdin export backup-2026-09-28.tar.gz            # المخطط واللغات والوسائط والإدخالات
verdin export content-only.tar.gz --no-media      # دون ملفات الوسائط
verdin import verdin backup-2026-09-28.tar.gz     # إلى هذا المشروع
```

شغّلهما بتهيئة المشروع (`verdin.toml` نفسه والبيئة نفسها التي يستخدمها
الخادم). في حاوية: `docker compose exec verdin verdin export /data/backup.tar.gz`.

### ما الذي يتضمنه

- **ملفات المخطط**، كما هي.
- **اللغات.** يأخذها المشروع الفارغ كلها، بما فيها اللغة الافتراضية. والمشروع
  الذي لديه لغات لا يحصل إلا على المفقودة منها.
- **مجلدات الوسائط وملفاتها**، مع صيغها المتجاوبة. تحتفظ الملفات بـ
  `documentId` الخاص بها؛ وتتغير معرّفاتها الرقمية.
- **كل نسخة من كل إدخال**: المسودات والنسخ المنشورة وكل اللغات، مع
  تواريخها وعلاقاتها (عبر `documentId`) ووسائطها، بما فيها العلاقات والوسائط
  داخل المكوّنات والمناطق الديناميكية. تُضمَّن الحقول الخاصة وتجزئات كلمات المرور.

**غير مُضمَّن**: المستخدمون المسؤولون، والأدوار، ورموز API، والـ webhooks، وإعدادات الميزات، ومسارات
المراجعة، وحزم النشر. أعِد إنشاءها على الهدف، أو استعِد تفريغ قاعدة بيانات
بدلًا من ذلك.

:::caution
يحتوي التصدير على حقول خاصة وتجزئات كلمات المرور. خزّنه كما تخزّن تفريغ قاعدة بيانات.
:::

### الاستيراد

1. يكتب الاستيراد ملفات المخطط ويرحّل قاعدة البيانات بالخطوات الآمنة فقط.
2. ملفات المخطط الموجودة مسبقًا والمختلفة توقفه، ما لم تمرّر `--force`.
3. أنواع المحتوى التي تحتوي على إدخالات بالفعل توقفه أيضًا، ما لم تمرّر
   `--force`؛ فتُضاف الإدخالات حينها بجوار الإدخالات الموجودة.
4. تحتفظ المستندات المستوردة بـ `documentId` الخاص بها، لذا يفشل الاستيراد إلى مشروع
   يحتوي على المستندات نفسها بالفعل.

لا يطلق الاستيراد الـ webhooks ولا خطافات الإضافات، ولا يكتب في السجل.

### صيغة الأرشيف

أرشيف tar مضغوط بـ gzip:

| المسار | المحتويات |
| --- | --- |
| `manifest.json` | `format: "verdin-export"`، وإصدار الصيغة، وإصدار Verdin، والنسخ لكل نوع محتوى |
| `schema/…` | ملفات المخطط |
| `locales.json` | `{ default, locales: [{ code, name }] }` |
| `folders.json`، `files.jsonl` | مجلدات الوسائط وملفاتها، كائن JSON واحد لكل سطر |
| `assets/{hash}{ext}` | الكائنات المخزّنة للملفات وصيغها |
| `entries/{uid}.jsonl` | نسخة واحدة لكل سطر: `documentId`، `locale`، `published`، والتواريخ، `data`، `relations`، `media` |

لجلب مشروع Strapi بدلًا من ذلك، راجع [الترحيل من Strapi](/ar/migrate/from-strapi/).

## اختبر عمليات الاستعادة

استعِد إلى قاعدة بيانات تجريبية بين حين وآخر،
وشغّل Verdin عليها بـ `verdin start`، وتحقق من أنك تستطيع تسجيل الدخول وقراءة الإدخالات
والوسائط.

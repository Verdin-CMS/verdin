Verdin نظام إدارة محتوى headless مفتوح المصدر مكتوب بلغة Rust. تنمذج أنواع المحتوى، ويكتب
محرروك وينشرون في لوحة إدارة، وتقرأ مواقعك وتطبيقاتك المحتوى
عبر REST API أو GraphQL API. لا يعرض Verdin الصفحات: واجهتك الأمامية هي التي تفعل ذلك.

وهو إعادة كتابة لـ [Strapi v5](https://strapi.io): لصيغة المخطط وAPI المحتوى
الشكل نفسه، لذا يمكن لمشروع Strapi وواجهته الأمامية الانتقال بتغييرات قليلة.

## لمن هو

- **المطورون الذين يبنون موقعًا أو تطبيقًا** ويريدون نظام إدارة محتوى يمكنهم تشغيله كعملية واحدة، وإبقاء
  نموذج المحتوى في git، والقراءة منه من أي واجهة أمامية: Astro، أو Next.js، أو تطبيق جوال.
- **الفرق التي تستخدم Strapi** وتريد الـ API نفسه باستهلاك موارد أقل، أو تحتاج إلى ميزات
  يحتفظ بها Strapi للخطط المدفوعة. لا توجد نسخة للمؤسسات في Verdin: SSO وسجلات التدقيق
  ومسارات المراجعة وحزم النشر جزء من المشروع مفتوح المصدر.
- **المحررون**، الذين يحصلون على المسودات والنشر والسجل والمعاينات في لوحة إدارة متاحة
  بـ 18 لغة.

## ما الذي تحتويه العلبة

ملف تنفيذي واحد، `verdin`، هو الخادم وأداة سطر الأوامر ولوحة الإدارة.
لا توجد بيئة تشغيل Node.js ولا `node_modules` في الإنتاج.

| المجال | ما تحصل عليه |
| --- | --- |
| قواعد البيانات | PostgreSQL 14+ وMySQL 8.4+ وMariaDB 10.11+ وSQLite، تغطيها مجموعة الاختبارات نفسها. |
| نموذج المحتوى | أنواع المجموعات، والأنواع المفردة، والمكوّنات، والمناطق الديناميكية، والعلاقات، والوسائط، والنص المنسّق بـ Markdown أو بصيغة الكتل في Strapi. المخطط ملفات JSON في مشروعك. |
| تغييرات المخطط | يصبح كل تغيير خطة ترحيل بمستوى مخاطر وبالـ SQL الدقيق. لا تُنفَّذ الخطوات المُدمِّرة إلا عندما تسمح بها. |
| الواجهات البرمجية | REST تحت `/api` بمعاملات Strapi v5 (`filters`، `populate`، `sort`، `pagination`)، ونقطة نهاية GraphQL اختيارية، ومستند OpenAPI، وعميل TypeScript مُنمَّط. |
| التحرير | المسودة والنشر، والمحتوى المترجم، وسجل المحتوى، وحزم النشر، ومسارات المراجعة، والتعليقات والمهام، والحضور المباشر، والمعاينة والتحرير المرئي على موقعك. |
| الوصول | أدوار إدارة تصل إلى مستوى الحقول واللغات، ورموز API، وصلاحيات الوصول العام، وSSO عبر OpenID Connect، وتسجيل الدخول الثنائي بمفاتيح المرور، وسجلات التدقيق. |
| ميزات الموقع | البحث النصي الكامل، وخريطة الموقع، وإعادات التوجيه، والقوائم والنماذج، والـ webhooks، والتحديثات في الوقت الفعلي. |
| التوسيع | إضافات WebAssembly تتصل بعمليات الكتابة، وتضيف مسارات ومهامًا، وتجلب أدوات للوحة الإدارة وحقولًا مخصصة، محصورة في القدرات التي تعلنها. |

## علاقته بـ Strapi v5

**ما هو متطابق:**

- تستخدم ملفات المخطط صيغة Strapi: `schema/content-types/<singularName>.json` و
  `schema/components/<category>/<name>.json`.
- REST content API: المسارات، وصيغة الاستجابة المسطّحة مع `documentId`، ومعاملات الاستعلام
  وعواملها، ودلالات الكتابة (`POST` أو `PUT` ينشر ما لم تمرّر
  `?status=draft`)، وأجسام الأخطاء.
- مخطط GraphQL مصمَّم على شكل إضافة GraphQL في Strapi v5.
- يتبع المستخدمون النهائيون (التسجيل، وتسجيل الدخول، وOAuth، والأدوار) واجهة `users-permissions`.

**ما هو مختلف:**

- **تغييرات المخطط ترحيلات مخطَّطة.** يقارن Verdin ملفات المخطط بـ
  قاعدة البيانات ويعرض لك الخطوات قبل تنفيذها. ويرفض `verdin start` العمل ما دامت
  قاعدة البيانات متأخرة عن المخطط.
- **لا يعمل منشئ أنواع المحتوى إلا في وضع التطوير.** في الإنتاج يأتي المخطط
  من مستودعك.
- **الإضافات WebAssembly، لا JavaScript.** إضافات Strapi، والمتحكمات والخدمات
  أو ملفات دورة الحياة المخصصة في `src/`، لا تعمل في Verdin.
- **لا تُشارَك قاعدة البيانات مع Strapi.** تنقل مشروع Strapi بـ
  `verdin import strapi`، الذي يمنح كل مستند معرّفًا جديدًا.
- **بعض الإضافات على REST**: إجراءات النشر وإلغاء النشر
  (`POST /api/<route>/<documentId>/actions/publish`)، والمكوّن المُعبّأ يعود
  كاملًا، بما في ذلك المكوّنات المتداخلة.

يسرد [التوافق مع Strapi](/ar/migrate/compatibility/) الاختلافات بالتفصيل.

## متى لا تستخدمه

- **تعتمد على إضافات Strapi أو شيفرة خادم مخصصة بـ JavaScript.** لا يستطيع Verdin تشغيلها؛
  وستضطر إلى إعادة كتابتها كإضافات WebAssembly أو نقل المنطق إلى مكان آخر.
- **تحتاج إلى إصدار 1.0 مستقر.** Verdin في الإصدار 0.10: لا تزال الإصدارات الفرعية قادرة على تغيير
  التهيئة والسلوك. اقرأ [الترقية](/ar/migrate/upgrading/) قبل كل منها.
- **تريد أن يعرض نظام إدارة المحتوى صفحاتك.** Verdin نظام headless؛ اقرنه بإطار عمل للواجهة
  الأمامية أو بمولّد مواقع ثابتة.
- **تريد خدمة مُدارة.** Verdin مستضاف ذاتيًا: تشغّل الملف التنفيذي أو صورة Docker
  على بنيتك التحتية.

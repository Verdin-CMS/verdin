في هذا الدرس تبني مدونة ثابتة باستخدام [Astro](https://astro.build) تقرأ
محتواها من Verdin: صفحة رئيسية تسرد المقالات، وصفحة لكل مقالة على
`/articles/<slug>/` مع تصنيفها، واختياريًا، صفحة تعرض المسودات من
رابط المعاينة في لوحة الإدارة. تستخدم العميل المُنمَّط `@verdin/client` مع أنواع مولّدة من
المخطط.

كُتب لـ Astro 7.3 (`create-astro` 5.2) وNode.js 22.12 أو أحدث، مع Verdin و
`@verdin/client` 0.10. يبني [درس Next.js](/ar/start/tutorial-nextjs/) المدونة نفسها
باستخدام Next.js.

## قبل أن تبدأ

تحتاج إلى الملف التنفيذي `verdin` في `PATH` الخاص بك (راجع [البدء السريع](/ar/start/quickstart/))،
وNode.js وGit. ستحصل في النهاية على مجلدين متجاورين: `cms`، مشروع Verdin، و
`blog`، موقع Astro.

## 1. أعِدّ Verdin بمخطط المدونة

ينمذج المشروع [`examples/blog`](https://github.com/Verdin-CMS/verdin/tree/main/examples/blog)
في المستودع مدونة: مقالات بعنوان، و`slug`، ومقتطف، و`body` بصيغة Markdown، و
تصنيف ووسوم، بالإضافة إلى نوع مفرد للصفحة الرئيسية وبعض المكوّنات.

<Steps>

1. أنشئ مشروع Verdin وانسخ المخطط المثالي إليه:

   ```sh title="Terminal"
   git clone --depth 1 https://github.com/Verdin-CMS/verdin.git
   verdin new cms
   cp verdin/examples/blog/schema/content-types/{article,category,tag,homepage}.json cms/schema/content-types/
   cp -r verdin/examples/blog/schema/components/* cms/schema/components/
   ```

2. شغّله:

   ```sh title="Terminal"
   cd cms
   verdin dev
   ```

   ينشئ التشغيل الأول جداول أنواع المحتوى الأربعة.

3. افتح [http://localhost:1337/admin/](http://localhost:1337/admin/) وأنشئ المسؤول الأول.

4. تحت **المجموعات**، افتح **Category**، واختر **إدخال جديد**، وسمّه `News` واحفظ.

5. افتح **Article**، واختر **إدخال جديد**، واملأ عنوانًا ومقتطفًا وجسمًا بـ
   Markdown. يُولَّد الـ `slug` من العنوان. اختر `News` تصنيفًا واختر
   **نشر**. أضف مقالة ثانية بالطريقة نفسها.

6. افتح **الإعدادات ← الوصول العام**، واسمح بـ **بحث** و**بحث عن واحد** لـ **Article** و
   **Category**، واختر **حفظ**.

</Steps>

تحقق من أن الـ API يجيب:

```sh title="Terminal"
curl 'localhost:1337/api/articles?populate=category'
```

<Aside>
تعبئة علاقة تحتاج إلى صلاحية القراءة على هدفها. بدون **بحث** على **Category**،
يجيب `populate=category` بـ `400` مع ``invalid key `category` in populate``.
</Aside>

## 2. أنشئ مشروع Astro

في طرفية جديدة، بجوار `cms`:

```sh title="Terminal"
npm create astro@latest blog -- --template minimal --no-git --yes
cd blog
npm install @verdin/client marked
```

يحوّل [`marked`](https://marked.js.org) الـ Markdown في الحقل `body` إلى HTML.

## 3. ولّد الأنواع

يقرأ `verdin types` المخطط ويكتب واجهة TypeScript لكل نوع محتوى و
مكوّن، وخريطة `VerdinSchema` للمسارات من أجل العميل. شغّله من `blog`، مشيرًا
إلى تهيئة مشروع Verdin:

```sh title="Terminal"
verdin types -c ../cms/verdin.toml -o src/verdin-types.ts
```

يحتوي الملف، من بين أشياء أخرى، على:

```ts title="src/verdin-types.ts"
export interface Article extends DocumentBase {
  title: string;
  slug: string;
  excerpt: string | null;
  body: string | null;
  // …
  category?: Category | null;
  tags?: Tag[];
}
```

العلاقات والوسائط والمكوّنات اختيارية لأن الـ API لا يعيدها إلا عندما
تعبّئها. شغّل الأمر من جديد كلما تغيّر المخطط.

## 4. اتصل بـ Verdin

أعلن عنوان URL للخادم، ورمز API اختياريًا، في البيئة المُنمَّطة لـ Astro:

```js title="astro.config.mjs"
// @ts-check
import { defineConfig, envField } from 'astro/config';

export default defineConfig({
  env: {
    schema: {
      VERDIN_URL: envField.string({ context: 'server', access: 'public', default: 'http://localhost:1337' }),
      VERDIN_TOKEN: envField.string({ context: 'server', access: 'secret', optional: true }),
    },
  },
});
```

بدون رمز يقرأ العميل بصفة الدور العام، وهو ما فتحته في الخطوة 1.
للقراءة برمز بدلًا من ذلك، أنشئ رمزًا **للقراءة فقط** في **الإعدادات ← رموز API** و
ضعه في `.env` على شكل `VERDIN_TOKEN=…`.

أنشئ العميل مرة واحدة وشاركه:

```ts title="src/lib/verdin.ts"
import { createClient } from '@verdin/client';
import { VERDIN_TOKEN, VERDIN_URL } from 'astro:env/server';
import type { VerdinSchema } from '../verdin-types';

export const verdin = createClient<VerdinSchema>({
  url: VERDIN_URL,
  token: VERDIN_TOKEN,
});
```

لم يعد `verdin.collection('articles')` يقبل إلا مسارات مخططك، ونتائجه
مُنمَّطة كـ `Article`.

## 5. أضف تخطيطًا

استبدل HTML الصفحة الابتدائية بتخطيط تتشاركه الصفحات:

```astro title="src/layouts/Layout.astro"
---
interface Props {
  title: string;
}

const { title } = Astro.props;
---

<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width" />
    <title>{title}</title>
  </head>
  <body>
    <header><a href="/">My blog</a></header>
    <main>
      <slot />
    </main>
  </body>
</html>
```

## 6. اسرد المقالات

```astro title="src/pages/index.astro"
---
import Layout from '../layouts/Layout.astro';
import { verdin } from '../lib/verdin';

const { data: articles } = await verdin.collection('articles').find({
  fields: ['title', 'slug', 'excerpt', 'publishedAt'],
  populate: { category: { fields: ['name'] } },
  sort: ['publishedAt:desc'],
});
---

<Layout title="My blog">
  <h1>Articles</h1>
  <ul>
    {articles.map((article) => (
      <li>
        <a href={`/articles/${article.slug}/`}>{article.title}</a>
        {article.category && <small> in {article.category.name}</small>}
        {article.excerpt && <p>{article.excerpt}</p>}
      </li>
    ))}
  </ul>
</Layout>
```

الاستعلام هو استدعاء REST
`GET /api/articles?fields[0]=title&…&populate[category][fields][0]=name&sort[0]=publishedAt:desc`،
بصيغة Strapi v5. يُبقي `fields` الاستجابة صغيرة، ويضيف `populate` التصنيف
باسمه فقط. لا يقرأ الدور العام إلا المقالات المنشورة.

## 7. أضف صفحة لكل مقالة

يبني Astro صفحة لكل مقالة. يجلب `getStaticPaths` المقالات مع
تصنيفها ويمرّر كلًا منها إلى صفحتها:

```astro title="src/pages/articles/[slug].astro"
---
import type { GetStaticPaths } from 'astro';
import { marked } from 'marked';
import Layout from '../../layouts/Layout.astro';
import { verdin } from '../../lib/verdin';

export const getStaticPaths = (async () => {
  const { data: articles } = await verdin.collection('articles').find({
    populate: { category: true },
    pagination: { pageSize: 100 },
  });
  return articles.map((article) => ({
    params: { slug: article.slug },
    props: { article },
  }));
}) satisfies GetStaticPaths;

const { article } = Astro.props;
const html = await marked.parse(article.body ?? '');
---

<Layout title={article.title}>
  <article>
    <h1>{article.title}</h1>
    {article.category && <p>Category: {article.category.name}</p>}
    <Fragment set:html={html} />
  </article>
</Layout>
```

`pageSize` محدود بـ `[api].max_page_size` (100 افتراضيًا). مع مقالات أكثر،
اجلب الصفحات في حلقة باستخدام `meta.pagination.pageCount`.

<Aside type="caution">
لا يعقّم `marked` الـ HTML. هذا مقبول لـ Markdown يكتبه محرروك؛ أما إذا
كان المحتوى قد يأتي من أشخاص غير موثوقين، فعقّم الـ HTML قبل عرضه.
</Aside>

## 8. شغّله

```sh title="Terminal"
npm run dev
```

افتح [http://localhost:4321](http://localhost:4321): تعرض القائمة مقالاتك المنشورة، وكل منها يرتبط بـ
صفحته. يكتب `npm run build` الموقع الثابت في `dist/`.

يقرأ البناء الثابت المحتوى مرة واحدة. لنشر التغييرات، أعِد بناء الموقع عندما يتغير
المحتوى، مثلًا من webhook أو رابط نشر؛ راجع
[النشر وCDN](/ar/guides/integrations/deploys-and-cdn/).

يبدو مشروعك الآن هكذا:

<FileTree>
- blog/
  - astro.config.mjs
  - src/
    - verdin-types.ts يولّده `verdin types`
    - lib/
      - verdin.ts
    - layouts/
      - Layout.astro
    - pages/
      - index.astro
      - articles/
        - [slug].astro
</FileTree>

## 9. اختياري: معاينة المسودات

يستطيع المسؤول فتح مسودة على موقعك برمز معاينة قصير الأمد. يقرأ الرمز
ذلك المستند وحده، بما في ذلك المسودات، ولا شيء غيره. ولأن المسودات تتغير بعد
البناء، تُعرض صفحة المعاينة مع كل طلب، وهو ما يحتاج إلى محوّل (adapter):

```sh title="Terminal"
npx astro add node --yes
```

أضف عميلًا يرسل رمز المعاينة في الترويسة `x-verdin-preview`:

```ts title="src/lib/verdin.ts" ins={10-16}
import { createClient } from '@verdin/client';
import { VERDIN_TOKEN, VERDIN_URL } from 'astro:env/server';
import type { VerdinSchema } from '../verdin-types';

export const verdin = createClient<VerdinSchema>({
  url: VERDIN_URL,
  token: VERDIN_TOKEN,
});

/** A client that reads one draft with the preview token from the admin's link. */
export function previewClient(previewToken: string) {
  return createClient<VerdinSchema>({
    url: VERDIN_URL,
    headers: { 'x-verdin-preview': previewToken },
  });
}
```

ثم الصفحة. يعرضها `prerender = false` عند الطلب؛ ويصل الرمز كمعامل الاستعلام
`preview`:

```astro title="src/pages/preview/[documentId].astro"
---
import { VerdinError } from '@verdin/client';
import { marked } from 'marked';
import Layout from '../../layouts/Layout.astro';
import { previewClient } from '../../lib/verdin';

export const prerender = false;

const { documentId } = Astro.params;
const token = Astro.url.searchParams.get('preview');
if (!documentId || !token) {
  return new Response('Missing preview token', { status: 401 });
}

let article;
try {
  ({ data: article } = await previewClient(token)
    .collection('articles')
    .findOne(documentId, { status: 'draft', populate: { category: true } }));
} catch (error) {
  if (error instanceof VerdinError) {
    return new Response('This preview link has expired', { status: error.status });
  }
  throw error;
}
const html = await marked.parse(article.body ?? '');
Astro.response.headers.set('cache-control', 'no-store');
---

<Layout title={`Preview: ${article.title}`}>
  <p><strong>Draft preview</strong></p>
  <article>
    <h1>{article.title}</h1>
    {article.category && <p>Category: {article.category.name}</p>}
    <Fragment set:html={html} />
  </article>
</Layout>
```

لا يستطيع رمز المعاينة سرد الإدخالات، لذا تبحث الصفحة عن المسودة بـ `documentId`
لا بالـ slug. أخبر الآن Verdin بمكان الصفحة:

<Steps>

1. في لوحة الإدارة، افتح **الإعدادات ← الميزات**، وفعّل **المعاينة** واختر
   **إعداد عناوين URL للمعاينة**.
2. عيّن قالب عنوان URL لـ **Article** إلى `http://localhost:4321/preview/{documentId}` و
   احفظ. يُلحق Verdin الرمز على شكل `?preview=…`.
3. افتح مقالة، وغيّرها واختر **حفظ المسودة**، ثم اختر **فتح المعاينة**.

</Steps>

تعرض الصفحة المسودة. تدوم الروابط 60 دقيقة افتراضيًا. راجع
[المعاينة](/ar/guides/content/preview/) للعناصر النائبة والإعدادات، و
[التحرير المرئي](/ar/guides/frontend/visual-editing/) للتحرير من المعاينة.

يجلب `verdin import strapi` مشروع Strapi v4 أو v5 إلى Verdin: تصبح أنواع محتواه
ومكوّناته ملفات مخطط، وتُستورد إدخالاته ولغاته ومكتبة وسائطه وعلاقاته
ومستخدموه النهائيون وصلاحياته العامة. تشرح هذه الصفحة عملية ترحيل خطوة بخطوة و
تسرد ما يجب على واجهتك الأمامية تغييره. لمقارنة ميزة بميزة، راجع
[التوافق مع Strapi](/ar/migrate/compatibility/).

## قبل أن تبدأ

- مشروع Strapi v4 أو v5 يمكنك تشغيل `strapi export` فيه.
- مشروع Verdin جديد (`verdin new my-site`)، أو مشروع لا يحتوي على ملفات مخطط بالأسماء
  نفسها. راجع [البدء السريع](/ar/start/quickstart/).
- قاعدة البيانات وتخزين الوسائط اللذان سيستخدمهما مشروع Verdin في الإنتاج، إن أمكن:
  تُنسخ الملفات إلى موفّر الرفع المُعدّ أثناء الاستيراد.

## 1. صدّر من Strapi

في مشروع Strapi:

```sh frame="terminal"
npx strapi export --no-encrypt -f my-export      # يكتب my-export.tar.gz
```

لا يستطيع Verdin قراءة عمليات التصدير المشفّرة (`.tar.gz.enc`)؛ صدّر من جديد بـ `--no-encrypt`.
وتعمل أيضًا عمليات التصدير غير المضغوطة (`--no-compress`، أي `.tar`) ومجلد تصدير مفكوك.

## 2. استورد إلى Verdin

<Steps>

1. أنشئ المشروع واستورد ملف التصدير:

   ```sh frame="terminal"
   verdin new my-site && cd my-site
   verdin import strapi ../my-export.tar.gz
   ```

2. اقرأ الملخص. تطبع أداة الاستيراد عدد المستندات والنسخ والملفات والمجلدات
   واللغات والروابط التي استوردتها، ثم سطرًا لكل تحذير.

3. شغّل خادم التطوير وافتح لوحة الإدارة:

   ```sh frame="terminal"
   verdin dev
   ```

</Steps>

ينفّذ الأمر هذه الخطوات بالترتيب:

1. يكتب ملف مخطط واحدًا لكل نوع محتوى `api::` ولكل مكوّن في `schema/`. إذا
   لم يجتز المخطط المحوَّل التحقق، لا يُكتب شيء.
2. يرحّل قاعدة البيانات (الخطوات الآمنة).
3. يستورد اللغات، ومجلدات الوسائط وملفاتها، والإدخالات (كل مسودة ونسخة منشورة و
   لغة)، والعلاقات، والوسائط المرفقة بالإدخالات والمكوّنات.
4. يستورد المستخدمين النهائيين وأدوارهم والصلاحيات العامة والموثّقة.
5. يكتب `strapi-id-map.json` في مجلد المشروع.

| الخيار | الأثر |
| --- | --- |
| `--schema-only` | التوقف بعد كتابة ملفات المخطط. مفيد لمراجعة المخطط أو تعديله أولًا. |
| `--force` | الكتابة فوق ملفات المخطط الموجودة، والاستيراد إلى أنواع محتوى تحتوي على إدخالات بالفعل. |

بدون `--force`، يتوقف الاستيراد إذا كان ملف مخطط سيكتبه موجودًا بالفعل، أو
إذا كان نوع محتوى يحتوي على إدخالات بالفعل.

## ما الذي ينتقل

| Strapi | Verdin |
| --- | --- |
| أنواع المحتوى `api::…` والمكوّنات | ملفات مخطط، مع الإبقاء على `collectionName`، والمسودة والنشر، وخيارات i18n، وخيارات الحقول (`required`، `private`، `unique`، والأطوال، و`regex`، والقيم الافتراضية…) |
| العلاقات بين أنواع `api::` | العلاقات نفسها |
| العلاقات داخل المكوّنات | مراجع `oneWay` / `manyWay` |
| العلاقات متعددة الأشكال (`morphToOne`، `morphToMany`، `morphOne`، `morphMany`) | نفسها، مع روابطها إلى أنواع المحتوى المستوردة |
| حقول الوسائط (في المكوّنات أيضًا) | حقول الوسائط |
| صفوف v5 (مسودة ومنشورة) | نسخ مسودة ومنشورة |
| صفوف v4 | مسودة، بالإضافة إلى نسخة منشورة عندما يكون `publishedAt` معيَّنًا؛ وتصبح `localizations` لغات لمستند واحد |
| `plugin::i18n.locale` | اللغات (تبقى لغة Strapi الافتراضية هي الافتراضية) |
| `plugin::upload.file` و`folder` | ملفات مكتبة الوسائط (مع صيغها) والمجلدات |
| حقول `password` | حقول `password`، مع الإبقاء على تجزئات bcrypt من Strapi |
| الحقول المخصصة (`customField`) | السمة مع الإبقاء على `customField`؛ راجع أدناه |
| الحقول الشرطية (`conditions`، Strapi 5.17) | يُحتفظ بها في المخطط ويطبّقها المحرر |
| `plugin::users-permissions.user` | المستخدمون النهائيون، مع كلمات مرورهم bcrypt (تُعاد تجزئتها بـ Argon2id عند تسجيل الدخول التالي)، و`confirmed` و`blocked` |
| أدوار Users & Permissions | تصبح صلاحيات دور Public هي الصلاحيات العامة في Verdin؛ ويصبح Authenticated والأدوار المخصصة أدوارًا للمستخدمين النهائيين |
| صلاحيات الأدوار على أنواع المحتوى والرفع | الصلاحيات `find` و`findOne` و`create` و`update` و`delete`؛ وللرفع `find` و`findOne` و`upload` و`destroy` |

## ما الذي لا ينتقل

يُبلَّغ عنه كتحذيرات:

- العلاقات إلى المستخدمين المسؤولين أو المستخدمين النهائيين أو أنواع الإضافات الأخرى (لا تُستورد إلا أهداف
  `api::`). تُستبعد الحقول `createdBy` / `updatedBy`.
- `unique` على سمات `text` و`richtext` و`blocks` و`json` (يدعمه Verdin على
  الأنواع النصية القصيرة).
- أنواع السمات التي لا يعرفها Verdin، وأنواع العلاقات التي لا يستطيع تخزينها داخل
  مكوّن.
- أنصاف العلاقات التي لا يطابق `inversedBy` / `mappedBy` فيها الجانب الآخر.
- رموز اللغات غير الصالحة.

لا يُستورد إطلاقًا: المستخدمون المسؤولون وأدوار الإدارة، ورموز API، ورموز النقل،
والـ webhooks، وحزم النشر، ومراحل مسارات المراجعة، وسجل المحتوى وسجلات التدقيق، و
إعدادات إضافات Strapi. شيفرة Strapi الخاصة بك — المتحكمات، والخدمات، والمسارات، والسياسات،
والـ middlewares، وخطافات دورة الحياة، ومهام cron، وتخصيصات لوحة الإدارة — ليس لها مقابل
في Verdin لتُحوَّل إليه؛ راجع [أعِد بناء الشيفرة المخصصة](#أعِد-بناء-الشيفرة-المخصصة).

<Aside type="note">
تحتفظ الحقول المخصصة باسم `customField` الخاص بها، مثل `plugin::color-picker.color`. يعرضها
المحرر عبر [إضافة](/ar/extending/plugins/) توفّر ذلك الحقل، ويرجع
إلى حقل الإدخال الخاص بالنوع المخزّن عندما لا توجد إضافة.
</Aside>

## خريطة المعرّفات

يولّد Verdin معرّفات مستندات جديدة: قيم `documentId` في Strapi من 24 حرفًا و
في Verdin من 26، لذا يحصل كل مستند على معرّف جديد. وتتغير قيم `id` الرقمية أيضًا.
يسجّل `strapi-id-map.json` هذا الربط:

```json title="strapi-id-map.json"
{
  "documents": {
    "api::article": {
      "hq7xw1c6m2vkn0f3t8ybz5sd": "01k6b3xg0r9m2m7c1d4e5f6g7h"
    }
  },
  "files": {
    "12": 3
  }
}
```

- مفاتيح `documents` هي uid نوع المحتوى في Verdin (`api::article`، أي `api::article.article`
  في Strapi)، ثم `documentId` في Strapi (v5) أو معرّف صف (v4:
  معرّف واحد يمثّل كل لغات المستند).
- يربط `files` معرّفات ملفات Strapi بمعرّفات ملفات Verdin.

استخدمه لإعادة كتابة المعرّفات المخزّنة خارج نظام إدارة المحتوى: الروابط في شيفرة واجهتك الأمامية، والمعرّفات في
قاعدة بيانات أخرى، والتحليلات، والإشارات المرجعية.

## تحقق من النتيجة

1. ينجح `verdin schema check`، ويقول `verdin migrate plan` إن قاعدة البيانات
   محدّثة.
2. في لوحة الإدارة، افتح كل مجموعة وقارن عدد الإدخالات والمسودات
   واللغات مع Strapi.
3. افتح بعض الإدخالات التي تحتوي على علاقات ومكوّنات ومناطق ديناميكية ووسائط، وتحقق
   من أن الروابط تشير إلى المستندات والملفات الصحيحة.
4. افتح **مكتبة الوسائط** وتحقق من وجود المجلدات والصور (مع صيغها).
5. في **الإعدادات ← الوصول العام** و**الإعدادات ← المستخدمون النهائيون**، راجع
   الصلاحيات والأدوار المستوردة.
6. استدعِ الـ API كما تفعل واجهتك الأمامية وقارن الاستجابات مع استجابات Strapi.

ثم اعتمد `schema/`، وأنشئ مسؤوليك ورموز API والـ webhooks، وانشر (راجع
[قائمة التحقق للإنتاج](/ar/deploy/production-checklist/)).

## تغييرات الواجهة الأمامية

يتبع API المحتوى أشكال REST وGraphQL في Strapi v5، لذا تعمل معظم الطلبات
كما هي. غيّر ما يلي:

- **عنوان URL الأساسي.** وجّه الواجهة الأمامية إلى خادم Verdin. يوجد API المحتوى تحت
  `/api` (`[api].prefix`)، وGraphQL على `/graphql` بمجرد تفعيله في
  **الإعدادات ← الميزات**.
- **رموز API.** لا تُستورد الرموز: أنشئ رموزًا جديدة في **الإعدادات ← رموز API**
  واستبدلها في بيئة واجهتك الأمامية.
- **معرّفات المستندات.** كل `documentId` و`id` رقمي جديد. استبدل المعرّفات المكتوبة مباشرة
  في الواجهة الأمامية بتلك الموجودة في `strapi-id-map.json`، أو الأفضل، ابحث عن الإدخالات بـ
  slug أو بحقل `uid` آخر.
- **عناوين URL للوسائط.** تشير عناوين URL للملفات إلى الموفّر الجديد: `/uploads/…` على خادم Verdin
  للموفّر المحلي، أو `[upload.provider].public_url` لـ S3. حدّث نطاقات الصور
  المسموح بها في إطار عملك (مثلًا `images.remotePatterns` في Next.js).
- **المستخدمون النهائيون المسجّلو الدخول** يجب أن يسجّلوا الدخول من جديد: كلمات مرورهم تعمل، لكن رموز JWT التي أصدرها
  Strapi لا تعمل.
- **CORS.** إذا كان متصفح يستدعي الـ API من مصدر آخر، فأدرجه في
  `[api].cors_origins`.
- **Webhooks.** أعِد إنشاءها في **الإعدادات ← Webhooks**. حدث Strapi
  `entry.draft-discard` اسمه `entry.discard-draft`، وعمليات التسليم موقّعة
  (راجع [Webhooks](/ar/guides/integrations/webhooks/)).
- **الواجهات الأمامية لـ Strapi v4** تحتاج إلى تغييرات v5 أيضًا: استجابات مسطّحة دون
  `attributes`، و`documentId` بدلًا من `id` في عناوين URL، و`status=draft` بدلًا من
  `publicationState=preview`.

للوصول المُنمَّط، ولّد أنواع TypeScript بـ `verdin types` واستخدم
[العميل المُنمَّط](/ar/guides/frontend/typed-client/).

## أعِد بناء الشيفرة المخصصة

| Strapi | Verdin |
| --- | --- |
| خطافات دورة الحياة، وmiddlewares خدمة المستندات | خطافات الإضافات (`beforeCreate`، `afterUpdate`…) في [إضافة WebAssembly](/ar/extending/plugins/) |
| المسارات والمتحكمات المخصصة | مسارات الإضافات تحت `/api/plugins/<name>/` |
| مهام Cron | مهام الإضافات (`[[jobs]]`) |
| الحقول المخصصة | الحقول المخصصة للإضافات |
| أدوات لوحة الإدارة | أدوات الإضافات، أو أدوات لوحة المعلومات المدمجة |
| شعار لوحة الإدارة وألوانها ونصوصها | `[admin.branding]` في `verdin.toml` |
| `config/*.js` | `verdin.toml` ومتغيرات البيئة ([مرجع التهيئة](/ar/reference/configuration/)) |

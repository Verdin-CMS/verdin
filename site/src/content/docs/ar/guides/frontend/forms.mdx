تتولى ميزة **النماذج** نماذج موقعك (التواصل، والاشتراك في النشرة، والتسجيل في
الفعاليات) دون خدمة نماذج خارجية. يعرّف المحررون الحقول في لوحة الإدارة، ويعرضها موقعك
ويرسلها إلى Verdin، ويُتحقق من الإرسالات وتُخزَّن وتُرسل بالبريد و
تُصدَّر بصيغة CSV.

## فعّلها

في **الإعدادات ← الميزات**، فعّل **النماذج**، ثم اختر **إدارة النماذج** (أو انتقل إلى
**الإعدادات ← النماذج**). تتطلب إدارة النماذج وقراءة الإرسالات الصلاحية
**إدارة SEO وإعادات التوجيه والقوائم والنماذج** (`site.manage`)، التي يملكها الدور المدمج
Editor. راجع [الصلاحيات](/ar/reference/permissions/).

لرسائل الإشعار، هيّئ موفّرًا في [`[email]`](/ar/reference/configuration/)؛
مع الموفّر الافتراضي `log`، لا تُكتب الرسائل إلا في سجل الخادم.

## أنشئ نموذجًا

<Steps>

1. في **الإعدادات ← النماذج**، اختر **نموذج جديد**.
2. امنحه اسمًا (مثل **تواصل**) و**Slug** (`contact`). الـ slug جزء من
   عنوان URL للنموذج.
3. في تبويب **الحقول**، اختر **إضافة حقل** لكل حقل، مع **التسمية**،
   و**الاسم**، و**النوع**، و**مطلوب**، و**العنصر النائب** و**الحد الأقصى للطول**.
4. في تبويب **الإعدادات**، عيّن:
   - **الإشعار**: عناوين البريد التي تتلقى كل إرسال.
   - **رسالة النجاح**: تُعاد إلى موقعك بعد الإرسال.
   - **مصيدة الرسائل العشوائية**: مفعّلة افتراضيًا (راجع [الرسائل العشوائية](#الرسائل-العشوائية)).
5. احفظ. يعرض تبويب **التكامل** نقطة النهاية العامة ومثالًا للنسخ.

</Steps>

| النوع | التسمية في لوحة الإدارة | يقبل |
| --- | --- | --- |
| `text` | **نص** | أي نص. |
| `email` | **البريد الإلكتروني** | عنوان بريد إلكتروني. |
| `textarea` | **نص طويل** | أي نص. |
| `number` | **رقم** | رقم، يُخزَّن كرقم. |
| `select` | **اختيار** | واحد من **الخيارات** الخاصة به (واحد لكل سطر). |
| `checkbox` | **خانة اختيار** | `true` أو `on` أو `1` أو `yes` تعني محدَّدة؛ وأي شيء آخر لا. يجب تحديد خانة الاختيار المطلوبة. |
| `date` | **التاريخ** | أي نص (استخدم `<input type="date">`). |
| `url` | **عنوان URL** | عنوان URL. |
| `tel` | **الهاتف** | أي نص. |

تبدأ أسماء الحقول بحرف، ثم أحرف أو أرقام أو `_`، وتكون فريدة في النموذج.
للنموذج من 1 إلى 50 حقلًا. طول القيم لا يتجاوز **الحد الأقصى للطول** (5,000 حرف
افتراضيًا، و20,000 على الأكثر).

## اعرض النموذج

يعيد `GET /api/_forms/{slug}` التعريف، فيستطيع موقعك عرض الحقول التي
اختارها المحررون:

```json
{
  "data": {
    "slug": "contact",
    "name": "Contact",
    "fields": [
      { "name": "email", "label": "Email", "type": "email", "required": true },
      { "name": "message", "label": "Message", "type": "textarea", "required": true, "maxLength": 2000 },
      { "name": "topic", "label": "Topic", "type": "select", "options": ["Sales", "Support"] }
    ],
    "honeypot": "_gotcha"
  }
}
```

`honeypot` هو `null` عندما تكون مصيدة الرسائل العشوائية معطّلة. يُخزَّن التعريف مؤقتًا لمدة دقيقة
(`Cache-Control: public, max-age=60`).

## أرسل

يأخذ `POST /api/_forms/{slug}` القيم بصيغة JSON (الحقول، أو `{ "data": { … } }`) أو
كإرسال نموذج عادي (`application/x-www-form-urlencoded`). لا حاجة إلى رمز.

<Tabs syncKey="form">
<TabItem label="نموذج HTML">

```html
<form method="post" action="https://cms.example.com/api/_forms/contact">
  <input name="email" type="email" required />
  <textarea name="message" required maxlength="2000"></textarea>
  <input name="_gotcha" tabindex="-1" autocomplete="off" aria-hidden="true" style="position:absolute;left:-9999px" />
  <button>Send</button>
</form>
```

</TabItem>
<TabItem label="fetch">

```js
const response = await fetch('https://cms.example.com/api/_forms/contact', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ data: { email, message, _gotcha: '' } }),
});
const body = await response.json();
if (response.ok) showThanks(body.data.message);
else showErrors(body.error.details.errors); // [{ path: ['email'], message: 'must be an email address' }]
```

</TabItem>
</Tabs>

| الإجابة | متى |
| --- | --- |
| `201` مع `{ "data": { "message": … } }` | مقبول. `message` هي **رسالة النجاح**، أو `Thank you!`. |
| `400` `ValidationError` | قيمة مفقودة أو غير صالحة. يسرد `details.errors` القيمة `{ path, message }` لكل حقل. |
| `404` | لا يوجد نموذج بهذا الـ slug، أو الميزة معطّلة. |
| `413` | الإرسال أكبر من 64 KB. |
| `429` | أرسل الزائر نفسه أكثر من 10 إرسالات إلى هذا النموذج في دقيقة. |

تُقصّ المسافات من القيم ويُتحقق منها مقابل الحقول. تُسقط الحقول غير المعروفة، فلا يستطيع
الزائر إضافة بيانات لم تطلبها.

يتلقى إرسال نموذج HTML العادي إجابة JSON كصفحة. لتجربة أفضل،
أرسل بـ `fetch` واعرض الرسالة بنفسك. الإرسال من المتصفح إلى مصدر
آخر يحتاج إلى مصدر موقعك في [`[api].cors_origins`](/ar/reference/configuration/).

### الرسائل العشوائية

مع تفعيل **مصيدة الرسائل العشوائية**، أضف حقل `_gotcha` مخفيًا وفارغًا إلى النموذج. تملأ الروبوتات كل
حقل؛ والإرسال الذي يكون فيه `_gotcha` مملوءًا يُجاب بأنه مقبول (`201`) ثم يُرمى،
فلا يتعلم الروبوت شيئًا. مع حد المعدل، يوقف ذلك معظم الرسائل العشوائية في النماذج دون
CAPTCHA.

## اقرأ الإرسالات

يسرد تبويب **الإرسالات** في النموذج ما أرسله الزوار، مع وقت
**الاستلام**. يمكنك حذف إرسال، ويُنزّل **تصدير CSV** الإرسالات كلها.

يُرسل كل إرسال مقبول أيضًا بالبريد إلى عناوين **الإشعار**، مع رابط إلى
الإرسالات في لوحة الإدارة (مبني من [`[server].public_url`](/ar/reference/configuration/)).

<Aside type="note">
يخزّن Verdin قيم كل إرسال، ووكيل المستخدم (user agent) للزائر، وتجزئة بمفتاح لـ
عنوان IP الخاص به (لا العنوان نفسه)، وهو ما يكفي لاكتشاف فيض من الإرسالات دون تتبع الأشخاص.
حذف نموذج يحذف إرسالاته.
</Aside>

## API الإدارة

تستخدم لوحة الإدارة `/admin/api/site/forms` و`/admin/api/site/forms/{id}`، بالإضافة إلى
`/admin/api/site/forms/{id}/submissions` و`…/submissions/export` (CSV)، مع رمز وصول
لمسؤول و`site.manage`. راجع [API الإدارة](/ar/api/admin/).

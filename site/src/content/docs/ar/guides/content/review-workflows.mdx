مسار المراجعة قائمة مرتّبة من المراحل، مثل *To do* و*In review* و*Ready*،
تمر بها إدخالات بعض أنواع المحتوى قبل نشرها. يعدّ هذا الدليل
مسارًا، وينقل الإدخالات ويسندها، ويعرض ما يقابل ذلك في API الإدارة.

في Strapi، مسارات المراجعة ميزة للمؤسسات (Enterprise). أما في Verdin فهي جزء من النواة
مفتوحة المصدر.

## قبل أن تبدأ

- فعّل **الإعدادات ← الميزات ← مسارات المراجعة**. وهي معطّلة افتراضيًا.
- يتطلب إعداد المسارات **إدارة مسارات المراجعة** (`workflows.manage`).
- يتطلب نقل إدخال وإسناده صلاحية التحديث عليه. راجع
  [الصلاحيات](/ar/reference/permissions/).

## أنشئ مسارًا

<Steps>

1. افتح **الإعدادات ← مسارات المراجعة** واختر **مسار جديد**.
2. امنحه **الاسم**.
3. تحت **أنواع المحتوى**، اختر الأنواع التي تتبعه إدخالاتها. يتبع النوع مسارًا
   واحدًا على الأكثر.
4. تحت **المراحل**، اسرد المراحل بالترتيب. لكل منها **اسم المرحلة** و**اللون**. استخدم
   **إضافة مرحلة** للمزيد، وأزرار الأسهم لإعادة ترتيبها. تبدأ الإدخالات الجديدة في
   المرحلة الأولى.
5. اختياريًا، اختر **الأدوار التي يمكنها نقل الإدخالات إلى هذه المرحلة** على مرحلة ما. إن لم تُحدَّد أي
   أدوار، يستطيع ذلك كل من يستطيع تحديث الإدخال.
6. اختياريًا، عيّن **المرحلة المطلوبة للنشر**. عندئذ لا يمكن نشر الإدخالات إلا ما دامت
   في تلك المرحلة. أما **أي مرحلة** فتترك النشر دون قيد.
7. احفظ.

</Steps>

الإدخالات التي كانت موجودة قبل انضمام نوعها إلى المسار تكون في المرحلة الأولى.

عندما تغيّر مسارًا لاحقًا:

- إزالة مرحلة تعيد إدخالاتها إلى المرحلة الأولى.
- إزالة نوع محتوى من المسار تمسح مراحل إدخالاته.
- حذف المسار يمسح مراحل إدخالاته والمُسنَدين إليها.

## انقل الإدخالات وأسندها

يعرض محرر الإدخال لوحة **المراجعة** مع **المرحلة** و**المُكلَّف**.

- اختر **مرحلة** أخرى لنقل الإدخال. لا يمكن اختيار المراحل المحجوزة لأدوار أخرى،
  وتقول اللوحة ذلك. يستطيع المسؤولون الذين لديهم **إدارة مسارات المراجعة** دائمًا نقل
  الإدخالات.
- اختر **المُكلَّف** من المسؤولين النشطين الذين يستطيعون قراءة نوع المحتوى، أو اختر
  **إزالة المُكلَّف**. يستطيع كل من يستطيع تحديث الإدخال إسناده.
- عندما يكون للمسار مرحلة مطلوبة، تقول اللوحة أي مرحلة يجب أن يبلغها الإدخال
  قبل أن يعمل **نشر**.

يعرض عرض القائمة عمود **المرحلة**، وتسرد الصفحة الرئيسية الإدخالات المُسنَدة إليك
تحت **المُسنَدة إليّ**. تحتفظ الأنواع المترجمة بمرحلة لكل لغة.

## ما تمنعه مرحلة النشر

تنطبق المرحلة المطلوبة على كل طرق النشر: لوحة الإدارة وREST وGraphQL و
حزم النشر والإضافات. نشر إدخال خارج تلك المرحلة يفشل بـ `400`:

```text
the entry must be in the review stage `Ready` to be published
```

في Strapi لا ينطبق شرط المرحلة إلا على لوحة الإدارة. وتختلف أدوار المراحل أيضًا:
ففي Verdin تحدّ من يستطيع نقل الإدخالات *إلى* مرحلة ما.

## سجلات التدقيق والـ webhooks

- تُسجَّل تغييرات المراحل والإسنادات في [سجلات التدقيق](/ar/guides/content/audit-logs/)
  على شكل `entry.stage` و`entry.assign`.
- يمكن للـ webhooks الاشتراك في **تغيّرت مرحلة الإدخال** (`review-workflows.updateEntryStage`).
  راجع [Webhooks](/ar/guides/integrations/webhooks/).

## API الإدارة

كل المسارات تحت `/admin/api` وتأخذ رمز وصول لمسؤول.

| المسار | الصلاحية | يفعل |
| --- | --- | --- |
| `GET /review-workflows`، `GET /review-workflows/{id}` | `workflows.manage` | المسارات مع مراحلها. |
| `POST /review-workflows`، `PUT /review-workflows/{id}` | `workflows.manage` | إنشاء مسار أو استبداله (الجسم أدناه). |
| `DELETE /review-workflows/{id}` | `workflows.manage` | تفقد إدخالات أنواعه مراحلها. |
| `GET /content/{uid}/{documentId}/review?locale=` | قراءة الإدخال | المرحلة، والمُكلَّف، والمراحل التي يمكنك نقل الإدخال إليها (`canMoveTo`). |
| `PUT /content/{uid}/{documentId}/review?locale=` | تحديث الإدخال | `{ "stageId": 3, "assigneeId": 7 }`. الحقلان اختياريان؛ و`"assigneeId": null` يزيل المُكلَّف. |
| `GET /content/{uid}/review?documentIds=a,b` | قراءة النوع | مراحل ما يصل إلى 200 إدخال، مع المسار في `meta.workflow`. |
| `GET /review/assigned` | مسجّل الدخول | الإدخالات المُسنَدة إليك. |
| `GET /review/assignees?uid=` | تحديث النوع | المسؤولون النشطون الذين يستطيعون قراءة النوع. |
| `GET /review/roles` | `workflows.manage` | رموز الأدوار وأسماؤها، لأدوار المراحل. |

مسار كما يُرسل إلى `POST` و`PUT`:

```json
{
  "name": "Editorial",
  "contentTypes": ["api::article"],
  "stages": [
    { "id": 1, "name": "To do", "color": "#4945ff" },
    { "id": 2, "name": "In review", "color": "#ff8800" },
    { "name": "Ready", "color": "#2f9e44", "roles": ["editor"] }
  ],
  "publishStage": "Ready"
}
```

- للمسار من 1 إلى 50 مرحلة بأسماء فريدة وألوان بصيغة `#rrggbb`.
- يسمّي `publishStage` إحدى المراحل؛ اتركه إن لم ترد أيًا منها.
- أرسل المراحل الموجودة مع `id` الخاص بها حتى تبقى إدخالاتها حيث هي. المراحل التي
  لا تحمل `id` جديدة.

<Aside type="note">
إيقاف الميزة يخفي المراحل ويوقف فرض مرحلة النشر. ويُحتفظ بـ
المسارات ومراحل الإدخالات إلى أن تعيد تفعيلها.
</Aside>

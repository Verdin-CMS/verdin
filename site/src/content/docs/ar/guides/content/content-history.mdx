يحتفظ Verdin بنسخة من الإدخال في كل مرة يُنشأ فيها، أو يُحفظ، أو يُنشر، أو يُلغى نشره،
أو تُتجاهل مسودته، من أي API. يبيّن هذا الدليل كيف تعثر على نسخة قديمة و
تستعيدها، وكم نسخة يُحتفظ بها، وما يقابل ذلك في API الإدارة.

يعمل سجل المحتوى مثل نظيره في Strapi، حيث هو ميزة مدفوعة.

## قبل أن تبدأ

- **الإعدادات ← الميزات ← سجل المحتوى** مفعّل افتراضيًا. ما دام معطّلًا، لا تُسجَّل أي
  نسخ ويكون السجل غير متاح.
- تتطلب قراءة سجل إدخال صلاحية القراءة على الإدخال؛ وتتطلب الاستعادة صلاحية التحديث.
  تنطبق قيود الحقول: لا ترى، ولا تستعيد، إلا الحقول التي يستطيع دورك قراءتها أو
  تحديثها. راجع [الصلاحيات](/ar/reference/permissions/).

## استعِد نسخة

<Steps>

1. افتح الإدخال واختر **السجل**.
2. تعرض قائمة **النسخ** كل نسخة مع حدثها (**إنشاء**، **حفظ**،
   **نشر**، **إلغاء النشر**، **تجاهل المسودة**)، وتاريخها ومن أجراها. التغييرات
   التي أُجريت عبر API المحتوى تعرض **API** بصفته المؤلف.
3. اختر نسخة لعرض حقولها.
4. اختر **استعادة** وأكّد.

</Steps>

تحل النسخة محل المسودة الحالية؛ انشرها بعد ذلك عندما تكون جاهزًا. في الأنواع
التي لا تستخدم المسودة والنشر، تحدّث الاستعادة الإدخال مباشرة.

ما يُستبعد عند الاستعادة:

- الحقول التي لم تعد موجودة في المخطط تُسرد ولا تُستعاد.
- تُحذف المراجع إلى الإدخالات أو الملفات المحذوفة، ويخبرك المحرر بالحقول التي
  فقدتها.

يعيدك **العودة إلى المحرر** إلى الإدخال دون تغيير أي شيء.

## كم نسخة يُحتفظ بها

يحتفظ Verdin بأحدث `[history].max_versions` نسخة لكل إدخال ولغة (50
افتراضيًا) ويزيل الأقدم مع وصول نسخ جديدة:

```toml title="verdin.toml"
[history]
max_versions = 100
```

لكل لغة من إدخال مترجم سجلها الخاص. حذف إدخال، أو إحدى
لغاته، يحذف نسخه أيضًا. راجع [مرجع التهيئة](/ar/reference/configuration/).

<Aside type="note">
على عكس Strapi، حيث يُحتفظ بالسجل لعدد من الأيام، يحتفظ Verdin بعدد من
النسخ لكل إدخال، مهما كان عمرها.
</Aside>

## API الإدارة

كل المسارات تحت `/admin/api`.

| المسار | الصلاحية | يفعل |
| --- | --- | --- |
| `GET /history/{uid}/{documentId}?locale=&page=&pageSize=` | قراءة الإدخال | النسخ، من الأحدث إلى الأقدم، دون بياناتها (20 لكل صفحة، و100 على الأكثر). |
| `GET /history/versions/{id}` | قراءة الإدخال | نسخة واحدة مع بياناتها. |
| `POST /history/versions/{id}/restore` | تحديث الإدخال | يستعيد النسخة كمسودة حالية. |

تسرد إجابة الاستعادة ما استُبعد:

```json
{
  "data": {
    "documentId": "k3v9…",
    "restored": 42,
    "dropped": [{ "field": "tags", "count": 1 }]
  }
}
```

تجيب المسارات بـ `404` ما دامت الميزة معطّلة.

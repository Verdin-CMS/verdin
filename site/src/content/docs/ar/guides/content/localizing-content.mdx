يحتفظ نوع المحتوى المترجم بنسخة واحدة من كل إدخال لكل لغة. يضيف هذا الدليل
اللغات التي تنشر بها، ويفعّل الترجمة لنوع ما، ويترجم الإدخالات في لوحة
الإدارة، ويقرأ كل لغة أو يكتبها عبر الـ API. للنموذج الذي يقوم عليه ذلك (الحقول
المشتركة، والعلاقات بين الأنواع المترجمة)، راجع
[التدويل](/ar/concepts/internationalization/).

الترجمة جزء من النواة: لا توجد ميزة يجب تفعيلها. وهي تعمل مثل إضافة i18n في Strapi v5
وتأخذ المعامل `locale` نفسه.

## قبل أن تبدأ

- لإضافة لغات أو إعادة تسميتها أو حذفها تحتاج إلى **إدارة اللغات** (`locales.manage`).
- لجعل نوع مترجمًا تعدّل مخططه، في **منشئ أنواع المحتوى** (`verdin dev`)
  أو في `schema/content-types/<name>.json`.
- راجع [الصلاحيات](/ar/reference/permissions/) لمعرفة صلاحيات المحتوى التي يحتاجها المحررون.

## أضف اللغات

ينشئ التشغيل الأول الإنجليزية (`en`) لغةً افتراضية. تستخدم الطلبات التي لا تسمّي لغة
اللغة الافتراضية، وتبدأ الإدخالات الجديدة بها.

<Steps>

1. افتح **الإعدادات ← التدويل** واختر **إضافة لغة**.
2. أدخل **الرمز**: رمز لغة بأحرف صغيرة، اختياريًا مع منطقة أو نظام كتابة، مثل
   `fr` أو `pt-BR` أو `zh-Hans`. يُملأ الاسم نيابةً عنك ويمكن تغييره.
3. حدد **اجعلها اللغة الافتراضية** إذا كانت الطلبات التي لا تحمل لغة يجب أن تستخدمها، ثم احفظ.

</Steps>

لتغيير اللغة الافتراضية لاحقًا، اختر **تعيين كافتراضية** على لغة أخرى. لا يمكن حذف
اللغة الافتراضية.

<Aside type="caution" title="حذف لغة يحذف إدخالاتها">
حذف لغة يحذف نهائيًا كل إدخال مكتوب بها، في كل نوع محتوى،
بما في ذلك النسخ المنشورة. تطلب منك نافذة الحوار كتابة رمز اللغة للتأكيد.
</Aside>

## اجعل نوع محتوى مترجمًا

في **منشئ أنواع المحتوى**، افتح النوع وفعّل **مترجم** في إعداداته.
ثم قرّر، حقلًا بحقل، أي القيم تختلف لكل لغة: الحقل الذي يكون فيه **مترجم**
معطّلًا يحمل قيمة واحدة تتشاركها كل اللغات.

الشيء نفسه في ملف المخطط، لنوع `article` في المشروع المثالي:

```json title="schema/content-types/article.json" {6,9}
{
  "kind": "collectionType",
  "singularName": "article",
  "pluralName": "articles",
  "displayName": "Article",
  "pluginOptions": { "i18n": { "localized": true } },
  "attributes": {
    "title": { "type": "string", "required": true },
    "readingTime": { "type": "integer", "pluginOptions": { "i18n": { "localized": false } } }
  }
}
```

كيف تتصرف الحقول المشتركة:

- حفظ حقل مشترك في لغة واحدة يكتبه في مسودات كل اللغات.
- نشر لغة ينسخ حقولها المشتركة إلى النسخ المنشورة في اللغات
  الأخرى.
- يمكن أن تكون العلاقات وحقول الوسائط مشتركة أيضًا.

الأنواع التي لا تحمل `pluginOptions.i18n.localized` غير مترجمة وتتجاهل معاملات `locale`.
تغيير ترجمة نوع هو تغيير في المخطط: راجع الترحيل بـ
`verdin migrate plan` قبل نشره.

## ترجم إدخالًا في لوحة الإدارة

<Steps>

1. افتح الإدخال واختر اللغة الهدف في مبدّل **اللغة** أعلى
   المحرر. تعرض اللغات التي لا نسخة لها **لم يُنشأ بعد**.
2. يقول المحرر إن الإدخال ليس له نسخة بتلك اللغة بعد وإن الحفظ ينشئها.
   تعرض الحقول المشتركة قيمها بالفعل.
3. للبدء من ترجمة موجودة، اختر **الملء من لغة أخرى** في ذلك
   التنبيه. اختر المصدر في **النسخ من** واختر **نسخ الحقول**. ينسخ ذلك
   الحقول المترجمة، بما فيها العلاقات والوسائط، إلى النموذج. لا يُحفظ شيء بعد.
4. عدّل الحقول، ثم **حفظ المسودة** أو **نشر**. لكل لغة مسودتها ونسختها
   المنشورة.

</Steps>

لعرض القائمة مبدّل **اللغة** نفسه: يسرد النسخ بلغة واحدة في كل
مرة. الحذف من المحرر لا يزيل إلا النسخة باللغة الحالية؛ وتبقى اللغات
الأخرى.

مع تفعيل ميزة **إجراءات الذكاء الاصطناعي**، يستطيع المحرر أيضًا ترجمة الحقول النصية من
مسودة لغة أخرى. راجع [إجراءات الذكاء الاصطناعي](/ar/guides/integrations/ai-actions/).

## احصر المحررين في بعض اللغات

يمكن لصلاحيات المحتوى الخاصة بدور أن تغطي بعض اللغات فقط. في **الإعدادات ← الأدوار**، افتح
الدور، وابحث عن نوع المحتوى واختر **اللغات**. اختر **هذه اللغات فقط** وحدّدها.
لا يستطيع المسؤولون الذين لديهم ذلك الدور قراءة النسخ في اللغات الأخرى أو تغييرها؛ ويعرض مبدّل
**اللغة** تلك اللغات على أنها "(بلا وصول)".

## اقرأ اللغات واكتبها عبر الـ API

أضف `locale` إلى أي طلب REST، أو مرّره كوسيط في GraphQL. بدونه، تُستخدم
اللغة الافتراضية. اللغة غير المعروفة خطأ `400`.

<Tabs syncKey="api">
<TabItem label="REST">

```sh title="Terminal"
# قراءة النسخ الفرنسية
curl 'http://localhost:1337/api/articles?locale=fr'

# إنشاء النسخة الفرنسية من مستند أو تحديثها
curl -X PUT 'http://localhost:1337/api/articles/<documentId>?locale=fr' \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"data":{"title":"Bonjour"}}'

# حذف النسخة الفرنسية فقط
curl -X DELETE 'http://localhost:1337/api/articles/<documentId>?locale=fr' \
  -H "Authorization: Bearer $TOKEN"
```

</TabItem>
<TabItem label="GraphQL">

```graphql
query {
  articles(locale: "fr") {
    documentId
    title
    locale
  }
}
```

</TabItem>
<TabItem label="TypeScript">

```ts
const { data } = await verdin.collection('articles').find({ locale: 'fr' });
```

</TabItem>
</Tabs>

ما يمكن توقعه:

- ينشئ `PUT` مع `locale` نسخة تلك اللغة عندما لا يملك المستند واحدة بعد.
- تتضمن استجابات الأنواع المترجمة `locale`. تتشارك كل النسخ `documentId` نفسه.
- يحذف `DELETE` النسخة باللغة المطلوبة فقط (اللغة الافتراضية عندما لا تُحدَّد
  لغة). تُحذف الروابط التي تشير إلى المستند عندما لا تبقى أي لغة.
- عندما يرتبط نوع مترجم بنوع مترجم آخر، تحلّ القراءات الهدف في
  اللغة نفسها، وكذلك تفعل عوامل التصفية عبر العلاقات. الأهداف غير المترجمة
  تتشاركها كل اللغات.
- تسجّل حمولات الـ webhook ونسخ السجل اللغة.

على عكس Strapi، ليس لـ API المحتوى مسار `/api/i18n/locales`. تُسرد اللغات في
API الإدارة على `GET /admin/api/i18n/locales`، وتُدار عبر `POST` و
`PUT /admin/api/i18n/locales/{code}` و`DELETE /admin/api/i18n/locales/{code}`
(`locales.manage`).

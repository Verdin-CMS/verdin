تصدّر قائمة الإدارة لكل نوع محتوى إدخالاته بصيغة CSV أو JSON، وتستوردها
من جديد من النوع نفسه من الملفات: لإصلاح كثير من الإدخالات في جدول بيانات، أو تحميل كتالوج
منتجات، أو نسخ الإدخالات بين المشاريع. يتناول هذا الدليل الاتجاهين وصيغة
الملف.

هذا مخصص لإدخالات نوع محتوى واحد في كل مرة. لنقل مشروع كامل، راجع
[`verdin export` و`verdin import verdin`](/ar/reference/cli/). وللقدوم من Strapi، راجع
[الترحيل من Strapi](/ar/migrate/from-strapi/).

## قبل أن تبدأ

- يتطلب التصدير صلاحية القراءة على نوع المحتوى. لا تُصدَّر إلا الحقول التي يستطيع دورك
  قراءتها.
- يتطلب الاستيراد صلاحية الإنشاء، أو التحديث، أو كليهما: الصفوف التي تنشئ إدخالات تحتاج إلى
  الإنشاء، والصفوف التي تحدّثها تحتاج إلى التحديث. ونشر الصفوف المستوردة يحتاج أيضًا إلى
  النشر. راجع [الصلاحيات](/ar/reference/permissions/).

## صدّر الإدخالات

<Steps>

1. افتح قائمة نوع المحتوى واضبطها بالطريقة التي تريد بها التصدير: عوامل التصفية، والبحث،
   والترتيب، والحالة، واللغة.
2. اختر **تصدير**، ثم **تصدير بصيغة CSV** أو **تصدير بصيغة JSON**.

</Steps>

يحتوي الملف على الإدخالات التي تعرضها القائمة، بعوامل تصفيتها وبحثها وترتيبها، عبر كل
الصفحات، حتى 50,000 إدخال. يبدأ كل صف بـ `documentId`، تليه الحقول.

## استورد الإدخالات

<Steps>

1. افتح قائمة نوع المحتوى واختر **استيراد**.
2. اختر **الملف**: ملف `.csv` بصف ترويسة، أو ملف `.json` يحتوي على قائمة
   كائنات، حتى 1 MB.
3. تحت **الأعمدة**، اختر الحقل الذي يذهب إليه كل عمود. الأعمدة التي تحمل اسم حقل
   مطابَقة مسبقًا. اختر **تخطٍ** لاستبعاد عمود، و**معرّف المستند (تحديث)** لـ
   العمود الذي يسمّي الإدخالات الموجودة.
4. اختياريًا، فعّل **نشر الإدخالات المستوردة**. وإلا فستُحفظ كمسودات.
5. اختر **تحقّق**. يتحقق Verdin من كل صف، بما في ذلك القيود والمراجع، دون
   كتابة أي شيء، ويبلّغ عن الصفوف التي سينشئها أو يحدّثها أو يرفضها.
6. أصلح الملف إن لزم، ثم اختر **استيراد**.

</Steps>

كيف تُكتب الصفوف:

- الصف الذي يحتوي على `documentId` يحدّث ذلك الإدخال؛ والصفوف الأخرى تنشئ إدخالات جديدة.
- تُكتب الصفوف واحدًا تلو الآخر. الصف الذي يفشل يُبلَّغ عنه مع حقله والمشكلة،
  ويُتخطّى؛ وتظل الصفوف الأخرى تُكتب.
- يسرد التقرير ما يصل إلى 100 صف فيها أخطاء، والأعمدة التي لم تطابق أي حقل.
- يأخذ الاستيراد 5,000 صف على الأكثر. قسّم الملفات الأكبر.
- تُكتب الإدخالات باللغة الحالية للقائمة.

<Aside type="caution">
يمرّر الاستيراد صفوفك عبر التحقق نفسه الذي يمر به المحرر، لكن لا يوجد تراجع.
شغّل **تحقّق** أولًا، وصدّر القائمة قبل تحديث كبير حتى تتمكن من استعادتها. مع تفعيل
[سجل المحتوى](/ar/guides/content/content-history/)، يحتفظ كل إدخال محدَّث بنسخته
السابقة.
</Aside>

## صيغة الملف

تستخدم الحقول الأشكال نفسها التي تستخدمها صيغة الكتابة في API المحتوى:

| الحقل | القيمة |
| --- | --- |
| النصوص والأرقام والقيم المنطقية والتواريخ | كما في الـ API (`true`/`false`، تواريخ ISO 8601). |
| العلاقات | قيم `documentId` للإدخالات المرتبطة. |
| الوسائط | معرّفات الملفات من مكتبة الوسائط. |
| العلاقات متعددة الأشكال | `uid:documentId`، مثل `api::article:k3v9…`. |
| المكوّنات والمناطق الديناميكية والكتل وJSON | JSON. |

في CSV، تُضم القوائم (عدة علاقات أو ملفات) بالرمز `|`.

```csv title="articles.csv"
documentId,title,slug,featured,tags
,Hello world,hello-world,true,t1a2b3|t4c5d6
k3v9x8…,Updated title,updated-title,false,
```

الصفوف نفسها بصيغة JSON:

```json title="articles.json"
[
  { "title": "Hello world", "slug": "hello-world", "featured": true, "tags": ["t1a2b3", "t4c5d6"] },
  { "documentId": "k3v9x8…", "title": "Updated title", "slug": "updated-title", "featured": false }
]
```

تصدير قائمة هو دائمًا ملف استيراد صالح لنوع المحتوى نفسه.

## API الإدارة

- يأخذ `GET /admin/api/content/{uid}/export?format=csv` (أو `json`) معاملات الاستعلام
  الخاصة بالقائمة: `filters`، `_q`، `sort`، `status` و`locale`.
- يأخذ `POST /admin/api/content/{uid}/import?locale=` محتوى الملف كسلسلة نصية:

```json
{
  "format": "csv",
  "data": "title,slug\nHello world,hello-world\n",
  "mapping": { "slug": "slug", "notes": null },
  "dryRun": true,
  "publish": false
}
```

يربط `mapping` عمودًا بحقل؛ و`null` يتخطى العمود، وتحتفظ الأعمدة غير المربوطة
باسمها. يحدّ `[server].body_limit` جسم الطلب (1 MB افتراضيًا).

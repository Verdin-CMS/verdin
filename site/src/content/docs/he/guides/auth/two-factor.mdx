אימות דו-שלבי מוסיף שלב שני אחרי הסיסמה: קוד בן 6 ספרות מאפליקציית אימות, או מפתח גישה
(passkey: טביעת אצבע, זיהוי פנים, נעילת מסך או מפתח אבטחה). המדריך הזה מגדיר את שניהם, הופך
אותם לחובה לתפקיד, ומסביר מה לעשות כשמנהל מאבד את שלו. ל-Strapi אין מקבילה מובנית.

אימות דו-שלבי מיועד למנהלים. [משתמשי קצה](/he/guides/auth/end-users/) מתחברים עם סיסמה או עם
ספק OAuth.

## לפני שמתחילים

- אין תכונה להפעיל: כל מנהל יכול להגדיר גורם שני בפרופיל שלו.
- מפתחות גישה קשורים לכתובת של פאנל הניהול. הגדירו את `[server].public_url` לכתובת שמנהלים
  פותחים, כמו `https://cms.example.com`. דפדפנים מציעים מפתחות גישה רק ב-`https://` (וב-
  `localhost`).
- שמרו על `VERDIN_TOKEN_PEPPER` יציב: סודות אפליקציית האימות וקודי השחזור מוגנים באמצעותו,
  ושינוי שלו הופך אותם לבלתי שמישים.

## הגדרת אפליקציית אימות

<Steps>

1. פתחו את ה**פרופיל** שלכם ומצאו את **אימות דו-שלבי**.
2. תחת **אפליקציית אימות**, בחרו **הגדרה** ואשרו את הסיסמה שלכם.
3. סרקו את קוד ה-QR עם אפליקציה כמו 1Password, Google Authenticator או Authy. אם אתם לא
   יכולים לסרוק אותו, הזינו את מפתח ההגדרה שמוצג מתחתיו.
4. הזינו את ה**קוד בן 6 ספרות** שהאפליקציה מציגה ובחרו **הפעלה**.
5. שמרו את **קודי השחזור** ש-Verdin מציג: בחרו **הורדה** או העתיקו אותם, ואז בחרו
   **שמרתי אותם**.

</Steps>

הקודים עוקבים אחרי תקן TOTP (צעדים של 30 שניות, SHA-1, 6 ספרות). גם קוד מהצעד הקודם או הבא
מתקבל, כדי לאפשר סטיית שעון. אם קודים נדחים, בדקו את השעה במכשיר שלכם.

## הוספת מפתח גישה

<Steps>

1. תחת **מפתחות גישה**, בחרו **הוספת מפתח גישה**.
2. תנו לו **שם**, כמו "MacBook Touch ID", ואשרו את הסיסמה שלכם.
3. עקבו אחרי ההנחיות של הדפדפן.

</Steps>

אפשר לרשום עד 20 מפתחות גישה ולהסיר אותם עם **הסרה**. מפתחות גישה הם גורם שני אחרי הסיסמה,
לא תחליף לה.

## קודי שחזור

מקבלים 10 קודי שחזור כשמגדירים את הגורם הראשון. כל אחד מחבר אתכם פעם אחת אם איבדתם את
האפליקציה או את מפתחות הגישה. הפרופיל מציג כמה נשארו; **יצירת קודים חדשים** מחליפה את כולם
(הישנים מפסיקים לעבוד).

<Aside type="caution">
הקודים מוצגים פעם אחת. אחסנו אותם במנהל סיסמאות או במקום לא מקוון, לא ליד המכשיר שמחזיק את
אפליקציית האימות שלכם.
</Aside>

## התחברות עם גורם שני

אחרי הסיסמה, דף ההתחברות מבקש את **קוד אימות**. בחרו **שימוש במפתח גישה** או **שימוש בקוד
שחזור** כדי להחליף שיטה. יש לכם 5 דקות לסיים; אחרי זה, הזינו שוב את הסיסמה.

## חיוב אימות דו-שלבי לתפקיד

<Steps>

1. פתחו את **הגדרות ← תפקידים** ואת התפקיד.
2. הפעילו את **דרישת אימות דו-שלבי** ושמרו.

</Steps>

חברים בלי גורם שני מתבקשים להגדיר אחד כשהם מתחברים. עד שיעשו זאת, הם יכולים לפתוח רק את
הפרופיל שלהם. ב-**הגדרות ← משתמשים**, השורה שלהם מציגה **חסר 2FA**; מנהלים שיש להם גורם שני
מציגים **2FA**.

כל עוד התפקיד שלכם מחייב גורם שני, Verdin מסרב להסיר את האחרון שלכם: הוסיפו מפתח גישה לפני
שאתם מכבים את האפליקציה, או גורם אחר לפני שאתם מסירים את מפתח הגישה היחיד שלכם.

## איפוס הגורם השני של מנהל אחר

כשמנהל מאבד את המכשיר ואת קודי השחזור שלו:

<Steps>

1. פתחו את **הגדרות ← משתמשים** ומצאו את המנהל.
2. בחרו **איפוס אימות דו-שלבי** ואשרו.

</Steps>

זה מסיר את אפליקציית האימות, את מפתחות הגישה ואת קודי השחזור שלו, כך שהוא מתחבר עם הסיסמה
בלבד. אם התפקיד שלו מחייב אימות דו-שלבי, הוא חייב להגדיר אותו שוב. הפעולה דורשת **ניהול
משתמשים**; רק Super Admin יכול לאפס Super Admin אחר.

`verdin admin reset-password` מאפס רק את הסיסמה, לא את הגורם השני.

## כניסה יחידה (SSO)

מנהלים שמתחברים דרך [כניסה יחידה](/he/guides/auth/sso/) מתבקשים גם הם להזין את הגורם השני
שלהם ב-Verdin, אלא אם הספק מסומן ב-**הספק אוכף MFA**.

## API הניהול

כל הנתיבים נמצאים תחת `/admin/api`. אלה שמשנים גורמים מקבלים את ה-`password` שלכם.

| נתיב | עושה |
| --- | --- |
| `POST /auth/login` | עם גורם שני, עונה `{ twoFactorRequired: true, twoFactorToken, methods }` במקום סשן. |
| `POST /auth/login/two-factor` | `{ twoFactorToken, code }` (TOTP או קוד שחזור), או `{ twoFactorToken, challengeToken, credential }` למפתח גישה. עונה עם הסשן. |
| `POST /auth/login/passkey/options` | `{ twoFactorToken }`: האתגר של מפתח הגישה. |
| `GET /auth/two-factor` | הגורמים שלכם: `totp`, `passkeys`, `recoveryCodesLeft`, `required`. |
| `POST /auth/two-factor/totp/setup`, `/totp/enable`, `/totp/disable` | הגדרה (סיסמה), הפעלה (קוד) וכיבוי (סיסמה) של אפליקציית האימות. |
| `POST /auth/two-factor/recovery-codes` | קודי שחזור חדשים. |
| `POST /auth/two-factor/passkeys/options`, `POST /auth/two-factor/passkeys`, `DELETE /auth/two-factor/passkeys/{id}` | רישום והסרה של מפתחות גישה. |
| `DELETE /users/{id}/two-factor` | איפוס הגורמים של מנהל אחר (`users.manage`). |

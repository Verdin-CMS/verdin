Verdin שומר גרסה של רשומה בכל פעם שהיא נוצרת, נשמרת, מתפרסמת, פרסומה מבוטל או שהטיוטה שלה
נמחקת, מכל API. המדריך הזה מראה איך למצוא גרסה ישנה ולשחזר אותה, כמה גרסאות נשמרות, ואת
API הניהול המתאים.

היסטוריית התוכן עובדת כמו זו של Strapi, שם היא תכונה בתשלום.

## לפני שמתחילים

- **הגדרות ← תכונות ← היסטוריית תוכן** פעיל כברירת מחדל. כל עוד הוא כבוי, לא נרשמות גרסאות
  וההיסטוריה אינה זמינה.
- קריאת ההיסטוריה של רשומה דורשת הרשאת קריאה לרשומה; שחזור דורש הרשאת עדכון. הגבלות שדות
  חלות: אתם רואים, ומשחזרים, רק את השדות שהתפקיד שלכם יכול לקרוא או לעדכן. ראו
  [הרשאות](/he/reference/permissions/).

## שחזור גרסה

<Steps>

1. פתחו את הרשומה ובחרו **היסטוריה**.
2. הרשימה **גרסאות** מציגה כל גרסה עם האירוע שלה (**נוצר**, **נשמר**, **פורסם**, **הפרסום
   בוטל**, **הטיוטה בוטלה**), התאריך שלה ומי יצר אותה. שינויים שבוצעו דרך API התוכן מציגים
   **API** כמחבר.
3. בחרו גרסה כדי לראות את השדות שלה.
4. בחרו **שחזור** ואשרו.

</Steps>

הגרסה מחליפה את הטיוטה הנוכחית; פרסמו אותה אחר כך כשתהיו מוכנים. בסוגים בלי טיוטה ופרסום,
השחזור מעדכן את הרשומה ישירות.

מה מושמט בשחזור:

- שדות שכבר לא קיימים בסכמה מפורטים ולא משוחזרים.
- הפניות לרשומות או לקבצים שנמחקו מושמטות, והעורך אומר לכם אילו שדות איבדו אותן.

**חזרה לעורך** חוזר לרשומה בלי לשנות כלום.

## כמה גרסאות נשמרות

Verdin שומר את `[history].max_versions` הגרסאות החדשות ביותר של כל רשומה ושפה (50 כברירת
מחדל) ומסיר ישנות יותר כשמגיעות גרסאות חדשות:

```toml title="verdin.toml"
[history]
max_versions = 100
```

לכל שפה של רשומה מתורגמת יש היסטוריה משלה. מחיקת רשומה, או אחת מהשפות שלה, מוחקת גם את
הגרסאות שלה. ראו את [תיעוד התצורה](/he/reference/configuration/).

<Aside type="note">
בניגוד ל-Strapi, שבו ההיסטוריה נשמרת למשך מספר ימים, Verdin שומר מספר גרסאות לכל רשומה, לא
משנה כמה הן ישנות.
</Aside>

## API הניהול

כל הנתיבים נמצאים תחת `/admin/api`.

| נתיב | הרשאה | עושה |
| --- | --- | --- |
| `GET /history/{uid}/{documentId}?locale=&page=&pageSize=` | קריאת הרשומה | גרסאות, מהחדשה לישנה, בלי הנתונים שלהן (20 לעמוד, עד 100). |
| `GET /history/versions/{id}` | קריאת הרשומה | גרסה אחת עם הנתונים שלה. |
| `POST /history/versions/{id}/restore` | עדכון הרשומה | משחזר את הגרסה כטיוטה הנוכחית. |

תשובת השחזור מפרטת מה הושמט:

```json
{
  "data": {
    "documentId": "k3v9…",
    "restored": 42,
    "dropped": [{ "field": "tags", "count": 1 }]
  }
}
```

הנתיבים עונים `404` כל עוד התכונה כבויה.

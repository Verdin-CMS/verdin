מנהלים יכולים לדון ברשומה בשרשורי תגובות, להגיב על שדה אחד, לאזכר זה את זה ולהקצות משימות עם
תאריכי יעד, בלי לצאת מהעורך. המדריך הזה מכסה את שניהם, מי יכול לעשות מה, ואת API הניהול.
ל-Strapi אין מקבילה.

## לפני שמתחילים

- **הגדרות ← תכונות ← תגובות ומשימות** פעיל כברירת מחדל.
- הרשאת קריאה לסוג התוכן של רשומה מספיקה כדי לקרוא ולכתוב את התגובות והמשימות שלה.
- מנהלים שמאוזכרים ומנהלים שמשימות הוקצו להם מקבלים הודעת דוא"ל דרך `[email]`. עם ספק ברירת
  המחדל `log`, הודעות הדוא"ל הולכות רק ליומן השרת. ראו את
  [תיעוד התצורה](/he/reference/configuration/).

## תגובה על רשומה

<Steps>

1. פתחו את הרשומה ובחרו **תגובות**. הכפתור מציג את מספר השרשורים הפתוחים.
2. בלשונית **תגובות**, כתבו ב**תגובה חדשה**. הקלידו `@` כדי לאזכר מנהל.
3. בחרו **פרסום תגובה**, או לחצו Control או Command ו-Enter.

</Steps>

כדי להגיב על שדה אחד, השתמשו בכפתור התגובה שליד השדה (**תגובה על** ואחריו שם השדה). שרשורים
של שדה מוצגים תחת **על** השדה הזה; **הצגת הכול** מציג שוב את כל השרשורים.

בשרשור אפשר:

- **תשובה**.
- **פתרון** כשהדיון הסתיים, ו**פתיחה מחדש** מאוחר יותר. שרשורים שנפתרו עוברים ל**שרשורים
  שנפתרו**. רק התגובה הראשונה של שרשור פותרת אותו.
- **עריכת תגובה** בתגובות שלכם.
- **מחיקת תגובה** או **מחיקת שרשור** בתגובות שלכם. Super Admin יכול למחוק כל תגובה.

בסוגים מתורגמים התגובות נשמרות לכל שפה, והן מחזיקות עד 10,000 תווים.

## אזכור מנהל

מנהלים שמאוזכרים מקבלים הודעת דוא"ל עם התגובה וקישור לרשומה, בתנאי שהם יכולים לקרוא אותה. אף
פעם לא תקבלו הודעת דוא"ל על אזכור של עצמכם.

## הקצאת משימה

<Steps>

1. פתחו את הלשונית **משימות** באותו חלון ובחרו **משימה חדשה**.
2. הזינו **כותרת**, ובאופן אופציונלי **תיאור**, **אחראי** ו**תאריך יעד**. האחראי חייב להיות
   מסוגל לקרוא את הרשומה.
3. בחרו **יצירת משימה**.

</Steps>

האחראי מקבל הודעת דוא"ל, אלא אם הקצה את המשימה לעצמו. משימות שעבר תאריך היעד שלהן מוצגות
כבאיחור. סמנו משימה כבוצעה מהשורה שלה.

היוצר והאחראי של משימה יכולים לשנות אותה או להשלים אותה. רק היוצר שלה מוחק אותה. Super Admin
יכול לעשות את שניהם בכל משימה.

כדי לראות את המשימות הפתוחות שלכם בכל הרשומות, הוסיפו את הווידג'ט **המשימות שלי** לדף הבית:
בחרו **התאמה אישית**, ואז **הוספת ווידג׳ט**.

## עבודה משותפת בזמן אמת

כשמנהל אחר מוסיף, פותר או מוחק תגובה או משימה ברשומה שפתוחה אצלכם, הפאנל אומר **התגובות
עודכנו.** או **המשימות עודכנו.** ומציג את השינוי.

## API הניהול

כל הנתיבים נמצאים תחת `/admin/api`. `uid`, `documentId` ו-`locale` מזהים את הרשומה.

| נתיב | עושה |
| --- | --- |
| `GET /comments?uid=&documentId=&locale=` | השרשורים של הרשומה עם התשובות שלהם. |
| `POST /comments` | `{ uid, documentId, locale?, field?, parentId?, body }`. `parentId` הופך אותה לתשובה. |
| `PUT /comments/{id}` | `{ body }`. רק התגובות שלכם. |
| `DELETE /comments/{id}` | התגובות שלכם, או כל תגובה כ-Super Admin. |
| `POST /comments/{id}/resolve`, `POST /comments/{id}/reopen` | על התגובה הראשונה של שרשור. |
| `GET /tasks?uid=&documentId=&locale=` | המשימות של הרשומה. |
| `GET /tasks?mine=true&status=open` | המשימות שלכם, בכל הרשומות שאתם עדיין יכולים לקרוא. |
| `POST /tasks` | `{ uid, documentId, locale?, title, description?, assigneeId?, dueDate? }`, עם `dueDate` בפורמט `YYYY-MM-DD`. |
| `PUT /tasks/{id}` | היוצר או האחראי. כל אחד מ-`title`, `description`, `assigneeId`, `dueDate` (`null` מנקה אותם), ו-`status` (`open` או `done`). |
| `DELETE /tasks/{id}` | היוצר בלבד (או Super Admin). |

בגוף תגובה, אזכור נכתב `@[Name](user:12)`, כאשר `12` הוא המזהה של המנהל.

<Aside type="note">
הנתיבים עונים `404` כל עוד התכונה כבויה. כיבוי שלה מסתיר את התגובות והמשימות; הן נשמרות
לפעם שתפעילו אותה מחדש.
</Aside>

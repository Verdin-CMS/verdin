התקציר לעורכים הוא הודעת דוא"ל יומית שאומרת לכל מנהל כמה רשומות השתנו מאז שהסתכל עליהן
לאחרונה, לפי סוג תוכן. הוא כבוי לכולם עד שכל מנהל מפעיל אותו. המדריך הזה מכסה את הצד של
המנהל, את הגדרות השרת ואיך זה עובד עם כמה מופעים.

## איך "לא נצפה" עובד

רשומה הופכת ללא נצפתה עבורכם כשמישהו אחר משנה אותה, מכל API. היא נצפית שוב ברגע שתפתחו
אותה. אותם סימונים מפעילים את תגי ה-**חדש** בסרגל הצד (כבו אותם עם **הצגת תגי פריטים שלא
נצפו**) ואת הווידג'ט **טרם נצפו** בדף הבית.

## הפעלת התקציר

<Steps>

1. פתחו את ה**פרופיל** שלכם (או את תפריט ההעדפות בסרגל העליון).
2. תחת **העדפות**, הפעילו את **דוא״ל יומי על שינויים שלא נצפו**.

</Steps>

המתג מגדיר את ההעדפה `"digest": "daily"` בחשבון שלכם
(`PUT /admin/api/users/me/preferences`). כבו אותו באותה דרך.

מה תקבלו:

- הודעה עם מספר הרשומות שלא נצפו לכל סוג תוכן שאתם יכולים לקרוא, וקישור לפאנל הניהול.
- כלום בימים שבהם אין שום דבר חדש.
- רק כל עוד החשבון שלכם פעיל.

## הגדרות שרת

התקציר נשלח ב-`[digest].hour_utc`, דרך `[email]`:

```toml title="verdin.toml"
[email]
provider = "smtp"
from = "Verdin <no-reply@example.com>"

[email.smtp]
host = "smtp.example.com"

[digest]
hour_utc = 7    # 0–23, UTC; 8 by default
```

| מפתח | ברירת מחדל | תיאור |
| --- | --- | --- |
| `[digest].enabled` | `true` | שליחת התקציר מהמופע הזה. |
| `[digest].hour_utc` | `8` | השעה (UTC) שבה התקציר יוצא. |

הקישור בהודעה משתמש ב-`[server].public_url`; הגדירו אותו כש-Verdin רץ מאחורי proxy. עם ספק
הדוא"ל ברירת המחדל `log`, ההודעות רק נכתבות ליומן השרת. ראו את
[תיעוד התצורה](/he/reference/configuration/).

## כמה מופעים

כל מופע עם `[digest].enabled = true` מנסה לשלוח את התקציר בשעה שנקבעה. הראשון שתופס את היום
במסד הנתונים שולח אותו, והאחרים מדלגים על אותו יום, כך שהמנהלים מקבלים הודעה אחת. כדי להשאיר
את המשימה במופע ידוע, הגדירו `enabled = false` באחרים:

```sh title="Terminal"
VERDIN_DIGEST__ENABLED=false verdin start
```

<Aside type="note">
התקציר הוא תוספת של Verdin; ל-Strapi אין מקבילה.
</Aside>

הנתונים של פרויקט Verdin נמצאים בשני מקומות: **מסד הנתונים** (תוכן, מנהלים, תפקידים,
אסימונים, הגדרות, היסטוריה, יומני ביקורת) ו**אחסון המדיה** (הקבצים של ספריית המדיה, בדיסק
או ב-bucket). קובצי הסכמה נמצאים במאגר שלכם. גבו את שני המאגרים; `verdin export` מוסיף
ארכיון נייד של התוכן.

| שיטה | מכיל | מתאים ל |
| --- | --- | --- |
| dump של מסד הנתונים + עותק של המדיה | הכול | התאוששות מאסון של אותו פרויקט |
| `verdin export` | סכמה, שפות, מדיה, כל גרסה של כל רשומה | העברת תוכן למופע אחר או למנוע מסד נתונים אחר; עותק נוסף ונייד |

## Dumps של מסד הנתונים

השתמשו בכלים של מסד הנתונים שלכם, או בגיבויים האוטומטיים של הספק שלכם:

```sh frame="terminal"
# PostgreSQL
pg_dump --format=custom --file=verdin-$(date +%F).dump "$VERDIN_DATABASE_URL"

# MySQL / MariaDB
mysqldump --single-transaction --routines -h <host> -u <user> -p <database> > verdin-$(date +%F).sql

# SQLite: עותק עקבי בזמן שהשרת רץ
sqlite3 /data/verdin.db ".backup '/backups/verdin-$(date +%F).db'"
```

אל תעתיקו קובץ SQLite פעיל עם `cp`: השתמשו ב-`.backup` (או עצרו קודם את השרת).

dump מכיל hashes של סיסמאות, hashes של אסימוני API ושדות פרטיים. הצפינו אותו והרחיקו אותו
מהשרתים שהוא מגן עליהם. כדי לשחזר אחד, צריך גם את אותם `VERDIN_TOKEN_PEPPER`
ו-`VERDIN_ADMIN_JWT_SECRET`: בלי ה-pepper, אסימוני API והקודים מאפליקציית האימות של
המנהלים מפסיקים לעבוד.

## אחסון המדיה

- **ספק מקומי**: העתיקו את תיקיית ההעלאות (`[upload].provider.dir`,
  `/data/uploads` באימג' של Docker) עם גיבוי הקבצים הרגיל שלכם, אחרי ה-dump של מסד הנתונים,
  כדי שלא יחסר אף קובץ שה-dump מפנה אליו.
- **ספק S3**: הפעילו versioning או רפליקציה ב-bucket, או העתיקו אותו עם הכלים של הספק שלכם.

אפשר לבנות מחדש את המטמון של המרות התמונות ואת אינדקס החיפוש, והם לא צריכים גיבוי.

## `verdin export`

`verdin export` כותב את הסכמה, התוכן והמדיה של פרויקט ל-`.tar.gz` אחד, ו-
`verdin import verdin` משחזר אותו לאותו פרויקט או למופע אחר, בכל מנוע מסד נתונים.

```sh frame="terminal"
verdin export backup-2026-09-28.tar.gz            # סכמה, שפות, מדיה ורשומות
verdin export content-only.tar.gz --no-media      # בלי קובצי מדיה
verdin import verdin backup-2026-09-28.tar.gz     # לתוך הפרויקט הזה
```

הריצו אותן עם התצורה של הפרויקט (אותו `verdin.toml` ואותה סביבה כמו השרת). בקונטיינר:
`docker compose exec verdin verdin export /data/backup.tar.gz`.

### מה נכלל

- **קובצי סכמה**, כמו שהם.
- **שפות.** פרויקט ריק מקבל את כולן, כולל שפת ברירת המחדל. פרויקט שכבר יש לו שפות מקבל רק
  את החסרות.
- **תיקיות וקובצי מדיה**, עם הפורמטים הרספונסיביים שלהם. הקבצים שומרים על ה-`documentId`
  שלהם; המזהים המספריים שלהם משתנים.
- **כל גרסה של כל רשומה**: טיוטות, גרסאות מפורסמות וכל השפות, עם התאריכים, הקשרים (לפי
  `documentId`) והמדיה שלהן, כולל קשרים ומדיה בתוך רכיבים ואזורים דינמיים. שדות פרטיים
  ו-hashes של סיסמאות נכללים.

**לא נכלל**: משתמשי ניהול, תפקידים, אסימוני API, webhooks, הגדרות תכונות, תהליכי בקרה
ומהדורות. צרו אותם מחדש ביעד, או שחזרו dump של מסד הנתונים במקום זאת.

:::caution
ייצוא מכיל שדות פרטיים ו-hashes של סיסמאות. אחסנו אותו כמו dump של מסד נתונים.
:::

### ייבוא

1. הייבוא כותב את קובצי הסכמה ומבצע הגירה של מסד הנתונים עם שלבים בטוחים בלבד.
2. קובצי סכמה שכבר קיימים ושונים גורמים לו לעצור, אלא אם מעבירים `--force`.
3. גם סוגי תוכן שכבר יש להם רשומות גורמים לו לעצור, אלא אם מעבירים `--force`; אז הרשומות
   נוספות לצד הקיימות.
4. מסמכים מיובאים שומרים על ה-`documentId` שלהם, כך שייבוא לפרויקט שכבר יש בו את אותם
   מסמכים נכשל.

הייבוא לא מפעיל webhooks או hooks של תוספים, והוא לא כותב היסטוריה.

### פורמט הארכיון

ארכיון tar מכווץ ב-gzip:

| נתיב | תוכן |
| --- | --- |
| `manifest.json` | `format: "verdin-export"`, גרסת הפורמט, גרסת Verdin, גרסאות לכל סוג תוכן |
| `schema/…` | קובצי הסכמה |
| `locales.json` | `{ default, locales: [{ code, name }] }` |
| `folders.json`, `files.jsonl` | תיקיות וקובצי מדיה, אובייקט JSON אחד לכל שורה |
| `assets/{hash}{ext}` | האובייקטים השמורים של הקבצים ושל הפורמטים שלהם |
| `entries/{uid}.jsonl` | גרסה אחת לכל שורה: `documentId`, `locale`, `published`, תאריכים, `data`, `relations`, `media` |

כדי להביא במקום זאת פרויקט Strapi, ראו [מעבר מ-Strapi](/he/migrate/from-strapi/).

## בדקו את השחזורים שלכם

מדי פעם שחזרו למסד נתונים זמני, הפעילו עליו את Verdin עם `verdin start`, ובדקו שאפשר
להתחבר ולקרוא רשומות ומדיה.

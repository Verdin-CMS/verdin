## What is in the box

- **Content-type builder** in the admin panel (in `verdin dev`), with schemas stored as
  versionable JSON files in the Strapi format.
- **Media library** with responsive image formats, on local disk or any S3-compatible
  storage.
- **Internationalization**, **end users** (sign-up, sign-in, OAuth), **webhooks** with
  signed payloads and a delivery log.
- **WebAssembly plugins** that hook into writes, add routes and jobs, and bring admin
  widgets and custom fields — sandboxed to the capabilities they declare.
- **TypeScript types** generated from the schema (`verdin types`) and a typed client,
  `@verdin/client`.

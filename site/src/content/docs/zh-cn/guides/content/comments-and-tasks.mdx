管理员无需离开编辑器，就可以在评论讨论串中讨论条目、针对某个字段发表评论、互相提及，以及分配带截止日期的任务。本指南介绍这两项功能、谁可以做什么，以及管理 API。Strapi 没有对应功能。

## 开始之前

- **设置 → 功能 → 评论与任务** 默认开启。
- 只要能读取条目所属的内容类型，就可以读写其评论和任务。
- 被提及的管理员和任务负责人会通过 `[email]` 收到邮件。使用默认的 `log` 提供方时，邮件只会写入服务器日志。参见[配置参考](/zh-cn/reference/configuration/)。

## 评论条目

<Steps>

1. 打开条目并选择 **评论**。该按钮会显示进行中的讨论串数量。
2. 在 **评论** 标签页中，在 **新评论** 里输入内容。输入 `@` 可以提及管理员。
3. 选择 **评论**，或者按 Control 或 Command 加 Enter。

</Steps>

要针对某个字段发表评论，请使用字段旁边的评论按钮（**评论** 加上字段名）。字段讨论串会显示在 **关于** 该字段之下；**显示全部** 会重新列出所有讨论串。

在讨论串中，你可以：

- **回复**。
- 讨论结束后将其 **标记为已解决**，之后还可以 **重新打开**。已解决的讨论串会移到 **已解决的讨论串** 中。只有讨论串的第一条评论可以将其标记为已解决。
- 对自己的评论使用 **编辑评论**。
- 对自己的评论使用 **删除评论** 或 **删除讨论串**。Super Admin 可以删除任何评论。

在本地化类型上，评论按语言区域分别保存，每条最多 10,000 个字符。

## 提及管理员

被提及的管理员会收到一封包含该评论和条目链接的邮件，前提是他们能够读取该条目。提及自己时永远不会收到邮件。

## 分配任务

<Steps>

1. 打开同一面板中的 **任务** 标签页，选择 **新建任务**。
2. 输入 **标题**，并可选择填写 **描述**、**负责人** 和 **截止日期**。负责人必须能够读取该条目。
3. 选择 **创建任务**。

</Steps>

负责人会收到邮件，除非任务是他们分配给自己的。超过截止日期的任务会显示为已逾期。在任务所在行上即可将其标记为已完成。

任务的创建者和负责人可以修改或完成它。只有创建者可以删除它。Super Admin 对任何任务都可以执行这两种操作。

要跨条目查看你的待办任务，请把 **我的任务** 小组件添加到首页：选择 **自定义**，然后选择 **添加小组件**。

## 实时协作

当其他管理员在你打开的条目上添加、解决或删除评论或任务时，面板会提示 **评论已更新。** 或 **任务已更新。**，并显示相应的变化。

## 管理 API

所有路由都位于 `/admin/api` 下。`uid`、`documentId` 和 `locale` 指定条目。

| 路由 | 作用 |
| --- | --- |
| `GET /comments?uid=&documentId=&locale=` | 该条目的讨论串及其回复。 |
| `POST /comments` | `{ uid, documentId, locale?, field?, parentId?, body }`。`parentId` 表示这是一条回复。 |
| `PUT /comments/{id}` | `{ body }`。只限你自己的评论。 |
| `DELETE /comments/{id}` | 你自己的评论，Super Admin 可以删除任何评论。 |
| `POST /comments/{id}/resolve`、`POST /comments/{id}/reopen` | 作用于讨论串的第一条评论。 |
| `GET /tasks?uid=&documentId=&locale=` | 该条目的任务。 |
| `GET /tasks?mine=true&status=open` | 你的任务，涵盖你仍能读取的所有条目。 |
| `POST /tasks` | `{ uid, documentId, locale?, title, description?, assigneeId?, dueDate? }`，其中 `dueDate` 格式为 `YYYY-MM-DD`。 |
| `PUT /tasks/{id}` | 创建者或负责人。可以修改 `title`、`description`、`assigneeId`、`dueDate`（`null` 表示清空）以及 `status`（`open` 或 `done`）中的任意项。 |
| `DELETE /tasks/{id}` | 仅限创建者（或 Super Admin）。 |

在评论正文中，提及写作 `@[Name](user:12)`，其中 `12` 是管理员的 id。

<Aside type="note">
功能关闭时，这些路由返回 `404`。关闭功能会隐藏评论和任务；它们会被保留，待你重新开启时恢复。
</Aside>

Verdin は、Rust で書かれたオープンソースのヘッドレス CMS です。あなたがコンテンツタイプをモデル化し、編集者が管理パネルで執筆・公開し、サイトやアプリは REST または GraphQL の API でコンテンツを読みます。Verdin はページを描画しません。描画はフロントエンドが行います。

Verdin は [Strapi v5](https://strapi.io) の書き直しです。スキーマの形式とコンテンツ API は同じ形なので、Strapi のプロジェクトとそのフロントエンドは少ない変更で移行できます。

## 誰のためのものか

- **サイトやアプリを作る開発者。** 1 つのプロセスとして動かせ、コンテンツモデルを git で管理でき、Astro、Next.js、モバイルアプリなど、どのフロントエンドからでも読める CMS を求める人に向いています。
- **Strapi を使っているチーム。** 同じ API をより少ないリソースで使いたい、または Strapi が有料プランに限定している機能が必要なチームに向いています。Verdin に Enterprise エディションはありません。SSO、監査ログ、レビューワークフロー、リリースはオープンソースのプロジェクトに含まれています。
- **編集者。** 18 の言語で使える管理パネルで、下書き、公開、履歴、プレビューが使えます。

## 含まれるもの

1 つの実行ファイル `verdin` が、サーバー、コマンドラインツール、管理パネルを兼ねます。本番環境に Node.js のランタイムも `node_modules` もありません。

| 領域 | 得られるもの |
| --- | --- |
| データベース | PostgreSQL 14 以降、MySQL 8.4 以降、MariaDB 10.11 以降、SQLite。すべて同じテストスイートでカバーされています。 |
| コンテンツモデル | コレクションタイプ、シングルタイプ、コンポーネント、ダイナミックゾーン、リレーション、メディア、Markdown または Strapi の blocks 形式のリッチテキスト。スキーマはプロジェクト内の JSON ファイルです。 |
| スキーマの変更 | すべての変更が、リスクレベルと正確な SQL を持つマイグレーションプランになります。破壊的なステップは、許可した場合にだけ実行されます。 |
| API | Strapi v5 のパラメーター（`filters`、`populate`、`sort`、`pagination`）を使う `/api` 配下の REST、任意の GraphQL エンドポイント、OpenAPI ドキュメント、型付きの TypeScript クライアント。 |
| 編集 | 下書きと公開、多言語化されたコンテンツ、コンテンツ履歴、リリース、レビューワークフロー、コメントとタスク、ライブのプレゼンス、自分のサイト上でのプレビューとビジュアル編集。 |
| アクセス | フィールドとロケールまで絞り込める管理者のロール、API トークン、公開アクセスの許可、OpenID Connect による SSO、パスキーによる二段階認証、監査ログ。 |
| サイトの機能 | 全文検索、サイトマップ、リダイレクト、メニュー、フォーム、Webhook、リアルタイム更新。 |
| 拡張 | 書き込みにフックし、ルートとジョブを追加し、管理画面のウィジェットとカスタムフィールドを提供する WebAssembly のプラグイン。宣言した機能の範囲に制限されます。 |

## Strapi v5 との関係

**同じ点:**

- スキーマファイルは Strapi の形式を使います: `schema/content-types/<singularName>.json` と `schema/components/<category>/<name>.json`。
- REST のコンテンツ API: ルート、`documentId` を持つフラットなレスポンスの形式、クエリパラメーターと演算子、書き込みの意味論（`POST` や `PUT` は `?status=draft` を渡さない限り公開する）、エラーのボディ。
- GraphQL のスキーマは Strapi v5 の GraphQL プラグインと同じ形です。
- エンドユーザー（サインアップ、ログイン、OAuth、ロール）は `users-permissions` の API に従います。

**異なる点:**

- **スキーマの変更は計画されたマイグレーションです。** Verdin はスキーマファイルをデータベースと比較し、実行する前にステップを表示します。データベースがスキーマに追いついていない間、`verdin start` は実行を拒否します。
- **コンテンツタイプビルダーは開発モードでのみ動きます。** 本番環境では、スキーマはリポジトリから来ます。
- **プラグインは JavaScript ではなく WebAssembly です。** Strapi のプラグインや、`src/` にある独自のコントローラー、サービス、ライフサイクルのファイルは Verdin では動きません。
- **データベースは Strapi と共有しません。** Strapi のプロジェクトは `verdin import strapi` で移行し、すべてのドキュメントに新しい ID が付きます。
- **REST にいくつかの追加があります**: 公開と非公開のアクション（`POST /api/<route>/<documentId>/actions/publish`）。また、populate したコンポーネントは、ネストしたコンポーネントを含めて丸ごと返されます。

[Strapi との互換性](/ja/migrate/compatibility/)に違いが詳しく一覧されています。

## 使うべきでない場合

- **Strapi のプラグインや JavaScript の独自のサーバーコードに依存している。** Verdin はそれらを実行できません。WebAssembly のプラグインとして書き直すか、ロジックを別の場所に移す必要があります。
- **安定した 1.0 が必要。** Verdin は 0.10 で、マイナーリリースでまだ設定や動作が変わることがあります。各リリースの前に[アップグレード](/ja/migrate/upgrading/)を読んでください。
- **CMS にページを描画してほしい。** Verdin はヘッドレスです。フロントエンドのフレームワークか静的サイトジェネレーターと組み合わせてください。
- **マネージドサービスがほしい。** Verdin はセルフホストです。自分のインフラでバイナリか Docker イメージを実行します。

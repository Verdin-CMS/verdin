管理者は、エディターを離れずに、コメントのスレッドでエントリーについて話し合い、1 つのフィールドにコメントし、互いをメンションし、期限付きのタスクを割り当てられます。このガイドでは、その両方、誰が何をできるか、そして Admin API を説明します。Strapi には対応する機能がありません。

## 始める前に

- **設定 → 機能 → コメントとタスク**はデフォルトでオンです。
- エントリーのコンテンツタイプを読み取れれば、そのコメントとタスクを読み書きできます。
- メンションされた管理者とタスクの担当者には、`[email]` を通じてメールが送られます。デフォルトの `log` プロバイダーでは、メールはサーバーのログにだけ出力されます。[設定のリファレンス](/ja/reference/configuration/)を参照してください。

## エントリーにコメントする

<Steps>

1. エントリーを開き、**コメント**を選びます。ボタンには、未解決のスレッドの数が表示されます。
2. **コメント**タブの**新しいコメント**に書きます。`@` を入力すると管理者をメンションできます。
3. **コメント**を選ぶか、Control または Command と Enter を押します。

</Steps>

1 つのフィールドにコメントするには、フィールドの隣にあるコメントボタン（**_フィールド名_にコメント**）を使います。フィールドのスレッドは、そのフィールドの **_フィールド名_について**に表示されます。**すべて表示**で、再びすべてのスレッドが一覧されます。

スレッドでは次のことができます。

- **返信**。
- 議論が終わったら**解決済みにする**、後から**再開する**。解決済みのスレッドは**解決済みのスレッド**に移ります。スレッドを解決できるのは、スレッドの最初のコメントだけです。
- 自分のコメントで**コメントを編集**。
- 自分のコメントで**コメントを削除**または**スレッドを削除**。Super Admin はどのコメントも削除できます。

多言語化された型では、コメントはロケールごとに保持され、最大 10,000 文字まで書けます。

## 管理者をメンションする

メンションされた管理者は、エントリーを読み取れる限り、コメントとエントリーへのリンクを含むメールを受け取ります。自分自身をメンションしても、メールは送られません。

## タスクを割り当てる

<Steps>

1. 同じパネルの**タスク**タブを開き、**新規タスク**を選びます。
2. **タイトル**と、任意で**説明**、**担当者**、**期限**を入力します。担当者はエントリーを読み取れる必要があります。
3. **タスクを作成**を選びます。

</Steps>

担当者には、自分で自分に割り当てた場合を除き、メールが送られます。期限を過ぎたタスクは期限切れと表示されます。タスクは、その行から完了にできます。

タスクの作成者と担当者は、タスクを変更したり完了にしたりできます。削除できるのは作成者だけです。Super Admin はどのタスクでも両方を行えます。

エントリーをまたいで自分の未完了のタスクを確認するには、ホームページに**自分のタスク**ウィジェットを追加します。**カスタマイズ**を選び、続いて**ウィジェットを追加**を選びます。

## リアルタイムの共同作業

あなたが開いているエントリーで、別の管理者がコメントやタスクを追加、解決、削除すると、パネルに<strong>コメントが更新されました。</strong>または<strong>タスクが更新されました。</strong>と表示され、変更が反映されます。

## Admin API

すべてのルートは `/admin/api` 配下にあります。`uid`、`documentId`、`locale` でエントリーを指定します。

| ルート | 動作 |
| --- | --- |
| `GET /comments?uid=&documentId=&locale=` | エントリーのスレッドとその返信。 |
| `POST /comments` | `{ uid, documentId, locale?, field?, parentId?, body }`。`parentId` を指定すると返信になります。 |
| `PUT /comments/{id}` | `{ body }`。自分のコメントのみ。 |
| `DELETE /comments/{id}` | 自分のコメント。Super Admin はどのコメントでも可。 |
| `POST /comments/{id}/resolve`、`POST /comments/{id}/reopen` | スレッドの最初のコメントに対して。 |
| `GET /tasks?uid=&documentId=&locale=` | エントリーのタスク。 |
| `GET /tasks?mine=true&status=open` | 自分のタスク。まだ読み取れるエントリーをまたいで取得します。 |
| `POST /tasks` | `{ uid, documentId, locale?, title, description?, assigneeId?, dueDate? }`。`dueDate` は `YYYY-MM-DD` です。 |
| `PUT /tasks/{id}` | 作成者または担当者。`title`、`description`、`assigneeId`、`dueDate`（`null` で消去）、`status`（`open` または `done`）のいずれか。 |
| `DELETE /tasks/{id}` | 作成者のみ（または Super Admin）。 |

コメントの本文では、メンションは `@[Name](user:12)` と書きます。`12` は管理者の ID です。

<Aside type="note">
機能がオフの間、ルートは `404` を返します。オフにするとコメントとタスクは非表示になりますが、再びオンにするときのために保持されます。
</Aside>

編集者向けダイジェストは、最後に確認してから変更されたエントリーの数を、コンテンツタイプごとに各管理者へ知らせる毎日のメールです。各管理者がオンにするまで、全員に対してオフです。このガイドでは、管理者側の操作、サーバーの設定、複数のインスタンスでの動作を説明します。

## 「未読」の仕組み

誰か他の人がエントリーを変更すると、どの API からであっても、そのエントリーはあなたにとって未読になります。エントリーを開くと、再び既読になります。同じ印が、サイドバーの**新規**バッジ（**未読バッジを表示**でオフにできます）と、ホームページの**未読**ウィジェットにも使われます。

## ダイジェストをオンにする

<Steps>

1. **プロフィール**（またはトップバーの環境設定メニュー）を開きます。
2. **環境設定**で、**未確認の変更を毎日メールで受け取る**をオンにします。

</Steps>

このスイッチは、アカウントに環境設定 `"digest": "daily"` を設定します（`PUT /admin/api/users/me/preferences`）。同じ方法でオフにします。

受け取るもの:

- 読み取れるコンテンツタイプごとの未読のエントリーの数と、管理パネルへのリンクを含むメッセージ。
- 新しいものがない日には何も届きません。
- アカウントが有効な間だけ届きます。

## サーバーの設定

ダイジェストは `[digest].hour_utc` に、`[email]` を通じて送られます。

```toml title="verdin.toml"
[email]
provider = "smtp"
from = "Verdin <no-reply@example.com>"

[email.smtp]
host = "smtp.example.com"

[digest]
hour_utc = 7    # 0–23, UTC; 8 by default
```

| キー | デフォルト | 説明 |
| --- | --- | --- |
| `[digest].enabled` | `true` | このインスタンスからダイジェストを送ります。 |
| `[digest].hour_utc` | `8` | ダイジェストを送る時刻（UTC）。 |

メール内のリンクは `[server].public_url` を使います。Verdin をプロキシの背後で実行する場合は設定してください。デフォルトの `log` メールプロバイダーでは、メッセージはサーバーのログにだけ書き込まれます。[設定のリファレンス](/ja/reference/configuration/)を参照してください。

## 複数のインスタンス

`[digest].enabled = true` のすべてのインスタンスが、設定した時刻にダイジェストを送ろうとします。データベースでその日を最初に確保したインスタンスが送信し、他のインスタンスはその日をスキップするので、管理者に届くメールは 1 通です。ジョブを特定のインスタンスで実行するには、他のインスタンスで `enabled = false` を設定します。

```sh title="Terminal"
VERDIN_DIGEST__ENABLED=false verdin start
```

<Aside type="note">
ダイジェストは Verdin 独自の機能で、Strapi には対応する機能がありません。
</Aside>

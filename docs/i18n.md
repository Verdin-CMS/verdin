# Content internationalization

A localized content type keeps one version of each document per locale. All versions share the same `documentId`. Each locale has its own draft and published version.

## Locales

Manage locales in **Settings → Internationalization** (permission `locales.manage`). The first start adds English (`en`) as the default. One locale is always the default: requests that name no locale use it.

Deleting a locale also deletes every entry written in it.

## Schema

Turn localization on for a content type, and opt single fields out when they should be the same in every locale:

```json
{
  "kind": "collectionType",
  "singularName": "article",
  "pluralName": "articles",
  "displayName": "Article",
  "pluginOptions": { "i18n": { "localized": true } },
  "attributes": {
    "title": { "type": "string" },
    "price": { "type": "decimal", "pluginOptions": { "i18n": { "localized": false } } }
  }
}
```

Fields with `localized: false` are **shared**. Saving a shared field in one locale writes it to the drafts of every locale. Publishing a locale copies its shared fields to the published versions of the other locales. This applies to relations and media too.

Types without `pluginOptions.i18n.localized` are not localized. They ignore `locale` parameters.

## API

Add `locale` to any REST request (Strapi v5 format), or pass it as an argument in GraphQL:

```sh
curl 'localhost:1337/api/articles?locale=fr'
curl -XPUT 'localhost:1337/api/articles/<documentId>?locale=fr' -H 'content-type: application/json' \
  -d '{"data":{"title":"Bonjour"}}'          # creates the French version if it does not exist
curl -XDELETE 'localhost:1337/api/articles/<documentId>?locale=fr'   # only the French version
```

```graphql
query { articles(locale: "fr") { documentId title locale } }
```

- Responses of localized types include `locale`.
- An unknown locale is a `400` error.
- Deleting a document deletes only the version in the requested locale (the default locale when none is given). Links pointing at the document are removed once no locale is left.
- When a localized type links to another localized type, reads resolve the target in the same locale. Filters through relations work the same way. Targets that are not localized are shared by every locale.
- Webhook payloads and history versions record the locale.

In the admin, use the locale switcher in the list and the editor. **Fill from another locale** copies the localized fields of another locale into the form.

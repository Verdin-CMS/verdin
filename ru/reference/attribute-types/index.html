Справочник по типам атрибутов

Атрибуты — это поля типа содержимого или компонента, объявленные в разделе attributes его файла схемы. На этой странице перечислены все значения type, параметры, которые они принимают, то, как Verdin их проверяет и хранит, и как они выглядят в API. Формат — это формат Strapi v5; отличия перечислены в конце.

Файлы схемы строгие: неизвестный ключ или параметр, который тип не принимает, — это ошибка, о которой verdin schema check сообщает с путём (attributes.title.maxLength).

Параметры всех атрибутов

Заголовок раздела «Параметры всех атрибутов»
Параметр По умолчанию Описание
type обязательный Один из типов ниже.
required false Значение должно быть задано. Проверяется при публикации записи (черновики могут быть неполными) и при каждой записи в тип без черновиков и публикации. Действует и внутри компонентов и динамических зон.
private false Никогда не возвращается content API и не может использоваться в filters или sort. Атрибуты password всегда private.
configurable true Флаг Strapi для конструктора в админке; сохраняется как записан.
pluginOptions.i18n.localized true В локализованном типе содержимого false делает значение общим для всех локалей вместо отдельного значения для каждой.
customField не задан plugin::<plugin>.<field> (или global::<field>): админка редактирует атрибут через пользовательское поле плагина. type определяет, как хранится значение. См. Плагины.
conditions не задан Условные поля Strapi ({ "visible": <JSON Logic> }). Редактор скрывает поле, пока правило ложно, а сервер не требует заполнять скрытое поле.
default не задан Значение новых записей, если при записи атрибут не передан. Должно быть корректным для типа. Принимают его не все типы (см. каждый тип).

Имена атрибутов начинаются с буквы, дальше идут буквы, цифры и _, не больше 50 символов. В типах содержимого зарезервированы id, documentId, locale, publicationState, publishedAt, createdAt, updatedAt, createdBy и updatedBy; в компонентах — id. Два имени, соответствующие одной колонке (metaTitle и meta_title), — ошибка.

Где хранятся значения

Заголовок раздела «Где хранятся значения»

Каждый атрибут типа содержимого — это колонка таблицы типа (collectionName или имя во множественном числе) с именем в snake_case. Связи и медиа хранятся в таблицах связей. Черновик и его опубликованная версия — это две строки, по одной на локаль в локализованных типах.

Типы колонок по базам данных:

Колонка PostgreSQL MySQL и MariaDB SQLite
varchar varchar(255) varchar(255) text
text text longtext text
integer integer int integer
bigint bigint bigint integer
double double precision double real
decimal numeric(p,s) decimal(p,s) text (точно)
boolean boolean tinyint(1) integer
date date date text
time time(3) time(3) text
datetime timestamptz(3) datetime(3) text
json jsonb json text

У типа содержимого не больше 60 атрибутов string, email, uid и enumeration (ограничение MySQL на размер строки); для остальных используйте text.

unique

Заголовок раздела «unique»

Типы, принимающие unique: true, получают уникальный индекс по (column, locale, publication_state): две опубликованные записи или два черновика в одной локали не могут иметь одинаковое значение, а черновик и его собственная опубликованная версия — могут. Запись, которая нарушает это правило, завершается ошибкой валидации для атрибута. Внутри компонентов unique принимается, но не обеспечивается (значения компонентов хранятся в JSON).

Текст

Заголовок раздела «Текст»

string

Заголовок раздела «string»

Одна строка текста.

Параметр Описание
minLength, maxLength Границы длины в символах. maxLength не больше 255.
regex Шаблон, которому должно соответствовать значение. Синтаксис как в JavaScript, включая lookaround и обратные ссылки.
unique См. unique.
default Строка в пределах границ, соответствующая regex.

Хранится как varchar(255). API: строка.

text

Заголовок раздела «text»

Более длинный простой текст (textarea в админке).

Параметр Описание
minLength, maxLength Границы длины, без верхнего предела.
default Строка в пределах границ.

Хранится как text (longtext в MySQL). API: строка.

richtext

Заголовок раздела «richtext»

Текст в Markdown. Те же параметры, хранение и API, что у text; админка редактирует его в редакторе Markdown.

blocks

Заголовок раздела «blocks»

Rich text в формате JSON-блоков Strapi: список блоков paragraph, heading (level от 1 до 6), list (format ordered или unordered, с дочерними list-item, вложенность до 8 уровней), quote, code (необязательный language) и image. Строчные дочерние элементы — узлы text с отметками bold, italic, underline, strikethrough и code и узлы link. Не больше 10 000 блоков.

Параметров нет, default нет. Хранится как JSON. API: список блоков в записанном виде.

email

Заголовок раздела «email»

Адрес email (name@domain.tld, без пробелов).

Параметр Описание
minLength, maxLength Границы длины; maxLength не больше 255.
unique См. unique.
default Адрес email.

Хранится как varchar(255). API: строка.

password

Заголовок раздела «password»

Секрет, который при записи хешируется Argon2id.

Параметр Описание
minLength, maxLength Границы длины пароля в том виде, в каком он отправлен.

default нет. Всегда private: никогда не возвращается, не фильтруется и не сортируется. Внутри компонентов не допускается. Хранится как varchar(255) (хеш). Импорт сохраняет существующие хеши bcrypt и Argon2 как есть, поэтому импортированные учётные записи могут входить.

uid

Заголовок раздела «uid»

Идентификатор для URL, например slug. Админка генерирует его по targetField.

Параметр Описание
targetField Атрибут string или text того же типа, из которого генерируется значение.
minLength, maxLength Границы длины; maxLength не больше 255.
regex Шаблон, которому должны соответствовать значения; без него — ^[A-Za-z0-9\-_.~]*$.
default Корректное значение.

Всегда уникален (см. unique). Хранится как varchar(255). API: строка.

enumeration

Заголовок раздела «enumeration»

Одно значение из фиксированного списка.

Параметр Описание
enum Значения: хотя бы одно, каждое от 1 до 255 символов, без повторов.
default Одно из значений.

Хранится как varchar(255). API: строка. Запись любого другого значения завершается ошибкой.

Числа

Заголовок раздела «Числа»

integer

Заголовок раздела «integer»

32-битное целое число (от −2 147 483 648 до 2 147 483 647).

Параметр Описание
min, max Границы (целые числа).
unique См. unique.
default Целое число в пределах границ.

Хранится как integer. API: число. При записи принимаются числа и строки с целыми числами.

biginteger

Заголовок раздела «biginteger»

64-битное целое число. Те же параметры, что у integer.

Хранится как bigint. API: строка ("9007199254740993"), как в Strapi, потому что числа JavaScript теряют точность после 2⁵³. При записи принимаются строки и числа.

float

Заголовок раздела «float»

Число с плавающей точкой двойной точности. Те же параметры, что у integer, с числовыми границами.

Хранится как double precision (double, real). API: число.

decimal

Заголовок раздела «decimal»

Точное десятичное число.

Параметр По умолчанию Описание
precision 10 Общее число цифр, от 1 до 38.
scale 2 Цифр после запятой, не больше precision.
min, max Границы.
unique См. unique.
default Число в пределах границ.

Значения округляются до scale цифр (половина — от нуля, как в базах данных) и отклоняются, если до запятой больше precision - scale цифр. При записи принимаются числа и числовые строки. Хранится как numeric(precision,scale) (text в SQLite, поэтому ничего не округляется). API: число, как его возвращает Strapi. Целые значения отдаются целыми (25, а не 25.0), остальные — кратчайшим float, который читается обратно без потерь (12.5). С [api].decimal_as_string API вместо этого возвращает точную строку.

Даты и логические значения

Заголовок раздела «Даты и логические значения»

boolean

Заголовок раздела «boolean»

true или false. Принимает default. Хранится как boolean (tinyint(1), integer). API: логическое значение.

date

Заголовок раздела «date»

Календарная дата, YYYY-MM-DD. Принимает unique и default. Хранится как date. API: "2026-09-29".

time

Заголовок раздела «time»

Время суток: HH:MM, HH:MM:SS или HH:MM:SS.mmm. Принимает unique и default. Хранится с точностью до миллисекунд. API: "14:30:00.000".

datetime

Заголовок раздела «datetime»

Момент времени: временная метка ISO 8601 с часовым поясом (Z или +02:00). Принимает unique и default. Хранится в UTC с точностью до миллисекунд. API: "2026-09-29T12:30:00.000Z".

json

Заголовок раздела «json»

Любое значение JSON. Принимает default (любой JSON). Хранится как jsonb (json, text). API: значение в записанном виде. В filters атрибуты JSON поддерживают только $null и $notNull, и по ним нельзя сортировать.

Медиа

Заголовок раздела «Медиа»

media

Заголовок раздела «media»

Файлы из медиатеки.

Параметр По умолчанию Описание
multiple false Хранить список файлов вместо одного.
allowedTypes любые Виды файлов: images, videos, audios, files (всё остальное).

default нет. Хранится в таблице связей {table}_{attribute}_mda с сохранением порядка. При записи принимаются id файлов: 12, { "id": 12 }, их список или null. API: только с populate; объект файла (url, mime, width, formats…, как в Strapi), их список или null. См. Медиа.

Связи

Заголовок раздела «Связи»

relation

Заголовок раздела «relation»

Ссылки на документы другого типа содержимого.

Параметр Описание
relation oneToOne, oneToMany, manyToOne, manyToMany, oneWay, manyWay или полиморфный вид (ниже).
target Целевой тип содержимого: article, api::article или api::article.article.
inversedBy На владеющей стороне двусторонней связи: атрибут цели, который её отражает.
mappedBy На другой стороне: владеющий атрибут цели.

Две стороны двусторонней связи должны быть согласованы: oneToMany отражает manyToOne, oneToOne и manyToMany отражают сами себя, а сторона с mappedBy указывает атрибут, чей inversedBy ссылается обратно. У oneWay и manyWay другой стороны нет.

Ссылки хранятся в {table}_{attribute}_lnk на владеющей стороне (стороне без mappedBy), указывают на documentId цели и сохраняют порядок. При записи принимаются значения documentId:

Запись Значение
"d8f3…", { "documentId": "d8f3…" }, их список Заменить ссылки.
null или [] Удалить все ссылки.
{ "set": [...] } Заменить ссылки.
{ "connect": [...], "disconnect": [...] } Добавить и удалить ссылки. Элемент connect может содержать position: { "before": id }, { "after": id }, { "start": true } или { "end": true }.

API: только с populate, в виде связанных документов (не больше 1000 на запись и связь), или { "count": n } с populate[tags][count]=true. См. Связи.

Внутри компонентов допускаются только oneWay и manyWay; компонент хранит значения documentId.

Полиморфные связи

Заголовок раздела «Полиморфные связи»

relation принимает также полиморфные виды, которые связывают документы любого типа содержимого:

relation Параметры Описание
morphToOne нет Ссылается на один документ любого типа.
morphToMany нет Ссылается на документы любых типов.
morphOne target, morphBy Обратная сторона: читает ссылки атрибута morphBy типа morphToOne или morphToMany в target.
morphMany target, morphBy То же для нескольких.

Владельцы хранят пары (type, documentId) в {table}_{attribute}_mph. При записи принимаются элементы { "__type": "api::article", "documentId": "…" } (один, список, null или { "set": [...] }). Подгруженные элементы содержат свой тип в __type. Внутри компонентов не допускаются.

Компоненты и динамические зоны

Заголовок раздела «Компоненты и динамические зоны»

component

Заголовок раздела «component»

Группа полей, определённая в schema/components/<category>/<name>.json.

Параметр По умолчанию Описание
component обязательный UID компонента, category.name (shared.seo).
repeatable false Хранить список элементов вместо одного.
min, max Число элементов; только с repeatable.

default нет: новые элементы получают значения по умолчанию собственных атрибутов. Хранится как JSON в строке записи, у каждого элемента есть id. При записи принимается объект элемента (или список) с id, чтобы сохранить существующий элемент. API: только с populate, элемент или список целиком. В filters можно фильтровать по полям компонента (filters[seo][metaTitle][$eq]=…). См. Компоненты и динамические зоны.

dynamiczone

Заголовок раздела «dynamiczone»

Список элементов, каждый из которых — один из нескольких компонентов.

Параметр Описание
components Разрешённые UID компонентов: хотя бы один, без повторов.
min, max Число элементов.

Каждый элемент содержит __component со своим UID. Хранится как JSON в строке записи. API: только с populate, список целиком. Фильтрация по компоненту — filters[blocks][__component][$eq]=blocks.hero. Динамические зоны нельзя вкладывать в компоненты.

Проверки между полями

Заголовок раздела «Проверки между полями»

Помимо параметров отдельных атрибутов, тип содержимого может объявить в validations правила по нескольким полям, которые проверяются тогда же, когда required:

rule — выражение JSON Logic по записи, которое должно выполняться. Оно может использовать var, ==, !=, ===, !==, <, >, <=, >=, !, !!, and, or, in, if, ?:, +, -, *, /, %, min, max и cat. message сообщается у field (атрибута типа) или у записи. Это дополнение Verdin; в Strapi аналога нет.

Отличия от Strapi

Заголовок раздела «Отличия от Strapi»
  • Компоненты хранятся в JSON в строке записи, а не в таблицах компонентов с таблицами соединения. Чтение не требует JOIN; как следствие, атрибуты password, полиморфные связи и двусторонние связи не могут находиться внутри компонентов, а unique там не обеспечивается.
  • Подгруженные компоненты возвращаются целиком. populate для компонента или динамической зоны возвращает все его поля; выбрать вложенные поля, как в Strapi, нельзя.
  • Строгие файлы схемы. Неизвестные ключи и параметры, которые тип не принимает, — ошибки, тогда как Strapi их игнорирует. В pluginOptions читается только i18n.localized; остальное игнорируется.
  • string, email и uid ограничены 255 символами — размером колонки, — а не падают на уровне базы данных.
  • conditions (условные поля) работают как в Strapi 5.17: скрытые поля не обязательны.
  • validations — собственная функция Verdin.
  • Остальное совпадает со Strapi v5: имена типов, их параметры, значения biginteger в виде строк, запись связей через connect, disconnect, set и position и формат блоков.

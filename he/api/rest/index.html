REST API

כל סוג תוכן מקבל נתיבי REST תחת הקידומת של API התוכן, /api כברירת מחדל ([api].prefix). הנתיבים, הפרמטרים ומבנה התגובות עוקבים אחרי Strapi v5, כך שרוב הפרונטאנדים שנכתבו עבור Strapi עובדים בלי שינוי. העמוד הזה הוא התיעוד המלא; הדוגמאות משתמשות ב-דוגמת הבלוג (מאמרים, קטגוריות, תגיות ודף בית).

השרת גם מתאר את הנתיבים של הסכמה שלכם במסמך OpenAPI 3.1 בכתובת GET /api/_openapi.json. העמודים של API התוכן לדוגמה מציגים את המסמך של הבלוג, וסביבת הניסוי ל-API מאפשרת לנסות בקשות.

דוגמה

Section titled “דוגמה”

אותה שאילתה בכל API: עשרת המאמרים האחרונים של קטגוריה, עם שם הקטגוריה שלהם.

  • REST
  • GraphQL
  • TypeScript

ראו GraphQL API ולקוח עם טיפוסים.

אימות

Section titled “אימות”
כותרת Authorization מבקש הרשאות
אין ציבורי הגדרות ← גישה ציבורית
Bearer vd_… אסימון API הסוג וההרשאות של האסימון
Bearer <JWT> משתמש קצה תפקיד משתמש הקצה שלו

אסימון לא מוכר, שפג תוקפו או פגום מחזיר 401; הוא אף פעם לא נופל חזרה לגישה ציבורית. מבקש תקין בלי ההרשאה מקבל 403. ראו הרשאות.

דפדפנים ממקורות אחרים יכולים לקרוא ל-API רק כש-[api].cors_origins מפרט אותם.

נתיבים

Section titled “נתיבים”

סוגי אוסף מוגשים לפי ה-pluralName שלהם:

שיטה ונתיב פעולה תשובה
GET /api/articles find 200, עמוד של מסמכים
GET /api/articles/{documentId} findOne 200, מסמך אחד
POST /api/articles create 201, המסמך שנוצר
PUT /api/articles/{documentId} update 200, המסמך המעודכן
DELETE /api/articles/{documentId} delete 204, בלי גוף

סוגים יחידים מוגשים לפי ה-singularName שלהם:

שיטה ונתיב פעולה תשובה
GET /api/homepage find 200, או 404 לפני הכתיבה הראשונה
PUT /api/homepage update 200; ה-PUT הראשון יוצר את המסמך
DELETE /api/homepage delete 204

POST על סוג יחיד עונה 405.

פעולות

Section titled “פעולות”

לסוגים עם טיוטה ופרסום יש עוד שלושה נתיבים, שדורשים את ההרשאה publish. ל-Strapi אין מקבילה ב-REST.

שיטה ונתיב השפעה תשובה
POST /api/articles/{documentId}/actions/publish מפרסם את הטיוטה. הגרסה המפורסמת
POST /api/articles/{documentId}/actions/unpublish מוחק את הגרסה המפורסמת. הטיוטה
POST /api/articles/{documentId}/actions/discard-draft מחליף את הטיוטה בגרסה המפורסמת. הטיוטה

שלושתם מקבלים ?locale= בסוגים מתורגמים.

כתיבה

Section titled “כתיבה”

POST ו-PUT מקבלים גוף JSON עם אובייקט data:

  • PUT הוא עדכון חלקי: מאפיינים שלא שולחים שומרים על הערך שלהם. רכיבים ואזורים דינמיים שנשלחים מחליפים את הערך השמור.
  • בסוגים עם טיוטה ופרסום, POST ו-PUT כותבים את הטיוטה ומפרסמים אותה, כמו ב-Strapi v5. הוסיפו ?status=draft כדי לכתוב רק את הטיוטה. אם הפרסום נכשל באימות, שום דבר לא נכתב.
  • מפתחות לא מוכרים, שדות מערכת (id, documentId, חותמות זמן) והצדדים ההפוכים (mappedBy) של קשרים הם שגיאות אימות.
  • קשרים מקבלים ערכי documentId, רשימות, null, או { connect, disconnect, set }; ראו קשרים. שדות מדיה מקבלים מזהי קבצים.
  • התגובה היא הגרסה שנכתבה, כפי שהיא נקראת עם ה-fields וה-populate של הבקשה.
  • DELETE מסיר את כל הגרסאות של המסמך (בסוגים מתורגמים, את הגרסה בשפה המבוקשת).

פרמטרי שאילתה

Section titled “פרמטרי שאילתה”
פרמטר דוגמה ברירת מחדל
filters filters[title][$containsi]=rust אין
sort sort=publishedAt:desc לפי id, בסדר עולה
pagination pagination[page]=2&pagination[pageSize]=10 עמוד 1, 25 לעמוד
fields fields[0]=title&fields[1]=slug כל שדה סקלרי
populate populate[category][fields][0]=name כלום
status status=draft published
hasPublishedVersion hasPublishedVersion=false אין
locale locale=fr שפת ברירת המחדל
_q _q=ownership אין

הפרמטרים משתמשים בכתיב הסוגריים של Strapi. אפשר לכתוב רשימות עם אינדקסים (sort[0]=a&sort[1]=b), עם סוגריים ריקים (sort[]=a) או בחזרה על המפתח (sort=a&sort=b). קודדו סוגריים וערכים כרגיל ב-URL; לקוחות כמו qs או הלקוח עם הטיפוסים בונים את המחרוזות האלה בשבילכם.

פרמטר לא מוכר, שדה לא מוכר או private, או ערך פגום הם 400 ValidationError שמציין את הבעיה. שום דבר לא מתעלמים ממנו בשקט.

מסננים

Section titled “מסננים”

filters[field][operator]=value. ערך בלבד פירושו $eq: filters[slug]=hello-verdin.

כמה תנאים באותה רמה חייבים כולם להתקיים. צרפו אותם עם אופרטורים לוגיים:

אופרטור מתאים ל טיפוסים
$eq, $ne שווה, לא שווה כל הסקלריים
$eqi, $nei שווה, לא שווה, בלי תלות ברישיות טקסט
$lt, $lte, $gt, $gte קטן מ, קטן או שווה, גדול מ, גדול או שווה כל הסקלריים חוץ מבוליאניים
$between בין שני ערכים, כולל: [$between][0]=1&[$between][1]=5 כל הסקלריים חוץ מבוליאניים
$in, $notIn ברשימה, לא ברשימה: [$in][0]=a&[$in][1]=b כל הסקלריים
$contains, $notContains מכיל, לא מכיל טקסט
$containsi, $notContainsi כנ“ל, בלי תלות ברישיות טקסט
$startsWith, $startsWithi מתחיל ב (בלי תלות ברישיות) טקסט
$endsWith, $endsWithi מסתיים ב (בלי תלות ברישיות) טקסט
$null, $notNull ריק, מוגדר: [$null]=true כל השדות
$and, $or כל התנאים, חלק מהתנאים ברשימה לוגי
$not שולל אובייקט מסנן לוגי
  • טיפוסי הטקסט הם string, text, richtext, email, uid ו-enumeration. json ו-blocks מקבלים רק $null ו-$notNull.
  • הערכים מומרים לטיפוס של השדה: מספרים שלמים, מספרים, true/false (או 1/0), תאריכים כ-YYYY-MM-DD, שעות כ-HH:MM:SS, ותאריך-שעה כ-ISO 8601.
  • אפשר לסנן לפי id, documentId, createdAt, updatedAt, publishedAt ובסוגים מתורגמים גם לפי locale.
  • השוואות טקסט מתנהגות אותו דבר בכל מסד נתונים: $eq, $contains ושאר האופרטורים בלי i מדויקים, וגרסאות ה-…i מתעלמות מרישיות (ומסימני הטעמה ב-MySQL וב-MariaDB; SQLite מקפל רק אותיות ASCII).
  • בבקשה יש לכל היותר 100 תנאים.

סינון דרך קשרים

Section titled “סינון דרך קשרים”

סננו לפי השדות של מסמכים קשורים, בכל צד של הקשר ובקינון:

תנאי to-many מתקיים כשמסמך קשור כלשהו מתאים. מסמכים קשורים נבדקים בגרסה ובשפה שנקראות. אי אפשר לסנן קשרים פולימורפיים ושדות מדיה.

סינון לפי רכיבים ואזורים דינמיים

Section titled “סינון לפי רכיבים ואזורים דינמיים”

אפשר לסנן שדות סקלריים של רכיבים, כולל רכיבים מקוננים; רכיב חוזר מתאים כשפריט כלשהו מתאים. אזורים דינמיים מסוננים רק לפי __component. ראו רכיבים ואזורים דינמיים.

מיון

Section titled “מיון”
  • field או field:asc|desc; הכיוון ברירת המחדל הוא asc.
  • אפשר למיין לפי כל שדה סקלרי חוץ מ-json ו-blocks, כולל שדות מערכת.
  • relation.field ממיין לפי שדה של קשר to-one.
  • ערכים ריקים באים אחרונים בשני הכיוונים, ושוויון מוכרע לפי id, כך שהעמודים יציבים.

שדות

Section titled “שדות”

fields בוחר מאפיינים סקלריים:

id ו-documentId מוחזרים תמיד. קשרים, מדיה, רכיבים ואזורים דינמיים אף פעם לא נבחרים דרך fields: השתמשו ב-populate.

Populate

Section titled “Populate”

קשרים, מדיה, רכיבים ואזורים דינמיים מוחזרים רק כשהם עוברים populate:

צורה ממלא
populate=* כל קשר, שדה מדיה, רכיב ואזור דינמי, ברמה אחת, ו-localizations בסוגים מתורגמים
populate=category,tags או populate[0]=category&populate[1]=tags השדות שצוינו
populate[category]=true השדה שצוין (false משמיט אותו)
populate[category][fields][0]=name השדה, עם אפשרויות

כל קשר שעובר populate מקבל fields, filters, sort, populate (מקונן, עד 5 רמות בסך הכול) ו-count:

  • קשר to-one הוא אובייקט או null; קשר to-many הוא מערך, בסדר הקישור או בסדר ה-sort של ה-populate.
  • count=true מחזיר { "count": 12 } במקום המסמכים (רק בקשרי to-many).
  • מוחזרים לכל היותר 1,000 מסמכים קשורים לכל מסמך וקשר; count מדויק.
  • רכיבים ואזורים דינמיים חוזרים בשלמותם, כולל רכיבים מקוננים והקשרים והמדיה שלהם. האפשרויות של Strapi לכל רמה עבורם (populate[blocks][on][…]) מתקבלות ומתעלמים מהן.
  • שדות מדיה חוזרים כאובייקטי קבצים.
  • קשרים פולימורפיים מקבלים רק count.
  • מסמכים קשורים נקראים באותו סטטוס ובאותה שפה כמו המסמך. populate של סוג שהמבקש לא יכול לקרוא הוא 400; populate=* מדלג עליו.

כל רמה היא שאילתה מקובצת אחת לכל קשר, כך ש-populate עמוק נשאר מהיר ואף פעם לא מחזיר שורות כפולות.

סטטוס

Section titled “סטטוס”

בסוגים עם טיוטה ופרסום, status בוחר את הגרסה:

  • status=published (ברירת המחדל) קורא גרסאות מפורסמות.
  • status=draft קורא טיוטות, ודורש את ההרשאה readDrafts בנוסף ל-find או ל-findOne.

hasPublishedVersion=true|false שומר מסמכים שיש להם, או שאין להם, גרסה מפורסמת: ?status=draft&hasPublishedVersion=false מפרט מסמכים שמעולם לא פורסמו. בסוגים בלי טיוטה ופרסום זה 400.

בכתיבות, status=draft שומר את הטיוטה בלי לפרסם אותה. ראו טיוטה ופרסום.

שפה

Section titled “שפה”

locale=fr קורא וכותב את הגרסה הצרפתית של סוגים מתורגמים. בלעדיו, הבקשות משתמשות בשפת ברירת המחדל. קוד לא תקין או לא מוכר הוא 400. סוגים שאינם מתורגמים מתעלמים ממנו. ראו בינאום.

בסוגים מתורגמים, populate=localizations מוסיף את גרסאות השפה האחרות של המסמך, באותו סטטוס, כל אחת עם ה-locale שלה. הוא מקבל את האפשרויות של קשר ממולא (fields, filters, sort, populate, count), וכלול ב-populate=*. לסוגים שאינם מתורגמים אין localizations.

GET /api/i18n/locales מפרט את השפות כמערך פשוט במבנה של Strapi (id, documentId, name, code, isDefault, createdAt, updatedAt, publishedAt, locale). הוא דורש את ההענקה find על plugin::i18n.locale. ראו לוקליזציה של תוכן.

חיפוש

Section titled “חיפוש”

_q מוצא מסמכים ששדות הטקסט שלהם מכילים את המילים, בלי תלות ברישיות (עד 200 תווים):

בלי אינדקס חיפוש זה מתאים, כמו ב-Strapi, לכל שדה string, text, richtext, email, uid או enumeration שאינו פרטי. עם [search] enabled = true, התוצאות מדורגות לפי רלוונטיות אלא אם מעבירים sort. שאר המסננים והעימוד עדיין חלים. ראו חיפוש.

תגובות

Section titled “תגובות”

רשימה:

מסמך אחד: { "data": { … }, "meta": {} }.

  • המסמכים שטוחים, כמו ב-Strapi v5: בלי עטיפת attributes.
  • המאפיינים מופיעים בסדר הסכמה, בין id/documentId לבין חותמות הזמן; סוגים מתורגמים מוסיפים locale. שדות private אף פעם לא מופיעים.
  • ערכי biginteger הם מחרוזות. ערכי decimal הם מספרים, מעוגלים לפי ה-scale שלהם (מחרוזות עם [api].decimal_as_string = true). תאריכים הם YYYY-MM-DD, שעות HH:MM:SS.mmm, ותאריך-שעה YYYY-MM-DDTHH:MM:SS.mmmZ ב-UTC.

קריאות מוצלחות נושאות ETag; שלחו אותו בחזרה ב-If-None-Match כדי לקבל 304 Not Modified. הן נושאות גם כותרות Cache-Tag ו-Surrogate-Key לניקוי CDN (ראו פריסות ו-CDN).

שגיאות

Section titled “שגיאות”

לשגיאות יש המבנה של Strapi:

סטטוס name מתי
400 ValidationError פרמטרים, גוף או תוכן לא תקינים. details.errors מפרט את בעיות התוכן עם הנתיב שלהן.
401 UnauthorizedError אסימון פגום, לא מוכר או שפג תוקפו.
403 ForbiddenError למבקש אין ההרשאה (לטיוטות, readDrafts).
404 NotFoundError נתיב, סוג תוכן או מסמך לא מוכרים.
405 MethodNotAllowedError POST על סוג יחיד, או PUT או DELETE על הנתיב של סוג אוסף.
408 הבקשה נמשכה יותר מ-[server].request_timeout_secs (30 שניות).
413 הגוף גדול מ-[server].body_limit (1 MB).
429 RateLimitError מעבר ל-[api].public_rate_limit או ל-[api].token_rate_limit. Retry-After אומר מתי לנסות שוב.
500 ApplicationError שגיאה לא צפויה; הפרטים נמצאים רק ביומן השרת.

ספריית המדיה

Section titled “ספריית המדיה”

נתיבי ההעלאה של Strapi, שנבדקים מול ההרשאות של ספריית המדיה. הם עונים באובייקטים ובמערכים פשוטים, בלי data, כמו Strapi:

נתיב הרשאה גוף או פרמטרים
POST /api/upload create Multipart: files (עד 20), fileInfo JSON אופציונלי (name, alternativeText, caption, folder, focalPoint), אחד לכל קובץ או אחד לכולם
POST /api/upload?id={id} update Multipart fileInfo, ואופציונלית קובץ חדש שמחליף את התוכן
GET /api/upload/files find pagination[page], pagination[pageSize], sort, filters[name][$containsi]
GET /api/upload/files/{id} findOne
DELETE /api/upload/files/{id} delete

ראו מדיה.

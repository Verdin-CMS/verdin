安装

Verdin 是一个内置管理后台的二进制文件。每次发布都会为 Linux（x86-64 和 ARM64，静态 musl 构建）、macOS（Intel 和 Apple 芯片）以及 Windows（x86-64）发布它，并附带 SHA256SUMS 文件，见发布页面。选择适合你机器的安装方式即可；它们安装的都是同一个二进制文件。

然后从 verdin new 开始，按快速开始继续。

安装脚本（Linux 和 macOS）

Section titled “安装脚本（Linux 和 macOS）”

脚本会检测系统和架构，从最新的 GitHub 发布下载匹配的压缩包，用该发布的 SHA256SUMS 校验它，然后把 verdin 安装到 /usr/local/bin（以 root 身份运行时），否则安装到 ~/.local/bin。它需要 curl 或 wget、tar，以及 sha256sum、shasum 或 openssl。

选项 变量 默认值
--version <X.Y.Z> VERDIN_VERSION 最新发布
--dir <directory> VERDIN_INSTALL_DIR /usr/local/bin（root）或 ~/.local/bin

如果想在运行之前先阅读脚本，请先下载它：curl -fsSLO https://raw.githubusercontent.com/verdin-cms/verdin/main/install.sh。

包管理器

Section titled “包管理器”
  • Homebrew
  • Debian / Ubuntu
  • winget
  • cargo binstall

在 macOS 和 Linux 上：

该 formula 安装发布的二进制文件（Linux 上为 musl 构建）。brew upgrade verdin 会升级到下一个发布。

从发布页面下载适合你架构（amd64 或 arm64）的 .deb 并安装：

该软件包会添加一个 verdin 系统用户、一个 systemd 服务（未启用），以及位于 /etc/verdin/ 的配置。Linux 服务器逐步介绍如何运行它。目前还没有 apt 仓库：升级时请安装下一个发布的 .deb。

在 Windows 上：

winget 会把 verdin 添加到新终端的 PATH 中。没有 winget 时，请从发布页面下载 .zip，并把 verdin.exe 放到 PATH 中的某个位置。

مرجع التهيئة

التهيئة طبقات: القيم الافتراضية المدمجة ← verdin.toml ← البيئة. الملف اختياري؛ ولكل مفتاح قيمة افتراضية. تُرفض المفاتيح غير المعروفة، فيفشل الخطأ الإملائي عند البدء بدلًا من تجاهله.

  • تجاوز أي مفتاح بـ VERDIN_<SECTION>__<KEY> (شرطتان سفليتان)، مثلًا VERDIN_SERVER__PORT=8080 أو VERDIN_ADMIN__SECURE_COOKIES=false. تأخذ الجداول المتداخلة __ إضافية: VERDIN_ADMIN__BRANDING__TITLE=ACME. تُرفض المفاتيح غير المعروفة هنا أيضًا، لذا يجب أن يسمّي أي متغير يبدأ بـ VERDIN_ ويحتوي على __ مفتاحًا حقيقيًا.
  • VERDIN_DATABASE_URL اختصار لـ database.url.
  • الملف هو verdin.toml في مجلد العمل، أو المسار المعطى بـ -c, --config أو VERDIN_CONFIG. تُحَلّ المسارات النسبية فيه (المخطط، والإضافات، والملفات المرفوعة، وملفات SQLite) نسبةً إلى مجلد الملف.
  • يُحمَّل ملف .env المجاور للتهيئة أولًا؛ والمتغيرات المعيّنة بالفعل في البيئة لها الأولوية.

لا تُقرأ الأسرار أبدًا من verdin.toml؛ راجع متغيرات البيئة.

[server]

Section titled “[server]”
المفتاح الافتراضي الوصف
host "0.0.0.0" العنوان الذي يُستمع عليه.
port 1337 المنفذ الذي يُستمع عليه.
public_url غير معيَّن حيث تصل المتصفحات إلى الخادم، مثل "https://cms.example.com". يُستخدم للروابط في رسائل البريد واستدعاءات SSO؛ وافتراضيًا http://localhost:{port}.
body_limit "1mb" أكبر جسم طلب لطلبات الـ API العادية (لعمليات الرفع حدها الخاص). عدد من البايتات أو سلسلة مع b أو kb أو mb أو gb.
request_timeout_secs 30 الحد الزمني لطلبات الـ API العادية.
sync_interval_secs 10 عدد مرات التقاط الإعدادات التي غيّرتها نسخ أخرى (الميزات، ومفاتيح الإضافات، واللغات، ومسارات المراجعة)؛ و0 يوقفها (نسخة واحدة).
trusted_proxies [] الوكلاء العكسيون (عناوين IP أو نطاقات CIDR، مثل ["10.0.0.0/8"]) الذين يسمّي X-Forwarded-For الخاص بهم العميل. تستخدم حدود المعدل وسجلات التدقيق ذلك العنوان؛ وبدونه، يتشارك كل العملاء خلف الوكيل عنوانًا واحدًا.

[database]

Section titled “[database]”
المفتاح الافتراضي الوصف
url غير معيَّن عنوان URL للاتصال: postgres://… أو mysql://… (MySQL وMariaDB) أو sqlite://…. مطلوب؛ ويُعيَّن عادةً عبر VERDIN_DATABASE_URL.
pool_max 10 الحد الأقصى للاتصالات في المجمّع.

[schema]

Section titled “[schema]”
المفتاح الافتراضي الوصف
path "schema" مجلد المخطط، نسبةً إلى ملف التهيئة.

[api]

Section titled “[api]”
المفتاح الافتراضي الوصف
prefix "/api" المسار الذي يُقدَّم تحته API المحتوى. يجب أن يبدأ بـ / وألا ينتهي بها.
default_page_size 25 حجم الصفحة عندما لا يعيّن الطلب حجمًا. بين 1 وmax_page_size.
max_page_size 100 أكبر حجم صفحة يمكن للطلب طلبه.
decimal_as_string false تسلسل الأرقام العشرية كسلاسل نصية (دقيقة) بدلًا من أرقام (متوافقة مع Strapi).
public_rate_limit 0 الطلبات في الدقيقة لكل عنوان IP للعميل بدون رمز (0: بلا حد).
token_rate_limit 0 الطلبات في الدقيقة لكل رمز API أو مستخدم نهائي (0: بلا حد).
cache_ttl_secs 0 الاحتفاظ بالقراءات المجهولة في الذاكرة هذه المدة (0: بلا تخزين مؤقت)؛ والتغييرات تفرّغ الذاكرة المؤقتة.
cache_entries 1000 الحد الأقصى لعدد الاستجابات المخزّنة مؤقتًا.
cors_origins [] مصادر المتصفح المسموح لها باستدعاء API المحتوى وGraphQL من موقع آخر (["https://www.example.com"]: المخطط والمضيف والمنفذ، بلا مسار)، أو ["*"] لأي مصدر (بمفرده: لا يمكن جمع * مع مصادر). فارغ: لا تستطيع استدعاءهما من متصفح إلا الصفحات من المصدر نفسه. لا يقبل API الإدارة أبدًا الاستدعاءات عبر المصادر.

[admin]

Section titled “[admin]”
المفتاح الافتراضي الوصف
path "/admin" المسار الذي تُقدَّم تحته لوحة الإدارة؛ ويعيش الـ API الخاص بها على {path}/api.
secure_cookies غير معيَّن تعليم ملف تعريف ارتباط التجديد بـ Secure. غير المعيَّن يعني نعم في verdin start ولا في verdin dev (التطوير المحلي عبر HTTP العادي).
auth_rate_limit 20 محاولات تسجيل الدخول والتسجيل والتجديد لكل عنوان IP للعميل في الدقيقة.
assets_dir غير معيَّن تقديم لوحة الإدارة من هذا المجلد (نسبةً إلى ملف التهيئة) بدلًا من النسخة المضمَّنة في الملف التنفيذي.

[admin.branding]

Section titled “[admin.branding]”
المفتاح الافتراضي الوصف
title "Verdin" يُعرض في الشريط الجانبي، وفي صفحة تسجيل الدخول، وفي تبويب المتصفح.
logo غير معيَّن ملف صورة (SVG، PNG، WebP)، نسبةً إلى ملف التهيئة.
favicon غير معيَّن ملف أيقونة (ICO، PNG، SVG)، نسبةً إلى ملف التهيئة.
accent غير معيَّن لون #rrggbb للأزرار والروابط وحلقات التركيز.
translations {} نصوص الإدارة المستبدلة لكل لغة، مثلًا [admin.branding.translations.en] مع "auth.login.title" = "Welcome to ACME". المفاتيح هي مفاتيح admin/public/i18n/en.json.

[upload]

Section titled “[upload]”
المفتاح الافتراضي الوصف
provider { name = "local", dir = "public/uploads" } مكان تخزين الملفات؛ راجع أدناه.
max_file_size 209715200 أكبر ملف مقبول، بالبايت (200 MB).
responsive_formats true توليد صيغ متجاوبة للصور النقطية.
breakpoints large 1000، medium 750، small 500 الصيغ المتجاوبة كجداول { name, width } (breakpoints في Strapi). تُتخطّى الصيغ الأعرض من الصورة.
max_image_megapixels 100 حد فك الترميز ضد قنابل فك الضغط، بالميغابكسل.
max_original_size غير معيَّن الأصول النقطية الأكبر من هذا العدد من البكسلات (في أي جانب) تُصغَّر عند الرفع، ما يحذف أيضًا بياناتها الوصفية (EXIF، GPS). غير المعيَّن يُبقي الأصول كما أُرسلت.

الموفّر المحلي

Section titled “الموفّر المحلي”

الملفات تحت dir (نسبةً إلى المشروع)، يقدّمها Verdin على /uploads.

[upload.transforms]

Section titled “[upload.transforms]”

تحويلات الصور للملفات المحلية: /uploads/<file>?preset=thumb، أو ?w=&h=&fit=&format=&q= مع توقيع. تُخزَّن الرسوم مؤقتًا على القرص وتُسقط عندما يتغير الملف (بما في ذلك نقطة تركيزه). تُبقي عمليات القص بـ cover نقطة تركيز الملف ظاهرة؛ ولا تُكبَّر الصور أبدًا. يمكن تحويل JPEG وPNG وWebP وTIFF وBMP (لا GIF، التي قد تكون متحركة).

المفتاح الافتراضي الوصف
enabled true تقديم التحويلات.
presets {} تحويلات مسمّاة، مسموح بها دائمًا: { w, h, fit, format, q }.
allow_arbitrary false قبول أي معاملات دون توقيع. يُرسم كل عنوان URL مختلف ويُخزَّن مؤقتًا، لذا للشبكات الموثوقة فقط.
max_size 4096 أكبر w أو h، بالبكسل.
cache_dir ".cache/transforms" مكان الاحتفاظ بالرسوم (نسبةً إلى المشروع؛ وحذفه آمن).

المعاملات: w وh (بالبكسل)، وfit (cover، الافتراضي، يقص إلى المربع؛ وinside يلائمه داخله؛ وfill يمطّه)، وformat (jpeg، png، webp؛ ومخرج WebP بلا فقد) وq (جودة JPEG، من 1 إلى 100، افتراضيًا 80).

عناوين URL الموقّعة. مع تعيين VERDIN_IMAGE_SECRET، يكون s هو HMAC-SHA256 بترميز hex لـ <file>?<canonical query>، حيث يسرد الاستعلام القانوني المعاملات غير الافتراضية مرتّبة حسب الاسم (fit، format، h، q، w؛ مع حذف fit=cover):

موفّر S3

Section titled “موفّر S3”

أي خدمة متوافقة مع S3 (AWS، Cloudflare R2، MinIO، Backblaze B2…). تأتي بيانات الاعتماد من متغيرات البيئة القياسية AWS_* (AWS_ACCESS_KEY_ID، AWS_SECRET_ACCESS_KEY).

المفتاح الافتراضي الوصف
bucket مطلوب اسم الحاوية.
region غير معيَّن منطقة الحاوية.
endpoint غير معيَّن نقطة نهاية مخصصة للخدمات غير AWS، مثل https://<account>.r2.cloudflarestorage.com.
public_url مطلوب عنوان URL الأساسي العام للحاوية أو الـ CDN الخاص بها؛ تُربط الملفات على شكل {public_url}/{key}.
prefix "" بادئة المفاتيح داخل الحاوية.
path_style false طلبات بنمط المسار (MinIO ومعظم الخدمات المستضافة ذاتيًا).

[webhooks]

Section titled “[webhooks]”
المفتاح الافتراضي الوصف
allow_private_networks غير معيَّن السماح بعناوين URL للـ webhooks على عناوين loopback والعناوين الخاصة وlink-local؛ وينطبق أيضًا على أهداف النشر وwebhook ‏[cdn]. غير المعيَّن يعني لا في verdin start (وإلا لاستطاع مسؤول الوصول إلى خدمات داخلية) ونعم في verdin dev.
timeout_secs 10 الحد الزمني لكل تسليم.
retention_days 30 عدد أيام الاحتفاظ بسجل التسليم.

راجع Webhooks.

[history]

Section titled “[history]”
المفتاح الافتراضي الوصف
max_versions 50 عدد النسخ المحتفظ بها لكل مستند (تُزال الأقدم).

[email]

Section titled “[email]”
المفتاح الافتراضي الوصف
provider "log" log (كتابة الرسائل في السجل)، أو smtp، أو resend أو postmark.
from "Verdin <no-reply@localhost>" المرسل.
reply_to غير معيَّن عنوان الرد.

[email.smtp]

Section titled “[email.smtp]”
المفتاح الافتراضي الوصف
host "localhost" خادم SMTP.
port 587 منفذ SMTP.
username غير معيَّن مستخدم SMTP؛ وتأتي كلمة المرور من VERDIN_EMAIL_SMTP_PASSWORD.
security "starttls" starttls، أو tls (ضمني، عادةً المنفذ 465) أو none (مرحّلات محلية).

[plugins]

Section titled “[plugins]”
المفتاح الافتراضي الوصف
path "plugins" مجلد الإضافات (مجلد فرعي لكل منها)، نسبةً إلى ملف التهيئة.
run_jobs true تشغيل المهام المجدولة للإضافات على هذه النسخة (نسخة واحدة عندما تكون هناك عدة نسخ).

راجع الإضافات.

[audit]

Section titled “[audit]”
المفتاح الافتراضي الوصف
retention_days 90 عدد أيام الاحتفاظ بإدخالات سجل التدقيق.

[digest]

Section titled “[digest]”
المفتاح الافتراضي الوصف
enabled true إرسال الملخص اليومي من هذه النسخة (نسخة واحدة عندما تكون هناك عدة نسخ).
hour_utc 8 الساعة (UTC، 0–23) التي يُرسل فيها الملخص اليومي للتغييرات غير المُطّلع عليها.

[log]

Section titled “[log]”
المفتاح الافتراضي الوصف
format "pretty" pretty أو json.
level غير معيَّن (info) المرشّح الافتراضي؛ ولـ RUST_LOG الأولوية عند تعيينه.

[metrics]

Section titled “[metrics]”
المفتاح الافتراضي الوصف
enabled false تقديم مقاييس Prometheus على /_metrics: طلبات HTTP حسب المجال (api، admin_api، graphql، mcp، uploads…)، والطريقة، وفئة الحالة مع مدرجات زمن الاستجابة، وعمليات تسليم الـ webhooks المعلّقة، وتدفقات الوقت الفعلي المفتوحة، وحركة ناقل الأحداث، ومدة التشغيل.
token غير معيَّن تحتاج عمليات الجمع إلى Authorization: Bearer <token>. ويتغلب VERDIN_METRICS_TOKEN عليه. بدون رمز، يستطيع أي شخص يصل إلى المنفذ قراءة المقاييس.

[telemetry]

Section titled “[telemetry]”

التتبعات وتقارير الأخطاء، وكلاهما معطّل افتراضيًا ولا يستخدمهما إلا verdin start و verdin dev (راجع المراقبة).

المفتاح الافتراضي الوصف
enabled false تصدير تتبعات OpenTelemetry لطلبات HTTP واستعلامات قاعدة البيانات الخاصة بها عبر OTLP/HTTP (protobuf). يعطّله OTEL_SDK_DISABLED=true.
endpoint غير معيَّن (http://localhost:4318) عنوان URL الأساسي للمجمّع؛ ويُلحق به /v1/traces. يتغلب عليه OTEL_EXPORTER_OTLP_ENDPOINT (العنوان الأساسي) وOTEL_EXPORTER_OTLP_TRACES_ENDPOINT (العنوان الكامل).
service_name "verdin" قيمة service.name للتتبعات. يتغلب عليه OTEL_SERVICE_NAME.
sample_ratio 1.0 نسبة التتبعات المحتفَظ بها، من 0.0 إلى 1.0. الطلب الذي يحمل ترويسة traceparent يتبع قرار المستدعي.
sentry_dsn غير معيَّن الإبلاغ عن حالات الـ panic واستجابات 5xx إلى Sentry. يتغلب عليه SENTRY_DSN.
sentry_environment غير معيَّن بيئة Sentry. يتغلب عليه SENTRY_ENVIRONMENT؛ وإن لم يُعيَّن فهي production في verdin start وdevelopment في verdin dev.

[ai]

Section titled “[ai]”

إجراءات الذكاء الاصطناعي في لوحة الإدارة (مع تفعيل ميزة إجراءات الذكاء الاصطناعي في الإعدادات ← الميزات): ترجمة إدخال إلى لغة أخرى، وكتابة نص بديل للصور، وتلخيص النص، واقتراح بيانات SEO الوصفية. وهي تعيد اقتراحات؛ ولا يُحفظ شيء دون المحرر. يُقرأ المفتاح من VERDIN_AI_KEY (لا تحتاج الخوادم المحلية إلى أي مفتاح).

المفتاح الافتراضي الوصف
provider "none" anthropic أو openai أو openai-compatible (Ollama، LM Studio، vLLM…).
model claude-sonnet-5 لـ anthropic النموذج؛ مطلوب للموفّرين الآخرين.
base_url الخاص بالموفّر نقطة نهاية أخرى، مثل http://localhost:11434/v1.
max_tokens 2048 أطول إجابة.

يستطيع كل مسؤول إجراء 30 طلبًا للذكاء الاصطناعي في الدقيقة. يُرسل المحتوى والصور إلى الموفّر: اختر موفّرًا تسمح به مؤسستك.

[cdn]

Section titled “[cdn]”

يفرّغ ذاكرات CDN المؤقتة عندما يتغير المحتوى علنًا. توسم استجابات API المحتوى بـ vd وvd-<singularName> (ترويستا Cache-Tag وSurrogate-Key).

المفتاح الافتراضي الوصف
provider "none" cloudflare أو fastly أو webhook.
zone_id غير معيَّن منطقة Cloudflare (التفريغ حسب الوسم).
service_id غير معيَّن خدمة Fastly (التفريغ حسب surrogate key).
url غير معيَّن webhook: يستقبل POST { "tags": [...] }.
debounce_ms 1000 التغييرات المجمّعة قبل التفريغ.

يُقرأ رمز الـ API من VERDIN_CDN_TOKEN (ويُرسل كرمز bearer إلى الـ webhooks).

[search]

Section titled “[search]”
المفتاح الافتراضي الوصف
enabled false ترتيب _q بفهرس نص كامل (Tantivy) بدلًا من $containsi.
dir "data/search" مجلد الفهرس، نسبةً إلى المشروع. حذفه يعيد بناء الفهرس عند البدء التالي.
memory_mb 50 ميزانية الذاكرة للفهرسة.

يعيش الفهرس على قرص النسخة. مع عدة نسخ، فعّل ناقل الأحداث لكي يتبع كل فهرس عمليات الكتابة في جميعها.

[cluster]

Section titled “[cluster]”

ناقل الأحداث المشترك، لعدة نسخ من مشروع واحد (راجع تشغيل عدة نسخ).

المفتاح الافتراضي الوصف
bus "none" none: تبقى أحداث الوقت الفعلي والحضور وإبطال ذاكرة التخزين المؤقت وتحديثات البحث في كل نسخة. database: تصل إلى كل نسخة عبر قاعدة بيانات المشروع (LISTEN/NOTIFY في PostgreSQL، والاستطلاع الدوري في MySQL وMariaDB وSQLite).
poll_interval_ms 1000 كم مرة تقرأ MySQL وMariaDB وSQLite أحداث النسخ الأخرى. تُوقَظ PostgreSQL بـ NOTIFY ولا تستخدم هذا الإيقاع إلا حين لا تستطيع الاستماع.
instance_id غير معيَّن (عشوائي عند كل بدء) اسم هذه النسخة على الناقل وفي السجلات.

عيّنه على كل نسخة، أو بـ VERDIN_CLUSTER__BUS=database.

متغيرات البيئة

Section titled “متغيرات البيئة”

إلى جانب تجاوزات VERDIN_<SECTION>__<KEY>، يقرأ Verdin هذه المتغيرات:

المتغير الوصف
VERDIN_CONFIG مسار ملف التهيئة (مثل --config).
VERDIN_DATABASE_URL اختصار لـ database.url.
VERDIN_ADMIN_JWT_SECRET يوقّع رموز جلسات الإدارة. مطلوب، 32 بايت على الأقل؛ ولّده بـ verdin secrets.
VERDIN_TOKEN_PEPPER تجزئة بمفتاح للرموز المخزّنة. مطلوب، 32 بايت على الأقل؛ ولّده بـ verdin secrets.
VERDIN_ADMIN_PASSWORD كلمة المرور لـ verdin admin create وverdin admin reset-password (وإلا تُقرأ من stdin)؛ راجع مرجع سطر الأوامر.
VERDIN_EMAIL_SMTP_PASSWORD كلمة مرور SMTP.
VERDIN_EMAIL_API_KEY مفتاح API لموفّري Resend وPostmark.
VERDIN_SSO_<ID>_SECRET سرّ العميل لموفّر SSO؛ و<ID> هو معرّف الموفّر بأحرف كبيرة مع - كـ _ (راجع تسجيل الدخول الموحّد).
VERDIN_OAUTH_<PROVIDER>_SECRET سرّ العميل لموفّر OAuth للمستخدمين النهائيين، مسمّى مثل متغيرات SSO (راجع المستخدمون النهائيون).
VERDIN_AI_KEY مفتاح API لموفّر [ai].
VERDIN_CDN_TOKEN رمز API لموفّر [cdn].
VERDIN_IMAGE_SECRET يوقّع عناوين URL لتحويلات الصور (راجع [upload.transforms]).
VERDIN_METRICS_TOKEN رمز bearer لعمليات جمع /_metrics عند [metrics].enabled؛ ويتغلب على [metrics].token.
OTEL_EXPORTER_OTLP_ENDPOINT، OTEL_EXPORTER_OTLP_TRACES_ENDPOINT المجمّع لتتبعات [telemetry]؛ يتغلبان على [telemetry].endpoint. وتنطبق أيضًا متغيرات OTEL_EXPORTER_OTLP_* القياسية الأخرى (الترويسات والمهلة والضغط).
OTEL_SERVICE_NAME، OTEL_RESOURCE_ATTRIBUTES مورد التتبعات المصدَّرة؛ ويتغلب OTEL_SERVICE_NAME على [telemetry].service_name.
OTEL_SDK_DISABLED القيمة true توقف تصدير التتبعات حتى عند [telemetry].enabled.
SENTRY_DSN، SENTRY_ENVIRONMENT الإبلاغ عن الأخطاء إلى Sentry؛ يتغلبان على [telemetry].sentry_dsn وsentry_environment.
AWS_ACCESS_KEY_ID، AWS_SECRET_ACCESS_KEY بيانات اعتماد موفّر الرفع S3.
RUST_LOG مرشّح السجلات؛ وله الأولوية على [log].level.
